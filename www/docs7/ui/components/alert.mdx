title: Alert
---

A component for displaying important messages.

In this guide, you'll learn how to use the Alert component.

[Open the live example](https://docs.medusajs.com/ui/components/alert).

```tsx
import { Alert } from "@medusajs/ui"

export default function AlertDemo() {
  return <Alert>You are viewing Medusa docs.</Alert>
}

```

***

## Usage

```tsx
import { Alert } from "@medusajs/ui"
```

```tsx
<Alert>Here's a message</Alert>
```

***

## API Reference

### Alert Props

This component is based on the div element and supports all of its props

<Accordion title="variant">
  **Optional.** Type: `"error" | "success" | "warning" | "info"`

  Default: `"info"`

  The variant of the alert
</Accordion>

<Accordion title="dismissible">
  **Optional.** Type: `boolean`

  Default: `false`

  Whether the alert is dismissible
</Accordion>

***

## Examples

### Success Alert

[Open the live example](https://docs.medusajs.com/ui/components/alert#success-alert).

```tsx
import { Alert } from "@medusajs/ui"

export default function AlertSuccess() {
  return <Alert variant="success">Data updated successfully!</Alert>
}

```

### Warning Alert

[Open the live example](https://docs.medusajs.com/ui/components/alert#warning-alert).

```tsx
import { Alert } from "@medusajs/ui"

export default function AlertWarning() {
  return <Alert variant="warning">Be careful!</Alert>
}

```

### Error Alert

[Open the live example](https://docs.medusajs.com/ui/components/alert#error-alert).

```tsx
import { Alert } from "@medusajs/ui"

export default function AlertError() {
  return <Alert variant="error">An error occured while updating data.</Alert>
}

```

### Dismissible Alert

[Open the live example](https://docs.medusajs.com/ui/components/alert#dismissible-alert).

```tsx
import { Alert } from "@medusajs/ui"

export default function AlertDismissable() {
  return <Alert dismissible={true}>You are viewing Medusa docs.</Alert>
}

```
