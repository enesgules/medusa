---
title: Tooltip
---

A component that displays a pop-up with additional information when hovering over or focusing on an element.

In this guide, you'll learn how to use the Tooltip component.

```tsx
import { InformationCircleSolid } from "@medusajs/icons"
import { Tooltip } from "@medusajs/ui"

export default function TooltipDemo() {
  return (
    <Tooltip content="The quick brown fox jumps over the lazy dog.">
      <InformationCircleSolid />
    </Tooltip>
  )
}

```

## Usage

```tsx
import { Tooltip } from "@medusajs/ui"
```

```tsx
<Tooltip content="Tooltip content">Trigger</Tooltip>
```

***

## API Reference

### Tooltip Props

This component is based on the [Radix UI Tooltip](https://www.radix-ui.com/primitives/docs/components/tooltip) primitive.

<Accordion title="content">
  **Required.** Type: `React.ReactNode`

  The content to display in the tooltip.
</Accordion>

<Accordion title="onClick">
  **Optional.** Type: `React.MouseEventHandler<HTMLButtonElement>`

  A function that is triggered when the tooltip is clicked.
</Accordion>

<Accordion title="side">
  **Optional.** Type: `"bottom" | "left" | "top" | "right"`

  Default: `top`

  The side to position the tooltip.
</Accordion>

<Accordion title="maxWidth">
  **Optional.** Type: `number`

  Default: `220`

  The maximum width of the tooltip.
</Accordion>

<Accordion title="sideOffset">
  **Optional.** Type: `number`

  Default: `8`

  The distance in pixels between the tooltip and its trigger.
</Accordion>

<Accordion title="children">
  **Optional.** Type: `unknown`

  The element to trigger the tooltip.
</Accordion>

<Accordion title="open">
  **Optional.** Type: `boolean`

  Whether the tooltip is currently open.
</Accordion>

<Accordion title="defaultOpen">
  **Optional.** Type: `boolean`

  Whether the tooltip is open by default.
</Accordion>

<Accordion title="onOpenChange">
  **Optional.** Type: `(open: boolean) => void`

  A function that is called when the tooltip's open state changes.
</Accordion>

<Accordion title="delayDuration">
  **Optional.** Type: `number`

  The time in milliseconds to delay the tooltip's appearance.
</Accordion>

## Usage Outside Medusa Admin with TooltipProvider

If you're using the `Tooltip` component in a project other than the Medusa Admin, make sure to include the `TooltipProvider` somewhere up in your component tree:

```tsx
<TooltipProvider>
  <Tooltip content="Tooltip content">Trigger</Tooltip>
</TooltipProvider>
```

### TooltipProvider Reference

### TooltipProvider Props

<Accordion title="delayDuration">
  **Optional.** Type: `number`

  Default: `100`

  The duration from when the pointer enters the trigger until the tooltip gets opened.
</Accordion>

<Accordion title="skipDelayDuration">
  **Optional.** Type: `number`

  Default: `300`

  How much time a user has to enter another trigger without incurring a delay again.
</Accordion>

<Accordion title="disableHoverableContent">
  **Optional.** Type: `boolean`

  When `true`, trying to hover the content will result in the tooltip closing as the pointer leaves the trigger.
</Accordion>

## Examples

### Changing Tooltip Side

```tsx
import { Tooltip } from "@medusajs/ui"
import {
  ArrowLongDown,
  ArrowLongLeft,
  ArrowLongRight,
  ArrowLongUp,
} from "@medusajs/icons"

export default function TooltipSides() {
  return (
    <div className="flex gap-8 items-center justify-center">
      <Tooltip content="Top" side="top">
        <ArrowLongUp />
      </Tooltip>
      <Tooltip content="Bottom" side="bottom">
        <ArrowLongDown />
      </Tooltip>
      <Tooltip content="Left" side="left">
        <ArrowLongLeft />
      </Tooltip>
      <Tooltip content="Right" side="right">
        <ArrowLongRight />
      </Tooltip>
    </div>
  )
}

```

### Set Tooltip Max Width

```tsx
import { Tooltip } from "@medusajs/ui"
import { InformationCircleSolid } from "@medusajs/icons"

export default function TooltipMaxWidth() {
  return (
    <Tooltip
      content="This is a very long tooltip message that demonstrates how you can use the maxWidth prop to control the width of the tooltip."
      maxWidth={320}
      className="text-center"
    >
      <InformationCircleSolid />
    </Tooltip>
  )
}

```
