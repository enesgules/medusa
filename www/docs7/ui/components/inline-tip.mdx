---
title: Inline Tip
---

A component for displaying a note or tip inline.

In this guide, you'll learn how to use the Inline Tip component.

[Open the live example](https://docs.medusajs.com/ui/components/inline-tip).

```tsx
import { InlineTip } from "@medusajs/ui"

export default function InlineTipDemo() {
  return (
    <InlineTip
      label="Tip"
    >
      Medusa UI is a package of React components to be used in Medusa Admin customizations.
    </InlineTip>
  )
}
```

## Usage

```tsx
import { InlineTip } from "@medusajs/ui"
```

```tsx
<InlineTip
  label="This is a tip"
>
  <button>Hover me</button>
</InlineTip>
```

***

## API Reference

### InlineTip Props

This component is based on the `div` element and supports all of its props.

<Accordion title="label">
  **Required.** Type: `string`

  The label to display in the tip.
</Accordion>

<Accordion title="variant">
  **Optional.** Type: `"info" | "warning" | "error" | "success"`

  Default: `"info"`

  The variant of the tip.
</Accordion>

### Success Inline Tip

[Open the live example](https://docs.medusajs.com/ui/components/inline-tip#success-inline-tip).

