---
title: AdminUpdateShippingOptionPriceWithRegion
---

The properties to update in a shipping option price with a region.

## Properties

<Accordion title="id (optional)">
  The price's ID. If not provided, a new price is created; existing prices whose ID isn't included in the request are deleted.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The price's ID. If not provided, a new price is created; existing prices whose ID isn't included in the request are deleted."
  }
  ```
</Accordion>

<Accordion title="region_id (optional)">
  The ID of the region the price is associated with.

  ```json
  {
    "type": "string",
    "title": "region_id",
    "description": "The ID of the region the price is associated with."
  }
  ```
</Accordion>

<Accordion title="amount (optional)">
  The price's amount.

  ```json
  {
    "type": "number",
    "title": "amount",
    "description": "The price's amount."
  }
  ```
</Accordion>

<Accordion title="rules (optional)">
  The price's rules. These rules replace the price's existing rules, so omit a rule to remove it.

  ```json
  {
    "type": "array",
    "description": "The price's rules. These rules replace the price's existing rules, so omit a rule to remove it.",
    "items": {
      "$ref": "#/components/schemas/PriceRule"
    }
  }
  ```

  Related schemas:

  - [PriceRule](/api/schemas/price-rule)
</Accordion>
