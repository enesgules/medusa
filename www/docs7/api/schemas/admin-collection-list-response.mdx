The paginated list of product collections.

## Properties

<Accordion title="limit (required)">
  The maximum number of items returned.

  ```json
  {
    "type": "number",
    "title": "limit",
    "description": "The maximum number of items returned."
  }
  ```
</Accordion>

</Accordion>

    "title": "count",
