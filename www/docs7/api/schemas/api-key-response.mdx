## Properties

<Accordion title="id (required)">
  The API key's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The API key's ID."
  }
  ```
</Accordion>

<Accordion title="token (required)">
  The API key's token.

  ```json
  {
    "type": "string",
    "title": "token",
    "description": "The API key's token."
  }
  ```
</Accordion>

<Accordion title="redacted (required)">
  The redacted form of the API key's token. This is useful when showing portion of the token. For example `sk_...123`.

  ```json
  {
    "type": "string",
    "title": "redacted",
    "description": "The redacted form of the API key's token. This is useful when showing portion of the token. For example `sk_...123`."
  }
  ```
</Accordion>

<Accordion title="title (required)">
  The API key's title.

  ```json
  {
    "type": "string",
    "title": "title",
    "description": "The API key's title."
  }
  ```
</Accordion>

<Accordion title="type (required)">
  The API key's type. `secret` API keys are used for authenticating admin users, and `publishable` API key are used for storefronts and similar clients to scope requests to sales channels.

  ```json
  {
    "type": "string",
    "description": "The API key's type. `secret` API keys are used for authenticating admin users, and `publishable` API key are used for storefronts and similar clients to scope requests to sales channels.",
    "enum": [
      "secret",
      "publishable"
    ]
  }
  ```
</Accordion>

<Accordion title="last_used_at (required)">

    "type": "string",
