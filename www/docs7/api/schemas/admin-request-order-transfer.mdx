---
title: AdminRequestOrderTransfer
---

The details of the request to transfer the order.

## Properties

<Accordion title="customer_id (required)">
  The ID of the customer to transfer the order to.

  ```json
  {
    "type": "string",
    "title": "customer_id",
    "description": "The ID of the customer to transfer the order to."
  }
  ```
</Accordion>

<Accordion title="description (optional)">
  The description of the order transfer, which can be shown to the customer receiving the order transfer request.

  ```json
  {
    "type": "string",
    "title": "description",
    "description": "The description of the order transfer, which can be shown to the customer receiving the order transfer request."
  }
  ```
</Accordion>

<Accordion title="internal_note (optional)">
  An internal note viewable only by admin users.

  ```json
  {
    "type": "string",
    "title": "internal_note",
    "description": "An internal note viewable only by admin users."
  }
  ```
</Accordion>

<Accordion title="update_order_email (optional)">
  Whether to update the order's email to the email of the customer the order is being transferred to. By default, the order's email will not be updated.

  ```json
  {
    "type": "boolean",
    "title": "update_order_email",
    "default": false,
    "description": "Whether to update the order's email to the email of the customer the order is being transferred to. By default, the order's email will not be updated."
  }
  ```
</Accordion>
