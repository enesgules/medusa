## Properties

<Accordion title="id (required)">
  The transaction's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The transaction's ID."
  }
  ```
</Accordion>

<Accordion title="order_id (required)">

  ```json
  {
    "type": "string",
    "title": "order_id",
    "description": "The ID of the order this transaction belongs to."
  }
  ```
</Accordion>

<Accordion title="amount (required)">
  The transaction's amount.

  ```json
  {
    "type": "number",
    "title": "amount",
    "description": "The transaction's amount."
  }
  ```
</Accordion>

<Accordion title="currency_code (required)">
  The transaction's currency code.

  ```json
  {
    "type": "string",
    "title": "currency_code",
    "description": "The transaction's currency code.",
    "example": "usd"
  }
  ```
</Accordion>

<Accordion title="reference (required)">
  The name of a table that this transaction references. If this transaction is for captured payment, its value is `capture`. If this transaction is for refunded payment, its value is `refund`.

  ```json
  {
    "type": "string",
    "title": "reference",
    "description": "The name of a table that this transaction references. If this transaction is for captured payment, its value is `capture`. If this transaction is for refunded payment, its value is `refund`.",
    "enum": [
      "capture",
      "refund"
    ]
  }
  ```
</Accordion>

<Accordion title="reference_id (required)">
  The ID of the referenced record in the referenced table.

  ```json
  {
    "type": "string",
    "title": "reference_id",
    "description": "The ID of the referenced record in the referenced table."
  }
  ```
</Accordion>
