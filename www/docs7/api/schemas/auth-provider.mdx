---
title: AuthProvider
---

The public information of a registered auth provider instance. This is safe
to expose to unauthenticated clients and never contains provider options or
secrets.

## Properties

<Accordion title="id (required)">
  The registered instance ID of the provider, used in authentication routes
  (for example, `okta` in `POST /auth/user/okta`).

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The registered instance ID of the provider, used in authentication routes\n(for example, `okta` in `POST /auth/user/okta`)."
  }
  ```
</Accordion>

<Accordion title="identifier (required)">
  The provider's static identifier (for example, `oidc` or `emailpass`).

  ```json
  {
    "type": "string",
    "title": "identifier",
    "description": "The provider's static identifier (for example, `oidc` or `emailpass`)."
  }
  ```
</Accordion>

<Accordion title="display_name (required)">
  The name to display for the provider in a frontend application.

  ```json
  {
    "type": "string",
    "title": "display_name",
    "description": "The name to display for the provider in a frontend application."
  }
  ```
</Accordion>

<Accordion title="flow (required)">
  The authentication flow the provider uses:

  - `credentials`: the client submits credentials (for example, email and
    password) directly to the authentication route.
  - `redirect`: the client is redirected to the provider (for example, an
    OIDC identity provider) and returns through a callback.

  A frontend can use this to decide whether to render a credentials form or a
  "Continue with ..." redirect button.

  ```json
  {
    "type": "string",
    "description": "The authentication flow the provider uses:\n\n- `credentials`: the client submits credentials (for example, email and\npassword) directly to the authentication route.\n- `redirect`: the client is redirected to the provider (for example, an\nOIDC identity provider) and returns through a callback.\n\nA frontend can use this to decide whether to render a credentials form or a\n\"Continue with ...\" redirect button.",
    "enum": [
      "credentials",
      "redirect"
    ]
  }
  ```
</Accordion>
