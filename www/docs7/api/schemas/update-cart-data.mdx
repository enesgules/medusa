The details to update in a cart.

## Properties

<Accordion title="region_id (optional)">
  The ID of the associated region. This can affect the prices and currency code of the cart.

  ```json
  {
    "type": "string",
    "title": "region_id",
    "description": "The ID of the associated region. This can affect the prices and currency code of the cart."
  }
  ```
</Accordion>

<Accordion title="customer_id (optional)">
  The ID of the customer that the cart belongs to.

  ```json
  {
    "type": "string",
    "title": "customer_id",
    "description": "The ID of the customer that the cart belongs to."
  }
  ```
</Accordion>

<Accordion title="sales_channel_id (optional)">
  The ID of the associated sales channel.

  A product's availability in a sales channel only filters the products you retrieve. Medusa doesn't reject a variant added to the cart when its product isn't available in the cart's sales channel. Refer to the guide in the external documentation to learn how to enforce that validation.

  ```json
  {
    "type": "string",
    "title": "sales_channel_id",
    "description": "The ID of the associated sales channel.\n\nA product's availability in a sales channel only filters the products you retrieve. Medusa doesn't reject a variant added to the cart when its product isn't available in the cart's sales channel. Refer to the guide in the external documentation to learn how to enforce that validation.\n",
    "externalDocs": {
      "url": "https://docs.medusajs.com/resources/commerce-modules/cart/sales-channel-availability"
    }
  }
  ```
</Accordion>
