The details of requesting the order transfer.

## Properties

<Accordion title="description (optional)">
  The transfer's description, which can be shown to the other customer receiving the request.

  ```json
  {
    "type": "string",
    "title": "description",
    "description": "The transfer's description, which can be shown to the other customer receiving the request."
  }
  ```
</Accordion>

<Accordion title="update_order_email (optional)">

  ```json

    "title": "update_order_email",
    "default": false,
    "description": "Whether to update the order's email to the receiving customer's email. By default, the order's email will not be updated."
  }
  ```
</Accordion>
