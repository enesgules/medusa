The paginated list of stores.

## Properties

<Accordion title="limit (required)">
  The maximum number of items returned.

  ```json
  {
    "type": "number",
    "title": "limit",
    "description": "The maximum number of items returned."
  }
  ```
</Accordion>

<Accordion title="offset (required)">

  ```json
  {
    "type": "number",
    "title": "offset",
    "description": "The number of items skipped before retrieving the returned items."
  }
  ```
</Accordion>

<Accordion title="count (required)">
  The total number of items.

  ```json
  {
    "type": "number",
    "title": "count",
    "description": "The total number of items."
  }
  ```
</Accordion>

<Accordion title="stores (required)">

  ```json
  {

    "description": "The list of stores.",

      "$ref": "#/components/schemas/AdminStore"
    }
  }
  ```

  Related schemas:

  - [AdminStore](/api/schemas/admin-store)

<Accordion title="estimate_count (optional)">

</Accordion>
