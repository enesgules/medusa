---
title: AdminLocaleListResponse
---

The list of locales with pagination details.

## Properties

<Accordion title="limit (required)">
  The maximum number of locales returned.

  ```json
  {
    "type": "number",
    "title": "limit",
    "description": "The maximum number of locales returned."
  }
  ```
</Accordion>

<Accordion title="offset (required)">
  The number of locales skipped before retrieving the returned locales.

  ```json
  {
    "type": "number",
    "title": "offset",
    "description": "The number of locales skipped before retrieving the returned locales."
  }
  ```
</Accordion>

<Accordion title="count (required)">
  The total number of locales matching the query.

  ```json
  {
    "type": "number",
    "title": "count",
    "description": "The total number of locales matching the query."
  }
  ```
</Accordion>

<Accordion title="estimate_count (optional)">
  The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.

  ```json
  {
    "type": "number",
    "title": "estimate_count",
    "description": "The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.",
    "x-featureFlag": "index_engine"
  }
  ```
</Accordion>

<Accordion title="locales (required)">
  The list of locales.

  ```json
  {
    "type": "array",
    "description": "The list of locales.",
    "items": {
      "$ref": "#/components/schemas/AdminLocale"
    }
  }
  ```

  Related schemas:

  - [AdminLocale](/api/schemas/admin-locale)
</Accordion>
