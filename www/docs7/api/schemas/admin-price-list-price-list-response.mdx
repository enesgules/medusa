The list of prices associated with a price list.

## Properties

<Accordion title="limit (required)">
  The maximum number of prices to return.

  ```json
  {
    "type": "number",
    "title": "limit",
    "description": "The maximum number of prices to return."
  }
  ```
</Accordion>

<Accordion title="offset (required)">
  The number of items skipped before retrieving the prices.

  ```json
  {
    "type": "number",
    "title": "offset",
    "description": "The number of items skipped before retrieving the prices."
  }
  ```
</Accordion>

<Accordion title="count (required)">
  The maximum number of prices available.

  ```json
  {
    "type": "number",
    "title": "count",
    "description": "The maximum number of prices available."
  }
  ```
</Accordion>

<Accordion title="estimate_count (optional)">
  The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.

  ```json
  {
    "type": "number",
    "title": "estimate_count",
    "description": "The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.",
    "x-featureFlag": "index_engine"
  }
  ```
</Accordion>

<Accordion title="prices (required)">
  The list of prices associated with the price list.

  ```json
  {
    "type": "array",
    "description": "The list of prices associated with the price list.",
    "items": {
      "$ref": "#/components/schemas/AdminPrice"
    }
  }
  ```

  Related schemas:

  - [AdminPrice](/api/schemas/admin-price)
</Accordion>
