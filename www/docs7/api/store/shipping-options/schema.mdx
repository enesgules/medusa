title: Shipping Options schema
---

The shipping option's details.

## Properties

<Accordion title="id (required)">
  The shipping option's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The shipping option's ID."
  }
  ```
</Accordion>

<Accordion title="name (required)">
  The shipping option's name.

  ```json
  {
    "type": "string",
    "title": "name",
    "description": "The shipping option's name."
  }
  ```
</Accordion>

<Accordion title="price_type (required)">
  The shipping option's price type. If it's `flat`, the price is fixed and is set in the `prices` property. If it's `calculated`, the price is calculated on checkout by the associated fulfillment provider.

  ```json
  {
    "type": "string",
    "description": "The shipping option's price type. If it's `flat`, the price is fixed and is set in the `prices` property. If it's `calculated`, the price is calculated on checkout by the associated fulfillment provider.",
    "enum": [
      "flat",
      "calculated"
    ]
  }
  ```
</Accordion>

<Accordion title="service_zone_id (required)">
  The ID of the service zone the shipping option belongs to.

  ```json
  {
    "type": "string",
    "title": "service_zone_id",
    "description": "The ID of the service zone the shipping option belongs to."
  }
  ```
</Accordion>

<Accordion title="provider_id (required)">
  The ID of the fulfillment provider handling this option.

  ```json
  {
    "type": "string",
    "title": "provider_id",

  }
  ```
</Accordion>

<Accordion title="amount (required)">
  The shipping option's amount. For a shipping option whose `price_type` is `calculated`, this amount isn't reliable until it's computed by the fulfillment provider using the [Calculate Shipping Option Price API route](/api/store).

  ```json
  {
    "type": "number",
    "title": "amount",
    "description": "The shipping option's amount. For a shipping option whose `price_type` is `calculated`, this amount isn't reliable until it's computed by the fulfillment provider using the [Calculate Shipping Option Price API route](https://docs.medusajs.com/api/store#shipping-options_postshippingoptionsidcalculate)."
  }
  ```
</Accordion>
