---
title: Update Line Item
---

`POST /store/carts/{id}/line-items/{line_id}`

Update a line item's details in the cart.

[Storefront guide: How to update a cart's line item.](/resources/storefront-development/cart/manage-items#update-line-item-in-cart)

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

This operation does not require authentication.

[Authentication guide](/api/store/authentication)

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

let MEDUSA_BACKEND_URL = "http://localhost:9000"

if (process.env.NEXT_PUBLIC_MEDUSA_BACKEND_URL) {
  MEDUSA_BACKEND_URL = process.env.NEXT_PUBLIC_MEDUSA_BACKEND_URL
}

export const sdk = new Medusa({
  baseUrl: MEDUSA_BACKEND_URL,
  debug: process.env.NODE_ENV === "development",
  publishableKey: process.env.NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY,
})

sdk.store.cart.updateLineItem(
  "cart_123",
  "li_123",
  {
    quantity: 1
  }
)
.then(({ cart }) => {
  console.log(cart)
})
```

### cURL

```bash
curl -X POST '{backend_url}/store/carts/{id}/line-items/{line_id}' \
-H 'Content-Type: application/json' \
-H 'x-publishable-api-key: {your_publishable_api_key}' \
--data-raw '{
  "quantity": 8980402259623936,
  "metadata": {}
}'
```
