---
title: Retrieve Registration JWT Token
---

`POST /auth/customer/{auth_provider}/register`

This API route retrieves a registration JWT token of a customer that hasn't been registered yet. The token is used in the header of requests that create a customer.

[Storefront development: How to register a customer](/resources/storefront-development/customers/register)

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

This operation does not require authentication.

[Authentication guide](/api/store/authentication)

## Parameters

<Accordion title="auth_provider (path, required)">
  The provider used for authentication.


</Accordion>

## Request body

Optional.

### application/json

```json
{
  "schema": {
    "type": "object",
    "title": "input",
```

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

let MEDUSA_BACKEND_URL = "http://localhost:9000"

if (process.env.NEXT_PUBLIC_MEDUSA_BACKEND_URL) {
  MEDUSA_BACKEND_URL = process.env.NEXT_PUBLIC_MEDUSA_BACKEND_URL
}

export const sdk = new Medusa({
  baseUrl: MEDUSA_BACKEND_URL,
  debug: process.env.NODE_ENV === "development",
  publishableKey: process.env.NEXT_PUBLIC_MEDUSA_PUBLISHABLE_KEY,
})

await sdk.auth.register(
  "customer",
  "emailpass",
  {
    email: "customer@gmail.com",
    password: "supersecret"
  }
)

// all subsequent requests will use the token in the header
const { customer } = await sdk.store.customer.create({
  email: "customer@gmail.com",
  password: "supersecret"
})
```

### cURL

```bash
curl -X POST '{backend_url}/auth/customer/emailpass/register' \
-H 'Content-Type: application/json' \
--data-raw '{
  "email": "customer@gmail.com",
  "password": "supersecret"
}'
```
