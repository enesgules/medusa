---
title: Confirm Verification
---

`POST /auth/verification/confirm`

Confirm a verification token of the customer. This API route is used as the last step part of the email verification flow. It can also be used for custom flows, such as phone number verification. Once successfully verified, a customer can complete their registration and log into their account.

[Storefront guide: Register Customer with Email Verification.](/resources/storefront-development/customers/verify-account)

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

This operation does not require authentication.

[Authentication guide](/api/store/authentication)

## Request body

Optional.

### application/json

```json
{
  "schema": {
    "type": "object",
    "description": "The verification details",
    "required": [
      "code"
    ],
    "properties": {
      "code": {
        "type": "string",
        "title": "code",
        "description": "The token, OTP, or any other code that was sent to the customer for verification."
      },
      "code_provider": {
        "type": "string",
        "title": "code_provider",
        "description": "The provider to use for verification. This is optional. When not provided, the default `token` provider is used."
      }
    }
  }
}
```
