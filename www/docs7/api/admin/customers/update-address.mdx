---
title: Update Address
---

`POST /admin/customers/{id}/addresses/{address_id}`

Update a customer address's details.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.customer.updateAddress("cus_123", "cus_addr_123", {
  address_1: "123 Main St",
  city: "Anytown",
  country_code: "US",
  postal_code: "12345"
})
.then(({ customer }) => {
  console.log(customer)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/customers/{id}/addresses/{address_id}' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \

  "address_name": "{value}",
  "company": "{value}",
  "first_name": "{value}",

  "city": "{value}",
  "country_code": "{value}",
  "province": "{value}",

  "phone": "{value}",

}'
```
