---
title: List Addresses
---

`GET /admin/customers/{id}/addresses`

Retrieve a list of addresses in a customer. The addresses can be filtered by fields like `query`. The addresses can also be paginated.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

{
  "api_token": {

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.customer.listAddresses("cus_123")
.then(({ addresses }) => {
  console.log(addresses)
})
```

### cURL

```bash
curl '{backend_url}/admin/customers/{id}/addresses' \
-H 'Authorization: Bearer {jwt_token}'
```
