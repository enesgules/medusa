---
title: Product Tags
---

A tag is another way of organizing a product. Each tag has a name and a value.

Products are organized into the same tag if they have the same value.

These API routes allow admin users to manage product tags.

- [Get a Product Tag](/api/admin/product-tags/get-a-product-tag)
- [List Product Tags](/api/admin/product-tags/list-product-tags)
- [Create Product Tag](/api/admin/product-tags/create-product-tag)
- [Update a Product Tag](/api/admin/product-tags/update-a-product-tag)
- [Delete a Product Tag](/api/admin/product-tags/delete-a-product-tag)
