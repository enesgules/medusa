title: Create Gift Card
---

`POST /admin/gift-cards`

Create a gift card.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
    "scheme": "basic"
  }
}
```

```json
{
  "cookie_auth": {
    "type": "apiKey",
    "in": "cookie",
    "name": "connect.sid",
    "x-displayName": "Cookie Session ID"
  }
}
```

