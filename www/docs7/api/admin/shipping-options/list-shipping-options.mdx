---
title: List Shipping Options
---

`GET /admin/shipping-options`

Retrieve a list of shipping options. The shipping options can be filtered by fields such as `id`. The shipping options can also be sorted or paginated.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
    "scheme": "basic"
  }
}
```

```json
{
  "cookie_auth": {
```
