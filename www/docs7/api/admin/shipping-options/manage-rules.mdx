---
title: Manage Rules
---

`POST /admin/shipping-options/{id}/rules/batch`

Manage the rules of a shipping option to create, update, or delete them.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.shippingOption.updateRules("so_123", {
  create: [{ attribute: "enabled_in_store", operator: "eq", value: "true" }],
})
.then(({ shipping_option }) => {
  console.log(shipping_option)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/shipping-options/{id}/rules/batch' \
-H 'Authorization: Bearer {jwt_token}'
```
