title: Create Shipping Option
---

`POST /admin/shipping-options`

Create a shipping option.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.shippingOption.create({
  name: "Standard Shipping",
  profile_id: "shp_123",
})
.then(({ shipping_option }) => {
  console.log(shipping_option)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/shipping-options' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "name": "Julie",
  "service_zone_id": "{value}",
  "shipping_profile_id": "{value}",
  "price_type": "{value}",
  "provider_id": "{value}",
  "type": {
    "label": "{value}",
    "description": "{value}",
    "code": "{value}"
  },
  "prices": []
}'
```
