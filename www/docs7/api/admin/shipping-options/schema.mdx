title: Shipping Options schema

The shipping option's details.

## Properties

<Accordion title="id (required)">
  The shipping option's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The shipping option's ID."
  }
  ```
</Accordion>

<Accordion title="name (required)">
  The shipping option's name.

  ```json
  {
    "type": "string",
    "title": "name",
    "description": "The shipping option's name."
  }
  ```
</Accordion>

<Accordion title="price_type (required)">
  The shipping option's price type. If it's `flat`, the price is fixed and is set in the `prices` property. If it's `calculated`, the price is calculated on checkout by the associated fulfillment provider.

  ```json
  {
    "type": "string",
    "description": "The shipping option's price type. If it's `flat`, the price is fixed and is set in the `prices` property. If it's `calculated`, the price is calculated on checkout by the associated fulfillment provider.",
    "enum": [
      "calculated",
      "flat"
    ]
  }
  ```
</Accordion>

<Accordion title="service_zone_id (required)">
  The ID of the service zone this option belongs to.

  ```json
  {
    "type": "string",
    "title": "service_zone_id",

  ```
</Accordion>
