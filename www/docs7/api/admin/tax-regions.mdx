---
title: Tax Regions
---

A tax region is a region's tax settings. It has tax rates and rules. So, after you create a region, you must create a tax region for it.

A tax region can extend settings from a parent tax region.

These API routes allow admin users to manage tax regions.

- [Get a Tax Region](/api/admin/tax-regions/get-a-tax-region)
- [List Tax Regions](/api/admin/tax-regions/list-tax-regions)
- [Create Tax Region](/api/admin/tax-regions/create-tax-region)
- [Update a Tax Region](/api/admin/tax-regions/update-a-tax-region)
- [Delete a Tax Region](/api/admin/tax-regions/delete-a-tax-region)
