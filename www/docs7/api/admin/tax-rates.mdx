---
title: Tax Rates
---

A tax rate is a percentage amount used to calculate the tax amount of each taxable item's price, such as line items or shipping methods.

Each tax region has a default tax rate. You can create tax rates that override the default using tax rules.

These API routes allow admin users to manage tax rates and their rules.

- [Get a Tax Rate](/api/admin/tax-rates/get-a-tax-rate)
- [List Tax Rates](/api/admin/tax-rates/list-tax-rates)
- [Create Tax Rate](/api/admin/tax-rates/create-tax-rate)
- [Create Tax Rule](/api/admin/tax-rates/create-tax-rule)
- [Update a Tax Rate](/api/admin/tax-rates/update-a-tax-rate)
- [Delete a Tax Rate](/api/admin/tax-rates/delete-a-tax-rate)
- [Remove Rule](/api/admin/tax-rates/remove-rule)
