---
title: Execute a Workflow
---

`POST /admin/workflows-executions/{workflow_id}/run`

Execute a workflow by its ID.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
    "scheme": "basic"
  }
}
```

```json
{
  "cookie_auth": {
    "type": "apiKey",
    "in": "cookie",
    "name": "connect.sid",
    "x-displayName": "Cookie Session ID"
  }
}
```

```json
{
  "jwt_token": {
    "type": "http",

```
