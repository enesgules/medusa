---
title: Succed a Step
---

`POST /admin/workflows-executions/{workflow_id}/steps/success`

Set the status of a step in a workflow's execution as successful. This is useful for long-running workflows.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`
