---
title: Create Price List
---

`POST /admin/price-lists`

Create a price list.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

{
  "api_token": {

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.priceList.create({
  title: "My Price List",
  status: "active",
  type: "sale",
  prices: [
    {
      variant_id: "variant_123",
      amount: 10,
      currency_code: "usd",
      rules: {
        region_id: "reg_123"
      }
    }
  ]
})
.then(({ price_list }) => {
  console.log(price_list)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/price-lists' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "title": "{value}",
  "description": "{value}",
  "starts_at": "{value}",
  "ends_at": "{value}"
}'
```
