---
title: List Product Option Values
---

`GET /admin/product-options/{id}/values`

Retrieve a list of values in a product option. The values can be filtered by fields like `id`. The values can also be paginated.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
```
