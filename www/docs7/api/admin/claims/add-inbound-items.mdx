---
title: Add Inbound Items
---

`POST /admin/claims/{id}/inbound/items`

Add inbound (or return) items to a claim. These inbound items will have a `RETURN_ITEM` action.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.claim.addInboundItems(
  "claim_123", 
  {
    items: [
      {
        id: "orli_123",
        quantity: 1
      }
    ]
  },
  )
.then(({ return: returnData }) => {
  console.log(returnData)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/claims/{id}/inbound/items' \
-H 'Authorization: Bearer {jwt_token}'
```
