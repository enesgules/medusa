---
title: Index
---

The Index Module is a tool to perform high-performance queries across modules, for example, to filter linked modules.
The Index Module is currently experimental and is hidden behind a feature flag. Learn more about it and how to enable it in the [Index Module guide](/learn/fundamentals/module-links/index-module).
