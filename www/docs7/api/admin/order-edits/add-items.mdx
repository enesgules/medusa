---
title: Add Items
---

`POST /admin/order-edits/{id}/items`

Add new items to an order edit. These items will have the action `ITEM_ADD`.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.orderEdit.addItems("order_123", {
  items: [
    {
      variant_id: "variant_123",
      quantity: 1
    }
  ]
})
.then(({ order_preview }) => {
  console.log(order_preview)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/order-edits/{id}/items' \
-H 'Authorization: Bearer {jwt_token}'
```
