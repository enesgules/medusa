---
title: Add Shipping Method
---

`POST /admin/order-edits/{id}/shipping-method`

Add a shipping method to an exchange. The shipping method will have a `SHIPPING_ADD` action.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`
