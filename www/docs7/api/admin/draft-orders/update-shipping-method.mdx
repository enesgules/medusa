---
title: Update Shipping Method
---

`POST /admin/draft-orders/{id}/edit/shipping-methods/method/{method_id}`

Update an existing shipping method in a draft order edit.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.draftOrder.updateShippingMethod("order_123", "sm_123", {
 shipping_option_id: "so_123",
})
.then(({ draft_order_preview }) => {
  console.log(draft_order_preview)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/draft-orders/{id}/edit/shipping-methods/method/{method_id}' \
-H 'Authorization: Bearer {jwt_token}'
```
