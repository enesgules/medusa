---
title: Convert to Order
---

`POST /admin/draft-orders/{id}/convert-to-order`

Convert a draft order to an order. This will finalize the draft order and create a new order with the same details.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.draftOrder.convertToOrder("order_123")
.then(({ order }) => {
  console.log(order)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/draft-orders/{id}/convert-to-order' \
-H 'Authorization: Bearer {jwt_token}'
```
