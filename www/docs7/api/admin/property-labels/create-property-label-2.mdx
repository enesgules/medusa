title: Create Property Label
---

`POST /admin/property-labels/batch`

Create a property label.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
    "scheme": "basic"
  }
}
```

```json
{
  "cookie_auth": {
    "type": "apiKey",
    "in": "cookie",
    "name": "connect.sid",
    "x-displayName": "Cookie Session ID"
  }
}
```

```json
{
  "jwt_token": {
```
