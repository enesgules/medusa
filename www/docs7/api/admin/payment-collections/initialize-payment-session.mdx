---
title: Initialize Payment Session
---

`POST /admin/payment-collections/{id}/payment-sessions`

Initialize a Payment Session in a payment collection. This is useful for orders placed outside the checkout flow, such as draft orders, or when a payment session needs to be re-initialized for an existing payment collection.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.paymentCollection.createPaymentSession("paycol_123", {
  provider_id: "pp_stripe_stripe"
})
.then(({ payment_collection }) => {
  console.log(payment_collection)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/payment-collections/{id}/payment-sessions' \
-H 'Authorization: Bearer {access_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "provider_id": "{value}"
}'
```
