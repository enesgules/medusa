---
title: List Auth Providers
---

`GET /admin/users/{id}/auth-providers`

Retrieve a list of auth providers that a user can authenticate with. These represent the auth providers that the user has previously used to log in or register with the system.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.user.listAuthProviders("user_123")
.then(({ providers }) => {
  console.log(providers)
})
```

### cURL

```bash
curl '{backend_url}/admin/users/{id}/auth-providers' \
-H 'Authorization: Bearer {access_token}'
```
