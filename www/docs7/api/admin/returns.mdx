---
title: Returns
---

Admin users create a return when a customer returns an item to them.

Returns can also be created by customers through the storefront, and admins will be able to manage them and make refunds, if necessary. Refunds are made through the [Payment API Routes](/api/admin/returns)

These API routes allow admin users to manage returns.
