---
title: Shipping Option Types
---

Shipping option types define a group of shipping options with shared shipping characterstics. For example,  you may have "Standard" and "Express" shipping option types.
These API routes allow admins to manage shipping option types.

- [Get a Shipping Option Type](/api/admin/shipping-option-types/get-a-shipping-option-type)
- [List Shipping Option Types](/api/admin/shipping-option-types/list-shipping-option-types)
- [Create Shipping Option Type](/api/admin/shipping-option-types/create-shipping-option-type)
- [Update a Shipping Option Type](/api/admin/shipping-option-types/update-a-shipping-option-type)
- [Delete Shipping Option Type](/api/admin/shipping-option-types/delete-shipping-option-type)
