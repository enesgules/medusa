title: Manage Inventory Levels
---

`POST /admin/inventory-items/location-levels/batch`

Manage inventory levels to create, update, or delete them.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.inventoryItem.batchInventoryItemsLocationLevels({
  create: [{
    inventory_item_id: "iitem_123",
    location_id: "sloc_123",
    stocked_quantity: 10
  }],
  delete: ["ilvl_123"]
})
.then(({ created, updated, deleted }) => {
  console.log(created, updated, deleted)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/inventory-items/location-levels/batch' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "create": [
    {
      "location_id": "sloc_123",
      "inventory_item_id": "iitem_123",
      "stocked_quantity": 100,
      "incoming_quantity": 50
    }
  ],
  "update": [
    {
      "location_id": "sloc_456",
      "inventory_item_id": "iitem_456",
      "stocked_quantity": 200,
      "incoming_quantity": 75
    }
  ],
  "delete": [
    "iilev_123"
  ]
}'
```
