---
title: Add Service Zone
---

`POST /admin/fulfillment-sets/{id}/service-zones`

Add a service zone to a fulfillment set.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.fulfillmentSet.createServiceZone("fset_123", {
  name: "Europe Service Zone",
  geo_zones: [{
    type: "country",
    country_code: "us"
  }]
})
.then(({ fulfillment_set }) => {
  console.log(fulfillment_set)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/fulfillment-sets/{id}/service-zones' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "name": "Layla"
}'
```
