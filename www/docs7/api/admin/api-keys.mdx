---
title: Api Keys
---

API keys can be used for authentication or resource-scoping.

A secret API key can be used to authenticate admin users.  A publishable API key can be used to scope client requests to one or more sales channels.

These API routes allow admin users to manage both publishable and secret API keys.

- [Get API Key](/api/admin/api-keys/get-api-key)
- [List API Keys](/api/admin/api-keys/list-api-keys)
- [Create Api Key](/api/admin/api-keys/create-api-key)
- [Manage Sales Channels](/api/admin/api-keys/manage-sales-channels)
- [Revoke API Key](/api/admin/api-keys/revoke-api-key)
- [Update an API Key](/api/admin/api-keys/update-an-api-key)
- [Delete an Api Key](/api/admin/api-keys/delete-an-api-key)
