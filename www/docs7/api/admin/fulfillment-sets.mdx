---
title: Fulfillment Sets
---

A fulfillment set is a general form or way of fulfillment, such as "shipping" or "pick up".

All fulfillment-related configurations in a store are related to a fulfillment set.

These API routes allow admin users to manage fulfillment sets.

- [Get a Service Zone](/api/admin/fulfillment-sets/get-a-service-zone)
- [Add Service Zone](/api/admin/fulfillment-sets/add-service-zone)
- [Update Service Zone](/api/admin/fulfillment-sets/update-service-zone)
- [Delete Fulfillment Set](/api/admin/fulfillment-sets/delete-fulfillment-set)
- [Remove Service Zone](/api/admin/fulfillment-sets/remove-service-zone)
