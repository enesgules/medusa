---
title: Create View Configuration
---

`POST /admin/views/{entity}/configurations`

Create a new view configuration for an entity. If `is_system_default` is set to true, the created configuration will be set as the system default for the specified entity. Otherwise, it will be a custom configuration for the admin user.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

const { view_configuration } = await sdk.admin.views.createConfiguration(
  "orders",
  {
    name: "My Orders View",
    configuration: {
      visible_columns: ["display_id", "status"],
      column_order: ["display_id", "status"],
    },
  }
)
```

### cURL

```bash
curl -X POST '{backend_url}/admin/views/{entity}/configurations' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
-d '{
  "is_system_default": true,
  "name": "Custom View"
}'
```
