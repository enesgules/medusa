title: Refund Reasons
---

A refund reason is a possible reason used when issuing a refund to the customer, such as when returning an item and refunding the customer.

These API routes allow admin users to manage refund reasons.

- [Get a Refund Reason](/api/admin/refund-reasons/get-a-refund-reason)
- [List Refund Reasons](/api/admin/refund-reasons/list-refund-reasons)
- [Create Refund Reason](/api/admin/refund-reasons/create-refund-reason)
- [Update a Refund Reason](/api/admin/refund-reasons/update-a-refund-reason)
- [Delete a Refund Reason](/api/admin/refund-reasons/delete-a-refund-reason)
