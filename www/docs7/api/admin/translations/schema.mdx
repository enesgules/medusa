---
title: Translations schema
---

The translation's details.

## Properties

<Accordion title="id (required)">
  The translation's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The translation's ID."
  }
  ```
</Accordion>

<Accordion title="reference_id (required)">
  The ID of the resource that the translation belongs to. For example, the ID of a product.

  ```json
  {
    "type": "string",
    "title": "reference_id",
    "description": "The ID of the resource that the translation belongs to. For example, the ID of a product.",
    "example": "prod_123"
  }
  ```
</Accordion>

<Accordion title="reference (required)">
  The resource that the translation belongs to.

  ```json
  {
    "type": "string",
    "title": "reference",
    "description": "The resource that the translation belongs to.",
    "example": "product"
  }
  ```
</Accordion>

<Accordion title="locale_code (required)">
  The translation's locale code in BCP 47 format.

  ```json
  {
    "type": "string",
    "title": "locale_code",
    "description": "The translation's locale code in BCP 47 format.",
    "example": "fr-FR"
  }
  ```
</Accordion>

<Accordion title="translations (required)">
  The translation key-value pairs. Each key is a field in the resource, and the value is the translated text.

  ```json
  {
    "type": "object",
    "description": "The translation key-value pairs. Each key is a field in the resource, and the value is the translated text.",
    "example": {
      "title": "Chaussures",
      "description": "Des chaussures élégantes."
    }
  }
  ```
</Accordion>

<Accordion title="created_at (required)">
  The date that the translation was created.

  ```json
  {
    "type": "string",
    "format": "date-time",
    "title": "created_at",
    "description": "The date that the translation was created."
  }
  ```
</Accordion>

<Accordion title="updated_at (required)">
  The date that the translation was updated.

  ```json
  {
    "type": "string",
    "format": "date-time",
    "title": "updated_at",
    "description": "The date that the translation was updated."
  }
  ```
</Accordion>

<Accordion title="deleted_at (required)">
  The date that the translation was deleted.

  ```json
  {
    "type": "string",
    "format": "date-time",
    "title": "deleted_at",
    "description": "The date that the translation was deleted."
  }
  ```
</Accordion>
