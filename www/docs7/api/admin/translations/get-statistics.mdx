---
title: Get Statistics
---

`GET /admin/translations/statistics`

Get statistics on translations for specified locales and entity types. This includes overall translation progress for each entity type, and statistics for each locale within those entity types.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Parameters

<Accordion title="locales (query, required)">
  The locale codes to retrieve translation statistics for. Locale codes are in [BCP 47](https://gist.github.com/typpo/b2b828a35e683b9bf8db91b5404f1bd1) format.

  ```json
  {
    "name": "locales",
    "in": "query",
    "description": "The locale codes to retrieve translation statistics for. Locale codes are in [BCP 47](https://gist.github.com/typpo/b2b828a35e683b9bf8db91b5404f1bd1) format.",
    "required": true,
    "schema": {
      "oneOf": [
        {
          "type": "string",
          "title": "locales",
          "description": "A locale code to retrieve translation statistics for. Locale codes are in [BCP 47](https://gist.github.com/typpo/b2b828a35e683b9bf8db91b5404f1bd1) format."
        },
        {
          "type": "array",
          "description": "Locale codes to retrieve translation statistics for.",
          "items": {
            "type": "string",
            "title": "locales",
            "description": "A locale code in [BCP 47](https://gist.github.com/typpo/b2b828a35e683b9bf8db91b5404f1bd1) format."
          }
        }
      ]
    }
  }
  ```
</Accordion>

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.translation.statistics({
  entity_type: "product"
})
.then(({ statistics }) => {
  console.log(statistics)
})
```

### cURL

```bash
curl '{backend_url}/admin/translations/statistics' \
-H 'Authorization: Bearer {access_token}'
```
