---
title: List Settings
---

`GET /admin/translations/settings`

Retrieve the list of translatable fields for all entities, such as products and collections. You can also filter the results by entity type or active entities.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.translation.settings({
  entity_type: "product"
})
.then(({ translation_settings }) => {
  console.log(translation_settings)
})
```

### cURL

```bash
curl '{backend_url}/admin/translations/settings' \
-H 'Authorization: Bearer {access_token}'
```
