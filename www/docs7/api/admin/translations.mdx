title: Translations
---

A translation is a localized version of content in a specific locale. For example, a product description in French.
These API routes allow admin users to manage translations for different locales and resources.

- [List Translatable Entities](/api/admin/translations/list-translatable-entities)
- [List Settings](/api/admin/translations/list-settings)
- [List Translations](/api/admin/translations/list-translations)
- [Get Statistics](/api/admin/translations/get-statistics)
- [Manage Translation Settings](/api/admin/translations/manage-translation-settings)
- [Manage Translations](/api/admin/translations/manage-translations)
