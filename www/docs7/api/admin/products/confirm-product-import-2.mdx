---
title: Confirm Product Import
---

`POST /admin/products/imports/{transaction_id}/confirm`

Confirm that a created product import should start importing the products into Medusa.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.product.confirmImport("transaction_123")
.then(() => {
  console.log("Import confirmed")
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/products/imports/{transaction_id}/confirm' \
-H 'Authorization: Bearer {jwt_token}'
```
