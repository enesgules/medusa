title: Delete Variant
---

`DELETE /admin/products/{id}/variants/{variant_id}`

Delete a variant of a product.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.product.deleteVariant("prod_123", "variant_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

### cURL

```bash
curl -X DELETE '{backend_url}/admin/products/{id}/variants/{variant_id}' \
-H 'Authorization: Bearer {jwt_token}'
```
