---
title: Capture Payment
---

`POST /admin/payments/{id}/capture`

Capture an amount of a payment. This uses the `capturePayment` method of the payment provider associated with the payment's collection.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.payment.capture("paycol_123", {})
.then(({ payment }) => {
  console.log(payment)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/payments/{id}/capture' \
-H 'Authorization: Bearer {jwt_token}'
```
