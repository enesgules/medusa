---
title: List Payment Providers
---

`GET /admin/payments/payment-providers`

Retrieve a list of payment providers. The payment providers can be filtered by fields such as `id`. The payment providers can also be sorted or paginated.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.payment.listPaymentProviders()
.then(({ payment_providers, count, limit, offset }) => {
  console.log(payment_providers)
})
```

### cURL

```bash
curl '{backend_url}/admin/payments/payment-providers' \
-H 'Authorization: Bearer {jwt_token}'
```
