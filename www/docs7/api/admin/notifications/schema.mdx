---
title: Notifications schema
---

The notification's details.

## Properties

<Accordion title="id (required)">
  The notification's ID.

  ```json
  {
    "type": "string",
    "title": "id",
    "description": "The notification's ID."
  }
  ```
</Accordion>

<Accordion title="to (required)">
  Where to send the notification to. For example, if `channel` is `email`, this can be an email number.

  ```json
  {
    "type": "string",
    "title": "to",
    "description": "Where to send the notification to. For example, if `channel` is `email`, this can be an email number."
  }
  ```
</Accordion>

<Accordion title="channel (required)">
  Through which channel is the notification sent through.

  ```json
  {
    "type": "string",
    "title": "channel",
    "description": "Through which channel is the notification sent through.",
    "example": "email"
  }
  ```
</Accordion>

<Accordion title="template (required)">
  The ID of the template in a third-party service used as the notification's shape.

  ```json
  {
    "type": "string",
    "title": "template",
    "description": "The ID of the template in a third-party service used as the notification's shape."
  }
  ```
</Accordion>

<Accordion title="data (optional)">
  Data payload to send with the notification.

  ```json
  {
    "type": "object",
    "description": "Data payload to send with the notification."
  }
  ```
</Accordion>

<Accordion title="trigger_type (optional)">
  What triggered this notification.

  ```json
  {
    "type": "string",
    "title": "trigger_type",
    "description": "What triggered this notification.",
    "example": "order.created"
  }
  ```
</Accordion>

<Accordion title="resource_id (optional)">
  The ID of the associated resource. For example, if the notification was triggered because an order was created, this would be the ID of the order.

  ```json
  {
    "type": "string",
    "title": "resource_id",
    "description": "The ID of the associated resource. For example, if the notification was triggered because an order was created, this would be the ID of the order."
  }
  ```
</Accordion>

<Accordion title="resource_type (optional)">
  The type of the resource that triggered the notification.

  ```json
  {
    "type": "string",
    "title": "resource_type",
    "description": "The type of the resource that triggered the notification.",
    "example": "order"
  }
  ```
</Accordion>

<Accordion title="receiver_id (optional)">
  The ID of the user or customer that's receiving this notification.

  ```json
  {
    "type": "string",
    "title": "receiver_id",
    "description": "The ID of the user or customer that's receiving this notification."
  }
  ```
</Accordion>

<Accordion title="original_notification_id (optional)">
  The ID of the original notification, if this notification is resent.

  ```json
  {
    "type": "string",
    "title": "original_notification_id",
    "description": "The ID of the original notification, if this notification is resent."
  }
  ```
</Accordion>

<Accordion title="external_id (optional)">
  The ID of the notification in an external or third-party system.

  ```json
  {
    "type": "string",
    "title": "external_id",
    "description": "The ID of the notification in an external or third-party system."
  }
  ```
</Accordion>

<Accordion title="provider_id (required)">
  The ID of the provider used to send the notification.

  ```json
  {
    "type": "string",
    "title": "provider_id",
    "description": "The ID of the provider used to send the notification."
  }
  ```
</Accordion>

<Accordion title="created_at (required)">
  The date the notification was created.

  ```json
  {
    "type": "string",
    "format": "date-time",
    "title": "created_at",
    "description": "The date the notification was created."
  }
  ```
</Accordion>
