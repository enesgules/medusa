---
title: Campaigns
---

A campaign is a group of promotions that have the same conditions, such as start and end dates.

These API routes allow admin users to manage campaigns, their conditions, and promotions that belong to them.

- [Get a Campaign](/api/admin/campaigns/get-a-campaign)
- [List Campaigns](/api/admin/campaigns/list-campaigns)
- [Create Campaign](/api/admin/campaigns/create-campaign)
- [Manage Promotions](/api/admin/campaigns/manage-promotions)
- [Update a Campaign](/api/admin/campaigns/update-a-campaign)
- [Delete a Campaign](/api/admin/campaigns/delete-a-campaign)
