title: Invites
---

An admin can invite new users to manage their team. This allows new users to authenticate as admins and perform admin functionalities.

These API routes allow admin users to manage invites.

- [Get an Invite](/api/admin/invites/get-an-invite)
- [List Invites](/api/admin/invites/list-invites)
- [Accept Invite](/api/admin/invites/accept-invite)
- [Create Invite](/api/admin/invites/create-invite)
- [Refresh Invite Token](/api/admin/invites/refresh-invite-token)
- [Delete Invite](/api/admin/invites/delete-invite)
