---
title: Create Shipment
---

`POST /admin/fulfillments/{id}/shipment`

Create a shipment for a fulfillment. The fulfillment must not be shipped or canceled.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

sdk.admin.fulfillment.createShipment("ful_123", {
  labels: [
    {
      tracking_number: "123",
      tracking_url: "example.com",
      label_url: "example.com"
    }
  ]
})
.then(({ fulfillment }) => {
  console.log(fulfillment)
})
```

### cURL

```bash
curl -X POST '{backend_url}/admin/fulfillments/{id}/shipment' \
-H 'Authorization: Bearer {jwt_token}' \
-H 'Content-Type: application/json' \
--data-raw '{
  "labels": [
    {
      "tracking_number": "{value}",
      "tracking_url": "{value}",
      "label_url": "{value}"
    }
  ]
}'
```
