title: Return Reasons
---

A return reason is a possible reason that an item is returned from the customer, such as when returning an item.

These API routes allow admin users to manage return reasons.

- [Get a Return Reason](/api/admin/return-reasons/get-a-return-reason)
- [List Return Reasons](/api/admin/return-reasons/list-return-reasons)
- [Create Return Reason](/api/admin/return-reasons/create-return-reason)
- [Update a Return Reason](/api/admin/return-reasons/update-a-return-reason)
- [Delete a Return Reason](/api/admin/return-reasons/delete-a-return-reason)
