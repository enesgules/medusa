---
title: Users
---

A user is an admin user that can authenticate and perform functionalities as an admin user.

An admin user can invite other users to join their team. Once they accept the invite, they'll become admin users as well.

These API routes allow admin users to manage their team.

- [Get a User](/api/admin/users/get-a-user)
- [Get Logged-In User](/api/admin/users/get-logged-in-user)
- [List Auth Providers](/api/admin/users/list-auth-providers)
- [List Users](/api/admin/users/list-users)
- [Add Reset Password to User](/api/admin/users/add-reset-password-to-user)
- [Update a User](/api/admin/users/update-a-user)
- [Delete a User](/api/admin/users/delete-a-user)
