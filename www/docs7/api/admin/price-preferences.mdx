---
title: Price Preferences
---

A price preference is used to specify whether tax-inclusiveness is enabled for a context, such as a region or currency code.

These API routes allow admin users to manage whether a region or currency is tax inclusive.

- [Get a Price Preference](/api/admin/price-preferences/get-a-price-preference)
- [List Price Preferences](/api/admin/price-preferences/list-price-preferences)
- [Create Price Preference](/api/admin/price-preferences/create-price-preference)
- [Update a Price Preference](/api/admin/price-preferences/update-a-price-preference)
- [Delete a Price Preference](/api/admin/price-preferences/delete-a-price-preference)
