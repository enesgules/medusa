---
title: Get a Store Credit Account
---

`GET /admin/store-credit-accounts/{id}`

Retrieve a store credit account by its ID. You can expand the store credit account's relations or select the fields that should be returned.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

```json
{
  "api_token": {
    "type": "http",
    "x-displayName": "API Token",
    "scheme": "basic"
  }
}
```

```json
{
  "cookie_auth": {
```
