---
title: Delete Authentication Session
---

`DELETE /auth/session`

Deletes the cookie session ID previously set for authentication.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

Authentication is required.

[Authentication guide](/api/admin/authentication)

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

await sdk.auth.logout()

// user is now logged out
// you can't send any requests that require authentication
```

### cURL

```bash
curl -X DELETE '{backend_url}/auth/session' \
-H 'Cookie: connect.sid={sid}'
```
