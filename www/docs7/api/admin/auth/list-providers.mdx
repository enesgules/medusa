---
title: List Providers
---

`GET /auth/user/providers`

Retrieve a list of auth providers for the user actor type. This is useful to show the authentication option for the available providers.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

This operation does not require authentication.

[Authentication guide](/api/admin/authentication)

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

const { providers } = await sdk.auth.listProviders("user")
```

### cURL

```bash
curl '{backend_url}/auth/user/providers'
```
