---
title: Refresh Authentication Token
---

`POST /auth/token/refresh`

Refresh the authentication token of a user. This is useful after authenticating a user with a third-party service to ensure the token holds the new user's details, or when you don't want users to re-login every day.

[Learn about third-party authentication flow.](/resources/commerce-modules/auth/authentication-route#2-third-party-service-authenticate-flow)

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

Authentication is required.

[Authentication guide](/api/admin/authentication)

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

const token = await sdk.auth.refresh()

// all subsequent requests will use the token in the header
const { user } = await sdk.admin.user.me()
```

### cURL

```bash
curl -X POST '{backend_url}/auth/token/refresh' \
-H 'Authorization: Bearer {token}'
```
