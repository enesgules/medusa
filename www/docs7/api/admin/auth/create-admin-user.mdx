---
title: Create Admin User
---

`POST /auth/{auth_provider}/user`

Create an admin user for an auth provider. This is useful for providers like OIDC where the user is created in the provider and then needs to be created in Medusa. Be careful of using this endpoint with providers like Google or GitHub, as any one can sign up as an admin user. Make sure to disable these providers for admin users using the [http.authMethodsPerActor](/resources/commerce-modules/auth/auth-providers#configure-allowed-auth-providers-of-actor-types) configuration.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`

## Authentication

This operation does not require authentication.

[Authentication guide](/api/admin/authentication)

## Examples

### JS SDK

```js
import Medusa from "@medusajs/js-sdk"

export const sdk = new Medusa({
  baseUrl: import.meta.env.VITE_BACKEND_URL || "/",
  debug: import.meta.env.DEV,
  auth: {
    type: "session",
  },
})

const token = await sdk.auth.callback("user", "okta", queryParams)
await sdk.auth.createUser("okta", { Authorization: `Bearer ${token}` })
await sdk.auth.refresh()
```

### cURL

```bash
curl -X POST '{backend_url}/auth/okta/user'
```
