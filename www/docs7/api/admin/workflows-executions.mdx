title: Workflows Executions
---

These API routes allow you to track workflow executions in your Medusa application.

Depending on the workflow engine you use, executions may only be retained for a short while, or only until the Medusa application is restarted.

- [Get a Workflows Execution](/api/admin/workflows-executions/get-a-workflows-execution)
- [Get Exection](/api/admin/workflows-executions/get-exection)
- [List Workflows Executions](/api/admin/workflows-executions/list-workflows-executions)
- [Subscribe to Workflow](/api/admin/workflows-executions/subscribe-to-workflow)
- [Subscribe to Workflow Execution Events](/api/admin/workflows-executions/subscribe-to-workflow-execution-events)
- [Execute a Workflow](/api/admin/workflows-executions/execute-a-workflow)
- [Fail a Step](/api/admin/workflows-executions/fail-a-step)
- [Succed a Step](/api/admin/workflows-executions/succed-a-step)
