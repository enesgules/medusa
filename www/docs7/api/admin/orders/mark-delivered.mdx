---
title: Mark Delivered
---

`POST /admin/orders/{id}/fulfillments/{fulfillment_id}/mark-as-delivered`

Mark an order's fulfillment as delivered.

## Base URLs

- `http://localhost:9000`

- `https://api.medusajs.com`
