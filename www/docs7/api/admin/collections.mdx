title: Collections
---

A product collection organizes products into a collection for marketing purposes. For example, a summer collection.

These API routes allow admin users to manage collections and the products in them.

- [Get a Collection](/api/admin/collections/get-a-collection)
- [List Collections](/api/admin/collections/list-collections)
- [Create Collection](/api/admin/collections/create-collection)
- [Manage Products](/api/admin/collections/manage-products)
- [Update a Collection](/api/admin/collections/update-a-collection)
- [Delete a Collection](/api/admin/collections/delete-a-collection)
