title: AI-Friendly Medusa Documentation
---

Use the documentation assistant and Markdown pages to learn about Medusa with AI tools.

## Ask AI

Select **Ask AI** to ask a question about Medusa. You can also use `Ctrl + I` on Windows or Linux, or `Cmd + I` on macOS.

For example, you can ask:

- What is a workflow?
- How do I create a product review module?
- How do I update Medusa?

Include the code or error message that you want to understand. Use triple backticks to format code, and `Shift + Enter` to add a new line.

## Markdown pages

Use these files to read the documentation with an AI tool:

- [llms.txt](/llms.txt) contains links to the documentation pages.
- [llms-full.txt](/llms-full.txt) contains the documentation content.
- Append `.md` to a page URL to read its Markdown version. For example, [read this page as Markdown](/learn/introduction/build-with-llms-ai/ai-friendly-docs.md).

An HTTP client can also request Markdown with the `Accept: text/markdown` header.

## Medusa MCP server

To connect an AI agent to Medusa's MCP server, follow the [MCP server guide](/learn/introduction/build-with-llms-ai/mcp-server).
