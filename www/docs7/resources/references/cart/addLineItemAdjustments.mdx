This documentation provides a reference to the `addLineItemAdjustments` method. This belongs to the Cart Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="addlineitemadjustments-data-promiselineitemadjustmentdto" />

## addLineItemAdjustments(data): Promise\<[LineItemAdjustmentDTO](/resources/references/cart/interfaces/cartLineItemAdjustmentDTO)\[]>

This method adds line item adjustments to line items.

### Example

```ts
const lineItemAdjustments =
  await cartModuleService.addLineItemAdjustments([
    {
      item_id: "caliadj_123",
      code: "50%OFF",
      amount: 3000,
    },
    {
      item_id: "caliadj_321",
      code: "10%OFF",
      amount: 3000,
    },
  ])
```

<a id="addlineitemadjustments-parameters" />

### Parameters

**addLineItemAdjustments**

- `data`: [CreateLineItemAdjustmentDTO](/resources/references/cart/interfaces/cartCreateLineItemAdjustmentDTO)\[] — The line item adjustments to be created and added to line items. The line item is specified by the `item_id` field.
  - `code`: `string` — The code of the promotion that lead to this adjustment.
  - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount to adjust the original amount with.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `is_tax_inclusive`: `boolean` (optional) — Whether the adjustment amount includes tax.
  - `description`: `string` (optional) — The description of the adjustment.
  - `promotion_id`: `string` (optional) — The associated promotion's ID.
  - `provider_id`: `string` (optional) — The associated provider's ID.
  - `item_id`: `string` — The associated item's ID.
