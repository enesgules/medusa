This documentation provides a reference to the `upsertShippingMethodTaxLines` method. This belongs to the Cart Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method upsert shipping method tax lines.

## Example

```ts
const shippingMethodTaxLines = await orderModuleService
  .upsertShippingMethodTaxLines(
    [
      {
        code: "123",
        rate: 2
      },
      {
        id: "321",
        rate: 2
      }
    ]
  )
```
