## addLineItemTaxLines(taxLines): Promise\<[LineItemTaxLineDTO](/resources/references/cart/interfaces/cartLineItemTaxLineDTO)\[]>

This method creates and adds line item tax lines.

### Example

```ts
const lineItemTaxLines =
  await cartModuleService.addLineItemTaxLines([
    {
      code: "1000",
      rate: 10,
    },
    {
      code: "1234",
      rate: 20,
    },
  ])
```

### Parameters

**addLineItemTaxLines**

- `taxLines`: [CreateLineItemTaxLineDTO](/resources/references/cart/interfaces/cartCreateLineItemTaxLineDTO)\[] — The line item tax lines to be created.
  - `description`: `string` (optional) — The description of the tax line.
  - `tax_rate_id`: `string` (optional) — The associated tax rate's ID.
