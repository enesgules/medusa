This documentation provides a reference to the `addShippingMethodAdjustments` method. This belongs to the Cart Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="addshippingmethodadjustments-data-promiseshippingmethodadjustmentdto" />

## addShippingMethodAdjustments(data): Promise\<[ShippingMethodAdjustmentDTO](/resources/references/cart/interfaces/cartShippingMethodAdjustmentDTO)\[]>

This method adds shipping method adjustments to shipping methods.

### Example

```ts
const shippingMethodAdjustments =
  await cartModuleService.addShippingMethodAdjustments([
    {
      shipping_method_id: "casm_123",
      code: "FREESHIPPING",
      amount: 3000,
    },
    {
      shipping_method_id: "casm_321",
      code: "10%OFF",
      amount: 1500,
    },
  ])
```

<a id="addshippingmethodadjustments-parameters" />

### Parameters

**addShippingMethodAdjustments**

- `data`: [CreateShippingMethodAdjustmentDTO](/resources/references/cart/interfaces/cartCreateShippingMethodAdjustmentDTO)\[] — The shipping method adjustments to be created and added to shipping methods. The shipping method is specified by the `shipping_method_id` field.
  - `shipping_method_id`: `string` — The associated shipping method's ID.
  - `code`: `string` — The code of the promotion that lead to this adjustment.
  - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount to adjust the original amount with.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `description`: `string` (optional) — The description of the shipping method adjustment.
  - `promotion_id`: `string` (optional) — The associated promotion's ID.
  - `provider_id`: `string` (optional) — The associated provider's ID.
