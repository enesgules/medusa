---
title: UpsertLineItemAdjustmentDTO
---

The attributes in the line item adjustment to be created or updated.

**UpsertLineItemAdjustmentDTO**

- `id`: `string` (optional) — The ID of the line item adjustment.
- `item_id`: `string` — The associated item's ID.
- `code`: `string` (optional) — The code of the promotion that lead to the adjustment.
- `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) (optional) — The amount to adjust the original amount with.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `description`: `string` (optional) — The description of the line item adjustment.
- `promotion_id`: `string` (optional) — The associated promotion's ID.
- `provider_id`: `string` (optional) — The associated provider's ID.
