title: UpdateShippingMethodAdjustmentDTO
---

The attributes to update in the shipping method adjustment.

**UpdateShippingMethodAdjustmentDTO**

- `id`: `string` — The ID of the shipping method adjustment.
- `code`: `string` (optional) — The code of the promotion that lead to this adjustment.
- `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) (optional) — The amount to adjust the original amount with.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `description`: `string` (optional) — The description of the shipping method adjustment.
- `promotion_id`: `string` (optional) — The associated promotion's ID.
- `provider_id`: `string` (optional) — The associated provider's ID.
