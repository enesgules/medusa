This documentation provides a reference to the `updateLineItems` method. This belongs to the Cart Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="updatelineitems-data-promisecartlineitemdto" />

## updateLineItems(data): Promise\<[CartLineItemDTO](/resources/references/cart/interfaces/cartCartLineItemDTO)\[]>

This method updates existing line items.

### Example

```ts
const lineItems = await cartModuleService.updateLineItems([
  {
    selector: {
      id: "cali_123",
    },
    data: {
      quantity: 2,
    },
  },
  {
    selector: {
      variant_sku: "PANTS",
    },
    data: {
      unit_price: 3000,
    },
  },
])
```
