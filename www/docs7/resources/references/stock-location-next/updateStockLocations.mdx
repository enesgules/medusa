## updateStockLocations(id, input, context?): Promise\<[StockLocationDTO](/resources/references/stock_location_next/types/stock_location_nextStockLocationDTO)>

This method updates existing stock locations.

### Example

```ts
const stockLocations =
  await stockLocationModuleService.updateStockLocations([
    {
      id: "sloc_123",
      name: "Warehouse",
    },
    {
      id: "sloc_321",
      address_id: "laddr_123",
    },
  ])
```
