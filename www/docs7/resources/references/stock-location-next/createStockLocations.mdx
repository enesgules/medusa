## createStockLocations(input, context?): Promise\<[StockLocationDTO](/resources/references/stock_location_next/types/stock_location_nextStockLocationDTO)>

This method creates a stock location.

### Example

```ts
const stockLocation = await stockLocationModuleService.createStockLocations(
  {
    name: "Warehouse",
    address: {
      address_1: "1855 Powder Mill Rd",
      country_code: "us",
    },
  }
)
```
