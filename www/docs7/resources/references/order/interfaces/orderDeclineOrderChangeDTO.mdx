The details of declining the order change.

**DeclineOrderChangeDTO**

- `id`: `string` — The ID of the order change.
- `declined_by`: `string` (optional) — The user or customer who declined the order change.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
