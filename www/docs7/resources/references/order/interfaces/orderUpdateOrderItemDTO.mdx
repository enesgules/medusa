The data to update in the order items.

**UpdateOrderItemDTO**

- `id`: `string` — The ID of the item.
- `order_id`: `string` (optional) — The associated order's ID.
- `version`: `number` (optional) — The version of the item.
- `item_id`: `string` (optional) — The associated item's ID.
- `quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The quantity of the item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `fulfilled_quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The fulfilled quantity of the item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `return_requested_quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The requested quantity of the item to be returned.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `return_received_quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The quantity of the item received through a return.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `return_dismissed_quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The dismissed quantity of the item through a return.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `written_off_quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The quantity written off of the item due to an order change.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
