title: CreateOrderExchangeItemDTO
---

The order exchange item to be created.

**CreateOrderExchangeItemDTO**

- `exchange_id`: `string` — The associated exchange's ID.
- `item_id`: `string` — The associated item's ID.
- `quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The quantity of the order exchange item
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `note`: `string` (optional) — The note of the order exchange item
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
