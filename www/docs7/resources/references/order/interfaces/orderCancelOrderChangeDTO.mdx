The details of the order change cancelation.

**CancelOrderChangeDTO**

- `id`: `string` — The ID of the order change.
- `canceled_by`: `string` (optional) — The user or customer that canceled the order change.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
