The data of the line item to create.

**CreateOrderLineItemDTO**

- `title`: `string` — The title of the line item.
- `subtitle`: `string` (optional) — The subtitle of the line item.
- `thumbnail`: `string` (optional) — The thumbnail of the line item.
- `order_id`: `string` (optional) — The associated order's ID.
- `quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The quantity of the line item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `product_id`: `string` (optional) — The associated product's ID.
- `product_title`: `string` (optional) — The product title of the line item.
- `product_description`: `string` (optional) — The product description of the line item.
- `product_subtitle`: `string` (optional) — The product subtitle of the line item.
- `product_type`: `string` (optional) — The product type of the line item.
- `product_collection`: `string` (optional) — The product collection of the line item.
- `product_handle`: `string` (optional) — The product handle of the line item.
- `variant_id`: `string` (optional) — The associated variant's ID.
- `variant_sku`: `string` (optional) — The variant sku of the line item.
- `variant_barcode`: `string` (optional) — The variant barcode of the line item.
- `variant_title`: `string` (optional) — The variant title of the line item.
- `variant_option_values`: `Record<string, unknown>` (optional) — The variant option values of the line item.
- `requires_shipping`: `boolean` (optional) — Whether the line item requires shipping.
- `is_discountable`: `boolean` (optional) — Whether the line item is discountable.
- `is_tax_inclusive`: `boolean` (optional) — Whether the line item is tax inclusive.
- `compare_at_unit_price`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The compare-at unit price of the line item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `unit_price`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The unit price of the line item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `tax_lines`: [CreateOrderTaxLineDTO](/resources/references/order/interfaces/orderCreateOrderTaxLineDTO)\[] (optional) — The tax lines of the line item.
  - `description`: `string` (optional) — The description of the tax line.
  - `tax_rate_id`: `string` (optional) — The associated tax rate's ID.
  - `code`: `string` — The code of the tax line.
  - `rate`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The rate of the tax line.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `provider_id`: `string` (optional) — The associated provider's ID.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `data`: `null` | `Record<string, unknown>` (optional) — Holds data returned by the tax provider in key-value pairs.
- `adjustments`: [CreateOrderAdjustmentDTO](/resources/references/order/interfaces/orderCreateOrderAdjustmentDTO)\[] (optional) — The adjustments of the line item.
  - `code`: `string` (optional) — The code of the adjustment.
  - `amount`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The amount of the adjustment.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `description`: `string` (optional) — The description of the adjustment.
  - `promotion_id`: `string` (optional) — The associated promotion's ID.
  - `provider_id`: `string` (optional) — The associated provider's ID.
  - `is_tax_inclusive`: `boolean` (optional) — Whether the adjustment is tax inclusive.
  - `version`: `number` (optional) — The version of the adjustment.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
