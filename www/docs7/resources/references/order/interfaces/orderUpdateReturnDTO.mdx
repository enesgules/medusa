The attributes to update in the return.

**UpdateReturnDTO**

- `id`: `string` — The ID of the return.
- `location_id`: `null` | `string` (optional) — The ID of the location to return the items to.
- `refund_amount`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The refund amount of the return.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `no_notification`: `boolean` (optional) — Whether the customer should receive notifications related to updates on the return.
- `claim_id`: `string` (optional) — The associated claim's ID.
- `exchange_id`: `string` (optional) — The associated exchange's ID.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `items`: `object`\[] (optional) — The items of the return.
  - `quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The quantity of the item.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `null` | `string` (optional) — The internal note of the item.
  - `note`: `null` | `string` (optional) — The note of the item.
  - `reason_id`: `null` | `string` (optional) — The associated reason's ID.
  - `return_id`: `null` | `string` (optional) — The associated return's ID.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `status`: [ReturnStatus](/resources/references/order/types/orderReturnStatus) (optional) — The return's status.
- `requested_at`: `Date` (optional)
