title: UpdateOrderChangeDTO
---

The attributes to update in the order change.

**UpdateOrderChangeDTO**

- `id`: `string` — The ID of the order change.
- `status`: `string` (optional) — The status of the order change.
- `description`: `string` (optional) — The description of the order change.
- `return_id`: `null` | `string` (optional) — The associated return's ID.
- `internal_note`: `null` | `string` (optional) — The internal note of the order change.
- `requested_by`: `null` | `string` (optional) — The user or customer that requested the order change.
- `requested_at`: `null` | `Date` (optional) — The date the order change was requested.
- `confirmed_by`: `null` | `string` (optional) — The user or customer that confirmed the order change.
- `confirmed_at`: `null` | `Date` (optional) — The date the order change was confirmed.
- `declined_by`: `null` | `string` (optional) — The user or customer that declined the order change.
- `declined_reason`: `null` | `string` (optional) — The reason that the order change was declined.
- `declined_at`: `null` | `Date` (optional) — The date that the order change was declined.
- `canceled_by`: `null` | `string` (optional) — The user or customer that canceled the order change.
- `canceled_at`: `null` | `Date` (optional) — The date that the order change was canceled.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `carry_over_promotions`: `null` | `boolean` (optional) — Whether to carry over promotions to outbound exchange items.
- `no_notification`: `null` | `boolean` (optional) — Whether the customer shouldn't be notified of the order change.
