The attributes to update in the adjustment.

**UpdateOrderAdjustmentDTO**

- `id`: `string` — The ID of the adjustment.
- `code`: `string` (optional) — The code of the adjustment.
- `amount`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The amount of the adjustment.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `description`: `string` (optional) — The description of the adjustment.
- `promotion_id`: `string` (optional) — The associated promotion's ID.
- `provider_id`: `string` (optional) — The associated provider's ID.
