title: CreateOrderReturnItemDTO
---

The order return item to be created.

**CreateOrderReturnItemDTO**

- `return_id`: `string` — The ID of the associated return.
- `item_id`: `string` — The ID of the associated line item.
- `quantity`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) (optional) — The quantity to return.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `reason_id`: `string` (optional) — The ID of the associated return reason.
- `note`: `string` (optional) — The note of the return.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
