This documentation provides a reference to the `cancelFulfillment` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method cancels the fulfillment of an order, return, claim, or exchange.

## Example

```ts
await orderModuleService.cancelFulfillment({
  order_id: "123",
  items: [
    {
      id: "321",
      quantity: 1
    }
  ]
})
```
