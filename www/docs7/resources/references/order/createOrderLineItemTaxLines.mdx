## createOrderLineItemTaxLines(taxLines, sharedContext?): Promise\<[OrderLineItemTaxLineDTO](/resources/references/order/interfaces/orderOrderLineItemTaxLineDTO)\[]>

This method creates line item tax lines.

### Example

```ts
const lineItemTaxLines = await orderModuleService
  .createOrderLineItemTaxLines([
    {
      code: "123",
      rate: 2
    }
  ])
```
