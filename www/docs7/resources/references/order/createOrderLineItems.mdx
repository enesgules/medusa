This documentation provides a reference to the `createOrderLineItems` method. This belongs to the Order Module.

## createOrderLineItems(data, sharedContext?): Promise\<[OrderLineItemDTO](/resources/references/order/interfaces/orderOrderLineItemDTO)\[]>

This method creates a line item.

### Example

```ts
const lineItems = await orderModuleService.createOrderLineItems({
  title: "Shirt",
  quantity: 1,
  unit_price: 20
})
```
