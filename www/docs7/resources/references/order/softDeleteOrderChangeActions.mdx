This documentation provides a reference to the `softDeleteOrderChangeActions` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method soft-deletes order change actions by their IDs.

## Example

```ts
await orderModuleService.softDeleteOrderChangeActions([
  "123", "321"
])
```
