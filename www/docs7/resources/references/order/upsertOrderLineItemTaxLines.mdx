This documentation provides a reference to the `upsertOrderLineItemTaxLines` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method upserts line item tax lines.

## Example

```ts
const lineItemTaxLines = await orderModuleService
  .upsertOrderLineItemTaxLines(
    [
      {
        code: "123",
        rate: 2
      }
    ]
  )
```
