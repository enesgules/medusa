This documentation provides a reference to the `undoLastChange` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method reverts an order to its last change and keep the order changes and actions not applied.

## Example

```ts
await orderModuleService.revertLastChange("123")
```
