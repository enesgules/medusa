This documentation provides a reference to the `createOrderAddresses` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="createorderaddresses-data-sharedcontext-promiseorderaddressdto" />

## createOrderAddresses(data, sharedContext?): Promise\<[OrderAddressDTO](/resources/references/order/interfaces/orderOrderAddressDTO)\[]>

This method creates addresses.

### Example

```typescript
const addresses = await orderModuleService.createOrderAddresses([
  {
    first_name: "John",
    last_name: "Doe",
    address_1: "123 Main St",
    city: "Anytown",
    country_code: "us",
    province: "us-ca",
    postal_code: "12345"
  }
])
```
