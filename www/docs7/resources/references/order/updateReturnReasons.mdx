## updateReturnReasons(selector, data, sharedContext?): Promise\<[OrderReturnReasonDTO](/resources/references/order/interfaces/orderOrderReturnReasonDTO)\[]>

This method updates existing return reasons matching the specified filters.

### Example

```ts
const returnReasons = await orderModuleService.updateReturnReasons({
  id: "123"
}, {
  label: "Damaged"
})
```
