## createOrderShippingMethodTaxLines(taxLines, sharedContext?): Promise\<[OrderShippingMethodTaxLineDTO](/resources/references/order/interfaces/orderOrderShippingMethodTaxLineDTO)\[]>

This method creates shipping method tax lines.

### Example

```ts
const shippingMethodTaxLines = await orderModuleService
  .createOrderShippingMethodTaxLines([
    {
      code: "123",
```
