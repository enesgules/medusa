This documentation provides a reference to the `updateReturns` method. This belongs to the Order Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="updatereturns-data-sharedcontext-promisereturndto" />

## updateReturns(data, sharedContext?): Promise\<[ReturnDTO](/resources/references/order/interfaces/orderReturnDTO)\[]>

This method updates existing returns.

### Example

```ts
const returns = await orderModuleService.updateReturns([{
  selector: {
    id: "123"
  },
  data: {
    refund_amount: 10
  }
}])
```
