---
title: ValidateGiftCardsNotExpiredStepInput
---

Input to validate that none of the gift cards applied to a cart have expired.

**ValidateGiftCardsNotExpiredStepInput**

- `giftCards`: Pick\<[ModuleGiftCard](/resources/references/loyalty/types/loyaltyModuleGiftCard), "expires\_at" | "code">\[] — The gift cards applied to the cart.
  - `code`: `string` — The unique redemption code for the gift card.
  - `expires_at`: `string` | `null` — The date the gift card expires, or null if it does not expire.
