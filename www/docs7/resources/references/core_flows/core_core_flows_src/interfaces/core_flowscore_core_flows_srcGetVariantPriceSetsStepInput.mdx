The details of the variants to get price sets for.

**GetVariantPriceSetsStepInput**

- `variantIds`: `string`\[] — The IDs of the variants to get price sets for.
- `context`: `Record<string, unknown>` (optional) — The context to use when calculating the price sets. Learn more in [this documentation](/resources/commerce-modules/product/guides/price#retrieve-calculated-price-for-a-context).
