---
title: FetchShippingOptionForDraftOrderWorkflowInput
---

The data to fetch a shipping option's price for a draft order.

**FetchShippingOptionForDraftOrderWorkflowInput**

- `shipping_option_id`: `string` — The ID of the shipping option to fetch.
- `order_id`: `string` — The ID of the draft order.
- `currency_code`: `string` — The currency code of the draft order (used for flat-rate pricing).
