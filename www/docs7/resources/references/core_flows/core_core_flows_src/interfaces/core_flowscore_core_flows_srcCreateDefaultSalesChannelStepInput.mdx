title: CreateDefaultSalesChannelStepInput

The data to create a default sales channel.

**CreateDefaultSalesChannelStepInput**

- `data`: [CreateSalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelCreateSalesChannelDTO) — The default sales channel data.
  - `name`: `string` — The name of the sales channel.
  - `description`: `null` | `string` (optional) — The description of the sales channel.
  - `is_disabled`: `boolean` (optional) — Whether the sales channel is disabled.
