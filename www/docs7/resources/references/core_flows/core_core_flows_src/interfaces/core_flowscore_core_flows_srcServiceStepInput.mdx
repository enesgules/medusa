The remote query's details.

**ServiceStepInput**

- `fields`: `string`\[] — The fields to retrieve in the records.
- `variables`: `Record<string, any>` (optional) — Filters, context variables, or pagination fields to apply when retrieving the records.
- `throw_if_key_not_found`: `boolean` (optional) — Throw an error if a record isn't found matching an ID specified in the filters.
- `throw_if_relation_not_found`: `boolean` | `string`\[] (optional) — Throw an error if a specified relation isn't found.
- `list`: `boolean` (optional, default: true) — Whether to retrieve the records as an array. If disabled, only one record is retrieved as an object.
- `service`: `string` — The name of the module's service.
