title: AssociateProductsWithSalesChannelsStepInput

The data to associate products with sales channels.

**AssociateProductsWithSalesChannelsStepInput**

- `links`: `object`\[] — The links to create between products and sales channels.
  - `sales_channel_id`: `string` — The ID of the sales channel.
  - `product_id`: `string` — The ID of the product.
