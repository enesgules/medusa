title: AddDraftOrderShippingMethodsWorkflowInput

The details of the shipping methods to add to a draft order.

**AddDraftOrderShippingMethodsWorkflowInput**

- `order_id`: `string` — The ID of the draft order to add the shipping methods to.
- `shipping_option_id`: `string` — The ID of the shipping option to add as a shipping method.
- `custom_amount`: `null` | [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — The custom amount to add the shipping method with. If not specified, the shipping option's fixed or calculated price will be used.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
