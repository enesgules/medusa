---
title: BatchTranslationSettingsWorkflowInput
---

The translation settings to manage.

**BatchTranslationSettingsWorkflowInput**

- `create`: [CreateTranslationSettingsDTO](/resources/references/translation/interfaces/translationCreateTranslationSettingsDTO)\[] — Translation settings to create.
  - `entity_type`: `string` — The entity type.

    Example:

    ```
    "product"
    ```
  - `fields`: `string`\[] — The translatable fields.

    Example:

    ```
    ["title", "description", "material"]
    ```
  - `is_active`: `boolean` (optional) — Whether the entity translatable status is enabled.
- `update`: [UpdateTranslationSettingsDTO](/resources/references/translation/interfaces/translationUpdateTranslationSettingsDTO)\[] — Translation settings to update.
  - `id`: `string` — The ID of the translation settings to update.
  - `entity_type`: `string` (optional) — The entity type.

    Example:

    ```
    "product"
    ```
  - `fields`: `string`\[] (optional) — The translatable fields.

    Example:

    ```
    ["title", "description", "material"]
    ```
  - `is_active`: `boolean` (optional) — Whether the entity translatable status is enabled.
- `delete`: `string`\[] — Translation settings IDs to delete.
