title: SetRegionsPaymentProvidersStepInput

The data to set the payment providers available in regions.

**SetRegionsPaymentProvidersStepInput**

- `input`: `object`\[] — The regions to set the payment providers for.
  - `id`: `string` — The ID of the region.
  - `payment_providers`: `string`\[] (optional) — The IDs of the payment providers that are available in the region.
