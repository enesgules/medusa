---
title: BatchShippingOptionRulesInput
---

The data to manage the shipping option rules in bulk.

**BatchShippingOptionRulesInput**

- `create`: [CreateShippingOptionRuleDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateShippingOptionRuleDTO)\[] (optional) — The shipping option rules to create.
  - `attribute`: `string` — The attribute of the shipping option rule.
  - `operator`: [RuleOperatorType](/resources/references/fulfillment/types/fulfillmentRuleOperatorType) — The operator of the shipping option rule.
  - `value`: `string` | `string`\[] — The value(s) of the shipping option rule.
  - `shipping_option_id`: `string` — The associated shipping option's ID.
- `update`: [UpdateShippingOptionRuleDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateShippingOptionRuleDTO)\[] (optional) — The shipping option rules to update.
  - `attribute`: `string` (optional) — The attribute of the shipping option rule.
  - `operator`: [RuleOperatorType](/resources/references/fulfillment/types/fulfillmentRuleOperatorType) (optional) — The operator of the shipping option rule.
  - `value`: `string` | `string`\[] (optional) — The value(s) of the shipping option rule.
  - `shipping_option_id`: `string` (optional) — The associated shipping option's ID.
  - `id`: `string` — The ID of the shipping option rule.
- `delete`: `string`\[] (optional) — The IDs of the shipping option rules to delete.
