---
title: PrepareAdjustmentsFromPromotionActionsStepOutput
---

The details of the adjustments to create and remove.

**PrepareAdjustmentsFromPromotionActionsStepOutput**

- `lineItemAdjustmentsToCreate`: `object`\[] — The line item adjustments to create.
  - `code`: `string` — The promotion code that computed the adjustment.
  - `amount`: `number` — The amount of the adjustment.
  - `item_id`: `string` — The ID of the line item to adjust.
  - `promotion_id`: `string` (optional) — The ID of the applied promotion.
- `lineItemAdjustmentIdsToRemove`: `string`\[] — The line item adjustment IDs to remove.
- `shippingMethodAdjustmentsToCreate`: `object`\[] — The shipping method adjustments to create.
  - `code`: `string` — The promotion code that computed the adjustment.
  - `amount`: `number` — The amount of the adjustment.
  - `shipping_method_id`: `string` — The ID of the shipping method to adjust.
  - `promotion_id`: `string` (optional) — The ID of the applied promotion.
- `shippingMethodAdjustmentIdsToRemove`: `string`\[] — The shipping method adjustment IDs to remove.
- `computedPromotionCodes`: `string`\[] — The promotion codes that were computed.
- `skippedPromoCodes`: `object`\[] — The promotion codes that could not be applied, along with the reason.
  - `code`: `string` — The promotion code that was skipped.
  - `reason`: `"promotion_limit_exceeded"` | `"campaign_budget_exceeded"` — The reason the promotion code was skipped. - `promotion_limit_exceeded`: the promotion's usage limit has been reached. - `campaign_budget_exceeded`: the promotion's campaign budget has been exhausted.
