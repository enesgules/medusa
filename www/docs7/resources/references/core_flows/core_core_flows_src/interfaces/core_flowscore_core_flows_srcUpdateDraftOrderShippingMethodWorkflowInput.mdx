title: UpdateDraftOrderShippingMethodWorkflowInput
---

The details of the shipping method to update in the order edit.

**UpdateDraftOrderShippingMethodWorkflowInput**

- `order_id`: `string` — The ID of the order to update the shipping method in its edit.
- `data`: `object`
  - `shipping_method_id`: `string` — The ID of the shipping method to update.
  - `shipping_option_id`: `string` (optional) — The ID of the shipping method's option.
  - `custom_amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — Set a custom amount for the shipping method.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `null` | `string` (optional) — A note viewed by admins only related to the shipping method.
