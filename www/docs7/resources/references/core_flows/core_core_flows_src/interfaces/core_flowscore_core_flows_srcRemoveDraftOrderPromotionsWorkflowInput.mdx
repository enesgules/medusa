The details of the promotions to remove from a draft order.

**RemoveDraftOrderPromotionsWorkflowInput**

- `order_id`: `string` — The ID of the draft order to remove the promotions from.
- `promo_codes`: `string`\[] — The codes of the promotions to remove from the draft order.
