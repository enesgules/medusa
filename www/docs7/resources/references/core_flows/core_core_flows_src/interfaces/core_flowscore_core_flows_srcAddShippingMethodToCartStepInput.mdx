title: AddShippingMethodToCartStepInput
---

The details of the shipping methods to add.

**AddShippingMethodToCartStepInput**

- `shipping_methods`: [CreateShippingMethodDTO](/resources/references/cart/interfaces/cartCreateShippingMethodDTO)\[] — The shipping methods to add.
  - `name`: `string` — The name of the shipping method.
  - `cart_id`: `string` — The associated cart's ID.
  - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount of the shipping method.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `shipping_option_id`: `string` (optional) — The amount of the shipping method.
  - `data`: `Record<string, unknown>` (optional) — The data of the shipping method.
  - `tax_lines`: [CreateTaxLineDTO](/resources/references/cart/interfaces/cartCreateTaxLineDTO)\[] (optional) — The tax lines of the shipping method.
    - `description`: `string` (optional) — The description of the tax line.
    - `tax_rate_id`: `string` (optional) — The associated tax rate's ID.
    - `code`: `string` — The code of the tax line.
    - `rate`: `number` — The rate of the tax line.
    - `provider_id`: `string` (optional) — The associated provider's ID.
    - `item_id`: `string` (optional) — The associated item's ID.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
    - `data`: `null` | `Record<string, unknown>` (optional) — Holds data returned by the tax provider in key-value pairs.
  - `adjustments`: [CreateAdjustmentDTO](/resources/references/cart/interfaces/cartCreateAdjustmentDTO)\[] (optional) — The adjustments of the shipping method.
    - `code`: `string` — The code of the promotion that lead to this adjustment.
    - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount to adjust the original amount with.
    - `is_tax_inclusive`: `boolean` (optional) — Whether the adjustment amount includes tax.
    - `description`: `string` (optional) — The description of the adjustment.
    - `promotion_id`: `string` (optional) — The associated promotion's ID.
    - `provider_id`: `string` (optional) — The associated provider's ID.
