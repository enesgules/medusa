---
title: BatchTranslationsWorkflowInput
---

The translations to manage.

- `BatchTranslationsWorkflowInput`: `object` — The translations to manage.
  - `create`: [CreateTranslationDTO](/resources/references/translation/interfaces/translationCreateTranslationDTO)\[] — The translations to create.
    - `reference_id`: `string` — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
  - `update`: [UpdateTranslationDTO](/resources/references/translation/interfaces/translationUpdateTranslationDTO)\[] — The translations to update.
    - `reference_id`: `string` (optional) — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` (optional) — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` (optional) — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` (optional) — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
    - `id`: `string` — The ID of the translation to update.
  - `delete`: `string`\[] — The IDs of the translations to delete.
