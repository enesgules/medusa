The data to request a draft order edit.

- `RequestDraftOrderEditWorkflowInput`: `object` — The data to request a draft order edit.
  - `order_id`: `string` — The ID of the draft order to request the edit for.
  - `requested_by`: `string` (optional) — The ID of the user requesting the edit.
