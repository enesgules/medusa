---
title: OrderEditRequestWorkflowInput
---

The data to request an order edit.

- `OrderEditRequestWorkflowInput`: `object` — The data to request an order edit.
  - `order_id`: `string` — The ID of the order to request the edit for.
  - `requested_by`: `string` (optional) — The ID of the user requesting the edit.
  - `no_notification`: `boolean` (optional) — Whether to prevent sending the customer a notification about the order edit. The value is stored on the order change and passed to the emitted `order-edit.requested` event, allowing subscribers to check it before sending a notification.
