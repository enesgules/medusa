The data to confirm a return receival request.

- `ConfirmReceiveReturnRequestWorkflowInput`: `object` — The data to confirm a return receival request.
  - `return_id`: `string` — The ID of the return to confirm the receival for.
  - `confirmed_by`: `string` (optional) — The ID of the user that's confirming the return receival.
