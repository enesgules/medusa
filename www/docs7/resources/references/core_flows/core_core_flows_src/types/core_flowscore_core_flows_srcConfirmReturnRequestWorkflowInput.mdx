title: ConfirmReturnRequestWorkflowInput

The details of confirming a return request.

- `ConfirmReturnRequestWorkflowInput`: `object` — The details of confirming a return request.
  - `return_id`: `string` — The ID of the return to confirm its request.
  - `confirmed_by`: `string` (optional) — The ID of the user confirming the return request.
