The data to create a shipping method for an order edit.

- `CreateOrderEditShippingMethodWorkflowInput`: `object` — The data to create a shipping method for an order edit.
  - `order_id`: `string` — The ID of the order to create the shipping method for.
  - `shipping_option_id`: `string` — The ID of the shipping option to create the shipping method from.
  - `custom_amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) | `null` (optional) — The custom amount to create the shipping method with. If not provided, the shipping option's amount is used.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
