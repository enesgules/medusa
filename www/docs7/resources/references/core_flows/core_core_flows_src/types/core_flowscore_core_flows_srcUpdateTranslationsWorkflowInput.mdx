title: UpdateTranslationsWorkflowInput
---

The translations to update.

- `UpdateTranslationsWorkflowInput`: [UpdateTranslationsStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdateTranslationsStepInput) — The translations to update.
  - `selector`: [FilterableTranslationProps](/resources/references/translation/interfaces/translationFilterableTranslationProps) — The filters to select the translations to update.
    - `$and`: ([FilterableTranslationProps](/resources/references/translation/interfaces/translationFilterableTranslationProps) | [BaseFilterable](/resources/references/translation/interfaces/translationBaseFilterable)\<[FilterableTranslationProps](/resources/references/translation/interfaces/translationFilterableTranslationProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "and" condition.
    - `$or`: ([FilterableTranslationProps](/resources/references/translation/interfaces/translationFilterableTranslationProps) | [BaseFilterable](/resources/references/translation/interfaces/translationBaseFilterable)\<[FilterableTranslationProps](/resources/references/translation/interfaces/translationFilterableTranslationProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "or" condition.
    - `q`: `string` (optional) — Search through translated content using this search term. This searches within the JSONB translations field values.
    - `id`: `string` | `string`\[] | [OperatorMap](/resources/references/translation/types/translationOperatorMap)\<string | string\[]> (optional) — The IDs to filter the translations by.
    - `reference_id`: `string` | `string`\[] | [OperatorMap](/resources/references/translation/types/translationOperatorMap)\<string> (optional) — Filter translations by entity ID.
    - `reference`: `string` | `string`\[] | [OperatorMap](/resources/references/translation/types/translationOperatorMap)\<string> (optional) — Filter translations by entity type.
    - `locale_code`: `string` | `string`\[] | [OperatorMap](/resources/references/translation/types/translationOperatorMap)\<string> (optional) — Filter translations by locale code.
  - `update`: [UpdateTranslationDataDTO](/resources/references/translation/interfaces/translationUpdateTranslationDataDTO) — The data to update in the translations.
    - `reference_id`: `string` (optional) — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` (optional) — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` (optional) — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` (optional) — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
  - `translations`: [UpdateTranslationDTO](/resources/references/translation/interfaces/translationUpdateTranslationDTO)\[] — The translations to update by ID.
    - `reference_id`: `string` (optional) — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` (optional) — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` (optional) — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` (optional) — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
    - `id`: `string` — The ID of the translation to update.
