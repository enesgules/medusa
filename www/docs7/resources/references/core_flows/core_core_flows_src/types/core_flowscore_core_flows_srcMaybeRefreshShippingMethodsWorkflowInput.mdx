---
title: MaybeRefreshShippingMethodsWorkflowInput
---

The data to create a shipping method for an order edit.

- `MaybeRefreshShippingMethodsWorkflowInput`: `object` — The data to create a shipping method for an order edit.
  - `shipping_method_id`: `string` — The ID of the shipping method to refresh.
  - `order_id`: `string` — The ID of the order.
  - `action_id`: `string` — The ID of the ADD SHIPPING action to update.
  - `context`: `CalculatedRMAShippingContext` — Data to pass for the shipping calculation.
