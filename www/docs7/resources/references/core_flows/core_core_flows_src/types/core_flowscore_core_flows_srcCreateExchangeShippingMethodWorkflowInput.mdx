title: CreateExchangeShippingMethodWorkflowInput
---

The details to create the shipping method for the exchange.

- `CreateExchangeShippingMethodWorkflowInput`: `object` — The details to create the shipping method for the exchange.
  - `return_id`: `string` (optional) — The ID of the return associated with the exchange. If set, an inbound shipping method will be created for the return. If not set, an outbound shipping method will be created for the exchange.
  - `exchange_id`: `string` (optional) — The ID of the exchange to create the shipping method for.
  - `shipping_option_id`: `string` — The ID of the shipping option to create the shipping method from.
  - `custom_amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) | `null` (optional) — The custom amount to charge for the shipping method. If not set, the shipping option's amount is used.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
