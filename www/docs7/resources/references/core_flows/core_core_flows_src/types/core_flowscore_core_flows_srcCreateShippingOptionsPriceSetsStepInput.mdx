title: CreateShippingOptionsPriceSetsStepInput
---

The data to create price sets for shipping options.

- `CreateShippingOptionsPriceSetsStepInput`: `object`\[] — The data to create price sets for shipping options.
  - `id`: `string` — The ID of the shipping option.
  - `prices`: ([ShippingOptionsPriceCurrencyCode](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcShippingOptionsPriceCurrencyCode) | `ShippingOptionsPriceRegionId`)\[] — The prices to create for the shipping option.
    - `currency_code`: `string` — The currency code of the price.

      Example:

      ```
      usd
      ```
    - `amount`: `number` — The amount of the price.
    - `rules`: [PriceRule](/resources/references/pricing/models/PriceRule)\[] (optional) — The rules of the price.
