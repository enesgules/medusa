The data to refund a payment.

- `RefundPaymentsWorkflowInput`: `object`\[] — The data to refund a payment.
  - `payment_id`: `string` — The ID of the payment to refund.
  - `amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) — The amount to refund. Must be less than the refundable amount of the payment.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `created_by`: `string` (optional) — The ID of the user that's refunding the payment.
  - `note`: `string` (optional) — The note to attach to the refund.
  - `metadata`: `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
