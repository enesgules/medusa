title: UpdateCartPromotionsWorkflowInput
---

The details of the promotion updates on a cart.

- `UpdateCartPromotionsWorkflowInput`: `object` — The details of the promotion updates on a cart.
  - `cart_id`: `string` (optional) — The cart's ID.
  - `cart`: `any` (optional) — The Cart reference.
  - `promo_codes`: `string`\[] (optional) — The promotion codes to add to the cart, remove from the cart, or replace all existing promotions in the cart.
  - `action`: [ADD](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#add) | [REMOVE](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#remove) | [REPLACE](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#replace) (optional) — The action to perform with the specified promotion codes.
  - `force_refresh_payment_collection`: `boolean` (optional) — Wether to force the refresh of the cart payment collection. If the caller doesn't refresh it explicitly, you should probably set this property to true.
