---
title: UpdatePriceSetsStepInput
---

The data to update price sets. You can either update price sets with a selector
or by providing IDs in the price set objects to update.

- `UpdatePriceSetsStepInput`: `object` | `object` — The data to update price sets. You can either update price sets with a selector or by providing IDs in the price set objects to update.
  - `selector`: [FilterablePriceSetProps](/resources/references/pricing/interfaces/pricingFilterablePriceSetProps) (optional) — The filters to select which price sets to update.
    - `$and`: ([FilterablePriceSetProps](/resources/references/pricing/interfaces/pricingFilterablePriceSetProps) | [BaseFilterable](/resources/references/pricing/interfaces/pricingBaseFilterable)\<[FilterablePriceSetProps](/resources/references/pricing/interfaces/pricingFilterablePriceSetProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "and" condition.
    - `$or`: ([FilterablePriceSetProps](/resources/references/pricing/interfaces/pricingFilterablePriceSetProps) | [BaseFilterable](/resources/references/pricing/interfaces/pricingBaseFilterable)\<[FilterablePriceSetProps](/resources/references/pricing/interfaces/pricingFilterablePriceSetProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "or" condition.
    - `context`: `Record<string, [BigNumberInput](/references/pricing/types/pricing.BigNumberInput)>` (optional) — an object whose keys are the name of the context attribute. Its value can be a string or a BigNumberInput. For example, you can pass the `currency_code` property with its value being the currency code to calculate the price in. Another example is passing the `quantity` property to calculate the price for that specified quantity, which finds a price set whose `min_quantity` and `max_quantity` conditions match the specified quantity.
    - `id`: `string`\[] (optional) — IDs to filter price sets by.
    - `prices`: [FilterableMoneyAmountProps](/resources/references/pricing/interfaces/pricingFilterableMoneyAmountProps) (optional) — Filters to apply on a price set's associated money amounts.
  - `update`: [UpdatePriceSetDTO](/resources/references/pricing/interfaces/pricingUpdatePriceSetDTO) (optional) — The data to update the price sets with.
    - `prices`: [CreatePricesDTO](/resources/references/pricing/interfaces/pricingCreatePricesDTO)\[] (optional) — The prices to create and add to this price set.
  - `price_sets`: [UpsertPriceSetDTO](/resources/references/pricing/interfaces/pricingUpsertPriceSetDTO)\[] — The price sets to update.
    - `id`: `string` (optional) — A string indicating the ID of the price set to update. If not provided, a price set is created.
    - `prices`: [CreatePricesDTO](/resources/references/pricing/interfaces/pricingCreatePricesDTO)\[] (optional) — The prices to create and add to this price set.
