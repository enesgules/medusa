---
title: CreateClaimShippingMethodWorkflowInput
---

The data to create a shipping method for a claim.

- `CreateClaimShippingMethodWorkflowInput`: `object` — The data to create a shipping method for a claim.
  - `return_id`: `string` (optional) — The ID of the return associated with the claim. If this is set, the shipping method will be created as an inbound (return) shipping method. If not set, the shipping method will be created as an outbound (delivering new items) shipping method.
  - `claim_id`: `string` (optional) — The ID of the claim to create the shipping method for.
  - `shipping_option_id`: `string` — The ID of the shipping option to create the shipping method from.
  - `custom_amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) | `null` (optional) — A custom amount to set for the shipping method. If not set, the shipping option's amount is used.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
