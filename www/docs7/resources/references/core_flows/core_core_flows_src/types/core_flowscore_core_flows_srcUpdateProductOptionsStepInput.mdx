The data to identify and update the product options.

- `UpdateProductOptionsStepInput`: `object` — The data to identify and update the product options.
  - `selector`: [FilterableProductOptionProps](/resources/references/product/interfaces/productFilterableProductOptionProps) — The filters to select the product options to update.
    - `$and`: ([FilterableProductOptionProps](/resources/references/product/interfaces/productFilterableProductOptionProps) | [BaseFilterable](/resources/references/product/interfaces/productBaseFilterable)\<[FilterableProductOptionProps](/resources/references/product/interfaces/productFilterableProductOptionProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "and" condition.
    - `$or`: ([FilterableProductOptionProps](/resources/references/product/interfaces/productFilterableProductOptionProps) | [BaseFilterable](/resources/references/product/interfaces/productBaseFilterable)\<[FilterableProductOptionProps](/resources/references/product/interfaces/productFilterableProductOptionProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "or" condition.
    - `q`: `string` (optional) — Search through the options' titles.
    - `id`: `string` | `string`\[] (optional) — The IDs to filter product options by.
    - `title`: `string` | `string`\[] (optional) — The titles to filter product options by.
    - `is_exclusive`: `boolean` (optional) — Filter the product options by whether they are exclusive to a product or shared across products.
  - `update`: [UpdateProductOptionDTO](/resources/references/product/interfaces/productUpdateProductOptionDTO) — The data to update the product options with.
    - `title`: `string` (optional) — The product option's title.
    - `values`: `string`\[] (optional) — The product option values.
    - `ranks`: `Record<string, number>` (optional) — The rank for each option value. The key is the option value, and the value is the rank.

      Example:

      ```
      { * "Small": 1, * "Medium": 2, * "Large": 3 * }
      ```
    - `is_exclusive`: `boolean` (optional) — Whether the product option is exclusive to a product or shared across products.
    - `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — The metadata of the product option.
