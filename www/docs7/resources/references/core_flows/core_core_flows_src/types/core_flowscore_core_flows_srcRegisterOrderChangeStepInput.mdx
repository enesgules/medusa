---
title: RegisterOrderChangeStepInput
---

The input of the register order changes step.

- `RegisterOrderChangeStepInput`: [RegisterOrderChangeDTO](/resources/references/order/interfaces/orderRegisterOrderChangeDTO)\[] — The input of the register order changes step.
  - `order_id`: `string` — The associated order's ID.
  - `change_type`: [OrderChangeType](/resources/references/order/types/orderOrderChangeType) (optional) — The type of the order change.
  - `description`: `string` (optional) — The description of the order change.
  - `internal_note`: `null` | `string` (optional) — The internal note of the order change.
  - `created_by`: `string` (optional) — The user that created the order change.
  - `confirmed_by`: `string` (optional) — The user or customer that confirmed the order change.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `details`: `Record<string, unknown>` (optional) — The details of the order change action
  - `reference`: `string` (optional) — The name of the data model that this change references. For example, `shipping_address`.
  - `reference_id`: `string` (optional) — The ID of the data model's record referenced.
