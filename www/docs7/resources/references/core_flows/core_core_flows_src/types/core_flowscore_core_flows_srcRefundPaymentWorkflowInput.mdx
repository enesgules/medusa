title: RefundPaymentWorkflowInput
---

The data to refund a payment.

- `RefundPaymentWorkflowInput`: `object` — The data to refund a payment.
  - `payment_id`: `string` — The ID of the payment to refund.
  - `created_by`: `string` (optional) — The ID of the user that refunded the payment.
  - `amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — The amount to refund. If not provided, the full payment amount will be refunded.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `note`: `string` (optional) — The note to attach to the refund.
  - `refund_reason_id`: `string` (optional) — The ID of the refund reason to attach to the refund.
