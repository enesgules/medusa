title: BatchPropertyLabelsWorkflowOutput
---

Output type for batch property labels workflow.

> **Note**
>
> This is available starting from [Medusa v2.13.7](https://github.com/medusajs/medusa/releases/tag/v2.13.7).

- `BatchPropertyLabelsWorkflowOutput`: [BatchWorkflowOutput](/resources/references/types/CommonTypes/types/typesCommonTypesBatchWorkflowOutput)\<[PropertyLabelDTO](/resources/references/settings/interfaces/settingsPropertyLabelDTO)> — Output type for batch property labels workflow.
  - `created`: T\[] — The records that were created in the bulk operation.
  - `updated`: T\[] — The records that were updated in the bulk operation.
  - `deleted`: `string`\[] — The IDs of the records deleted in the bulk operation.
