---
title: AddProductOptionsToProductStepInput
---

The data to add one or more product options to products.

- `AddProductOptionsToProductStepInput`: [ProductOptionProductPair](/resources/references/product/interfaces/productProductOptionProductPair)\[] — The data to add one or more product options to products.
  - `product_option_id`: `string` — The product option's ID.
  - `product_id`: `string` — The product's ID.
  - `product_option_value_ids`: `string`\[] (optional) — The IDs of specific option values to link. If not provided, all values will be linked.
