title: AddOrderTransactionStepInput
---

The transaction(s) to add to the order.

- `AddOrderTransactionStepInput`: [CreateOrderTransactionDTO](/resources/references/order/interfaces/orderCreateOrderTransactionDTO) | [CreateOrderTransactionDTO](/resources/references/order/interfaces/orderCreateOrderTransactionDTO)\[] — The transaction(s) to add to the order.
  - `order_id`: `string` — The associated order's ID.
  - `return_id`: `string` (optional) — The associated return's ID.
  - `claim_id`: `string` (optional) — The associated claim's ID.
  - `exchange_id`: `string` (optional) — The associated exchange's ID.
  - `reference`: `string` (optional) — The data model this transaction references. For example, `payment`.
  - `reference_id`: `string` (optional) — The ID of the data model's record referenced. For example, `pay_132`.
  - `amount`: [BigNumberInput](/resources/references/order/types/orderBigNumberInput) — The amount of the transaction.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/order/types/orderBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `currency_code`: `string` — The currency code of the transaction.
