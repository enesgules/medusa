The data to create sales channels.

- `CreateSalesChannelsWorkflowInput`: `object` — The data to create sales channels.
  - `salesChannelsData`: [CreateSalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelCreateSalesChannelDTO)\[] — The sales channels to create.
    - `name`: `string` — The name of the sales channel.
    - `description`: `null` | `string` (optional) — The description of the sales channel.
    - `is_disabled`: `boolean` (optional) — Whether the sales channel is disabled.
