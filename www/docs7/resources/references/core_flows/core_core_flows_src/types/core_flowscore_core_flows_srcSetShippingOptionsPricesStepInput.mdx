title: SetShippingOptionsPricesStepInput
---

The data to set the prices of a shipping option.

- `SetShippingOptionsPricesStepInput`: `object`\[] — The data to set the prices of a shipping option.
  - `id`: `string` — The ID of the shipping option.
  - `prices`: [UpdateShippingOptionPriceRecord](/resources/references/types/WorkflowTypes/FulfillmentWorkflow/types/typesWorkflowTypesFulfillmentWorkflowUpdateShippingOptionPriceRecord)\[] (optional) — The prices of the shipping option.
    - `id`: `string` (optional) — The ID of the price record.
    - `currency_code`: `string` (optional) — The currency code of the price.

      Example:

      ```
      usd
      ```
    - `amount`: `number` (optional) — The amount of the price.
    - `rules`: [PriceRule](/resources/references/pricing/models/PriceRule)\[] (optional) — The rules of the price.
    - `region_id`: `string` (optional) — The ID of the region that this price applies in.
