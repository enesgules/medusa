    - `label`: `string` — The label of the return reason.
    - `description`: `string` (optional) — The description of the return reason.
    - `parent_return_reason_id`: `null` | `string` (optional) — The associated parent return reason's ID.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
