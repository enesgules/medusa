---
title: UpdateViewConfigurationStepInput
---

The input for updating a view configuration.

- `UpdateViewConfigurationStepInput`: `object` — The input for updating a view configuration.
  - `id`: `string` — The ID of the view configuration to update.
  - `data`: [UpdateViewConfigurationDTO](/resources/references/settings/interfaces/settingsUpdateViewConfigurationDTO) — The attributes to update in the view configuration.
    - `name`: `string` (optional) — The name of the configuration.
    - `configuration`: `object` (optional) — The configuration data.
