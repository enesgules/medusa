---
title: CreateOrUpdateOrderPaymentCollectionInput
---

The details of the order payment collection to create or update.

- `CreateOrUpdateOrderPaymentCollectionInput`: `object` — The details of the order payment collection to create or update.
  - `order_id`: `string` — The order to create or update payment collection for.
  - `amount`: `number` (optional) — The amount to charge. It can't be greater than the pending amount of the order. The order's payment collection will be created or updated with this amount. If no amount is set, the payment collection's amount is set to `0`.
