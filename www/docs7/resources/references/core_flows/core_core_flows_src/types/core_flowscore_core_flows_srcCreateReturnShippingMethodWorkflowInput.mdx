title: CreateReturnShippingMethodWorkflowInput
---

The data to create a shipping method for a return.

- `CreateReturnShippingMethodWorkflowInput`: `object` — The data to create a shipping method for a return.
  - `return_id`: `string` — The ID of the return to create the shipping method for.
  - `claim_id`: `string` (optional) — The ID of the claim associated with the return, if any.
  - `exchange_id`: `string` (optional) — The ID of the exchange associated with the return, if any.
  - `shipping_option_id`: `string` — The ID of the shipping option to create the shipping method from.
  - `custom_amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) | `null` (optional) — The custom amount to charge for the shipping method. If not provided, the amount from the shipping option will be used.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
