---
title: AuthorizePaymentSessionStepInput
---

The data to authorize the payment session.

- `AuthorizePaymentSessionStepInput`: `object` — The data to authorize the payment session.
  - `id`: `string` — The ID of the payment session to authorize.
  - `context`: `Record<string, unknown>` (optional) — The context to authorize the payment session with. This context is passed to the payment provider associated with the payment session.
