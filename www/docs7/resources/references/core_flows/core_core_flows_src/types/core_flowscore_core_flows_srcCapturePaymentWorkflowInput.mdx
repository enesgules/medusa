title: CapturePaymentWorkflowInput
---

The data to capture a payment.

- `CapturePaymentWorkflowInput`: `object` — The data to capture a payment.
  - `payment_id`: `string` — The ID of the payment to capture.
  - `captured_by`: `string` (optional) — The ID of the user that captured the payment.
  - `amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — The amount to capture. If not provided, the full payment amount will be captured.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
