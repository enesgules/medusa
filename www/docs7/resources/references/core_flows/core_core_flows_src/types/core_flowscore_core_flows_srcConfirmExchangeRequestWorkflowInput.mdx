title: ConfirmExchangeRequestWorkflowInput

The details to confirm an exchange request.

- `ConfirmExchangeRequestWorkflowInput`: `object` — The details to confirm an exchange request.
  - `exchange_id`: `string` — The ID of the exchange to confirm.
  - `confirmed_by`: `string` (optional) — The ID of the user that's confirming the exchange.
