---
title: RemoveProductOptionsFromProductStepInput
---

The data to remove one or more product options from products.

- `RemoveProductOptionsFromProductStepInput`: [ProductOptionProductPair](/resources/references/product/interfaces/productProductOptionProductPair)\[] — The data to remove one or more product options from products.
  - `product_option_id`: `string` — The product option's ID.
  - `product_id`: `string` — The product's ID.
  - `product_option_value_ids`: `string`\[] (optional) — The IDs of specific option values to link. If not provided, all values will be linked.
