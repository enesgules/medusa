The data to create one or more fulfillment sets.

- `CreateFulfillmentSetsStepInput`: [CreateFulfillmentSetDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateFulfillmentSetDTO)\[] — The data to create one or more fulfillment sets.
  - `name`: `string` — The name of the fulfillment set.
  - `type`: `string` — The type of the fulfillment set.
  - `service_zones`: Omit\<[CreateServiceZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateServiceZoneDTO), "fulfillment\_set\_id">\[] (optional) — The service zones associated with the fulfillment set.
    - `name`: `string` — The name of the service zone.
    - `geo_zones`: (Omit\<[CreateCountryGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCountryGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateProvinceGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateProvinceGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateCityGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCityGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateZipGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateZipGeoZoneDTO), "service\_zone\_id">)\[] (optional) — The geo zones associated with the service zone.
