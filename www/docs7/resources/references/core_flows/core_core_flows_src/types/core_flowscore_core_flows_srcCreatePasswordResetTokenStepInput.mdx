---
title: CreatePasswordResetTokenStepInput
---

Input for the create password reset token step.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `CreatePasswordResetTokenStepInput`: `object` — Input for the create password reset token step.
  - `entityId`: `string` — The entity ID for which to create the password reset token.
  - `provider`: `string` — The auth provider name.
  - `ttlSeconds`: `number` — Time-to-live for the token in seconds.
