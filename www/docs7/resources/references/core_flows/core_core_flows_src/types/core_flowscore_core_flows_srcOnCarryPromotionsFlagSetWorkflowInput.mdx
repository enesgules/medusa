---
title: OnCarryPromotionsFlagSetWorkflowInput
---

The data to set the carry over promotions flag for an order change.

- `OnCarryPromotionsFlagSetWorkflowInput`: `object` — The data to set the carry over promotions flag for an order change.
  - `order_change_id`: `string` — The order change's ID.
  - `carry_over_promotions`: `boolean` — Whether to carry over promotions to outbound exchange items.
