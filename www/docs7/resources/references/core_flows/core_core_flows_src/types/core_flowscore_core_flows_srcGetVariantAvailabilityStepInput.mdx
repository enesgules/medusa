title: GetVariantAvailabilityStepInput

The details required to compute the inventory availability for a list of variants in a given sales channel.

- `GetVariantAvailabilityStepInput`: `object` — The details required to compute the inventory availability for a list of variants in a given sales channel.
  - `variant_ids`: `string`\[] — The IDs of the variants to retrieve their availability.
  - `sales_channel_id`: `string` — The ID of the sales channel to retrieve the variant availability in.
