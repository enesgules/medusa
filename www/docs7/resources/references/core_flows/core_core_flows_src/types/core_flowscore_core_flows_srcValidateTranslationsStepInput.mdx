title: ValidateTranslationsStepInput
---

- `ValidateTranslationsStepInput`: [CreateTranslationDTO](/resources/references/translation/interfaces/translationCreateTranslationDTO)\[] | [CreateTranslationDTO](/resources/references/translation/interfaces/translationCreateTranslationDTO) | [UpdateTranslationDTO](/resources/references/translation/interfaces/translationUpdateTranslationDTO)\[] | [UpdateTranslationDTO](/resources/references/translation/interfaces/translationUpdateTranslationDTO) | [UpdateTranslationDataDTO](/resources/references/translation/interfaces/translationUpdateTranslationDataDTO)
  - `reference_id`: `string` — The ID of the data model being translated.

    Example:

    ```
    "prod_123"
    ```
  - `reference`: `string` — The name of the table that the translation belongs to.

    Example:

    ```
    "product"
    ```
  - `locale_code`: `string` — The BCP 47 language tag code for this translation.

    Example:

    ```
    "en-US"
    ```
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.

    Example:

    ```
    { * "title": "Product Title", * "description": "Product Description", * }
    ```
  - `id`: `string` — The ID of the translation to update.
