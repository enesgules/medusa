title: ConfirmOrderEditRequestWorkflowInput
---

The data to confirm an order edit request.

- `ConfirmOrderEditRequestWorkflowInput`: `object` — The data to confirm an order edit request.
  - `order_id`: `string` — The ID of the order to confirm the edit for.
  - `confirmed_by`: `string` (optional) — The ID of the user confirming the edit.
