title: CreateCompleteReturnValidationStepInput
---

The data to validate that a return can be created and completed.

- `CreateCompleteReturnValidationStepInput`: `object` — The data to validate that a return can be created and completed.
  - `order`: `any` — The order's details.
  - `input`: [CreateOrderReturnWorkflowInput](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCreateOrderReturnWorkflowInput) — The data to create a return.
    - `order_id`: `string` — The ID of the order to return items from.
    - `created_by`: `null` | `string` (optional) — The ID of the customer that's creating the return
    - `items`: [CreateReturnItem](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCreateReturnItem)\[] — The items to return.
    - `return_shipping`: `object` (optional) — The shipping details of the returned items.
    - `note`: `null` | `string` (optional) — More details about the return.
    - `receive_now`: `boolean` (optional) — Whether to mark the return as received immediately.
    - `refund_amount`: `number` (optional) — The amount to refund the customer.
    - `location_id`: `null` | `string` (optional) — The ID of the location to return the items to. If not provided, the return shipping option's location is used.
