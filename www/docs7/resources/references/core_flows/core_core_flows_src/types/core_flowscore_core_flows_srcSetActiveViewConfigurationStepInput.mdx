---
title: SetActiveViewConfigurationStepInput
---

The input for setting a view configuration as the active view.

- `SetActiveViewConfigurationStepInput`: `object` — The input for setting a view configuration as the active view.
  - `id`: `string` — The ID of the view configuration to set as active.
  - `entity`: `string` — The entity the view configuration is for.
  - `user_id`: `string` — The ID of the user to set the active view configuration for.
