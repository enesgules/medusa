---
title: MarkOrderFulfillmentAsDeliveredWorkflowInput
---

The details to mark a fulfillment in an order as delivered.

- `MarkOrderFulfillmentAsDeliveredWorkflowInput`: `object` — The details to mark a fulfillment in an order as delivered.
  - `orderId`: `string` — The ID of the order to mark the fulfillment as delivered in.
  - `fulfillmentId`: `string` — The ID of the fulfillment to mark as delivered.
  - `no_notification`: `boolean` (optional) — Whether to notify the customer about the delivery.
