---
title: SetActiveLayoutScopeStepInput
---

The input for setting the active layout scope for a user in a zone.

- `SetActiveLayoutScopeStepInput`: `object` — The input for setting the active layout scope for a user in a zone.
  - `zone`: `string` — The zone that the layout scope applies to.
  - `user_id`: `string` — The ID of the user whose active layout scope is set.
  - `scope`: `"personal"` | `"default"` (optional) — The active layout scope to set for the user. If not provided, the user's active scope is cleared.
