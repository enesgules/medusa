The data to refund one or more payments.

- `RefundPaymentsStepInput`: `object`\[] — The data to refund one or more payments.
  - `payment_id`: `string` — The ID of the payment to refund.
  - `amount`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) — The amount to refund.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `created_by`: `string` (optional) — The ID of the user that refunded the payment.
  - `note`: `string` (optional) — The note to attach to the refund.
  - `metadata`: `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
