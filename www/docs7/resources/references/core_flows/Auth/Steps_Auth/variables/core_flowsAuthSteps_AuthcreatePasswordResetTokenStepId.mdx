The ID of the create password reset token step.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `createPasswordResetTokenStepId`: `"create-password-reset-token"` (default: "create-password-reset-token") — The ID of the create password reset token step.
