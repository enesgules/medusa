The ID of the request verification step.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

- `requestVerificationStepId`: `"request-verification"` (default: "request-verification") — The ID of the request verification step.
