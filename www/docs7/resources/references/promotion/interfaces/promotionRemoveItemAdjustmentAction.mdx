---
title: RemoveItemAdjustmentAction
---

This action indicates that an adjustment must be removed from a line item. For example, remove the \$5 discount applied before.

**RemoveItemAdjustmentAction**

- `action`: `"removeItemAdjustment"` — The type of action.
- `adjustment_id`: `string` — The associated adjustment's ID.
- `item_id`: `string` — The associated item's ID.
- `description`: `string` (optional) — The promotion's description.
- `code`: `string` — The promotion's code.
