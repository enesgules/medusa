This documentation provides a reference to the `createCampaigns` method. This belongs to the Promotion Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="createcampaigns-data-sharedcontext-promisecampaigndto" />

## createCampaigns(data, sharedContext?): Promise\<[CampaignDTO](/resources/references/promotion/interfaces/promotionCampaignDTO)>

This method creates a campaign.

### Example

```ts
const campaign = await promotionModuleService.createCampaigns(
  {
    name: "Summer discounts",
    campaign_identifier: "G-123456",
    starts_at: new Date("2025-06-01"),
    ends_at: new Date("2025-09-01"),
    budget: {
      type: "usage",
      limit: 10,
    },
  }
)
```

<a id="createcampaigns-parameters" />

### Parameters

**createCampaigns**

- `data`: [CreateCampaignDTO](/resources/references/promotion/interfaces/promotionCreateCampaignDTO) — The campaign to be created.
  - `name`: `string` — The name of the campaign.
  - `description`: `null` | `string` (optional) — The description of the campaign.
  - `campaign_identifier`: `string` — The campaign identifier of the campaign.
  - `starts_at`: `null` | `Date` (optional) — The start date of the campaign.
  - `ends_at`: `null` | `Date` (optional) — The end date of the campaign.
  - `budget`: `null` | [CreateCampaignBudgetDTO](/resources/references/promotion/interfaces/promotionCreateCampaignBudgetDTO) (optional) — The associated campaign budget.
    - `type`: [CampaignBudgetTypeValues](/resources/references/promotion/types/promotionCampaignBudgetTypeValues) (optional) — The type of the campaign budget.
    - `limit`: `null` | `number` (optional) — The limit of the campaign budget.
    - `used`: `number` (optional) — How much is used of the campaign budget.
    - `currency_code`: `null` | `string` (optional) — The currency of the campaign.
    - `attribute`: `null` | `string` (optional) — The attribute that the budget limit is applied to. By default, the budget is applied globally. If the type is `use_by_attribute`, this field indicates the attribute the budget is tracked by. For example, `customer_id` means the budget is tracked per customer.

      Example:

      ```
      customer_id
      ```
- `sharedContext`: [Context](/resources/references/promotion/interfaces/promotionContext) (optional) — A context used to share resources, such as transaction manager, between the application and the module.
  - `transactionManager`: TManager (optional) — An instance of a transaction manager of type `TManager`, which is a typed parameter passed to the context to specify the type of the `transactionManager`.
  - `manager`: TManager (optional) — An instance of a manager, typically an entity manager, of type `TManager`, which is a typed parameter passed to the context to specify the type of the `manager`.
  - `isolationLevel`: `string` (optional) — A string indicating the isolation level of the context. Possible values are `READ UNCOMMITTED`, `READ COMMITTED`, `REPEATABLE READ`, or `SERIALIZABLE`.
  - `enableNestedTransactions`: `boolean` (optional) — A boolean value indicating whether nested transactions are enabled.
  - `eventGroupId`: `string` (optional) — A string indicating the ID of the group to aggregate the events to be emitted at a later point.
  - `transactionId`: `string` (optional) — A string indicating the ID of the current transaction.
  - `runId`: `string` (optional) — A string indicating the ID of the current run.
  - `messageAggregator`: [IMessageAggregator](/resources/references/promotion/interfaces/promotionIMessageAggregator) (optional) — An instance of a message aggregator, which is used to aggregate messages to be emitted at a later point.
  - `requestId`: `string` (optional) — A string indicating the ID of the current request.
  - `idempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the current workflow execution.
  - `parentStepIdempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the parent workflow execution.
  - `preventReleaseEvents`: `boolean` (optional) — preventReleaseEvents
  - `isCancelling`: `boolean` (optional) — A boolean value indicating whether the current workflow execution is being cancelled.
  - `cancelingFromParentStep`: `boolean` (optional) — Weither or not a sub workflow cancellation is being triggered from a parent step. If true, the parent step will not be triggered by the sub workflow.

<a id="createcampaigns-returns" />

### Returns

**createCampaigns**

- `Promise`: Promise\<[CampaignDTO](/resources/references/promotion/interfaces/promotionCampaignDTO)> — The created campaign.
  - `id`: `string` — The ID of the campaign.
  - `name`: `string` (optional) — The name of the campaign.
  - `description`: `string` (optional) — The description of the campaign.
  - `campaign_identifier`: `string` (optional) — The campaign identifier of the campaign.
  - `starts_at`: `Date` (optional) — The start date of the campaign.
  - `ends_at`: `Date` (optional) — The end date of the campaign.
  - `budget`: [CampaignBudgetDTO](/resources/references/promotion/interfaces/promotionCampaignBudgetDTO) (optional) — The associated campaign budget.
    - `id`: `string` — The ID of the campaign budget.
    - `type`: [CampaignBudgetTypeValues](/resources/references/promotion/types/promotionCampaignBudgetTypeValues) (optional) — The type of the campaign budget: - `spend` indicates that the budget is limited by the amount discounted by the promotions in the associated campaign. - `usage` indicates that the budget is limited by the number of times the promotions of the associated campaign have been used. - `use_by_attribute` indicates that the budget is limited by the number of times the promotions of the associated campaign have been used by a specific attribute value (for example, per customer) - `spend_by_attribute` indicates that the budget is limited by the amount discounted by the promotions in the associated campaign by a specific attribute value (for example, per customer)
    - `limit`: `null` | `number` (optional) — The limit of the campaign budget.
    - `used`: `number` (optional) — The usage from the campaign budget's limit: - If the budget's type is `spend`, the value of this attribute is the amount discounted so far by the promotions in the associated campaign. - If the budget's type is `usage`, the value of this attribute is the number of times the promotions of the associated campaign have been used so far.
    - `currency_code`: `string` (optional) — The currency of the campaign.
    - `attribute`: `string` (optional) — The attribute that the budget limit is applied to. By default, the budget is applied globally. If the type is `use_by_attribute`, this field indicates the attribute the budget is tracked by. For example, `customer_id` means the budget is tracked per customer.

      Example:

      ```
      customer_id
      ```
    - `usages`: [CampaignBudgetUsageDTO](/resources/references/promotion/interfaces/promotionCampaignBudgetUsageDTO)\[] (optional) — The usages of the campaign budget. This is only set if the budget's type is `use_by_attribute` or `spend_by_attribute`. Each usage tracks the budget usage for a specific attribute value.
  - `promotions`: [PromotionDTO](/resources/references/promotion/interfaces/promotionPromotionDTO)\[] (optional) — The associated promotions.
    - `id`: `string` — The ID of the promotion.
    - `code`: `string` (optional) — The code of the promotion.
    - `type`: [PromotionTypeValues](/resources/references/promotion/types/promotionPromotionTypeValues) (optional) — The type of the promotion: - `standard` indicates that a promotion is a standard one applied with conditions. - `buyget` indicates that a promotion is a "Buy X get Y" promotion.
    - `status`: [PromotionStatusValues](/resources/references/promotion/types/promotionPromotionStatusValues) (optional) — The status of the promotion: - `active` promotion is available for user to consume - `inactive` promotion is no longer available to the user - `draft` promotion is currently being prepared
    - `is_automatic`: `boolean` (optional) — Whether the promotion is applied automatically.
    - `is_tax_inclusive`: `boolean` (optional) — Whether the promotion is tax inclusive.
    - `limit`: `null` | `number` (optional) — The maximum number of times this promotion can be used across all orders.
    - `used`: `number` (optional) — The number of times this promotion has been used in completed orders.
    - `application_method`: [ApplicationMethodDTO](/resources/references/promotion/interfaces/promotionApplicationMethodDTO) (optional) — The associated application method.
    - `rules`: [PromotionRuleDTO](/resources/references/promotion/interfaces/promotionPromotionRuleDTO)\[] (optional) — The rules of the promotion.
    - `campaign_id`: `null` | `string` (optional) — The associated campaign.
    - `campaign`: [CampaignDTO](/resources/references/promotion/interfaces/promotionCampaignDTO) (optional) — The associated campaign.
