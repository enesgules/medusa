title: ModuleUpdateGiftCard
---

The data required to update a gift card.

- `ModuleUpdateGiftCard`: `object` — The data required to update a gift card.
  - `id`: `string` — The ID of the gift card to update.
  - `value`: `number` (optional) — The updated monetary value of the gift card.
  - `status`: [GiftCardStatus](/resources/references/loyalty/enums/loyaltyGiftCardStatus) (optional) — The updated status of the gift card.
    - `PENDING`: `"pending"` (optional)
    - `REDEEMED`: `"redeemed"` (optional)
  - `note`: `string` | `null` (optional) — An updated note about the gift card.
  - `currency_code`: `string` (optional) — The updated three-letter ISO currency code.

    Example:

    ```
    usd
    ```
  - `expires_at`: `string` | `null` (optional) — The updated expiration date, or null to remove the expiration.
  - `customer_id`: `string` (optional) — The updated ID of the customer associated with the gift card.
  - `metadata`: `Record<string, unknown>` (optional) — Updated custom key-value pairs attached to the gift card.
