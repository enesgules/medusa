This documentation provides a reference to the `listGiftCards` method. This belongs to the Loyalty Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves a paginated list of gift cards based on optional filters and configuration.

## Example

To retrieve a list of gift cards using their IDs:

```ts
const giftCards = await loyaltyModuleService.listGiftCards({
  id: ["gc_123", "gc_456"],
})
```

By default, only the first `15` records are retrieved. You can control pagination by specifying the `skip` and `take` properties of the `config` parameter:

```ts
const giftCards = await loyaltyModuleService.listGiftCards(
  { id: ["gc_123", "gc_456"] },
  { take: 20, skip: 2 }
)
```
