This documentation provides a reference to the PropertyLabel data model. It belongs to the Settings Module.

PropertyLabel stores custom display labels for entity properties.
Labels are global (shared across all admin users) and provide
consistent terminology throughout the admin interface.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/modules/settings/src/models/property-label.ts#L8)
