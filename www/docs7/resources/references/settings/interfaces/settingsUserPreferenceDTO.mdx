title: UserPreferenceDTO
---

The user preference data model.

**UserPreferenceDTO**

- `id`: `string` — The ID of the preference.
- `user_id`: `string` — The user ID.
- `key`: `string` — The preference key.
- `value`: `any` — The preference value.
- `created_at`: `Date` — The date the preference was created.
- `updated_at`: `Date` — The date the preference was last updated.
