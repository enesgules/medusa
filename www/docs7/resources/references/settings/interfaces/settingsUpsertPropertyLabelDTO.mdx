---
title: UpsertPropertyLabelDTO
---

The property label to be upserted (created or updated).

**UpsertPropertyLabelDTO**

- `id`: `string` (optional) — The ID of the property label to update.
- `entity`: `string` (optional) — The entity this label applies to (e.g., "Order", "Product").
- `property`: `string` (optional) — The property path (e.g., "display\_id", "customer.email").
- `label`: `string` (optional) — Custom display name for the property.
- `description`: `string` (optional) — Optional description providing context about the property.
