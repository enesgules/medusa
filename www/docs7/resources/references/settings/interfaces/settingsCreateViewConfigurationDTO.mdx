title: CreateViewConfigurationDTO
---

The view configuration to be created.

**CreateViewConfigurationDTO**

- `entity`: `string` — The entity this configuration is for.
- `name`: `string` (optional) — The name of the configuration. Required unless creating a system default.
- `user_id`: `null` | `string` (optional) — The user ID this configuration belongs to. Can be null for system defaults.
- `is_system_default`: `boolean` (optional) — Whether this is a system default configuration.
- `configuration`: `object` — The configuration data.
  - `visible_columns`: `string`\[] — The visible columns.
  - `column_order`: `string`\[] — The column order.
  - `column_widths`: `Record<string, number>` (optional) — The column widths.
  - `filters`: `Record<string, any>` (optional) — The filters to apply.
  - `sorting`: `null` | `object` (optional) — The sorting configuration.
    - `id`: `string`
    - `desc`: `boolean`
  - `search`: `string` (optional) — The search string.
