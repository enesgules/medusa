Partial filters for view configuration fields.

**ViewConfigurationFilterableFields**

- `id`: `string` | `string`\[] (optional) — The IDs to filter by.
- `entity`: `string` | `string`\[] (optional) — Filter by entity name.
- `user_id`: `null` | `string` | `string`\[] (optional) — Filter by user ID.
- `is_system_default`: `boolean` (optional) — Filter by system default flag.
- `name`: `string` | `string`\[] (optional) — Filter by name.
