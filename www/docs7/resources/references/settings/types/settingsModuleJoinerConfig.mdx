- `ModuleJoinerConfig`: Omit\<[JoinerServiceConfig](/resources/references/settings/interfaces/settingsJoinerServiceConfig), "serviceName" | "primaryKeys" | "relationships" | "extends"> & `object`
  - `alias`: [JoinerServiceConfigAlias](/resources/references/settings/interfaces/settingsJoinerServiceConfigAlias) | [JoinerServiceConfigAlias](/resources/references/settings/interfaces/settingsJoinerServiceConfigAlias)\[] (optional) — Property name to use as entrypoint to the service
    - `name`: `string` | `string`\[] — The alias name or list of alias names for the service entry point.
    - `entity`: `string` (optional) — The entity name associated with this alias.
    - `filterable`: `string`\[] (optional) — The list of fields that can be used as filters when querying through this alias.
    - `__internal`: `object` (optional) — Internal-only alias metadata used by the query layer.
    - `args`: `Record<string, any>` (optional) — Extra arguments to pass to the remoteFetchData callback
  - `fieldAlias`: `Record<string, string \| object>` (optional) — alias for deeper nested relationships (e.g. \{ 'price': 'prices.calculated\_price\_set.amount' })
    - `path`: `string`
    - `forwardArgumentsOnPath`: `string`\[]
  - `args`: `Record<string, any>` (optional) — Extra arguments to pass to the remoteFetchData callback
  - `schema`: `string` (optional) — GraphQL schema for the all module's available entities and fields
  - `idPrefixToEntityName`: `Record<string, string>` (optional)
  - `relationships`: [ModuleJoinerRelationship](/resources/references/settings/types/settingsModuleJoinerRelationship)\[] (optional)
    - `alias`: `string` — The alias used to reference the related service in queries.
    - `foreignKey`: `string` — The foreign key field on the related service used to join the relationship.
    - `primaryKey`: `string` — The primary key field on the current service used to join the relationship.
    - `serviceName`: `string` — The name of the related service.
    - `entity`: `string` (optional) — The entity name within the related service.
    - `inverse`: `boolean` (optional) — In an inverted relationship the foreign key is on the other service and the primary key is on the current service
    - `isList`: `boolean` (optional) — Force the relationship to return a list
    - `args`: `Record<string, any>` (optional) — Extra arguments to pass to the remoteFetchData callback
    - `deleteCascade`: `boolean` (optional) — If true, the link joiner will cascade deleting the relationship
    - `filterable`: `string`\[] (optional) — The fields to be filterable by the Index module using query.index
    - `hasMany`: `boolean` (optional) — Allow multiple relationships to exist for this entity
  - `extends`: `object`\[] (optional)
    - `serviceName`: `string`
    - `entity`: `string` (optional)
    - `fieldAlias`: `Record<string, string \| object>` (optional)
    - `relationship`: Omit\<[ModuleJoinerRelationship](/resources/references/settings/types/settingsModuleJoinerRelationship), "hasMany">
  - `serviceName`: `string` (optional)
  - `primaryKeys`: `string`\[] (optional)
  - `isLink`: `boolean` (optional) — If the module is a link module
  - `linkableKeys`: `Record<string, string>` (optional) — Keys that can be used to link to other modules. e.g \{ product\_id: "Product" } "Product" being the entity it refers to
  - `isReadOnlyLink`: `boolean` (optional) — If true it expands a RemoteQuery property but doesn't create a pivot table
  - `extraDataFields`: `string`\[] (optional) — Fields that will be part of the link record aside from the primary keys that can be updated If not explicitly defined, this array will be populated by databaseConfig.extraFields
  - `databaseClientUrl`: `string` (optional) — Resolved database client URL for this module. This is used to determine if we can do in-DB cross module filtering
  - `databaseConfig`: `object` (optional)
    - `tableName`: `string` (optional) — Name of the pivot table. If not provided it is auto generated
    - `idPrefix`: `string` (optional) — Prefix for the id column. If not provided it is "link"
    - `extraFields`: [LinkModulesExtraFields](/resources/references/settings/types/settingsLinkModulesExtraFields) (optional)
