This documentation provides a reference to the `getSystemDefaultLayoutConfiguration` method. This belongs to the Settings Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

Retrieve the system default layout configuration for a zone, if any.

## Example

```ts
const layoutConfiguration =
  await settingsModuleService.getSystemDefaultLayoutConfiguration(
    "product.details"
  )
```
