This documentation provides a reference to the `hasEntity` method. This belongs to the Settings Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

Check if an entity exists by name.
Supports PascalCase, kebab-case, snake\_case, and plural forms.

## Example

```ts
const exists = settingsModuleService.hasEntity("product")
```

<a id="hasentity-parameters" />

## Parameters

**hasEntity**

- `name`: `string` — The name of the entity to check for.

<a id="hasentity-returns" />

## Returns

**hasEntity**

- `boolean`: `boolean` — Whether an entity with the specified name exists.
