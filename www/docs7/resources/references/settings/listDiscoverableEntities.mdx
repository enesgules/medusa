This documentation provides a reference to the `listDiscoverableEntities` method. This belongs to the Settings Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

List all discoverable entities from joiner configs.
Returns brief info about each entity.

## Example

```ts
const entities = await settingsModuleService.listDiscoverableEntities()
```

<a id="listdiscoverableentities-returns" />

## Returns

**listDiscoverableEntities**

- `Promise`: Promise\<[AdminEntityInfo](/resources/references/settings/interfaces/settingsAdminEntityInfo)\[]> — The list of discoverable entities.
  - `AdminEntityInfo[]`: [AdminEntityInfo](/resources/references/settings/interfaces/settingsAdminEntityInfo)\[]
    - `name`: `string` — Entity name in PascalCase.
    - `pluralName`: `string` — Plural/route key.
    - `module`: `string` — Module this entity belongs to.
    - `propertyCount`: `number` — Number of properties on this entity.
    - `hasOverrides`: `boolean` — Whether this entity has custom overrides.
