---
title: CrossModuleJoinLink
---

Describes a link table connecting the queried root entity to an external table.

- `CrossModuleJoinLink`: `object` — Describes a link table connecting the queried root entity to an external table.
  - `schema`: `string` (optional) — PostgreSQL schema for the link table. Defaults to `public`.
  - `table`: `string` — Link table name.
  - `sourceKey`: `string` — Column on the link table referencing the correlation source — the queried root entity when there is no `parent`, otherwise the parent join's target row.
  - `targetKey`: `string` — Column on the link table referencing the external entity.
