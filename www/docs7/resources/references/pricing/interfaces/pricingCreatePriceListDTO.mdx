title: CreatePriceListDTO
---

The price list to create.

**CreatePriceListDTO**

- `title`: `string` — The price list's title.
- `description`: `string` — The price list's description.
- `starts_at`: `null` | `string` (optional) — The price list is enabled starting from this date.
- `ends_at`: `null` | `string` (optional) — The price list expires after this date.
- `status`: [PriceListStatus](/resources/references/pricing/types/pricingPriceListStatus) (optional) — The price list's status.
- `type`: [PriceListType](/resources/references/pricing/types/pricingPriceListType) (optional) — The price list's type.
- `rules`: [CreatePriceListRules](/resources/references/pricing/interfaces/pricingCreatePriceListRules) (optional) — The rules to be created and associated with the price list.
- `prices`: [CreatePriceListPriceDTO](/resources/references/pricing/interfaces/pricingCreatePriceListPriceDTO)\[] (optional) — The prices associated with the price list.
  - `id`: `string` (optional) — The ID of the money amount.
  - `currency_code`: `string` — The currency code of this money amount.
  - `amount`: [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) — The amount of this money amount.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `min_quantity`: `null` | [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) (optional) — The minimum quantity required to be purchased for this money amount to be applied.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `max_quantity`: `null` | [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) (optional) — The maximum quantity required to be purchased for this money amount to be applied.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `price_set_id`: `string` — The ID of the associated price set.
  - `rules`: [CreatePriceListPriceRules](/resources/references/pricing/interfaces/pricingCreatePriceListPriceRules) (optional) — The rules to add to the price. The object's keys are the attribute, and values are the value of that rule associated with this price.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
