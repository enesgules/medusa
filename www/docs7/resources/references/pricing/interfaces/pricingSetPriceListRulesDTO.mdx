title: SetPriceListRulesDTO
---

The rules to set in a price list.

**SetPriceListRulesDTO**

- `price_list_id`: `string` — The ID of the price list to set its rules.
- `rules`: `Record<string, string \| string[]>` — The rules to add to the price list. Each key of the object is the attribute, and its value is the value(s) of the rule.
