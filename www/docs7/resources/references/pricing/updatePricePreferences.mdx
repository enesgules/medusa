This documentation provides a reference to the `updatePricePreferences` method. This belongs to the Pricing Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="updatepricepreferences-id-data-sharedcontext-promisepricepreferencedto" />

## updatePricePreferences(id, data, sharedContext?): Promise\<[PricePreferenceDTO](/resources/references/pricing/interfaces/pricingPricePreferenceDTO)>

This method is used to update a price preference.

### Example

```ts
const pricePreference = await pricingModuleService.updatePricePreferences(
  "prpref_123",
  {
     is_tax_inclusive: false
  }
)
```

<a id="updatepricepreferences-parameters" />

### Parameters

**updatePricePreferences**

- `id`: `string` — The ID of the price preference to be updated.
- `data`: [UpdatePricePreferenceDTO](/resources/references/pricing/interfaces/pricingUpdatePricePreferenceDTO) — The attributes of the price preference to be updated
  - `attribute`: `null` | `string` (optional) — The rule attribute for the preference
  - `value`: `null` | `string` (optional) — The rule value for the preference
  - `is_tax_inclusive`: `boolean` (optional) — Flag specifying whether prices for the specified rule are tax inclusive.
- `sharedContext`: [Context](/resources/references/pricing/interfaces/pricingContext) (optional) — A context used to share resources, such as transaction manager, between the application and the module.
  - `transactionManager`: TManager (optional) — An instance of a transaction manager of type `TManager`, which is a typed parameter passed to the context to specify the type of the `transactionManager`.
  - `manager`: TManager (optional) — An instance of a manager, typically an entity manager, of type `TManager`, which is a typed parameter passed to the context to specify the type of the `manager`.
  - `isolationLevel`: `string` (optional) — A string indicating the isolation level of the context. Possible values are `READ UNCOMMITTED`, `READ COMMITTED`, `REPEATABLE READ`, or `SERIALIZABLE`.
  - `enableNestedTransactions`: `boolean` (optional) — A boolean value indicating whether nested transactions are enabled.
  - `eventGroupId`: `string` (optional) — A string indicating the ID of the group to aggregate the events to be emitted at a later point.
  - `transactionId`: `string` (optional) — A string indicating the ID of the current transaction.
  - `runId`: `string` (optional) — A string indicating the ID of the current run.
  - `messageAggregator`: [IMessageAggregator](/resources/references/pricing/interfaces/pricingIMessageAggregator) (optional) — An instance of a message aggregator, which is used to aggregate messages to be emitted at a later point.
  - `requestId`: `string` (optional) — A string indicating the ID of the current request.
  - `idempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the current workflow execution.
  - `parentStepIdempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the parent workflow execution.
  - `preventReleaseEvents`: `boolean` (optional) — preventReleaseEvents
  - `isCancelling`: `boolean` (optional) — A boolean value indicating whether the current workflow execution is being cancelled.
  - `cancelingFromParentStep`: `boolean` (optional) — Weither or not a sub workflow cancellation is being triggered from a parent step. If true, the parent step will not be triggered by the sub workflow.

<a id="updatepricepreferences-returns" />

### Returns

**updatePricePreferences**

- `Promise`: Promise\<[PricePreferenceDTO](/resources/references/pricing/interfaces/pricingPricePreferenceDTO)> — The updated price preference.
  - `id`: `string` — The ID of a price preference.
  - `attribute`: `null` | `string` — The rule attribute for the preference
  - `value`: `null` | `string` — The rule value for the preference
  - `is_tax_inclusive`: `boolean` — Flag specifying whether prices for the specified rule are tax inclusive.
  - `created_at`: `Date` — When the price preference was created.
  - `updated_at`: `Date` — When the price preference was updated.
  - `deleted_at`: `null` | `Date` — When the price preference was deleted.
