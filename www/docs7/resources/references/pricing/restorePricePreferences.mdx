This documentation provides a reference to the `restorePricePreferences` method. This belongs to the Pricing Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method restores soft deleted price preferences by their IDs.

## Example

```ts
await pricingModuleService.restorePricePreferences([
  "prpref_123",
  "prpref_321",
])
```

## Returns

**restorePricePreferences**

- `Promise`: Promise\<void | Record\<string, string\[]>> — An object that includes the IDs of related records that were restored. The object's keys are the ID attribute names of the price preferences entity's relations, and its value is an array of strings, each being the ID of the record associated with the price preferences through this relation. If there are no related records restored, the promise resolves to `void`.
  - `void \| Record<string, string[]>`: `void` | `Record<string, string[]>`
