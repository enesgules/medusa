This documentation provides a reference to the `addPriceListPrices` method. This belongs to the Pricing Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method is used to add prices to price lists.

## Example

```ts
const priceLists =
  await pricingModuleService.addPriceListPrices([
    {
      price_list_id: "plist_123",
      prices: [
        {
          currency_code: "usd",
          amount: 500,
          price_set_id: "pset_123",
        },
      ],
    },
  ])
```

    - `rules`: [CreatePriceListPriceRules](/resources/references/pricing/interfaces/pricingCreatePriceListPriceRules) (optional) — The rules to add to the price. The object's keys are the attribute, and values are the value of that rule associated with this price.
