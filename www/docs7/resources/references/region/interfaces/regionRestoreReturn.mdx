---
title: RestoreReturn
---

An object that is used to specify an entity's related entities that should be restored when the main entity is restored.

## Type parameters

**RestoreReturn**

- `TReturnableLinkableKeys`: `object` (optional)

**RestoreReturn**

- `returnLinkableKeys`: TReturnableLinkableKeys\[] (optional) — An array of strings, each being the ID attribute names of the entity's relations.
