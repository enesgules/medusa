This reference shows all the events emitted by the Medusa application related to the Region Module. If you use the module outside the Medusa application, these events aren't emitted.

### Summary

| Event                                                                 | Description                       |
| --------------------------------------------------------------------- | --------------------------------- |
| [`region.updated`](/resources/references/region/events#regionupdated) | Emitted when regions are updated. |
| [`region.created`](/resources/references/region/events#regioncreated) | Emitted when regions are created. |
| [`region.deleted`](/resources/references/region/events#regiondeleted) | Emitted when regions are deleted. |

### region.updated

Emitted when regions are updated.

#### Payload

```ts
{
  id, // The ID of the region
}
```

#### Workflows Emitting this Event

- [updateRegionsWorkflow](/resources/references/medusa-workflows/updateRegionsWorkflow)

### region.created

Emitted when regions are created.

#### Payload

```ts
{
  id, // The ID of the region
}
```

#### Workflows Emitting this Event

- [createRegionsWorkflow](/resources/references/medusa-workflows/createRegionsWorkflow)

### region.deleted

Emitted when regions are deleted.

#### Payload

```ts
{
  id, // The ID of the region
}
```

#### Workflows Emitting this Event

- [deleteRegionsWorkflow](/resources/references/medusa-workflows/deleteRegionsWorkflow)
