## listEntities

This method retrieves the list of entities that support view configurations.

> **Note**
>
> This is available starting from [Medusa v2.18.0](https://github.com/medusajs/medusa/releases/tag/v2.18.0).

### Example

```ts
sdk.admin.views.listEntities()
.then(({ entities }) => {
  console.log(entities)
})
```

<a id="listentities-parameters" />

### Parameters

**listEntities**

- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="listentities-returns" />

### Returns

**listEntities**

- `Promise`: Promise\<[AdminEntityListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminEntityListResponse)> — The list of supported entities.

    - `propertyCount`: `number` — Number of properties on this entity.
    - `hasOverrides`: `boolean` — Whether this entity has custom overrides.

## listConfigurations

This method retrieves a paginated list of view configurations for an entity.

> **Note**
>
> This is available starting from [Medusa v2.10.3](https://github.com/medusajs/medusa/releases/tag/v2.10.3).

### Example

To retrieve the list of view configurations:

```ts
sdk.admin.views.listConfigurations("orders")
.then(({ view_configurations, count, limit, offset }) => {
  console.log(view_configurations)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.views.listConfigurations("orders", {
  limit: 10,
  offset: 10
})
.then(({ view_configurations, count, limit, offset }) => {
  console.log(view_configurations)
})
```

## createConfiguration

This method creates a view configuration for an entity.

> **Note**
>
> This is available starting from [Medusa v2.10.3](https://github.com/medusajs/medusa/releases/tag/v2.10.3).

### Example

```ts
const { view_configuration } = await sdk.admin.views.createConfiguration(
  "orders",
  {
    name: "My Orders View",
    configuration: {
      visible_columns: ["display_id", "status"],
      column_order: ["display_id", "status"],
    },
  }
)
```

<a id="createconfiguration-parameters" />

### Parameters

**createConfiguration**

  - `name`: `null` | `string` (optional) — The name of the view configuration.
  - `is_system_default`: `boolean` (optional) — Whether this is a system default configuration.
  - `set_active`: `boolean` (optional) — Whether to set this view as the active view after creation.
  - `configuration`: `object` — The view configuration settings.
    - `visible_columns`: `string`\[] — The list of visible column IDs.
    - `column_order`: `string`\[] — The order of columns.
    - `column_widths`: `Record<string, number>` (optional) — Custom column widths.
    - `filters`: `Record<string, any>` (optional) — Active filters for the view.
    - `sorting`: `null` | `object` (optional) — Sorting configuration.
    - `search`: `string` (optional) — Search query for the view.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

sdk.admin.views.retrieveConfiguration("orders", "viewconfig_123")

sdk.admin.views.retrieveConfiguration("orders", "viewconfig_123", {

## retrieveActiveConfiguration

This method retrieves the active view configuration for an entity and the
authenticated user.

> **Note**
>
> This is available starting from [Medusa v2.10.3](https://github.com/medusajs/medusa/releases/tag/v2.10.3).

### Example

```ts
sdk.admin.views.retrieveActiveConfiguration("orders")
.then(({ view_configuration, active_view_configuration_id }) => {
  console.log(view_configuration)
})
```

<a id="retrieveactiveconfiguration-parameters" />

### Parameters

**retrieveActiveConfiguration**

- `entity`: `string` — The entity to retrieve the active view configuration for.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieveactiveconfiguration-returns" />

### Returns

**retrieveActiveConfiguration**

- `Promise`: Promise\<[AdminViewConfigurationResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminViewConfigurationResponse) & object> — The active view configuration, along with its ID.
  - `AdminViewConfigurationResponse`: `object`
  - `active_view_configuration_id`: `null` | `string` (optional)

## setActiveConfiguration

This method sets the active view configuration for an entity and the
authenticated user. Pass `null` as the `view_configuration_id` to clear the
active view.

> **Note**
>
> This is available starting from [Medusa v2.10.3](https://github.com/medusajs/medusa/releases/tag/v2.10.3).

### Example

```ts
await sdk.admin.views.setActiveConfiguration("orders", {
  view_configuration_id: "viewconfig_123",
})
```

<a id="setactiveconfiguration-parameters" />

### Parameters

**setActiveConfiguration**

- `entity`: `string` — The entity to set the active view configuration for.
- `body`: `object` — The active view configuration's details.
  - `view_configuration_id`: `null` | `string` — The ID of the view configuration to set as active, or `null` to clear it.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="setactiveconfiguration-returns" />

### Returns

**setActiveConfiguration**

- `Promise`: Promise\<object> — Whether the active view configuration was set successfully.
  - `success`: `boolean`
