This documentation provides a reference to the `sdk.admin.productCollection` set of methods used to send requests to Medusa's Admin API routes.

## create

This method creates a product collection. It sends a request to the
[Create Collection](/api/admin/collections/create-collection)
API route.

### Example

```ts
sdk.admin.productCollection.create({
  title: "Summer Collection"
})
.then(({ collection }) => {
  console.log(collection)
})
```

<a id="create-parameters" />

### Parameters

**create**

- `body`: [AdminCreateCollection](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateCollection) — The details of the product collection to create.
  - `title`: `string` — The collection's title.
  - `handle`: `string` (optional) — The collection's handle.
  - `external_id`: `null` | `string` (optional) — An external ID for the collection.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [AdminCollectionParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCollectionParams) (optional) — Configure the fields to retrieve in the product collection.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

  - `collection`: [AdminCollection](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCollection) — The collection's details.
    - `translations`: `null` | [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[] (optional) — The collection's translations.
    - `id`: `string` — The collection's ID.
    - `title`: `string` — The collection's title.

    - `deleted_at`: `null` | `string` — The date the collection was deleted.
    - `products`: [BaseProduct](/resources/references/types/interfaces/typesBaseProduct)\[] (optional) — The collection's products.

## list

This method retrieves a paginated list of collections. It sends a request to the
[List Collections](/api/admin/collections/list-collections) API route.

### Example

To retrieve the list of collections:

```ts
sdk.admin.productCollection.list()
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.productCollection.list({
  limit: 10,
  offset: 10
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each collection:

```ts
sdk.admin.productCollection.list({
  fields: "id,*products"
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
