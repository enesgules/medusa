This documentation provides a reference to the `sdk.admin.plugin` set of methods used to send requests to Medusa's Admin API routes.

## list

This method retrieves the list of plugins installed in a Medusa application.

### Example

```ts
sdk.admin.plugin.list()
.then(({ plugins }) => {
  console.log(plugins)
})
```

<a id="list-parameters" />

### Parameters

**list**

- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="list-returns" />

### Returns

**list**

- `Promise`: Promise\<[AdminPluginsListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPluginsListResponse)> — The list of plugins.
  - `plugins`: [AdminPlugin](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPlugin)\[] — The plugin's details.
    - `name`: `string` — The plugin's name.
