This documentation provides a reference to the `sdk.admin.fulfillmentProvider` set of methods used to send requests to Medusa's Admin API routes.

## list

This method retrieves a paginated list of fulfillment providers. It sends a request to the
[List Fulfillment Providers](/api/admin/fulfillment-providers/list-fulfillment-providers)
API route.

### Example

To retrieve the list of fulfillment providers:

```ts
sdk.admin.fulfillmentProvider.list()
.then(({ fulfillment_providers, count, limit, offset }) => {
  console.log(fulfillment_providers)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.fulfillmentProvider.list({
  limit: 10,
  offset: 10
})
.then(({ fulfillment_providers, count, limit, offset }) => {
  console.log(fulfillment_providers)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each fulfillment provider:

```ts
sdk.admin.fulfillmentProvider.list({
  fields: "id"
})
.then(({ fulfillment_providers, count, limit, offset }) => {
  console.log(fulfillment_providers)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="list-parameters" />

### Parameters

**list**

- `query`: [AdminGetFulfillmentProvidersParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminGetFulfillmentProvidersParams) (optional) — Filters and pagination configurations.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
  - `limit`: `number` (optional) — The maximum number of items to retrieve.
  - `offset`: `number` (optional) — The number of items to skip before retrieving the returned items.
  - `order`: `string` (optional) — The field to sort by and in which order.

    Example:

    ```
    -created_at
    ```
  - `with_deleted`: `boolean` (optional) — Whether to include soft-deleted items in the results.
  - `id`: `string` | `string`\[] (optional) — Filter by provider ID(s).
  - `q`: `string` (optional) — Query or keywords to filter the provider's searchable fields.
  - `is_enabled`: `boolean` (optional) — Filter by whether the provider is enabled.
  - `stock_location_id`: `string` | `string`\[] (optional) — Filter by stock location ID(s) to retrieve their associated fulfillment providers.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="list-returns" />

### Returns

**list**

- `Promise`: Promise\<[AdminFulfillmentProviderListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProviderListResponse)> — The paginated list of providers.
  - `limit`: `number` — The maximum number of items retrieved.
  - `offset`: `number` — The number of items to skip before retrieving the returned items.
  - `count`: `number` — The total number of items.
  - `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
  - `fulfillment_providers`: [AdminFulfillmentProvider](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProvider)\[] — The list of fulfillment providers.
    - `id`: `string` — The fulfillment provider's ID.
    - `is_enabled`: `boolean` — Whether the fulfillment provider is enabled.

## listFulfillmentOptions

This method retrieves a list of fulfillment options for a given fulfillment provider. It sends a request to the
[List Fulfillment Options](/api/admin/fulfillment-providers/list-fulfillment-options)
API route.

### Example

```ts
sdk.admin.fulfillmentProvider.listFulfillmentOptions("fp_123")
.then(({ fulfillment_options }) => {
  console.log(fulfillment_options)
})
```

<a id="listfulfillmentoptions-parameters" />

### Parameters

**listFulfillmentOptions**

- `id`: `string` — The ID of the fulfillment provider.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="listfulfillmentoptions-returns" />

### Returns

**listFulfillmentOptions**

- `Promise`: Promise\<[AdminFulfillmentProviderOptionsListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProviderOptionsListResponse)> — The list of fulfillment options.
  - `limit`: `number` — The maximum number of items retrieved.
  - `offset`: `number` — The number of items to skip before retrieving the returned items.
  - `count`: `number` — The total number of items.
  - `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
  - `fulfillment_options`: [AdminFulfillmentProviderOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProviderOption)\[] — The list of fulfillment options.
    - `id`: `string` — The fulfillment provider option's ID.
    - `is_return`: `boolean` — Whether the fulfillment provider option can be used for returns.
