This documentation provides a reference to the `sdk.admin.stockLocation` set of methods used to send requests to Medusa's Admin API routes.

## create

This method creates a new stock location. It sends a request to the
[Create Stock Location](/api/admin/stock-locations/create-stock-location)
API route.

### Example

```ts
sdk.admin.stockLocation.create({
  name: "Main Warehouse",
  address_id: "addr_123",
})
.then(({ stock_location }) => {
  console.log(stock_location)
})
```

<a id="create-parameters" />

### Parameters

**create**

- `body`: [AdminCreateStockLocation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateStockLocation) — The details of the stock location to create.
  - `name`: `string` — The name of the stock location.
  - `address_id`: `null` | `string` (optional) — The ID of the address to associate with the stock location. If you provide an `address`, you don't need to provide this property.
  - `address`: [AdminUpsertStockLocationAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpsertStockLocationAddress) (optional) — The address to create or update for the stock location. If you provide an `address_id`, you don't need to provide this property.
    - `country_code`: `string`
    - `address_1`: `string`
    - `metadata`: `null` | `Record<string, unknown>` (optional)
    - `address_2`: `null` | `string` (optional)
    - `company`: `null` | `string` (optional)
    - `city`: `null` | `string` (optional)
    - `phone`: `null` | `string` (optional)
    - `postal_code`: `null` | `string` (optional)
    - `province`: `null` | `string` (optional)
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the stock location.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the stock location.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="create-returns" />

### Returns

**create**

- `Promise`: Promise\<[AdminStockLocationResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStockLocationResponse)> — The stock location's details.
  - `stock_location`: [AdminStockLocation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStockLocation) — The stock location's details.
    - `id`: `string` — The ID of the stock location.
    - `name`: `string` — The name of the stock location.
    - `metadata`: `null` | `Record<string, unknown>` — The metadata associated with the stock location.
    - `address_id`: `string` — The ID of the address associated with the stock location.
    - `address`: [AdminStockLocationAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStockLocationAddress) (optional) — The address associated with the stock location.
    - `sales_channels`: [AdminSalesChannel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminSalesChannel)\[] (optional) — The sales channels associated with the stock location.
    - `fulfillment_providers`: [AdminFulfillmentProvider](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProvider)\[] (optional) — The fulfillment providers associated with the stock location.
    - `fulfillment_sets`: [AdminFulfillmentSet](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentSet)\[] (optional) — The fulfillment sets associated with the stock location.

## list

This method retrieves a list of stock locations. It sends a request to the
[List Stock Locations](/api/admin/stock-locations/list-stock-locations)
API route.

### Example

To retrieve the list of stock locations:

```ts
sdk.admin.stockLocation.list()
.then(({ stock_locations, count, limit, offset }) => {
  console.log(stock_locations)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.stockLocation.list({
  limit: 10,
  offset: 10
})
.then(({ stock_locations, count, limit, offset }) => {
  console.log(stock_locations)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each stock location:

```ts
sdk.admin.stockLocation.list({
  fields: "id,*sales_channels"
})
.then(({ stock_locations, count, limit, offset }) => {
  console.log(stock_locations)
})
```

Learn more about the `fields` property in the [API reference](/api/admin/select-fields-and-relations).
