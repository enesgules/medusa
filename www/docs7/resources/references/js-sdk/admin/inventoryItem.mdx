This documentation provides a reference to the `sdk.admin.inventoryItem` set of methods used to send requests to Medusa's Admin API routes.

## create

This method creates an inventory item. It sends a request to the
[Create Inventory Item](/api/admin/inventory-items/create-inventory-item)
API route.

### Example

```ts
sdk.admin.inventoryItem.create({
  sku: "SHIRT"
})
.then(({ inventory_item }) => {
  console.log(inventory_item)
})
```

  - `height`: `null` | `number` (optional) — The inventory item's height.
  - `width`: `null` | `number` (optional) — The inventory item's width.

## export

This method exports inventory items to a CSV file. The CSV file includes the
inventory levels of each item per stock location. It sends a request to the
[Export Inventory Items](/api/admin/inventory-items/export-inventory-items)
API route.

The export is processed asynchronously. Once it's done, admin users receive
a notification with the URL to download the exported file.

### Example

```ts
sdk.admin.inventoryItem.export({})
.then(({ transaction_id }) => {
  console.log(transaction_id)
})
```

## list

This method retrieves a paginated list of inventory items. It sends a request to the
[List Inventory Items](/api/admin/inventory-items/list-inventory-items)
API route.

### Example

To retrieve the list of inventory items:

```ts
sdk.admin.inventoryItem.list()
.then(({ inventory_items, count, limit, offset }) => {
  console.log(inventory_items)
```
