This documentation provides a reference to the `sdk.admin.order` set of methods used to send requests to Medusa's Admin API routes.

## retrieve

This method retrieves an order by its ID. It sends a request to the
[Get Order](/api/admin/orders/get-an-order)
API route.

### Example

To retrieve an order by its ID:

```ts
sdk.admin.order.retrieve("order_123")
.then(({ order }) => {
  console.log(order)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.order.retrieve("order_123", {
  fields: "id,*items"
})
.then(({ order }) => {
  console.log(order)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

### Parameters

**retrieve**

- `id`: `string` — The order's ID.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the order.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

## update

This method updates an order. It sends a request to the
[Update Order Email](/api/admin/orders/update-order)
API route.

### Example

```ts
sdk.admin.order.update(
  "order_123",
  {
    email: "new_email@example.com",
    shipping_address: {
      first_name: "John",
      last_name: "Doe",
      address_1: "123 Main St",
    }
  }
)
.then(({ order }) => {
  console.log(order)
})
```

```ts
sdk.admin.order.list()

})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.order.list({
  limit: 10,
  offset: 10
})
.then(({ orders, count, limit, offset }) => {
  console.log(orders)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each order:

```ts
sdk.admin.order.list({
  fields: "id,*items"

.then(({ orders, count, limit, offset }) => {

})
```

## export

This method starts an order export process to retrieve a CSV of exported orders. It sends
a request to the [Export Orders](/api/admin/orders/export-orders) API route.

You'll receive in the response the transaction ID of the workflow generating the CSV file.
To check the status of the execution, send a `GET` request to
`/admin/workflows-executions/export-orders/:transaction-id`.

Once the execution finishes successfully, a notification is created for the export.
You can retrieve the notifications using the `/admin/notification` API route to
retrieve the file's download URL.

> **Note**
>
> This is available starting from [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3).

```ts
sdk.admin.order.export()
.then(({ transaction_id }) => {
  console.log(transaction_id)
```
