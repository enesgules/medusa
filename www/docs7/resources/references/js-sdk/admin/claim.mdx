This documentation provides a reference to the `sdk.admin.claim` set of methods used to send requests to Medusa's Admin API routes.

## list

This method retrieves a paginated list of claims. It sends a request to the
[List Claims](/api/admin/claims/list-claims) API route.

### Example

To retrieve the list of claims:

```ts
sdk.admin.claim.list()
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.claim.list({
  limit: 10,
  offset: 10
})
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each claim:

```ts
sdk.admin.claim.list({
  fields: "id,*additional_items"
})
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## retrieve

This method retrieves a claim. It sends a request to the
[Get Claim](/api/admin/claims/get-a-claim) API route.

### Example

To retrieve a claim by its ID:

```ts
sdk.admin.claim.retrieve("claim_123")
.then(({ claim }) => {
  console.log(claim)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.claim.retrieve("claim_123", {
  fields: "id,*additional_items"
})
.then(({ claim }) => {
  console.log(claim)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## create

This method creates a claim. It sends a request to the
[Create Claim](/api/admin/claims/create-a-claim) API route.

### Example

```ts
sdk.admin.claim.create({
  type: "refund",
  order_id: "order_123",
})
.then(({ claim }) => {
  console.log(claim)
})
```

<a id="create-parameters" />

### Parameters

**create**

- `body`: [AdminCreateClaim](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateClaim) — The claim's details.
  - `type`: `"refund"` | `"replace"` — The claim's type. If `refund`, it means the claim's items are returned and the customer is refunded. If `replace`, it means the merchant will send new items in place of the returned items.
  - `order_id`: `string` — The ID of the order this claim is created for.
  - `description`: `string` (optional) — The claim's description.
  - `internal_note`: `string` (optional) — An internal note viewed by admin users only.
  - `reason_id`: `null` | `string` (optional) — The ID of the associated reason.
