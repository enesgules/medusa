This documentation provides a reference to the `sdk.admin.apiKey` set of methods used to send requests to Medusa's Admin API routes.

## list

This methods retrieves a paginated list of API keys. It sends a request to the
[List API Keys](/api/admin/api-keys/list-api-keys) API route.

### Example

To retrieve the list of API keys:

```ts
sdk.admin.apiKey.list()
.then(({ api_keys, count, limit, offset }) => {
  console.log(api_keys)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.apiKey.list({
  limit: 10,
  offset: 10
})
.then(({ api_keys, count, limit, offset }) => {
  console.log(api_keys)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each API key:

```ts
sdk.admin.apiKey.list({
  fields: "id,*sales_channels"
})
.then(({ api_keys, count, limit, offset }) => {
  console.log(api_keys)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## create

This method creates an API key. It sends a request to the [Create API Key](/api/admin/api-keys/create-api-key)
API route.

### Example

```ts
sdk.admin.apiKey.create({
  title: "Development",
  type: "publishable"
})
.then(({ api_key }) => {
  console.log(api_key)
})
```

## batchSalesChannels

This method manages the sales channels associated with a publishable API key to either add
or remove associations. It sends a request to the [Manage Sales Channels](/api/admin/api-keys/manage-sales-channels)
API route.

### Example

```ts
sdk.admin.apiKey.batchSalesChannels("apk_123", {
  add: ["sc_123"],
  remove: ["sc_321"]
})
.then(({ api_key }) => {
```
