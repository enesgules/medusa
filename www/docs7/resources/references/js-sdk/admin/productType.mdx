This documentation provides a reference to the `sdk.admin.productType` set of methods used to send requests to Medusa's Admin API routes.

## create

This method creates a product type. It sends a request to the
[Create Product Type](/api/admin/product-types/create-product-type)
API route.

### Example

```ts
sdk.admin.productType.create({
  value: "Clothes"
})
.then(({ product_type }) => {
  console.log(product_type)
})
```

### Parameters

**create**

- `body`: [AdminCreateProductType](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductType) — The product type's details.
  - `value`: `string` — The type's value.
  - `external_id`: `null` | `string` (optional) — An external ID for the product type.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the product type.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

    - `translations`: `null` | [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[] (optional) — The product type's translations.

## list

This method retrieves a paginated list of product types. It sends a request to the
[List Product Types](/api/admin/product-types/list-product-types) API route.

### Example

To retrieve the list of product types:

```ts
sdk.admin.productType.list()
.then(({ product_types, count, limit, offset }) => {
  console.log(product_types)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.productType.list({
  limit: 10,
  offset: 10
})
.then(({ product_types, count, limit, offset }) => {
  console.log(product_types)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each product type:

```ts
sdk.admin.productType.list({
  fields: "id,*products"
})
.then(({ product_types, count, limit, offset }) => {
  console.log(product_types)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
