This documentation provides a reference to the `sdk.admin.exchange` set of methods used to send requests to Medusa's Admin API routes.

## list

This method retrieves a paginated list of exchanges. It sends a request to the
[List Exchanges](/api/admin/exchanges/list-exchanges)
API route.

### Example

To retrieve the list of exchanges:

```ts
sdk.admin.exchange.list()
.then(({ exchanges, count, limit, offset }) => {
  console.log(exchanges)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.exchange.list({
  limit: 10,
  offset: 10
})
.then(({ exchanges, count, limit, offset }) => {
  console.log(exchanges)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each exchange:

```ts
sdk.admin.exchange.list({
  fields: "id,*order"
})
.then(({ exchanges, count, limit, offset }) => {
  console.log(exchanges)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## retrieve

This method retrieves an exchange by its ID. It sends a request to the
[Get Exchange](/api/admin/exchanges/get-an-exchange)
API route.

### Example

To retrieve an exchange by its ID:

```ts
sdk.admin.exchange.retrieve("exchange_123")
.then(({ exchange }) => {
  console.log(exchange)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.exchange.retrieve("exchange_123", {
  fields: "id,*order"
})
.then(({ exchange }) => {
  console.log(exchange)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

### Parameters

**retrieve**

- `id`: `string` — The exchange's ID.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the exchange.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).

## addInboundItems

This method adds inbound (or return) items to an exchange. These inbound items will
have the action `RETURN_ITEM`.

This method sends a request to the [Add Inbound Items](/api/admin/exchanges/add-inbound-items-to-an-exchange)
API route.

### Example

```ts
sdk.admin.exchange.addInboundItems("exchange_123", {
  items: [{
    id: "orli_123",
    quantity: 1
  }]
})
.then(({ return: returnData }) => {
  console.log(returnData)
})
```
