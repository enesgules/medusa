This documentation provides a reference to the `sdk.admin.product` set of methods used to send requests to Medusa's Admin API routes.

## import

This method creates a product import. The products are only imported after
the import is confirmed using the [confirmImport](/resources/references/js_sdk/admin/Product/methods/js_sdkadminProductconfirmImport) method.

This method sends a request to the
[Create Product Import](/api/admin/products/create-product-import)
API route.

### Example

```ts
sdk.admin.product.import({
  file // uploaded File instance
})
.then(({ transaction_id }) => {
  console.log(transaction_id)
})
```

<a id="import-parameters" />

### Parameters

**import**

- `body`: [AdminImportProductRequest](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminImportProductRequest) — The import's details.
  - `file`: [File](/resources/references/core_flows/core_flowsFile) — The CSV file to import the products from. It's an uploaded file of type [File](https://developer.mozilla.org/en-US/docs/Web/API/File).
- `query`: `object` (optional) — Query parameters to pass to the request.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="import-returns" />

### Returns

**import**

- `Promise`: Promise\<[AdminImportProductResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminImportProductResponse)> — The import's details.
  - `transaction_id`: `string` — The ID of the import product workflow execution's transaction. This is useful to confirm the import using the `/admin/products/:transaction-id/import` API route.
  - `summary`: `object` — Details of the products to create or update when the import is confirmed.
    - `toCreate`: `number` — The number of products that will be created by the import.
    - `toUpdate`: `number` — The number of products that will be updated by the import.

## createImport

the import is confirmed using the [confirmImport](/resources/references/js_sdk/admin/Product/methods/js_sdkadminProductconfirmImport) method.

This method sends a request to the
[Create Product Import](/api/admin/products/create-product-import-2)

## confirmImport

This method confirms a product import created using the method [import](/resources/references/js_sdk/admin/Product/methods/js_sdkadminProductimport).
It sends a request to the
[Confirm Product Import](/api/admin/products/confirm-product-import)
API route.

> **Note**
>
> This is available starting from [Medusa v2.8.5](https://github.com/medusajs/medusa/releases/tag/v2.8.5).

### Example

```ts
sdk.admin.product.confirmImport("transaction_123")
.then(() => {
  console.log("Import confirmed")
})
```

<a id="confirmimport-parameters" />

### Parameters

**confirmImport**

- `transactionId`: `string` — The ID of the transaction of the created product import. This is returned by the API route used to create the product import.
- `query`: `object` (optional) — Query parameters to pass in the request.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="confirmimport-returns" />

### Returns

**confirmImport**

- `Promise`: Promise\<object> — This method confirms a product import created using the method [import](/resources/references/js_sdk/admin/Product/methods/js_sdkadminProductimport). It sends a request to the [Confirm Product Import](/api/admin/products/confirm-product-import) API route.

## export

This method starts a product export process to retrieve a CSV of exported products.

You'll receive in the response the transaction ID of the workflow generating the CSV file.
To check the status of the execution, send a `GET` request to
`/admin/workflows-executions/export-products/:transaction-id`.

Once the execution finishes successfully, a notification is created for the export.
You can retrieve the notifications using the `/admin/notification` API route to
retrieve the file's download URL.

This method sends a request to the [Export Product](/api/admin/products/export-products)
API route.

### Example

```ts
sdk.admin.product.export({})
.then(({ transaction_id }) => {
  console.log(transaction_id)
})
```

## batch

This method manages products to create, update, or delete them. It sends a request to the
[Manage Products](/api/admin/products/manage-products)
API route.

### Example

```ts
sdk.admin.product.batch({
  create: [
    {
      title: "Shirt",
      options: [{
        title: "Default",
        values: ["Default Option"]
      }],
      variants: [
        {
          title: "Default",
          options: {
            Default: "Default Option"
          },
          prices: []
        }
      ]
    }
  ],
  update: [{
    id: "prod_123",
    title: "Pants"
  }],
  delete: ["prod_321"]
})
.then(({ created, updated, deleted }) => {
  console.log(created, updated, deleted)
})
```
