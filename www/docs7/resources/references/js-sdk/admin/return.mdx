This documentation provides a reference to the `sdk.admin.return` set of methods used to send requests to Medusa's Admin API routes.

## list

This method retrieves a list of returns. It sends a request to the
[List Returns](/api/admin/returns/list-returns)
API route.

### Example

To retrieve the list of returns:

```ts
sdk.admin.return.list()
.then(({ returns, count, limit, offset }) => {
  console.log(returns)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.return.list({
  limit: 10,
  offset: 10
})
.then(({ returns, count, limit, offset }) => {
  console.log(returns)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each return:

```ts
sdk.admin.return.list({
  fields: "id,*items"
})
.then(({ returns, count, limit, offset }) => {
  console.log(returns)
})
```

Learn more about the `fields` property in the [API reference](/api/admin/select-fields-and-relations).

## retrieve

This method retrieves a return by ID. It sends a request to the
[Get Return](/api/admin/returns/get-a-return)
API route.

### Example

To retrieve a return by its ID:

```ts
sdk.admin.return.retrieve("return_123")
.then(({ return }) => {
  console.log(return)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.return.retrieve("return_123", {
  fields: "id,*items"
})
.then(({ return }) => {
  console.log(return)
})
```

Learn more about the `fields` property in the [API reference](/api/admin/select-fields-and-relations).

<a id="retrieve-parameters" />

### Parameters

**retrieve**

- `id`: `string` — The ID of the return to retrieve.

  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
