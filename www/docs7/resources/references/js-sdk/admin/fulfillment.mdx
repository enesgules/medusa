This documentation provides a reference to the `sdk.admin.fulfillment` set of methods used to send requests to Medusa's Admin API routes.

## create

This method creates a fulfillment. It sends a request to the
[Create Fulfillment](/api/admin/fulfillments/create-fulfillment)
API route.

### Example

```ts
sdk.admin.fulfillment.create({
  location_id: "sloc_123",
  provider_id: "my_fulfillment",
  delivery_address: {
    country_code: "us"
  },
  items: [
    {
      title: "Shirt",
      sku: "SHIRT",
      quantity: 1,
      barcode: "123"
    }
  ],
  labels: [],
  order: {},
  order_id: "order_123"
})
.then(({ fulfillment }) => {
  console.log(fulfillment)
})
```

<a id="create-parameters" />

### Parameters

**create**

- `body`: [AdminCreateFulfillment](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateFulfillment) — The fulfillment's details.
  - `location_id`: `string` — The ID of the location the items are fulfilled from.
  - `provider_id`: `string` — The ID of the fulfillment provider used to handle the fulfillment.
  - `delivery_address`: [AdminFulfillmentDeliveryAddress](/resources/references/types/interfaces/typesAdminFulfillmentDeliveryAddress) — The address to deliver items to.
    - `first_name`: `null` | `string` (optional) — The address's first name.
    - `last_name`: `null` | `string` (optional) — The address's last name.
    - `phone`: `null` | `string` (optional) — The address's phone number.
    - `company`: `null` | `string` (optional) — The address's company.
    - `address_1`: `null` | `string` (optional) — The address's first line.
    - `address_2`: `null` | `string` (optional) — The address's second line.
    - `city`: `null` | `string` (optional) — The address's city.
    - `country_code`: `null` | `string` (optional) — The address's country code.

      Example:

      ```
      us
      ```
    - `province`: `null` | `string` (optional) — The address's lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province.
    - `postal_code`: `null` | `string` (optional) — The address's postal code.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
  - `items`: [AdminCreateFulfillmentItem](/resources/references/types/interfaces/typesAdminCreateFulfillmentItem)\[] — The items to fulfill.
    - `title`: `string` — The item's name.
    - `sku`: `string` — The item's SKU.
    - `quantity`: `number` — The item's quantity.
    - `barcode`: `string` — The item's barcode.
    - `line_item_id`: `null` | `string` (optional) — The ID of the associated line item in an order.
    - `inventory_item_id`: `null` | `string` (optional) — The ID of the associated inventory item.
  - `labels`: [AdminCreateFulfillmentLabel](/resources/references/types/interfaces/typesAdminCreateFulfillmentLabel)\[] — The fulfillment's shipment labels.
    - `tracking_number`: `string` — The tracking number of the fulfillment's shipment.
    - `tracking_url`: `string` — The tracking URL of the fulfillment's shipment.
    - `label_url`: `string` — The label URL of the fulfillment's shipment.
  - `order_id`: `string` — The ID of the order the fulfillment is created for.
  - `shipping_option_id`: `null` | `string` (optional) — The ID of the associated shipping option.
  - `data`: `null` | `Record<string, unknown>` (optional) — Data useful for the fulfillment provider handling the fulfillment. Learn more in [this documentation](/resources/commerce-modules/fulfillment).
  - `packed_at`: `null` | `Date` (optional) — The date the fulfillment items were packed.
  - `shipped_at`: `null` | `Date` (optional) — The date the fulfillment items were shipped.
  - `delivered_at`: `null` | `Date` (optional) — The date the fulfillment items were delivered.
  - `canceled_at`: `null` | `Date` (optional) — The date the fulfillment was canceled.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the fulfillment.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

    - `location_id`: `string` — The ID of the stock location the items are delivered from.

    - `labels`: [AdminFulfillmentLabel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentLabel)\[] — The fulfillment's labels.
    - `packed_at`: `null` | `string` — The date the fulfillment items were packed.

    - `delivered_at`: `null` | `string` — The date the fulfillment items were delivered.
    - `canceled_at`: `null` | `string` — The date the fulfillment was canceled.

    - `updated_at`: `string` — The date the fulfillment was updated.
