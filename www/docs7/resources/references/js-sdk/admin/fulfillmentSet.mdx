This documentation provides a reference to the `sdk.admin.fulfillmentSet` set of methods used to send requests to Medusa's Admin API routes.

## delete

This method deletes a fulfillment set. It sends a request to the
[Delete Fulfillment Set](/api/admin/fulfillment-sets/delete-fulfillment-set)
API route.

### Example

```ts
sdk.admin.fulfillmentSet.delete("fset_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

### Parameters

**delete**

- `id`: `string` — The fulfillment set's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

### Returns

**delete**

- `Promise`: Promise\<[AdminFulfillmentSetDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentSetDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"fulfillment_set"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.

## createServiceZone

This method adds a service zone to a fulfillment set. It uses the
[Add Service Zone](/api/admin/fulfillment-sets/add-service-zone)
API route.

### Example

```ts
sdk.admin.fulfillmentSet.createServiceZone("fset_123", {
  name: "Europe Service Zone",
  geo_zones: [{
    type: "country",
    country_code: "us"
  }]
})
.then(({ fulfillment_set }) => {
  console.log(fulfillment_set)
})
```

<a id="createservicezone-parameters" />

### Parameters

**createServiceZone**

- `id`: `string` — The fulfillment set's ID.
- `body`: [AdminCreateFulfillmentSetServiceZone](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateFulfillmentSetServiceZone) — The service zone's details.
  - `name`: `string` — The service zone's name.
  - `geo_zones`: [AdminUpsertFulfillmentSetServiceZoneGeoZone](/resources/references/types/types/typesAdminUpsertFulfillmentSetServiceZoneGeoZone)\[] — The service zone's geo zones to restrict it to specific geographical locations.
    - `country_code`: `string` — The geo zone's country code.

      Example:

      ```
      us
      ```
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
    - `type`: `"country"` — The geo zone's type.
    - `province_code`: `string` — The geo zone's lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code.
    - `city`: `string` — The geo zone's city.
    - `postal_expression`: `Record<string, unknown>` — The geo zone's postal expression or ZIP code.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the fulfillment set.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="createservicezone-returns" />

### Returns

**createServiceZone**

- `Promise`: Promise\<[AdminFulfillmentSetResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentSetResponse)> — The fulfillment set's details.
  - `fulfillment_set`: [AdminFulfillmentSet](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentSet) — The fulfillment set's details.
    - `id`: `string` — The fulfillment set's ID.
    - `name`: `string` — The fulfillment set's name.
    - `type`: `string` — The fulfillment set's type.

      Example:

      ```
      delivery
      ```
    - `location`: [AdminStockLocation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStockLocation) — The stock location associated with this fulfillment set.
    - `service_zones`: [AdminServiceZone](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminServiceZone)\[] — The fulfillment set's service zones.
    - `created_at`: `string` — The date the fulfillment set is created.
    - `updated_at`: `string` — The date the fulfillment set is updated.
    - `deleted_at`: `null` | `string` — The date the fulfillment set is deleted.

## retrieveServiceZone

This method retrieves a fulfillment set's service zone's details. It sends a request to the
[Get Service Zone](/api/admin/fulfillment-sets/get-a-service-zone)
API route.

### Example

To retrieve a fulfillment set's service zone by its ID:

```ts
sdk.admin.fulfillmentSet.retrieveServiceZone(
  "fset_123",
  "serzo_123"
)
.then(({ service_zone }) => {
  console.log(service_zone)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.fulfillmentSet.retrieveServiceZone(
  "fset_123",
  "serzo_123",
  {
    fields: "id,*geo_zones"
  }
)
.then(({ service_zone }) => {
  console.log(service_zone)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieveservicezone-parameters" />

### Parameters

**retrieveServiceZone**

- `fulfillmentSetId`: `string` — The fulfillment set's ID.
- `serviceZoneId`: `string` — The service zone's ID.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the service zone.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieveservicezone-returns" />

### Returns

**retrieveServiceZone**

- `Promise`: Promise\<[AdminServiceZoneResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminServiceZoneResponse)> — The service zone's details.
  - `service_zone`: [AdminServiceZone](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminServiceZone) — The service zone's details.
    - `id`: `string` — The service zone's ID.
    - `name`: `string` — The service zone's name.
    - `fulfillment_set_id`: `string` — The ID of the fulfillment set this service zone belongs to.
    - `fulfillment_set`: [AdminFulfillmentSet](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentSet) — The fulfillment set this service zone belongs to.
    - `geo_zones`: [AdminGeoZone](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminGeoZone)\[] — The service zone's geo zones.
    - `shipping_options`: [AdminShippingOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingOption)\[] — The shipping options that can be used in this service zone.
    - `created_at`: `string` — The date the service zone is created.
    - `updated_at`: `string` — The date the service zone is updated.
    - `deleted_at`: `null` | `string` — The date the service zone is deleted.
