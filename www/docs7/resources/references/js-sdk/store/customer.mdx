This documentation provides a reference to the `sdk.store.customer` set of methods used to send requests to Medusa's Store API routes.

## create

This method registers a customer. It sends a request to the [Register Customer](/api/store/customers/register-customer)
API route.

You must use the Auth.register method first to retrieve a registration token. Then, pass that
registration token in the `headers` parameter of this method as an authorization bearer header.

Related guide: [How to register customer in storefront](/resources/storefront-development/customers/register)

### Example

```ts
const token = await sdk.auth.register("customer", "emailpass", {
  "email": "customer@gmail.com",
  "password": "supersecret"
})

sdk.store.customer.create(
  {
    "email": "customer@gmail.com"
  },
  {},
  {
    Authorization: `Bearer ${token}`
  }
)
.then(({ customer }) => {
  console.log(customer)
})
```

- `body`: [StoreCreateCustomer](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCreateCustomer) — The customer's details.
  - `email`: `null` | `string` (optional) — The customer's email.
  - `company_name`: `null` | `string` (optional) — The customer's company name.
  - `first_name`: `null` | `string` (optional) — The customer's first name.
  - `last_name`: `null` | `string` (optional) — The customer's last name.

  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.

## listAddress

This method retrieves the logged-in customer's address. The customer must be logged in
first with the Auth.login method.

It sends a request to the [List Customer's Address](/api/store/customers/list-customers-addresses)
API route.

Related guides: [How to manage customer's addresses in the storefront](/resources/storefront-development/customers/addresses)

### Example

To retrieve the list of addresses:

```ts
// TODO must be authenticated as the customer to list their addresses
sdk.store.customer.listAddress()
.then(({ addresses, count, offset, limit }) => {
  console.log(addresses)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
// TODO must be authenticated as the customer to list their addresses
sdk.store.customer.listAddress({
  limit: 10,
  offset: 10
})
.then(({ addresses, count, offset, limit }) => {
  console.log(addresses)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each address:

```ts
// TODO must be authenticated as the customer to list their addresses
sdk.store.customer.listAddress({
  fields: "id,country_code"
})
.then(({ addresses, count, offset, limit }) => {
  console.log(addresses)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## retrieveAddress

first with the Auth.login method.

API route.

Related guides: [How to manage customer's addresses in the storefront](/resources/storefront-development/customers/addresses)

sdk.store.customer.retrieveAddress(
