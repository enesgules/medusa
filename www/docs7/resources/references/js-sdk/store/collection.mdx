This documentation provides a reference to the `sdk.store.collection` set of methods used to send requests to Medusa's Store API routes.

## list

This method retrieves a paginated list of product collections. It sends a request to the
[List Collections](/api/store/collections/list-collections) API route.

Related guide: [How to retrieve collections in a storefront](/resources/storefront-development/products/collections/list).

### Example

To retrieve the list of collections:

```ts
sdk.store.collection.list()
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.store.collection.list({
  limit: 10,
  offset: 10
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each collection:

```ts
sdk.store.collection.list({
  fields: "id,handle"
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

## retrieve

This method retrieves a collection by its ID. It sends a request to the [Get Collection](/api/store/collections/get-a-collection)
API route.

Related guide: [How to retrieve a collection in a storefront](/resources/storefront-development/products/collections/retrieve).

### Example

To retrieve a collection by its ID:

```ts
sdk.store.collection.retrieve("pcol_123")
.then(({ collection }) => {
  console.log(collection)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.store.collection.retrieve("pcol_123", {
  fields: "id,handle"
})
.then(({ collection }) => {
  console.log(collection)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

### Parameters

**retrieve**

- `id`: `string` — The ID of the collection to retrieve.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the collection.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

### Returns

**retrieve**

- `Promise`: Promise\<[StoreCollectionResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCollectionResponse)> — The collection.
  - `collection`: [StoreCollection](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCollection) — The collection's details.
    - `id`: `string` — The collection's ID.
    - `title`: `string` — The collection's title.
    - `handle`: `string` — The collection's handle.
    - `created_at`: `string` — The date the collection was created.
    - `updated_at`: `string` — The date the collection was updated.
    - `deleted_at`: `null` | `string` — The date the collection was deleted.
    - `external_id`: `null` | `string` (optional) — An external ID for the collection.
    - `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
    - `products`: [StoreProduct](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreProduct)\[] (optional) — The collection's products.
