This documentation provides a reference to the `sdk.store.cart` set of methods used to send requests to Medusa's Store API routes.

Related guides: [How to implement carts in the storefront](/resources/storefront-development/cart).

## create

This method creates a cart. It sends a request to the [Create Cart](/api/store/carts/create-cart)
API route.

Related guide: [How to create a cart in the storefront](/resources/storefront-development/cart/create).

### Example

```ts
sdk.store.cart.create({
  region_id: "reg_123"
})
.then(({ cart }) => {
  console.log(cart)
})
```

<a id="create-parameters" />

### Parameters

**create**

- `body`: [StoreCreateCart](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCreateCart) — The details of the cart to create.
  - `region_id`: `null` | `string` (optional) — The ID of the region that the cart is created in. If not provided, the default region of the store is used. If the store doesn't have a default region, an error is thrown.
  - `shipping_address`: `string` | [StoreAddAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddAddress) (optional) — The cart's shipping address.
    - `first_name`: `null` | `string` (optional) — The first name of the address.
    - `last_name`: `null` | `string` (optional) — The last name of the address.
    - `phone`: `null` | `string` (optional) — The phone number of the address.
    - `company`: `null` | `string` (optional) — The company of the address.
    - `address_1`: `null` | `string` (optional) — The first address line of the address.
    - `address_2`: `null` | `string` (optional) — The second address line of the address.
    - `city`: `null` | `string` (optional) — The city of the address.
    - `country_code`: `null` | `string` (optional) — The country code of the address.
    - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province/state of the address.
    - `postal_code`: `null` | `string` (optional) — The postal code of the address.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `billing_address`: `string` | [StoreAddAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddAddress) (optional) — The cart's billing address.
    - `first_name`: `null` | `string` (optional) — The first name of the address.
    - `last_name`: `null` | `string` (optional) — The last name of the address.
    - `phone`: `null` | `string` (optional) — The phone number of the address.
    - `company`: `null` | `string` (optional) — The company of the address.
    - `address_1`: `null` | `string` (optional) — The first address line of the address.
    - `address_2`: `null` | `string` (optional) — The second address line of the address.
    - `city`: `null` | `string` (optional) — The city of the address.
    - `country_code`: `null` | `string` (optional) — The country code of the address.
    - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province/state of the address.
    - `postal_code`: `null` | `string` (optional) — The postal code of the address.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `email`: `null` | `string` (optional) — The email of the customer associated with the cart.
  - `currency_code`: `null` | `string` (optional) — The cart's currency code. If not provided, the region's currency code is used.
  - `items`: [StoreAddCartLineItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddCartLineItem)\[] (optional) — The cart's items.
    - `variant_id`: `string` — The ID of the product variant to add to the cart.
    - `quantity`: `number` — The item's quantity in the cart.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
  - `sales_channel_id`: `null` | `string` (optional) — The ID of the associated sales channel. A product's availability in a sales channel only filters the products you retrieve. Medusa doesn't reject a variant added to the cart when its product isn't available in the cart's sales channel. Learn how to enforce that validation in [this guide](/resources/commerce-modules/cart/sales-channel-availability).
  - `promo_codes`: `string`\[] (optional) — The promotion codes to apply on the cart.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
  - `locale`: `null` | `string` (optional) — The BCP 47 language tag code of the locale.

    Example:

    ```
    "en-US"
    ```
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the cart.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

### Returns

**create**

- `Promise`: Promise\<[StoreCartResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartResponse)> — The created cart.

    - `updated_at`: `string` | `Date` (optional) — When the cart was updated.
    - `original_item_total`: `number` — The sum of all line items' original totals before discounts, including taxes.
    - `original_item_subtotal`: `number` — The sum of all line items' original subtotals before discounts, excluding taxes.
    - `original_item_tax_total`: `number` — The sum of all line items' original tax totals before discounts.
    - `item_total`: `number` — The sum of all line items' totals after discounts, including taxes.
    - `item_subtotal`: `number` — The sum of all line items' subtotals before discounts, excluding taxes.
    - `item_tax_total`: `number` — The sum of all line items' tax totals after discounts.
    - `original_total`: `number` — The cart's total before discounts, including taxes. Calculated as the sum of `original_item_total` and `original_shipping_total`.
    - `original_subtotal`: `number` — The cart's subtotal before discounts, excluding taxes. Calculated as the sum of `original_item_subtotal` and `original_shipping_subtotal`.
    - `original_tax_total`: `number` — The cart's tax total before discounts. Calculated as the sum of `original_item_tax_total` and `original_shipping_tax_total`.
    - `total`: `number` — The cart's final total after discounts and credit lines, including taxes.
    - `subtotal`: `number` — The cart's subtotal before discounts, excluding taxes. Calculated as the sum of `item_subtotal` and `shipping_subtotal`.
    - `tax_total`: `number` — The cart's tax total after discounts. Calculated as the sum of `item_tax_total` and `shipping_tax_total`.
    - `discount_total`: `number` — The total amount of discounts applied to the cart, including the tax portion of discounts.
    - `discount_tax_total`: `number` — The total amount of discounts applied to the cart's tax. Represents the tax portion of discounts.
    - `gift_card_total`: `number` — The gift card total of the cart.
    - `gift_card_tax_total`: `number` — The gift card tax total of the cart.
    - `shipping_total`: `number` — The sum of all shipping methods' totals after discounts, including taxes.
    - `shipping_subtotal`: `number` — The sum of all shipping methods' subtotals before discounts, excluding taxes.
    - `shipping_tax_total`: `number` — The sum of all shipping methods' tax totals after discounts.
    - `original_shipping_total`: `number` — The sum of all shipping methods' original totals before discounts, including taxes.
    - `original_shipping_subtotal`: `number` — The sum of all shipping methods' original subtotals before discounts, excluding taxes.
    - `original_shipping_tax_total`: `number` — The sum of all shipping methods' original tax totals before discounts.
    - `completed_at`: `string` | `Date` (optional) — The date the cart was completed.
    - `shipping_address`: [StoreCartAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartAddress) (optional) — The cart's shipping address.
    - `billing_address`: [StoreCartAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartAddress) (optional) — The cart's billing address.
    - `items`: [StoreCartLineItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartLineItem)\[] (optional) — The cart's items.
    - `shipping_methods`: [StoreCartShippingMethod](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartShippingMethod)\[] (optional) — The cart's shipping methods.

    - `region`: [StoreRegion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreRegion) (optional) — The cart's region
    - `promotions`: [StoreCartPromotion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreCartPromotion)\[] — The promotions applied to the cart.

## retrieve

This method retrieves a cart by its ID. It sends a request to the
[Get Cart](/api/store/carts/get-a-cart) API route.

Related guide: [How to retrieve a cart in the storefront](/resources/storefront-development/cart/retrieve).

### Example

To retrieve a cart by its ID:

```ts
sdk.store.cart.retrieve("cart_123")
.then(({ cart }) => {
  console.log(cart)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.store.cart.retrieve("cart_123", {
  fields: "id,*items"
})
.then(({ cart }) => {
  console.log(cart)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
