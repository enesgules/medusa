---
title: CurrencyDTO
---

A currency's data.

**CurrencyDTO**

- `code`: `string` — The ISO 3 character code of the currency.

  Example:

  ```
  usd
  ```
- `symbol`: `string` — The symbol of the currency.

  Example:

  ```
  $
  ```
- `symbol_native`: `string` — The symbol of the currecy in its native form. This is typically the symbol used when displaying a price.

  Example:

  ```
  $
  ```
- `name`: `string` — The name of the currency.

  Example:

  ```
  US Dollar
  ```
