This documentation provides a reference to the Currency data model. It belongs to the Currency Module.

**Currency**

- `code`: PrimaryKeyModifier\<TextProperty> — The ISO 3-character currency code. For example, `USD`.
  - `$dataType`: `string` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)
  - `#filterable`: `boolean` (optional)
  - `#sortable`: `boolean` (optional)
  - `#facetable`: `boolean` | `object` (optional)
    - `types`: [SearchFacetKind](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFacetKind)\[] (optional)
  - `#array`: `boolean` (optional)
  - `#searchable`: `boolean` | `object` (optional)
    - `weight`: `number` (optional)
  - `dataType`: `object` — The runtime dataType for the schema. It is not the same as the "\$dataType".
    - `name`: `"text"`
    - `options`: `Record<string, any>` (optional)
- `symbol`: [TextProperty](/resources/references/utils/classes/utilsTextProperty) — The symbol of the currency. For example, `$`.
  - `$dataType`: `string` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)
  - `#filterable`: `boolean` (optional)
  - `#sortable`: `boolean` (optional)
  - `#facetable`: `boolean` | `object` (optional)
    - `types`: [SearchFacetKind](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFacetKind)\[] (optional)
  - `#array`: `boolean` (optional)
  - `#searchable`: `boolean` | `object` (optional)
    - `weight`: `number` (optional)
  - `dataType`: `object` — The runtime dataType for the schema. It is not the same as the "\$dataType".
    - `name`: `"text"`
    - `options`: `Record<string, any>` (optional)
- `symbol_native`: [TextProperty](/resources/references/utils/classes/utilsTextProperty) — The native symbol of the currency, if it has a different local symbol.
  - `$dataType`: `string` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)
  - `#filterable`: `boolean` (optional)
  - `#sortable`: `boolean` (optional)

    - `name`: `"text"`
    - `options`: `Record<string, any>` (optional)
- `name`: [TextProperty](/resources/references/utils/classes/utilsTextProperty) — The name of the currency
  - `$dataType`: `string` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)

    - `types`: [SearchFacetKind](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFacetKind)\[] (optional)
  - `#array`: `boolean` (optional)
  - `#searchable`: `boolean` | `object` (optional)
    - `weight`: `number` (optional)
  - `dataType`: `object` — The runtime dataType for the schema. It is not the same as the "\$dataType".
    - `name`: `"text"`
    - `options`: `Record<string, any>` (optional)
- `decimal_digits`: `NumberProperty` — How many digits are after the decimal separator for prices in this currency.
- `rounding`: `BigNumberProperty` — The rounding percision of prices in this currency.
