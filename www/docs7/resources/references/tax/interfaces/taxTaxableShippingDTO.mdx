title: TaxableShippingDTO
---

The taxable shipping details.

**TaxableShippingDTO**

- `id`: `string` — The ID of the taxable shipping.
- `shipping_option_id`: `string` — The associated shipping option's ID.
- `unit_price`: [BigNumberInput](/resources/references/tax/types/taxBigNumberInput) (optional) — The unit price of the taxable shipping.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/tax/types/taxBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `currency_code`: `string` (optional) — The ISO 3 character currency code of the taxable shipping.
