The taxable item details.

**TaxableItemDTO**

- `id`: `string` — The ID of the taxable item.
- `product_id`: `string` — The associated product's ID.
- `product_type_id`: `string` (optional) — The ID of the type of the item's product.
- `quantity`: [BigNumberInput](/resources/references/tax/types/taxBigNumberInput) (optional) — The quantity of the taxable item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/tax/types/taxBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `unit_price`: [BigNumberInput](/resources/references/tax/types/taxBigNumberInput) (optional) — The unit price of the taxable item.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/tax/types/taxBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `currency_code`: `string` (optional) — The ISO 3 character currency code of the taxable item.
