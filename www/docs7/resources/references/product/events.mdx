This reference shows all the events emitted by the Medusa application related to the Product Module. If you use the module outside the Medusa application, these events aren't emitted.

## Product Events

### Summary

| Event                                                                    | Description                        |
| ------------------------------------------------------------------------ | ---------------------------------- |
| [`product.updated`](/resources/references/product/events#productupdated) | Emitted when products are updated. |
| [`product.created`](/resources/references/product/events#productcreated) | Emitted when products are created. |
| [`product.deleted`](/resources/references/product/events#productdeleted) | Emitted when products are deleted. |

### product.updated

Emitted when products are updated.

#### Payload

```ts
{
  id, // The ID of the product
}
```

#### Workflows Emitting this Event

- [updateProductsWorkflow](/resources/references/medusa-workflows/updateProductsWorkflow)
- [createAndLinkProductOptionsToProductWorkflow](/resources/references/medusa-workflows/createAndLinkProductOptionsToProductWorkflow)
- [batchProductsWorkflow](/resources/references/medusa-workflows/batchProductsWorkflow)
- [importProductsWorkflow](/resources/references/medusa-workflows/importProductsWorkflow)

### product.created

Emitted when products are created.

#### Payload

```ts

}
```

#### Workflows Emitting this Event

- [createProductsWorkflow](/resources/references/medusa-workflows/createProductsWorkflow)
- [batchProductsWorkflow](/resources/references/medusa-workflows/batchProductsWorkflow)
- [importProductsWorkflow](/resources/references/medusa-workflows/importProductsWorkflow)
