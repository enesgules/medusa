## updateProductVariants(id, data, sharedContext?): Promise\<[ProductVariantDTO](/resources/references/product/interfaces/productProductVariantDTO)>

This method is used to update a variant.

### Example

```ts
const variant = await productModuleService.updateProductVariants(
  "variant_123",
  {
    title: "Blue Shirt",
  }
```
