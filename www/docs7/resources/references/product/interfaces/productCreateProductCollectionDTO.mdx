title: CreateProductCollectionDTO
---

A product collection to create.

**CreateProductCollectionDTO**

- `title`: `string` — The product collection's title.
- `handle`: `string` (optional) — The product collection's handle. If not provided, the value of this attribute is set to the slug version of the title.
- `product_ids`: `string`\[] (optional) — The products to associate with the collection.
- `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — Holds custom data in key-value pairs.
