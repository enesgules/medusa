title: UpsertProductTypeDTO
---

A product type to create or update

**UpsertProductTypeDTO**

- `id`: `string` (optional) — The product type's ID. If provided, the product tag is updated. Otheriwse, it's created. In that case, the `value` property is required.
- `value`: `string` (optional) — The new value of the product type.
- `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — Holds custom data in key-value pairs.
