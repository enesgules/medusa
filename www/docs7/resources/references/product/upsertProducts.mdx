<a id="upsertproducts-data-sharedcontext-promiseproductdto" />

## upsertProducts(data, sharedContext?): Promise\<[ProductDTO](/resources/references/product/interfaces/productProductDTO)\[]>

This method updates existing products, or creates new ones if they don't exist.

### Example

```ts
const products = await productModuleService.upsertProducts([
  {
    id: "prod_123",
    handle: "pant",
  },
  {
    title: "Shirt",
  },
])
```
