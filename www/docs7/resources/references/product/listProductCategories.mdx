This documentation provides a reference to the `listProductCategories` method. This belongs to the Product Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method is used to retrieve a paginated list of product categories based on optional filters and configuration.

## Example

To retrieve a list of product categories using their IDs:

```ts
const categories = await productModuleService.listProductCategories({
  id: ["pcat_123", "pcat_321"],
})
```

To specify relations that should be retrieved within the product categories:

> **Note**
>
> You can only retrieve data models defined in the same module. To retrieve linked data models
> from other modules, use [Query](/learn/fundamentals/module-links/query) instead.

```ts
const categories = await productModuleService.listProductCategories(
  {
    id: ["pcat_123", "pcat_321"],
  },
  {
    relations: ["products"],
  }
)
```

By default, only the first `15` records are retrieved. You can control pagination by specifying the `skip` and `take` properties of the `config` parameter:

```ts
const categories = await productModuleService.listProductCategories(
  {
    id: ["pcat_123", "pcat_321"],
  },
  {
    relations: ["products"],
    take: 20,
    skip: 2,
  }
)
```
