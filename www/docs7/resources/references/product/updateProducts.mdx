## updateProducts(id, data, sharedContext?): Promise\<[ProductDTO](/resources/references/product/interfaces/productProductDTO)>

This method is used to update a product.

### Example

```ts
const product = await productModuleService.updateProducts(
  "prod_123",
  {
    handle: "pant",
  }
)
```
