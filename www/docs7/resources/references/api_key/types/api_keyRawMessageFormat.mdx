title: RawMessageFormat
---

- `RawMessageFormat`: `object`
  - `eventName`: `string`
  - `data`: TData
  - `source`: `string`
  - `object`: `string`
  - `action`: `string` (optional)
  - `context`: Pick\<[Context](/resources/references/api_key/interfaces/api_keyContext), "eventGroupId"> (optional)
    - `eventGroupId`: `string` (optional) — A string indicating the ID of the group to aggregate the events to be emitted at a later point.
  - `options`: `Record<string, any>` (optional)
