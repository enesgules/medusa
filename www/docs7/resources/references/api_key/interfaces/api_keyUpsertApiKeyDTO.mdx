The attributes in the API key to be created or updated.

**UpsertApiKeyDTO**

- `id`: `string` (optional) — The ID of the API key.
- `title`: `string` (optional) — The title of the API key.
- `type`: [ApiKeyType](/resources/references/api_key/types/api_keyApiKeyType) (optional) — The type of the API key. Required only when creating an API key.
- `created_by`: `string` (optional) — Who created the API key. It's only usable and required when creating an API key.
