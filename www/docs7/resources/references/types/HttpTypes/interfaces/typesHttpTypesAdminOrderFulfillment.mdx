## Properties

**AdminOrderFulfillment**

- `id`: `string` — The fulfillment's ID.
- `location_id`: `string` — The ID of the location the items are fulfilled from.
- `packed_at`: `null` | `Date` — The date the fulfillment was packed.
- `shipped_at`: `null` | `Date` — The date the fulfillment was shipped.
- `delivered_at`: `null` | `Date` — The date the fulfillment was delivered.
- `canceled_at`: `null` | `Date` — The date the fulfillment was canceled.
- `requires_shipping`: `boolean` — Whether the fulfillment requires shipping.
- `data`: `null` | `Record<string, unknown>` — Data necessary for the provider handling the fulfillment. Learn more in [this guide](/resources/commerce-modules/fulfillment/shipping-option#data-property).
- `provider_id`: `string` — The ID of the fulfillment provider handling this fulfillment.
- `shipping_option_id`: `null` | `string` — The ID of the associated shipping option.
- `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
- `created_at`: `Date` — The date the fulfillment was created.
- `created_by`: `null` | `string` — The ID of the user that created the fulfillment.
- `marked_shipped_by`: `null` | `string` — The ID of the user that shipped the fulfillment.
- `updated_at`: `Date` — The date the fulfillment was updated.
