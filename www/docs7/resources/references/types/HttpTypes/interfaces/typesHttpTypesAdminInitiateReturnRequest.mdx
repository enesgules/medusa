## Properties

**AdminInitiateReturnRequest**

- `order_id`: `string` — The ID of the order that the return belongs to.
- `location_id`: `string` (optional) — The ID of the stock location to return the items to.
- `description`: `string` (optional) — The return's description.
- `internal_note`: `string` (optional) — A note that is viewed by admins only to describe the return.
- `no_notification`: `boolean` (optional) — Whether to send a notification to the customer for return updates.
- `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the return.
