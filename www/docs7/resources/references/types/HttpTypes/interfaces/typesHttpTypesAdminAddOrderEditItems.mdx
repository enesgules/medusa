## Properties

**AdminAddOrderEditItems**

- `items`: `object`\[] — The details of the items to add.
  - `variant_id`: `string` — The ID of the product variant to add.
  - `quantity`: `number` — The item's quantity.
  - `unit_price`: `number` (optional) — A custom price to use for the item.
  - `internal_note`: `string` (optional) — An internal note viewed by admin users only.
  - `allow_backorder`: `boolean` (optional) — Whether the variant can be added even if it's out of stock.
  - `metadata`: `Record<string, unknown>` (optional) — Key-value pairs of custom data.
