## Properties

**StoreReturn**

- `id`: `string` — The return's ID.
- `order_id`: `string` — The ID of the order that the return belongs to.
- `status`: [ReturnStatus](/resources/references/order/types/orderReturnStatus) (optional) — The return's status.
- `exchange_id`: `string` (optional) — The ID of the exchange that the return belongs to, if available.
- `location_id`: `string` (optional) — The ID of the stock location that the items are returned to.
- `claim_id`: `string` (optional) — The ID of the claim that the return belongs to, if available.
- `display_id`: `number` — The display ID of the return.
- `refund_amount`: `number` (optional) — The amount that is to be refunded to the customer.
- `received_at`: `string` — The date when the return was received.
- `created_at`: `string` — The date when the return was created.
- `created_by`: `string` — The ID of the user that created the return.
- `canceled_at`: `string` — The date when the return was canceled.
- `requested_at`: `string`
- `items`: [StoreReturnItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreReturnItem)\[] — The return's items.
  - `id`: `string` — The return item's ID.
  - `quantity`: `number` — The quantity of the item that is to be returned.
  - `received_quantity`: `number` — The quantity of the item that has been received.
  - `damaged_quantity`: `number` — The quantity of the item that has been received and is damaged. This quantity is not added back to the quantity in the stock location.
  - `reason_id`: `string` (optional) — The ID of the associated return reason.
  - `note`: `string` (optional) — A note to describe why the item is being returned.
  - `item_id`: `string` — The ID of the order item that is being returned.
  - `return_id`: `string` — The ID of the return that the item belongs to.
  - `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the return item.
