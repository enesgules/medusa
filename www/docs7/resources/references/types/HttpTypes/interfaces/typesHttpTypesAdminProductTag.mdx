---
title: AdminProductTag
---

A product tag. Tags can be applied to products to help categorize them.

## Properties

**AdminProductTag**

- `translations`: `null` | [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[] (optional) — The tag's translations.
  - `id`: `string` — The ID of the translation.
  - `reference_id`: `string` — The ID of the entity being translated.

    Example:

    ```
    "prod_123"
    ```
  - `reference`: `string` — The name of the table that the translation belongs to.

    Example:

    ```
    "product"
    ```
  - `locale_code`: `string` — The BCP 47 language tag code for this translation.

    Example:

    ```
    "en-US"
    ```
  - `translations`: `Record<string, unknown>` — The translations of the resource. The object's keys are the field names of the data model, and its value is the translated value.

    Example:

    ```
    { * "title": "Product Title", * "description": "Product Description", * }
    ```
  - `created_at`: `string` | `Date` — The date and time the translation was created.
  - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
- `id`: `string` — The tag's ID.
- `value`: `string` — The tag's value.
- `created_at`: `string` — The date the tag was created.
- `updated_at`: `string` — The date the tag was updated.
- `deleted_at`: `null` | `string` (optional) — The date the tag was deleted.
- `external_id`: `null` | `string` (optional) — An external ID for the tag.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
