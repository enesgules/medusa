## Properties

**StoreCreateCart**

- `region_id`: `null` | `string` (optional) — The ID of the region that the cart is created in. If not provided, the default region of the store is used. If the store doesn't have a default region, an error is thrown.
- `shipping_address`: `string` | [StoreAddAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddAddress) (optional) — The cart's shipping address.
  - `first_name`: `null` | `string` (optional) — The first name of the address.
  - `last_name`: `null` | `string` (optional) — The last name of the address.
  - `phone`: `null` | `string` (optional) — The phone number of the address.
  - `company`: `null` | `string` (optional) — The company of the address.
  - `address_1`: `null` | `string` (optional) — The first address line of the address.
  - `address_2`: `null` | `string` (optional) — The second address line of the address.
  - `city`: `null` | `string` (optional) — The city of the address.
  - `country_code`: `null` | `string` (optional) — The country code of the address.
  - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province/state of the address.
  - `postal_code`: `null` | `string` (optional) — The postal code of the address.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `billing_address`: `string` | [StoreAddAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddAddress) (optional) — The cart's billing address.
  - `first_name`: `null` | `string` (optional) — The first name of the address.
  - `last_name`: `null` | `string` (optional) — The last name of the address.
  - `phone`: `null` | `string` (optional) — The phone number of the address.
  - `company`: `null` | `string` (optional) — The company of the address.
  - `address_1`: `null` | `string` (optional) — The first address line of the address.
  - `address_2`: `null` | `string` (optional) — The second address line of the address.
  - `city`: `null` | `string` (optional) — The city of the address.
  - `country_code`: `null` | `string` (optional) — The country code of the address.
  - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province/state of the address.
  - `postal_code`: `null` | `string` (optional) — The postal code of the address.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `email`: `null` | `string` (optional) — The email of the customer associated with the cart.
- `currency_code`: `null` | `string` (optional) — The cart's currency code. If not provided, the region's currency code is used.
- `items`: [StoreAddCartLineItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreAddCartLineItem)\[] (optional) — The cart's items.
  - `variant_id`: `string` — The ID of the product variant to add to the cart.
  - `quantity`: `number` — The item's quantity in the cart.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `sales_channel_id`: `null` | `string` (optional) — The ID of the associated sales channel. A product's availability in a sales channel only filters the products you retrieve.
