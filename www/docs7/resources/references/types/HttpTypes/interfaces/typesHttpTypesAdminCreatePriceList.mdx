The details of a price list to create.

## Properties

**AdminCreatePriceList**

- `title`: `string` — The price list's title.
- `description`: `string` — The price list's description.
- `starts_at`: `null` | `string` (optional) — The price list's start date.
- `ends_at`: `null` | `string` (optional) — The price list's end date.
- `status`: [PriceListStatus](/resources/references/pricing/types/pricingPriceListStatus) (optional) — The price list's status.
- `type`: [PriceListType](/resources/references/pricing/types/pricingPriceListType) (optional) — The price list's type.
- `rules`: `Record<string, string[]>` (optional) — The price list's rules.
- `prices`: [AdminCreatePriceListPrice](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreatePriceListPrice)\[] (optional) — The price list's prices.
  - `currency_code`: `string` — The price's currency code.

    Example:

    ```
    usd
    ```
  - `amount`: `number` — The price's amount.
  - `variant_id`: `string` — The ID of the variant this price applies to.
  - `min_quantity`: `null` | `number` (optional) — The minimum quantity that must be available in the cart for the price to be applied.
  - `max_quantity`: `null` | `number` (optional) — The maximum quantity allowed to be available in the cart for the price to be applied.
  - `rules`: `Record<string, string>` (optional) — The price's rules.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
