## Properties

**AdminImportProductsRequest**

- `file_key`: `string` — The file's identifier in the third-party system. For example, the S3 Module Provider returns the file's key in S3, whereas the Local File Module Provider returns the file's path.
- `originalname`: `string` — The original name of the file on the user's computer (aka clientName)
- `extension`: `string` — The file's extension.
- `size`: `number` — The file's size in bytes.
- `mime_type`: `string` — The file's mime type.
