---
title: AdminSearchParams
---

The parameters to pass when searching across admin entities.

## Properties

**AdminSearchParams**

- `q`: `string` (optional) — Applied to every entity searched.
- `entity`: `string` | `string`\[] (optional) — The entities / indexes to search, comma-separated. When the Search Module is enabled, defaults to every registered index. Otherwise defaults to the admin fallback entity set. Per entity, an index is used when one exists; otherwise the request falls back to `query.graph` for that entity only.
- `limit`: `number` (optional) — Per entity, not across the response — each group paginates on its own.
- `offset`: `number` (optional) — The number of items to skip before the results. Used for pagination.
