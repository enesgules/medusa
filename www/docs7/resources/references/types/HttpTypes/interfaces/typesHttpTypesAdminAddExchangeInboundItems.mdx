## Properties

**AdminAddExchangeInboundItems**

- `location_id`: `string` (optional) — The ID of the location the items are returned to.
- `items`: `object`\[] — The items to add to the exchange.
  - `id`: `string` — The ID of the order item returned.
  - `quantity`: `number` — The item's quantity.
  - `description`: `string` (optional) — The description of why the item is being returned.
  - `internal_note`: `string` (optional) — An internal note viewed by admin users only.
  - `reason_id`: `string` (optional) — The ID of the associated return reason.
  - `metadata`: `Record<string, unknown>` (optional) — Key-value pairs of custom data.
