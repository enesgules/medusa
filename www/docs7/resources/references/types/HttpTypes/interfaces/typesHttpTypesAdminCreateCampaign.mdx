## Properties

**AdminCreateCampaign**

- `name`: `string` — The campaign's name.
- `description`: `null` | `string` (optional) — The campaign's description.
- `campaign_identifier`: `string` — The campaign's identifier.
- `starts_at`: `null` | `Date` (optional) — The date the campaign and its promotions start at.
- `ends_at`: `null` | `Date` (optional) — The date the campaign and its promotions end at.
- `budget`: `null` | `object` (optional) — The campaign's budget.
  - `type`: [CampaignBudgetTypeValues](/resources/references/promotion/types/promotionCampaignBudgetTypeValues) (optional) — The budget's type. `spend` means the limit is set on the total amount discounted by the campaign's promotions; `usage` means the limit is set on the total number of times the campaign's promotions can be used. `use_by_attribute` means the limit is set for a specific condition, such as per customer.
  - `currency_code`: `null` | `string` (optional) — The budget's currency code.

    Example:

    ```
    usd
    ```
  - `limit`: `null` | `number` (optional) — The budget's limit.
  - `attribute`: `null` | `string` (optional) — The attribute that the budget limit is applied to. By default, the budget is applied globally. If the type is `use_by_attribute`, this field indicates the attribute the budget is tracked by. For example, `customer_id` means the budget is tracked per customer.

    Example:

    ```
    customer_id
    ```
