Full property descriptor with all metadata.

## Properties

**PropertyDescriptor**

- `name`: `string` — Property name/path (e.g., "display\_id", "customer.email").
- `displayName`: `string` — Human-readable display name.
- `dataType`: [PropertyDataType](/resources/references/types/HttpTypes/types/typesHttpTypesPropertyDataType) — The data type of the property.
- `renderMode`: `string` — How the property should be rendered in the UI.
- `nullable`: `boolean` — Whether the property can be null.
- `computed`: `boolean` — Whether this is a computed/derived property.
- `filter`: [PropertyFilterConfig](/resources/references/types/HttpTypes/interfaces/typesHttpTypesPropertyFilterConfig) — Filter configuration for this property.
  - `filterable`: `boolean` — Whether the property can be filtered.
  - `operators`: `string`\[] (optional) — Available filter operators for this property.
  - `enumValues`: `string`\[] (optional) — Enum values if the property is an enum type.
- `sortable`: `boolean` — Whether the property can be sorted.
- `semanticType`: `string` (optional) — Optional semantic type for additional context.
- `relationship`: `object` (optional) — Relationship information if this is a relationship field.
  - `type`: `string`
  - `entity`: `string`
  - `foreignKey`: `string` (optional)
- `source`: `object` — Source information about where this property comes from.
  - `module`: `string`
  - `entity`: `string`
