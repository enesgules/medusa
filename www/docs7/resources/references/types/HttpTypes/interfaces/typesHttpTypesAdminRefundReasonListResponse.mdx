## Properties

**AdminRefundReasonListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `refund_reasons`: [AdminRefundReason](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReason)\[] — The list of refund reasons.
  - `id`: `string` — The refund reason's ID.
  - `label`: `string` — The refund reason's label.

    Example:

    ```
    "Refund"
    ```
  - `code`: `string` — The refund reason's code.

    Example:

    ```
    "refund"
    ```
  - `description`: `null` | `string` (optional) — The refund reason's description.
  - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs that can be added to the refund reason.
  - `created_at`: `string` — The date that the refund reason was created.
  - `updated_at`: `string` — The date that the refund reason was updated.
