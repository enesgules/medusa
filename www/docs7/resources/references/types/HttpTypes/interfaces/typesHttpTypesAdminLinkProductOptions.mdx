## Properties

**AdminLinkProductOptions**

- `add`: (`string` | [AdminCreateProductOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductOption) | [AdminLinkProductOptionWithValues](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminLinkProductOptionWithValues))\[] (optional) — The list of options to add to the product. You can pass either: 1. The ID of an existing product option as a string. 2. An object with `id` and `value_ids` to add an existing product option with specific values. This is useful when you want to associate only specific option values of an option to the product. 3. An object to create a new product option.
  - `title`: `string` — The option's title.
  - `values`: `string`\[] — The option's values.
  - `ranks`: `Record<string, number>` (optional) — The rank for each option value. The keys are the option values, and the values are their respective ranks.

    Example:

    ```
    { * "Small": 1, * "Medium": 2, * "Large": 3 * }
    ```
  - `is_exclusive`: `boolean` (optional) — Whether the option is exclusive to a specific product, or can be shared across multiple products.
  - `id`: `string` — The ID of the product option to add.
  - `value_ids`: `string`\[] — The IDs of specific option values to add to the product. This is useful when you want to associate only specific values of an option to the product.
- `remove`: `string`\[] (optional) — The list of options to remove from the product.
- `update`: [AdminUpdateProductOptionValues](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateProductOptionValues)\[] (optional) — The list of product option value updates for existing product options.
  - `product_option_id`: `string` — The ID of the product option to update values for.
  - `add`: (`string` | `object`)\[] (optional) — The IDs of specific option values to add or new values to create.
    - `value`: `string`
  - `remove`: `string`\[] (optional) — The IDs of specific option values to remove.
