## Properties

**AdminCurrencyListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `currencies`: [AdminCurrency](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCurrency)\[] — The list of currencies
  - `code`: `string` — The currency's code.

    Example:

    ```
    usd
    ```
  - `symbol`: `string` — The currency's symbol.

    Example:

    ```
    $
    ```
  - `symbol_native`: `string` — The currency's symbol in its native language or country.

    Example:

    ```
    $
    ```
  - `name`: `string` — The currency's name.
  - `decimal_digits`: `number` — The number of digits after the decimal for prices in this currency.
  - `rounding`: `number` — The rounding percision applied on prices in this currency.
  - `created_at`: `string` — The date the currency was created.
  - `updated_at`: `string` — The date the currency was updated.
  - `deleted_at`: `null` | `string` — The date the currency was deleted.
