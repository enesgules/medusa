## Properties

**AdminLocaleListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `locales`: [AdminLocale](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminLocale)\[] — The list of locales.
  - `code`: `string` — The locale's code.

    Example:

    ```
    en-US
    ```
  - `name`: `string` — The locale's display name.

    Example:

    ```
    English (United States)
    ```
  - `created_at`: `string` — The date the locale was created.
  - `updated_at`: `string` — The date the locale was updated.
  - `deleted_at`: `null` | `string` — The date the locale was deleted.
