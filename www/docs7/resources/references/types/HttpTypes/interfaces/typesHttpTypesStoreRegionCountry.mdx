## Properties

**StoreRegionCountry**

- `id`: `string` — The country's ID.
- `iso_2`: `string` (optional) — The country's ISO 2 code.

  Example:

  ```
  us
  ```
- `iso_3`: `string` (optional) — The country's ISO 3 code.

  Example:

  ```
  usa
  ```
- `num_code`: `string` (optional) — The country's num code.

  Example:

  ```
  840
  ```
- `name`: `string` (optional) — The country's name.
- `display_name`: `string` (optional) — The country's name used for display.
