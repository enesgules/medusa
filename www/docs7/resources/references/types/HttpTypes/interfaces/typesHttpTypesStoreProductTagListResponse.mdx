## Properties

**StoreProductTagListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `product_tags`: [StoreProductTag](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreProductTag)\[] — The paginated list of tags.
  - `id`: `string` — The tag's ID.
  - `value`: `string` — The tag's value.
  - `created_at`: `string` — The date the tag was created.
  - `updated_at`: `string` — The date the tag was updated.
  - `deleted_at`: `null` | `string` (optional) — The date the tag was deleted.
  - `external_id`: `null` | `string` (optional) — An external ID for the tag.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
