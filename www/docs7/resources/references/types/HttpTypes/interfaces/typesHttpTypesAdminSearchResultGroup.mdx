---
title: AdminSearchResultGroup
---

One entity's results. Grouped rather than merged into a single list, because
relevance is only comparable within an index.

## Type parameters

**AdminSearchResultGroup**

- `T`: `object` (optional)

## Properties

**AdminSearchResultGroup**

- `entity`: `string`
- `data`: T\[] — The documents the index holds, in relevance order.
- `count`: `number` — Treat as an estimate — most engines only approximate a total.
- `offset`: `number`
- `limit`: `number`
