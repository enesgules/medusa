## Properties

**AdminLocaleResponse**

- `locale`: [AdminLocale](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminLocale) — The locale's details.
  - `code`: `string` — The locale's code.

    Example:

    ```
    en-US
    ```
  - `name`: `string` — The locale's display name.

    Example:

    ```
    English (United States)
    ```
  - `created_at`: `string` — The date the locale was created.
  - `updated_at`: `string` — The date the locale was updated.
  - `deleted_at`: `null` | `string` — The date the locale was deleted.
