## Properties

**StoreProductTypeListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `product_types`: [StoreProductType](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStoreProductType)\[] — The paginated list of types.
  - `id`: `string` — The product type's ID.
  - `value`: `string` — The product type's value.
  - `created_at`: `string` — The date the product type was created.
  - `updated_at`: `string` — The date the product type was updated.
  - `deleted_at`: `null` | `string` (optional) — The date the product type was deleted.
  - `external_id`: `null` | `string` (optional) — An external ID for the product type.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
