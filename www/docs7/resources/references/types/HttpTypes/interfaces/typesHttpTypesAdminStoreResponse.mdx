## Properties

**AdminStoreResponse**

- `store`: [AdminStore](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStore) — The store's details.
  - `id`: `string` — The store's ID.
  - `name`: `string` — The store's name.
  - `supported_currencies`: [AdminStoreCurrency](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStoreCurrency)\[] — The store's supported currencies.
    - `id`: `string` — The currency's ID.
    - `currency_code`: `string` — The currency code.

      Example:

      ```
      "usd"
      ```
    - `store_id`: `string` — The ID of the store that the currency belongs to.
    - `is_default`: `boolean` — Whether the currency is the default currency for the store.
    - `currency`: [AdminCurrency](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCurrency) — The currency's details.
    - `created_at`: `string` — The date the currency was created.
    - `updated_at`: `string` — The date the currency was updated.
    - `deleted_at`: `null` | `string` — The date the currency was deleted.
  - `supported_locales`: [AdminStoreLocale](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStoreLocale)\[] — The store's supported locales.
    - `id`: `string` — The locale's ID.
    - `locale_code`: `string` — The locale's code.

      Example:

      ```
      "en-US"
      ```
    - `store_id`: `string` — The ID of the store that the locale belongs to.
    - `locale`: [AdminLocale](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminLocale) — The locale's details.
    - `created_at`: `string` — The date the locale was created.
    - `updated_at`: `string` — The date the locale was updated.
    - `deleted_at`: `null` | `string` — The date the locale was deleted.
  - `default_sales_channel_id`: `null` | `string` — The store's default sales channel ID.
  - `default_region_id`: `null` | `string` — The store's default region ID.
  - `default_location_id`: `null` | `string` — The store's default location ID.
  - `metadata`: `null` | `Record<string, any>` — Custom key-value pairs that can be added to the store.
  - `created_at`: `string` — The date the store was created.
  - `updated_at`: `string` — The date the store was updated.
