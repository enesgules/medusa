The details to add inbound shipping to a claim.

## Properties

**AdminClaimAddInboundShipping**

- `shipping_option_id`: `string` — The ID of the shipping option to create the method from.
- `custom_amount`: `number` (optional) — A custom amount to use instead of the shipping option's amount.
- `description`: `string` (optional) — The method's description.
- `internal_note`: `string` (optional) — An internal note viewed by admin users only.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
