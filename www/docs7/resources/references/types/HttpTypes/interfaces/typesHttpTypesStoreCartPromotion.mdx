## Properties

**StoreCartPromotion**

- `id`: `string` — The promotion's ID.
- `code`: `string` (optional) — The promotion's code.
- `is_automatic`: `boolean` (optional) — Whether the promotion is applied automatically (without the customer needing to enter a code).
- `application_method`: `object` (optional) — How the promotion is applied.
  - `value`: `string` — The amount to be discounted.
  - `type`: [ApplicationMethodTypeValues](/resources/references/promotion/types/promotionApplicationMethodTypeValues) — The application method's type. If it's `fixed`, the promotion discounts a fixed amount. If it's `percentage`, the promotion discounts a percentage.
  - `currency_code`: `string` — The currency code of the discount.

    Example:

    ```
    usd
    ```
