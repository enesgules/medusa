## Properties

**AdminCreateProductCategory**

- `name`: `string` — The product category's name.
- `description`: `string` (optional) — The product category's description.
- `handle`: `string` (optional) — The product category's unique handle. Can be used to create human-readable URLs.
- `is_internal`: `boolean` (optional) — Whether the category is only available and viewable by admin users.
- `is_active`: `boolean` (optional) — Whether the category is active. If disabled, the category isn't retrieved in the store API routes.
- `parent_category_id`: `null` | `string` (optional) — The ID of the parent category.
- `rank`: `number` (optional) — The category's ranking among its sibling categories.
- `external_id`: `null` | `string` (optional) — An external identifier for the product category.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
