## Properties

**AdminFulfillmentResponse**

- `fulfillment`: [AdminFulfillment](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillment) — The fulfillment's details.
  - `id`: `string` — The fulfillment's ID.
  - `location_id`: `string` — The ID of the stock location the items are delivered from.
  - `provider_id`: `string` — The ID of the fulfillment provider handling the fulfillment.
  - `shipping_option_id`: `null` | `string` — The ID of the associated shipping option.
  - `provider`: [AdminFulfillmentProvider](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProvider) — The associated fulfillment provider's details.
    - `id`: `string` — The fulfillment provider's ID.
    - `is_enabled`: `boolean` — Whether the fulfillment provider is enabled.
  - `delivery_address`: [AdminFulfillmentAddress](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentAddress) — The address to deliver the items to.
    - `id`: `string` — The address's ID.
    - `fulfillment_id`: `null` | `string` — The ID of the fulfillment this address belongs to.
    - `company`: `null` | `string` — The address's company.
    - `first_name`: `null` | `string` — The address's first name.
    - `last_name`: `null` | `string` — The address's last name.
    - `address_1`: `null` | `string` — The address's first line.
    - `address_2`: `null` | `string` — The address's last line.
    - `city`: `null` | `string` — The address's city.
    - `country_code`: `null` | `string` — The address's country code.

      Example:

      ```
      us
      ```
    - `province`: `null` | `string` — The address's lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province.
    - `postal_code`: `null` | `string` — The address's postal code.
    - `phone`: `null` | `string` — The address's phone number.
    - `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
    - `created_at`: `string` — The date the address was created.
    - `updated_at`: `string` — The date the address was updated.
    - `deleted_at`: `null` | `string` — The date the address was deleted.
  - `items`: [AdminFulfillmentItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentItem)\[] — The items to fulfill.
    - `id`: `string` — The fulfillment item's ID.
    - `title`: `string` — The fulfillment item's title.
    - `quantity`: `number` — The fulfillment item's quantity.
    - `sku`: `string` — The fulfillment item's SKU.
    - `barcode`: `string` — The fulfillment item's barcode.
    - `line_item_id`: `null` | `string` — The ID of the associated line item in an order.
    - `inventory_item_id`: `null` | `string` — The ID of the associated inventory item.
    - `fulfillment_id`: `string` — The ID of the fulfillment that the item belongs to.
    - `created_at`: `string` — The date the fulfillment item was created.
    - `updated_at`: `string` — The date the fulfillment item was updated.
    - `deleted_at`: `null` | `string` — The date the fulfillment item was deleted.
  - `labels`: [AdminFulfillmentLabel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentLabel)\[] — The fulfillment's labels.
    - `id`: `string`
    - `tracking_number`: `string`
    - `tracking_url`: `string`
    - `label_url`: `string`
    - `fulfillment_id`: `string`
    - `created_at`: `string`
    - `updated_at`: `string`
    - `deleted_at`: `null` | `string`
  - `packed_at`: `null` | `string` — The date the fulfillment items were packed.
  - `shipped_at`: `null` | `string` — The date the fulfillment items were shipped.
  - `delivered_at`: `null` | `string` — The date the fulfillment items were delivered.
  - `canceled_at`: `null` | `string` — The date the fulfillment was canceled.
  - `data`: `null` | `Record<string, unknown>` — Data useful for the fulfillment provider handling the fulfillment. Learn more in [this documentation](/resources/commerce-modules/fulfillment).
  - `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
  - `created_at`: `string` — The date the fulfillment was created.
  - `updated_at`: `string` — The date the fulfillment was updated.
  - `deleted_at`: `null` | `string` — The date the fulfillment was deleted.
