## Properties

**AdminFulfillmentProviderListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `fulfillment_providers`: [AdminFulfillmentProvider](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminFulfillmentProvider)\[] — The list of fulfillment providers.
  - `id`: `string` — The fulfillment provider's ID.
  - `is_enabled`: `boolean` — Whether the fulfillment provider is enabled.
