## Properties

**AdminSetLayoutConfiguration**

- `is_default`: `boolean` (optional) — Whether to set the zone's system default configuration (applies to all users) instead of the current user's personal configuration.
- `configuration`: `object` — The layout configuration settings.
  - `widgets`: `Record<string, [AdminLayoutWidgetPreference](/references/types/HttpTypes/interfaces/types.HttpTypes.AdminLayoutWidgetPreference)>` — Per-widget placement and visibility preferences, keyed by widget ID.
    - `hidden`: `boolean` (optional) — Whether the widget is hidden.
    - `section`: `string` (optional) — Override which section this widget appears in.
    - `order`: `number` (optional) — Override the sort order of the widget within its section.
