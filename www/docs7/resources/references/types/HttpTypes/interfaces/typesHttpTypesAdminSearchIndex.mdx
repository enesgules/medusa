A registered search index and the fields it stores.

## Properties

**AdminSearchIndex**

- `name`: `string` — Unique index name, as used in `query.search({ entity })`.
- `entity`: `string` — The `query.graph` entrypoint used to hydrate non-indexed fields.
- `provider`: `string` — Identifier of the provider backing this index.
- `status`: [AdminSearchIndexStatus](/resources/references/types/HttpTypes/types/typesHttpTypesAdminSearchIndexStatus) — Lifecycle status of the index.
- `fields`: [AdminSearchIndexField](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminSearchIndexField)\[] — Leaf fields stored in the index.
  - `name`: `string` — Dotted path of the field in the index, e.g. `title` or `variants.sku`.
  - `type`: `string` — The field's index type.
  - `searchable`: `boolean` — Whether the field is used for free-text matching.
  - `filterable`: `boolean` — Whether the field can be used in filters.
  - `sortable`: `boolean` — Whether results can be sorted by this field.
  - `facetable`: `boolean` — Whether the field can be faceted.
