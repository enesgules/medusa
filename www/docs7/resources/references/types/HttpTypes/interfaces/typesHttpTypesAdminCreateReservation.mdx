## Properties

**AdminCreateReservation**

- `line_item_id`: `null` | `string` (optional) — The ID of the line item to create the reservation for.
- `location_id`: `string` — The ID of the location that the quantity is reserved from.
- `inventory_item_id`: `string` — The ID of the inventory item that the reservation is for.
- `quantity`: `number` — The quantity of the inventory item that is reserved.
- `description`: `null` | `string` (optional) — The description of the reservation.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the reservation.
