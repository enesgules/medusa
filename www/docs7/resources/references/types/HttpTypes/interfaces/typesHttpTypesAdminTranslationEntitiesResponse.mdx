---
title: AdminTranslationEntitiesResponse
---

Response for translation entities endpoint.
Returns paginated entities with only their translatable fields and all their translations.

## Properties

**AdminTranslationEntitiesResponse**

- `data`: `Record<string, unknown>` & `object`\[] — The list of entities with their translatable fields. Each entity contains only the fields configured as translatable for that entity type in the translation settings, plus all translations for all locales.
  - `id`: `string`
  - `translations`: [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[]
    - `id`: `string` — The ID of the translation.
    - `reference_id`: `string` — The ID of the entity being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` — The translations of the resource. The object's keys are the field names of the data model, and its value is the translated value.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
    - `created_at`: `string` | `Date` — The date and time the translation was created.
    - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
    - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
- `count`: `number` — The total count of entities.
- `offset`: `number` — The offset of the current page.
- `limit`: `number` — The limit of items per page.
