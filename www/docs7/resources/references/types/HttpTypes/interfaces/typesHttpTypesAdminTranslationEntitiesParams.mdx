Query parameters for translation entities endpoint.

## Properties

**AdminTranslationEntitiesParams**

- `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `limit`: `number` (optional) — The maximum number of items to retrieve.
- `offset`: `number` (optional) — The number of items to skip before retrieving the returned items.
- `order`: `string` (optional) — The field to sort by and in which order.

  Example:

  ```
  -created_at
  ```
- `with_deleted`: `boolean` (optional) — Whether to include soft-deleted items in the results.
- `type`: `string` — The entity type to retrieve (e.g., "product", "product\_variant"). This determines which table to query and which translatable fields to return.

  Example:

  ```
  "product"
  ```
- `id`: `string` | `string`\[] (optional) — Filter by entity ID(s). Can be a single ID or an array of IDs.

  Example:

  ```
  "prod_123"
  ```
