Response for translation statistics endpoint.

## Properties

**AdminTranslationStatisticsResponse**

- `statistics`: `Record<string, [AdminTranslationEntityStatistics](/references/types/HttpTypes/interfaces/types.HttpTypes.AdminTranslationEntityStatistics)>` — Statistics by entity type.
  - `expected`: `number` — Expected number of translated fields.
  - `translated`: `number` — Actual number of translated fields. This doesn't count translations that are null or empty.
  - `missing`: `number` — Number of missing translations for expected translatable fields.
  - `by_locale`: `Record<string, [AdminTranslationLocaleStatistics](/references/types/HttpTypes/interfaces/types.HttpTypes.AdminTranslationLocaleStatistics)>` — Breakdown of statistics by locale.
    - `expected`: `number` — Expected number of translated fields.
    - `translated`: `number` — Actual number of translated fields. This doesn't count translations that are null or empty.
    - `missing`: `number` — Number of missing translations for expected translatable fields.
