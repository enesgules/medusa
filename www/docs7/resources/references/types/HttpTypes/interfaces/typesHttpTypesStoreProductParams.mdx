## Properties

**StoreProductParams**

- `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `region_id`: `string` (optional) — The ID of the customer's region. This parameter must be included if you want to apply taxes on the product variant's price.
- `country_code`: `string` (optional) — The customer's country code. This parameter must be included if you want to apply taxes on the product variant's price.
- `province`: `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province, which can be taken from a customer's address. This parameter helps further narrowing down the taxes applied on a the product variant's prices.
- `cart_id`: `string` (optional) — The ID of the customer's cart, if available. If set, the cart's region and shipping address's country code and province are used instead of the `region_id`, `country_code`, and `province` parameters.
- `locale`: `string` (optional) — The locale code in BCP 47 format. Information of the product and related entities will be localized based on the provided locale. Learn more in the [Serve Translations in Storefront](/resources/commerce-modules/translation/storefront) guide.

  Example:

  ```
  "en-US" @http-validation-ignore
  ```
