## Properties

**AdminFulfillmentItem**

- `id`: `string` — The fulfillment item's ID.
- `title`: `string` — The fulfillment item's title.
- `quantity`: `number` — The fulfillment item's quantity.
- `sku`: `string` — The fulfillment item's SKU.
- `barcode`: `string` — The fulfillment item's barcode.
- `line_item_id`: `null` | `string` — The ID of the associated line item in an order.
- `inventory_item_id`: `null` | `string` — The ID of the associated inventory item.
- `fulfillment_id`: `string` — The ID of the fulfillment that the item belongs to.
- `created_at`: `string` — The date the fulfillment item was created.
- `updated_at`: `string` — The date the fulfillment item was updated.
- `deleted_at`: `null` | `string` — The date the fulfillment item was deleted.
