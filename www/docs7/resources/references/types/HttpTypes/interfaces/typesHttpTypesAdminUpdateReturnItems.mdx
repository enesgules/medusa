## Properties

**AdminUpdateReturnItems**

- `quantity`: `number` (optional) — The quantity of the item to return.
- `internal_note`: `null` | `string` (optional) — A note that is viewed by admins only to describe why the item is being returned.
- `reason_id`: `null` | `string` (optional) — The ID of the return reason to associate with the item.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the return item.
