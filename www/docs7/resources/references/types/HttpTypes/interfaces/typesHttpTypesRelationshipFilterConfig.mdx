---
title: RelationshipFilterConfig
---

Configuration for relationship-based dropdown filters.

## Properties

**RelationshipFilterConfig**

- `entity`: `string` — Related entity name (e.g., "SalesChannel").
- `value_field`: `string` — Field to use as filter value (e.g., "id").
- `display_field`: `string` — Field to display in dropdown (e.g., "name").
- `multiple`: `boolean` — Whether multiple selection is allowed.
- `endpoint`: `string` — API endpoint to fetch options (e.g., "/admin/sales-channels").
- `filter_key`: `string` (optional) — Key to use for filtering the relationship. If not provided, the column field is used.
