title: AdminInitializePaymentSession

The details of a payment session to initialize for a payment collection.

## Properties

**AdminInitializePaymentSession**

- `provider_id`: `string` — The ID of the provider to initialize a payment session for.
- `data`: `Record<string, unknown>` (optional) — Any data necessary for the payment provider to process the payment. Learn more in [this documentation](/resources/commerce-modules/payment/payment-session#data-property).
