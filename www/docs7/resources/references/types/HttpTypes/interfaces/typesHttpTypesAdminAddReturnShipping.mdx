## Properties

**AdminAddReturnShipping**

- `shipping_option_id`: `string` — The ID of the shipping option that the shipping method is created from.
- `custom_amount`: `number` (optional) — A custom amount to set for the shipping method. If not provided, the shipping option's fixed or calculated amount will be used.
- `description`: `string` (optional) — A note to describe the shipping method.
- `internal_note`: `string` (optional) — A note that is viewed by admins only to describe the shipping method.
- `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the shipping method.
