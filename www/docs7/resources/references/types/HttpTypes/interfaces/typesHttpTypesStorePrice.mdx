## Properties

**StorePrice**

- `id`: `string` — The price's ID.
- `currency_code`: `string` — The price's currency code.

  Example:

  ```
  usd
  ```
- `amount`: `number` — The price's amount.
- `min_quantity`: `null` | `number` — The minimum quantity that must be available in the cart for the price to be applied.
- `max_quantity`: `null` | `number` — The maximum quantity allowed to be available in the cart for the price to be applied.
- `price_rules`: [StorePriceRule](/resources/references/types/HttpTypes/interfaces/typesHttpTypesStorePriceRule)\[] (optional) — The rules enabled to enable the current price
  - `id`: `string` — The ID of the price rule.
  - `attribute`: `string` — The attribute of the price rule
  - `operator`: [PricingRuleOperatorValues](/resources/references/pricing/types/pricingPricingRuleOperatorValues) — The operator of the price rule
  - `value`: `string` — The value of the price rule.
