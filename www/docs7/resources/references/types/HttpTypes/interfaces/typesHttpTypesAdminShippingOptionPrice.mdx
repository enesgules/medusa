## Properties

**AdminShippingOptionPrice**

- `id`: `string` — The price's ID.
- `title`: `string` — The price's title.
- `currency_code`: `string` — The price's currency code.

  Example:

  ```
  usd
  ```
- `amount`: `number` — The price's amount.
- `raw_amount`: `Record<string, unknown>` — The price's raw amount.
- `min_quantity`: `null` | `number` — The minimum quantity that must be available in the cart for the price to be applied.
- `max_quantity`: `null` | `number` — The maximum quantity allowed to be available in the cart for the price to be applied.
- `price_set_id`: `string` — The ID of the price set this price belongs to.
- `created_at`: `string` — The date the price was created.
- `updated_at`: `string` — The date the price was updated.
- `deleted_at`: `null` | `string` — The date the price was deleted.
- `price_rules`: [AdminShippingOptionPriceRule](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingOptionPriceRule)\[] — The rules of the shipping option price.
  - `id`: `string` — The ID of the shipping option price rule.
  - `value`: `string` | `number` — The value of the shipping option price rule.

    Example:

    ```
    "region_123"
    ```
  - `operator`: [RuleOperatorType](/resources/references/types/CommonTypes/types/typesCommonTypesRuleOperatorType) — The operator of the shipping option price rule.

    Example:

    ```
    "eq"
    ```
  - `attribute`: `string` — The attribute of the shipping option price rule.

    Example:

    ```
    "region_id"
    ```
  - `price_id`: `string` — The ID of the shipping option price that this rule is created for.
  - `priority`: `number` — The priority of the shipping option price rule.
  - `created_at`: `string` — The date when the shipping option price rule was created.
  - `updated_at`: `string` — The date when the shipping option price rule was updated.
  - `deleted_at`: `null` | `string` — The date when the shipping option price rule was deleted.
- `rules_count`: `number` — The number of rules of the shipping option price.
