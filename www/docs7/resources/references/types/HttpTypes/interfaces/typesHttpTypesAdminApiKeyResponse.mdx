## Properties

**AdminApiKeyResponse**

- `api_key`: [AdminApiKey](/resources/references/types/interfaces/typesAdminApiKey) — The API key's details.
  - `id`: `string` — The API key's ID.
  - `token`: `string` — The API key's token.
  - `redacted`: `string` — The redacted form of the token, useful for displaying the API key.
  - `title`: `string` — The API key's title.
  - `type`: [ApiKeyType](/resources/references/api_key/types/api_keyApiKeyType) — The API key's type.
  - `last_used_at`: `null` | `Date` — The date the API key was last used.
  - `created_by`: `string` — The ID of the user that created the API key.
  - `created_at`: `Date` — The date the API key was created.
  - `updated_at`: `Date` — The date the API key was updated.
  - `revoked_by`: `null` | `string` — The ID of the user that revoked the API key.
  - `revoked_at`: `null` | `Date` — The date the API key was revoked.
  - `deleted_at`: `null` | `Date` — The date the API key was deleted.
