## Properties

**AdminReturnReasonListResponse**

- `limit`: `number` — The maximum number of items retrieved.
- `offset`: `number` — The number of items to skip before retrieving the returned items.
- `count`: `number` — The total number of items.
- `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
- `return_reasons`: [AdminReturnReason](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReason)\[] — The list of return reasons.
  - `id`: `string` — The return reason's ID.
  - `value`: `string` — The return reason's value.

    Example:

    ```
    "refund"
    ```
  - `label`: `string` — The return reason's label.

    Example:

    ```
    "Refund"
    ```
  - `description`: `null` | `string` (optional) — The return reason's description.
  - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs that can be added to the return reason.
  - `created_at`: `string` — The date that the return reason was created.
  - `updated_at`: `string` — The date that the return reason was updated.
