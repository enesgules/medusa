---
title: IDmlEntityConfig
---

The configuration for a DML entity. Can be a string (used as the table name)
or an object with optional name and required table name.

- `IDmlEntityConfig`: `string` | `object` — The configuration for a DML entity. Can be a string (used as the table name) or an object with optional name and required table name.
  - `name`: `string` (optional)
  - `tableName`: `string`
