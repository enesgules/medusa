title: EntityIndex
---

An index definition on a DML entity.

- `EntityIndex`: `object` — An index definition on a DML entity.
  - `name`: `string` (optional) — The name of the index. If not provided, Medusa generates the name.
  - `unique`: `boolean` (optional) — When enabled, a unique index is created on the specified properties.
  - `on`: [InferIndexableProperties](/resources/references/types/DmlTypes/types/typesDmlTypesInferIndexableProperties)\<Schema>\[] — The list of properties to create the index on.
  - `where`: Where | `null` (optional) — Conditions to restrict which records are indexed. Medusa scopes indexes to `deleted_at IS NULL` by default. Set this to `null` to opt out of that scope and create a non-partial index, which is required for indexes that back a foreign key with a cascading rule.
  - `type`: `string` (optional) — The type of the index. (e.g: GIN)
