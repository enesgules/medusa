The input for deleting documents from a search index.

## Properties

**SearchDeleteDocumentsInput**

- `index`: `string` — The physical name of the index to delete the documents from.
- `filters`: [SearchFilters](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFilters) — The filters selecting the documents to remove. Deleting by ID is a filter on the index's primary key, such as `{ id: ["prod_1", "prod_2"] }`.

    - `$not`: [SearchFilters](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFilters) (optional) — Filters that must not match.
