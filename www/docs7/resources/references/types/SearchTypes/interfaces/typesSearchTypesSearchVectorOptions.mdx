title: SearchVectorOptions
---

The options of a vector, or semantic, search.

## Properties

**SearchVectorOptions**

- `field`: `string` (optional) — The dotted path of the `vector` field to search in. Optional when the index declares exactly one vector field.
- `value`: `number`\[] (optional) — A pre-computed embedding to search with. Mutually exclusive with `query`. Allowed whether documents store customer-supplied embeddings or the engine embeds them.
- `query`: `string` (optional) — Text the engine embeds at query time. Requires the vector field to set `embed: true`. Mutually exclusive with `value`.
- `semantic_ratio`: `number` (optional) — How much the semantic score contributes relative to the keyword score, where `0` is keyword-only and `1` is semantic-only. Defaults to `1` when there is no free-text query, and `0.5` when both run together.
