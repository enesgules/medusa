---
title: SearchHit
---

A document matching a search query.

## Type parameters

**SearchHit**

- `T`: `object` (optional)

## Properties

**SearchHit**

- `id`: `string` — The value of the index's primary key for this document. `query.search` uses it to hydrate the rest of the entity through `query.graph`.
- `score`: `number` (optional) — The document's relevance score. Scales are provider-specific and not comparable across providers.
- `document`: T — The retrievable fields the search engine returned for this document.
- `highlights`: `Record<string, string[]>` (optional) — The highlighted fragments of the fields requested in the query's `search_options.highlight`, keyed by field path.
