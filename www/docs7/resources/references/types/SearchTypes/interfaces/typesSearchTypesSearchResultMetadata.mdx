---
title: SearchResultMetadata
---

The pagination and timing details of a search result.

## Properties

**SearchResultMetadata**

- `skip`: `number` — The number of documents skipped before the returned hits.
- `take`: `number` — The maximum number of hits returned.
- `count`: `null` | `number` — Usually it's an estimate on the count, very few providers return an exact count. If the user didn't ask for a count, it's `null`.
- `next_cursor`: `string` (optional) — The cursor to pass in the next query's pagination to retrieve the next page, on providers that paginate with cursors.
- `query`: `string` (optional) — The free-text query the result was computed for.
- `processing_time_ms`: `number` (optional) — How long the search engine took to run the query, in milliseconds.
