---
title: SearchFacetResult
---

The computed values of a facet requested in a search query. Its shape depends
on the requested facet's type.

- `SearchFacetResult`: `object` | `object` | `object` — The computed values of a facet requested in a search query. Its shape depends on the requested facet's type.
  - `type`: `"value"` — The facet counts per distinct value of the field.
  - `values`: `object`\[] — The distinct values of the field and how many documents hold each of them.
    - `value`: `string`
    - `count`: `number`
  - `other_count`: `number` (optional) — The number of documents falling outside the returned values, where the provider reports it.
  - `ranges`: `object`\[] — The requested ranges and how many documents fall in each of them.
    - `key`: `string` — The range's key, as passed in the request.
    - `from`: `number` | `string` (optional) — The range's inclusive lower bound.
    - `to`: `number` | `string` (optional) — The range's exclusive upper bound.
    - `count`: `number` — The number of documents in the range.
  - `min`: `number` — The field's smallest value among the matching documents.
  - `max`: `number` — The field's largest value among the matching documents.
  - `avg`: `number` (optional) — The average of the field's values, where the provider reports it.
  - `sum`: `number` (optional) — The sum of the field's values, where the provider reports it.
  - `count`: `number` — The number of documents the aggregations were computed over.
