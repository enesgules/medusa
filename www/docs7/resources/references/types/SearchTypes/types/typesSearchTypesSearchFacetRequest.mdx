---
title: SearchFacetRequest
---

A facet to compute alongside a search query's hits.

- `SearchFacetRequest`: `object` | `object` | `object` — A facet to compute alongside a search query's hits.
  - `field`: `string` — The dotted path of the field to facet on.
  - `type`: `"value"` (optional) — Count the documents per distinct value of the field. This is the default facet type.
  - `limit`: `number` (optional) — The maximum number of facet values to return.
  - `sort`: `"count"` | `"alpha"` (optional) — Whether to order the returned values by their count or alphabetically.
  - `query`: `string` (optional) — Restrict the returned facet values to those matching this string.
  - `ranges`: `object`\[] — The ranges to count the documents of.
    - `key`: `string` (optional) — A key identifying the range in the result.
    - `from`: `number` | `string` (optional) — The range's inclusive lower bound.
    - `to`: `number` | `string` (optional) — The range's exclusive upper bound.
