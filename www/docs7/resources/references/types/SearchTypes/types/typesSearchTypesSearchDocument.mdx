---
title: SearchDocument
---

A document stored in a search index. The `id` property holds the index's
primary key, which `query.search` uses to hydrate the rest of the entity
through `query.graph`.

- `SearchDocument`: `Record<string, unknown>` & `object` — A document stored in a search index. The `id` property holds the index's primary key, which `query.search` uses to hydrate the rest of the entity through `query.graph`.
  - `id`: `string`
