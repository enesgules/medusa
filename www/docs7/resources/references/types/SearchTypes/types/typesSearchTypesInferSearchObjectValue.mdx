title: InferSearchObjectValue
---

The value of an object field: declared sub-fields are type-checked, extra
keys are allowed — seeds commonly spread whole entities, and engines ignore
what the index does not declare.

> **Note**
>
> This is available starting from [Medusa v2.19.0](https://github.com/medusajs/medusa/releases/tag/v2.19.0).

- `InferSearchObjectValue`: \{ \[K in keyof Schema]?: InferSearchPropertyValue\<Schema\[K]> } & `Record<string, unknown>` — The value of an object field: declared sub-fields are type-checked, extra keys are allowed — seeds commonly spread whole entities, and engines ignore what the index does not declare.
