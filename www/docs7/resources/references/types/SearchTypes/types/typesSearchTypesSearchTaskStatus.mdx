---
title: SearchTaskStatus
---

The status of a write to a search index:

- `enqueued`: the search engine accepted the write but hasn't applied it yet.

- `processing`: the search engine is applying the write.

- `succeeded`: the write is applied.

- `failed`: the write didn't go through.

- `SearchTaskStatus`: `"enqueued"` | `"processing"` | `"succeeded"` | `"failed"` — The status of a write to a search index: - `enqueued`: the search engine accepted the write but hasn't applied it yet. - `processing`: the search engine is applying the write. - `succeeded`: the write is applied. - `failed`: the write didn't go through.
