---
title: S3FileServiceOptions
---

The options for the S3 file provider module.

## Properties

**S3FileServiceOptions**

- `file_url`: `string` — The base URL used to construct public file URLs.
- `access_key_id`: `string` (optional) — The AWS access key ID used for authentication.
- `secret_access_key`: `string` (optional) — The AWS secret access key used for authentication.
- `session_token`: `string` (optional) — The AWS session token used for temporary credentials.
- `authentication_method`: `"access-key"` | `"s3-iam-role"` (optional) — The authentication method to use when connecting to S3.
- `region`: `string` — The AWS region where the S3 bucket is located.
- `bucket`: `string` — The name of the S3 bucket to upload files to.
- `prefix`: `string` (optional) — An optional prefix (folder path) to prepend to uploaded file keys.
- `endpoint`: `string` (optional) — A custom endpoint URL, used for S3-compatible storage services.
- `cache_control`: `string` (optional) — The value of the `Cache-Control` header set on uploaded objects.
- `download_file_duration`: `number` (optional) — The duration in seconds for which a download URL remains valid.
- `additional_client_config`: `Record<string, any>` (optional) — Additional configuration options passed directly to the S3 client.
- `acl`: `false` | `"private"` | `"public-read"` | `"authenticated-read"` | `"bucket-owner-full-control"` (optional) — Controls the ACL set on uploaded objects. - `undefined` (default): Uses "public-read" for public files and "private" for private files. - `false`: Omits the ACL header entirely. Required for S3 buckets with BucketOwnerEnforced Object Ownership or Block Public Access enabled. - A specific `ObjectCannedACL` value: Uses that ACL for all uploads.
