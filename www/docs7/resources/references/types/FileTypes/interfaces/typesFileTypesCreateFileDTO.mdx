The File to be created.

## Properties

**CreateFileDTO**

- `filename`: `string` — The name of the uploaded file
- `mimeType`: `string` — The mimetype of the uploaded file

  Example:

  ```
  image/png
  ```
- `content`: `string` — The file content as a base64-encoded string.
- `access`: [FileAccessPermission](/resources/references/types/FileTypes/types/typesFileTypesFileAccessPermission) (optional) — The access level of the file. Defaults to private if not passed
