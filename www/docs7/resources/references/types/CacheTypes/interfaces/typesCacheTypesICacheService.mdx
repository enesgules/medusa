## Methods

### get

This method retrieves data from the cache.

#### Example

```ts
const data = await cacheModuleService.get("my-key")
```

<a id="get-type-parameters" />

#### Type Parameters

**get**

- `T`: `object` (optional)

<a id="get-parameters" />

#### Parameters

**get**

- `key`: `string` — The key of the item to retrieve.

<a id="get-returns" />

#### Returns

**get**

- `Promise`: Promise\<null | T> — The item that was stored in the cache. If the item was not found, null is returned.
  - `null \| T`: `null` | T

### set

This method stores data in the cache.

#### Example

```ts
await cacheModuleService.set("my-key", { product_id: "prod_123" }, 60)
```

<a id="set-parameters" />

#### Parameters

**set**

- `key`: `string` — The key of the item to store.
- `data`: `unknown` — The data to store in the cache.
- `ttl`: `number` (optional) — The time-to-live (TTL) value in seconds. If not provided, the default TTL value is used. The default value is based on the used Cache Module.

<a id="set-returns" />

#### Returns

**set**

- `Promise`: Promise\<void> — This method stores data in the cache.

### invalidate

This method removes an item from the cache.

#### Example

```ts
await cacheModuleService.invalidate("my-key")
```

<a id="invalidate-parameters" />

#### Parameters

**invalidate**

- `key`: `string` — The key of the item to remove.

<a id="invalidate-returns" />

#### Returns

**invalidate**

- `Promise`: Promise\<void> — This method removes an item from the cache.
