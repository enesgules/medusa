---
title: BaseCartLineItemTotals
---

The cart line item totals details.

## Properties

**BaseCartLineItemTotals**

- `original_total`: `number` (optional) — The line item's original total before discounts, including taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `original_subtotal`: `number` (optional) — The line item's original subtotal before discounts, excluding taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `original_tax_total`: `number` (optional) — The line item's original tax total before discounts. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `item_total`: `number` (optional) — The line item's total after discounts, including taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `item_subtotal`: `number` (optional) — The line item's subtotal before discounts, excluding taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `item_tax_total`: `number` (optional) — The line item's tax total after discounts. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `total`: `number` (optional) — The line item's total after discounts, including taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `subtotal`: `number` (optional) — The line item's subtotal before discounts, excluding taxes. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `tax_total`: `number` (optional) — The line item's tax total after discounts. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `discount_total`: `number` (optional) — The total amount of discounts applied to the line item, including the tax portion of discounts. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
- `discount_tax_total`: `number` (optional) — The total amount of discounts applied to the line item's tax. Represents the tax portion of discounts. This field is only available if you expand the `items.*` relation. Learn more in the [Cart Totals](/resources/storefront-development/cart/totals#retrieve-and-show-cart-item-totals) guide.
