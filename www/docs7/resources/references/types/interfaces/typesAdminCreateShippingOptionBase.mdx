---
title: AdminCreateShippingOptionBase
---

Common properties for all shipping option create inputs.

## Properties

**AdminCreateShippingOptionBase**

- `name`: `string` — The name of the shipping option. Customers can view this name during checkout.

  Example:

  ```
  "Standard Shipping"
  ```
- `service_zone_id`: `string` — The ID of the service zone that the shipping option belongs to. Learn more in the [Shipping Options](/resources/commerce-modules/fulfillment/shipping-option#service-zone-restrictions) documentation.
- `shipping_profile_id`: `string` — The ID of the shipping profile that the shipping option belongs to. Learn more in the [Shipping Options](/resources/commerce-modules/fulfillment/shipping-option#shipping-profiles-and-types) documentation.
- `data`: `Record<string, unknown>` (optional) — Additional data that is useful for third-party fulfillment providers that process fulfillments for the shipping option. Learn more in the [Shipping Options](/resources/commerce-modules/fulfillment/shipping-option#data-property) documentation.
- `price_type`: [ShippingOptionPriceType](/resources/references/fulfillment/types/fulfillmentShippingOptionPriceType) — The type of the shipping option's price: - `flat`: the price is a fixed amount set in the `prices` property. - `calculated`: the price is calculated during checkout by the shipping option's fulfillment provider.
- `provider_id`: `string` — The ID of the fulfillment provider that the shipping option belongs to.
- `type`: [AdminCreateShippingOptionType](/resources/references/types/interfaces/typesAdminCreateShippingOptionType) (optional) — The type of shipping option. Learn more in the [Shipping Option](/resources/commerce-modules/fulfillment/shipping-option#shipping-profiles-and-types) documentation.
  - `label`: `string` — The label of the shipping option type.
  - `description`: `string` (optional) — The description of the shipping option type.
  - `code`: `string` — The code of the shipping option type.
- `type_id`: `string` (optional) — The ID of the type of shipping option. Learn more in the [Shipping Option](/resources/commerce-modules/fulfillment/shipping-option#shipping-profiles-and-types) documentation.
- `rules`: [AdminCreateShippingOptionRule](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateShippingOptionRule)\[] (optional) — The rules of the shipping option. Learn more in the [Shipping Option Rules](/resources/commerce-modules/fulfillment/shipping-option#shipping-option-rules) documentation.
  - `operator`: [RuleOperatorType](/resources/references/types/CommonTypes/types/typesCommonTypesRuleOperatorType) — The operator of the shipping option rule.
  - `attribute`: `string` — The attribute of the shipping option rule.

    Example:

    ```
    `enabled_in_store`
    ```
  - `value`: `string` | `string`\[] — The value of the shipping option rule.

    Example:

    ```
    `true`
    ```
- `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the shipping option.
