## Properties

**BaseOrderAddress**

- `id`: `string` — The address's ID.
- `customer_id`: `string` (optional) — The ID of the customer this address belongs to.
- `first_name`: `string` (optional) — The address's first name.
- `last_name`: `string` (optional) — The address's last name.
- `phone`: `string` (optional) — The address's phone.
- `company`: `string` (optional) — The address's company.
- `address_1`: `string` (optional) — The address's first line.
- `address_2`: `string` (optional) — The address's second line.
- `city`: `string` (optional) — The address's city.
- `country_code`: `string` (optional) — The address's country code.

  Example:

  ```
  us
  ```
- `province`: `string` (optional) — The address's lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province.
- `postal_code`: `string` (optional) — The address's postal code.
- `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
- `created_at`: `string` | `Date` — The date the address was created.
- `updated_at`: `string` | `Date` — The date the address was updated.
