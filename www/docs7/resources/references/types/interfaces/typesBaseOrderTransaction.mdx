## Properties

**BaseOrderTransaction**

- `id`: `string` — The transaction's ID.
- `order_id`: `string` — The ID of the order this transaction belongs to.
- `amount`: `number` — The transaction's amount.
- `currency_code`: `string` — The transaction's currency code.

  Example:

  ```
  usd
  ```
- <a id="reference" />`reference`: `"refund"` | `"capture"` — Whether the transaction references a capture or refund.
- `reference_id`: `string` — The ID of the capture or refund, depending on the value of [reference](/resources/references/types/interfaces/typesBaseOrderTransaction#reference).
- `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
- `created_at`: `string` | `Date` — The date the transaction was created.
- `updated_at`: `string` | `Date` — The date the transaction was updated.
