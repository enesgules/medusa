The details required to list shipping options for a cart.

## Properties

**ListShippingOptionsForCartWorkflowInputDTO**

- `cart_id`: `string` — The ID of the cart to list shipping options for.
- `is_return`: `boolean` — Whether to list shipping options for a return shipment.
- `sales_channel_id`: `string` (optional) — The ID of the sales channel to filter shipping options by.
- `region_id`: `string` (optional) — The ID of the region to filter shipping options by.
- `currency_code`: `string` — The currency code of the cart.

  Example:

  ```
  usd
  ```
- `shipping_address`: `object` — The shipping address to filter shipping options by.
  - `city`: `string` (optional) — The city of the shipping address.
  - `country_code`: `string` (optional) — The country code of the shipping address.

    Example:

    ```
    us
    ```
  - `province`: `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province or state of the shipping address.
