- `data`: `Record<string, unknown>` (optional) — Data is a combination of the input from the user and what is stored in the database for the associated model.
- `context`: Omit\<[PaymentProviderContext](/resources/references/types/interfaces/typesPaymentProviderContext), "customer"> & `object` — The context of creating the account holder.

    - `phone`: `string` | `null` (optional) — The customer's phone number.
    - `billing_address`: [PaymentAddressDTO](/resources/references/types/types/typesPaymentAddressDTO) | `null` (optional) — The customer's billing address.
