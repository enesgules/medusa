## Methods

### getProvider

This method returns the service of the configured Analytics Module Provider in `medusa-config.ts`. This is useful
if you want to execute custom methods defined in the provider's service or you need direct access to it.

#### Example

```ts
const postHogProviderService = analyticsModuleService.getProvider()
// TODO: perform custom actions with the provider
```

<a id="getprovider-returns" />

#### Returns

**getProvider**

- `track`: (`data`: [TrackAnalyticsEventDTO](/resources/references/types/interfaces/typesTrackAnalyticsEventDTO)) => Promise\<void>
- `identify`: (`data`: [IdentifyAnalyticsEventDTO](/resources/references/types/types/typesIdentifyAnalyticsEventDTO)) => Promise\<void>
- `shutdown`: () => Promise\<void> (optional)

### track

This method tracks an event in the analytics provider. The Analytics Module
will use the `track` method of the underlying provider configured in `medusa-config.ts` to track the event.

#### Example

```ts
await analyticsModuleService.track({
  event: "order_placed",
  properties: {
    order_id: "order_123",
    customer_id: "customer_456",
    total: 100,
  }
})
```

<a id="track-parameters" />

#### Parameters

**track**

- `data`: [TrackAnalyticsEventDTO](/resources/references/types/interfaces/typesTrackAnalyticsEventDTO) — The event's details.
  - `event`: `string` — The event name
  - `actor_id`: `string` (optional) — The actor of the event, if there is any
  - `group`: `object` (optional) — The group that the event is for, such as an organization or team.
    - `type`: `string` (optional) — The name of the group.

      Example:

      ```
      "organization"
      ```
    - `id`: `string` (optional) — The group's ID.
  - `properties`: `Record<string, any>` (optional) — The properties of the event. The format and content is dynamic and depends on the integrated provider.

<a id="track-returns" />

#### Returns

**track**

- `Promise`: Promise\<void> — Resolves when the event is tracked successfully.

### identify

This method identifies an actor or group in the analytics provider. The Analytics Module
will use the `identify` method of the underlying provider configured in `medusa-config.ts` to identify the actor or group.

#### Example

```ts
await analyticsModuleService.identify({
  actor_id: "123",
  properties: {
    name: "John Doe"
  }
})
```

<a id="identify-parameters" />

#### Parameters

**identify**

- `data`: [IdentifyAnalyticsEventDTO](/resources/references/types/types/typesIdentifyAnalyticsEventDTO) — The details of the actor or group.
  - `actor_id`: `string` — The actor of the event, if there is any.
  - `properties`: `Record<string, any>` (optional) — The properties of the actor. The format and content is dynamic and depends on the integrated provider.
  - `group`: `object` — The group that the event is for, such as an organization or team.
    - `type`: `string` — The name of the group.

      Example:

      ```
      "organization"
      ```
    - `id`: `string` — The group's ID.

<a id="identify-returns" />

#### Returns

**identify**

- `Promise`: Promise\<void> — Resolves when the actor or group is identified successfully.
