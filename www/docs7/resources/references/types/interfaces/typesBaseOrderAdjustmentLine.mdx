## Properties

**BaseOrderAdjustmentLine**

- `id`: `string` — The adjustment line's ID.
- `code`: `string` (optional) — The adjustment's promotion code.
- `amount`: `number` — The adjustment's amount.
- `order_id`: `string` — The ID of the order this adjustment line belongs to.
- `description`: `string` (optional) — The adjustment's description.
- `promotion_id`: `string` (optional) — The ID of the applied promotion.
- `provider_id`: `string` (optional) — The ID of the associated provider.
- `created_at`: `string` | `Date` — The date the adjustment was created.
- `updated_at`: `string` | `Date` — The date the adjustment was updated.
