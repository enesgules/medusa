---
title: UploadStreamDescriptorType
---

The details of the file being uploaded through a stream.

## Properties

**UploadStreamDescriptorType**

- `name`: `string` — The name of the file.
- `ext`: `string` (optional) — The extension of the file.
- `isPrivate`: `boolean` (optional) — Whether the file should be uploaded to a private bucket or location. By convention, the default value of this property is `true`.
