title: FileServiceGetUploadStreamResult
---

The relevant details to upload a file through a stream.

## Properties

**FileServiceGetUploadStreamResult**

- `writeStream`: `PassThrough` — A [PassThrough](https://nodejs.org/api/stream.html#class-streampassthrough) write stream object to be used to write the file.
- `promise`: Promise\<any> — A promise that should resolved when the writing process is done to finish the upload.
- `url`: `string` — The URL of the file once it’s uploaded.
- `fileKey`: `string` — The identifier of the file in the storage. For example, for a local file service, this can be the file's name.
