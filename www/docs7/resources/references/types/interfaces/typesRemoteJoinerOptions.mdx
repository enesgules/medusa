---
title: RemoteJoinerOptions
---

Options controlling the behavior of a remote joiner query execution.

## Properties

**RemoteJoinerOptions**

- `throwIfKeyNotFound`: `boolean` (optional) — Whether to throw an error if a requested key is not found in the result.
- `throwIfRelationNotFound`: `boolean` | `string`\[] (optional) — Whether to throw an error if a requested relation is not found, or a list of relation names to check.
- `initialData`: `object` | `object`\[] (optional) — Initial data to use as the starting dataset for the query instead of fetching from a service.
- `initialDataOnly`: `boolean` (optional) — Whether to use only the initial data without fetching additional data from services.
- `locale`: `string` (optional) — The locale to use for the query. Translation will be applied to the query result based on the locale.
- `cache`: `object` (optional)
  - `enable`: `boolean` | (`args`: `any`\[]) => `undefined` | `boolean` (optional) — Whether to enable the cache. This is only useful if you want to enable without providing any other options or if you want to enable/disable the cache based on the arguments.
  - `key`: `string` | (`args`: `any`\[], `cachingModule`: [ICachingModuleService](/resources/references/types/CachingTypes/interfaces/typesCachingTypesICachingModuleService)) => `string` | Promise\<string> (optional) — The key to use for the cache. If a function is provided, it will be called with the arguments as the first argument and the container as the second argument.
  - `tags`: `string`\[] | (`args`: `any`\[]) => `undefined` | `string`\[] (optional) — The tags to use for the cache. Used on their own unless `computeAutomaticTags` is set, in which case the automatically computed tags are stored alongside them.
  - `computeAutomaticTags`: `boolean` (optional, default: false) — Whether the automatically computed tags should be applied along with the ones given in `tags`, rather than `tags` being used on its own. Automatic tags are computed from the result, which only exposes entities that carry an `id`. They therefore never cover link tables (whose rows are usually not selected), relations queried without their `id`, or entities that affect the result without appearing in it - pass only those in `tags` and enable this, instead of restating every entity the result already exposes. Has no effect when `tags` is omitted, since tags are computed either way.
  - `ttl`: `number` | (`args`: `any`\[]) => `undefined` | `number` (optional) — The time-to-live (TTL) value in seconds.
  - `autoInvalidate`: `boolean` | (`args`: `any`\[]) => `undefined` | `boolean` (optional) — Whether to auto invalidate the cache whenever it is possible.
  - `providers`: `string`\[] | (`args`: `any`\[]) => `undefined` | `string`\[] (optional) — The providers to use for the cache.
