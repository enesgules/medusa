## Properties

**AdminExchangeAddShippingMethod**

- `shipping_option_id`: `string` — The ID of the shipping option the method is created from.
- `custom_amount`: `number` (optional) — A custom amount for the shipping method. If not specified, the shipping option's amount is used.
- `description`: `string` (optional) — The shipping method's description.
- `internal_note`: `string` (optional) — An internal note viewed by admin users only.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
