## Properties

**AdminClaimAddItems**

- `items`: `object`\[] — The items to add to the claim.

  - `quantity`: `number` — The quantity to claim.
  - `reason`: [ClaimReason](/resources/references/types/enums/typesClaimReason) (optional) — The reason for adding this item to the claim.
    - `MISSING_ITEM`: `"missing_item"` (optional)
    - `WRONG_ITEM`: `"wrong_item"` (optional)
    - `PRODUCTION_FAILURE`: `"production_failure"` (optional)
    - `OTHER`: `"other"` (optional)
  - `description`: `string` (optional) — The claim item's description.
  - `internal_note`: `string` (optional) — An internal note viewed by admin users only.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
