title: PluginDetails
---

Resolved details of a plugin loaded by the Medusa application.

## Properties

**PluginDetails**

- `resolve`: `string` — The path to the plugin's package or directory.
- `name`: `string` — The plugin's name as inferred from its package.
- `id`: `string` — A unique identifier for the plugin instance.
- `options`: `Record<string, unknown>` — The options passed to the plugin.
- `version`: `string` — The plugin's version as specified in its `package.json`.
- `admin`: [PluginAdminDetails](/resources/references/types/types/typesPluginAdminDetails) (optional) — Admin dashboard details for the plugin, if any.
  - `type`: `"local"` | `"package"`
  - `resolve`: `string`
- `modules`: [InputConfigModules](/resources/references/types/CommonTypes/types/typesCommonTypesInputConfigModules) (optional) — Module configurations provided by the plugin.
