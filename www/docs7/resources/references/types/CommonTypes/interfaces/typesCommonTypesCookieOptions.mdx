---
title: CookieOptions
---

Cookie options used when setting cookies in the HTTP layer.

## Properties

**CookieOptions**

- `secure`: `boolean` (optional) — Whether the cookie should only be sent over HTTPS connections.
- `sameSite`: `"lax"` | `"strict"` | `"none"` (optional) — The `SameSite` attribute of the cookie, controlling cross-site request behavior.
- `maxAge`: `number` (optional) — The maximum age of the cookie in milliseconds.
- `httpOnly`: `boolean` (optional) — Whether the cookie is accessible only via HTTP(S) and not JavaScript.
- `priority`: `"low"` | `"medium"` | `"high"` (optional) — The priority of the cookie as defined in RFC 8030.
- `domain`: `string` (optional) — The domain for which the cookie is valid.
- `path`: `string` (optional) — The URL path for which the cookie is valid.
- `signed`: `boolean` (optional) — Whether the cookie should be signed.
