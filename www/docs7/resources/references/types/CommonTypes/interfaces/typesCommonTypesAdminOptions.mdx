title: AdminOptions
---

Admin dashboard configurations.

## Properties

**AdminOptions**

- `disable`: `boolean` (optional) — Whether to disable the admin dashboard. If set to `true`, the admin dashboard is disabled, in both development and production environments. The default value is `false`.

  Example:

  ````
  js title="medusa-config.ts" module.exports = defineConfig({ admin: { disable: process.env.ADMIN_DISABLED === "true" || false }, // ... }) ```
  ````
- `path`: `/${string}` — The path to the admin dashboard. The default value is `/app`. The value cannot be one of the reserved paths: - `/admin` - `/store` - `/auth`

  Example:

  ```
  title="medusa-config.ts" module.exports = defineConfig({ admin: { path: process.env.ADMIN_PATH || `/app`, }, // ... })
  ```
- `backendUrl`: `string` (optional) — The URL of your Medusa application. Defaults to the browser origin. This is useful to set when running the admin on a separate domain.

  Example:

  ````
  js title="medusa-config.ts" module.exports = defineConfig({ admin: { backendUrl: process.env.MEDUSA_BACKEND_URL || "http://localhost:9000" }, // ... }) ```
  ````
- `storefrontUrl`: `string` (optional) — The URL of your Medusa storefront application. This will help generate links from the admin to provide to customers to complete any processes

  Example:

  ````
  js title="medusa-config.ts" module.exports = defineConfig({ admin: { storefrontUrl: process.env.MEDUSA_STOREFRONT_URL || "http://localhost:9000" }, // ... }) ```
  ````
- `outDir`: `string` (optional) — The directory where the admin build is output. This is where the build process places the generated files. The default value is `./build`.
- `vite`: (`config`: `InlineConfig`) => `InlineConfig` (optional) — Configure the Vite configuration for the admin dashboard. This function receives the default Vite configuration and returns the modified configuration. The default value is `undefined`.
- `maxUploadFileSize`: `number` (optional) — The maximum file size for media uploads in bytes. The default value is `1048576` (1MB). Set to `Infinity` to disable the file size limit.

  Example:

  ````
  js title="medusa-config.ts" module.exports = defineConfig({ admin: { maxUploadFileSize: 10 * 1024 * 1024, // 10MB }, // ... }) ```
  ````
