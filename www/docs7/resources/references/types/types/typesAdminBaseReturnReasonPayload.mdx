---
title: AdminBaseReturnReasonPayload
---

- `AdminBaseReturnReasonPayload`: `object`
  - `value`: `string` — The return reason's value.

    Example:

    ```
    "refund"
    ```
  - `label`: `string` — The return reason's label.

    Example:

    ```
    "Refund"
    ```
  - `description`: `string` (optional) — The return reason's description.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — Custom key-value pairs that can be added to the return reason.
