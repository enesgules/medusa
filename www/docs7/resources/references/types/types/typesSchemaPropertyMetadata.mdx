---
title: SchemaPropertyMetadata
---

The meta-data returned by a shared schema property parse method.
Domain-specific metadata (DML indexes, search facets, etc.) extends this.

`TDataType` types `defaultValue` to match the property's `$dataType`.
Defaults to `any` so untyped call sites (compilers, helpers) keep working.

> **Note**
>
> This is available starting from [Medusa v2.19.0](https://github.com/medusajs/medusa/releases/tag/v2.19.0).

- `SchemaPropertyMetadata`: `object` — The meta-data returned by a shared schema property parse method. Domain-specific metadata (DML indexes, search facets, etc.) extends this. `TDataType` types `defaultValue` to match the property's `$dataType`. Defaults to `any` so untyped call sites (compilers, helpers) keep working.
  - `fieldName`: `string`
  - `defaultValue`: TDataType (optional)
  - `nullable`: `boolean`
  - `computed`: `boolean`
  - `dataType`: `object`
    - `name`: `string`
    - `options`: `Record<string, any>` (optional)
