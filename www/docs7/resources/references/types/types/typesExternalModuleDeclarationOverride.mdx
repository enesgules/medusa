- `ExternalModuleDeclarationOverride`: [ExternalModuleDeclaration](/resources/references/types/ModulesSdkTypes/types/typesModulesSdkTypesExternalModuleDeclaration) & `object`
  - `scope`: `"external"`
  - `definition`: [CustomModuleDefinition](/resources/references/types/ModulesSdkTypes/types/typesModulesSdkTypesCustomModuleDefinition) (optional)
    - `key`: `string` (optional)
    - `label`: `string` (optional)
    - `isQueryable`: `boolean` (optional)
    - `dependencies`: `string`\[] (optional)
  - `server`: `object` (optional)
    - `type`: `"http"`
    - `url`: `string`
    - `keepAlive`: `boolean`
  - `options`: `Record<string, unknown>` (optional)
  - `alias`: `string` (optional) — If multiple modules are registered with the same key, the alias can be used to differentiate them
  - `main`: `boolean` (optional) — If the module is the main module for the key when multiple ones are registered
  - `key`: `string` — key to be used to identify the module, if not provided, it will be inferred from the module joiner config service name.
  - `disable`: `boolean` (optional) — By default, modules are enabled, if provided as true, this will disable the module entirely.
