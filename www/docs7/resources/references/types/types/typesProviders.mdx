---
title: Providers
---

- `Providers`: (`string` | `object`)\[]
  - `id`: `string` — The ID of the provider to use, as set in `medusa-config.ts`.
  - `ttl`: `number` (optional) — Optional custom time-to-live (TTL) (in seconds) for this provider. If not provided, the default TTL configured in the provider is used, or the default TTL of the Caching Module if not configured in the provider.
