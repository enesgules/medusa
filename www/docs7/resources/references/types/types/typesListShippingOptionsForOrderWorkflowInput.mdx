title: ListShippingOptionsForOrderWorkflowInput

The context for retrieving the shipping options.

- `ListShippingOptionsForOrderWorkflowInput`: `object` — The context for retrieving the shipping options.
  - `order_id`: `string` — The order's ID.
  - `is_return`: `boolean` (optional, default: false) — Whether to retrieve return shipping options. By default, non-return shipping options are retrieved.
  - `enabled_in_store`: `boolean` (optional) — Whether to retrieve the shipping option's enabled in the store, which is the default.
