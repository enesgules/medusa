The context for retrieving the shipping options.

- `ListShippingOptionsForCartWithPricingWorkflowInput`: `object` — The context for retrieving the shipping options.
  - `cart_id`: `string` — The cart's ID.
  - `options`: `object`\[] (optional) — Specify the shipping options to retrieve their details and prices. If not provided, all applicable shipping options are retrieved.
    - `id`: `string` — The shipping option's ID.
    - `data`: `Record<string, unknown>` (optional) — Custom data relevant for the fulfillment provider that processes this shipping option. It can be data relevant to calculate the shipping option's price. Learn more in [this documentation](/resources/commerce-modules/fulfillment/shipping-option#data-property).
  - `is_return`: `boolean` (optional, default: false) — Whether to retrieve return shipping options. By default, non-return shipping options are retrieved.
  - `enabled_in_store`: `boolean` (optional, default: true) — Whether to retrieve the shipping option's enabled in the store, which is the default.
