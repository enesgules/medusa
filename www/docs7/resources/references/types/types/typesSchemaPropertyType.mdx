---
title: SchemaPropertyType
---

Definition of a schema property type. It should have a parse
method to get the metadata and a type-only property
to get its static type.

> **Note**
>
> This is available starting from [Medusa v2.19.0](https://github.com/medusajs/medusa/releases/tag/v2.19.0).

- `SchemaPropertyType`: `object` — Definition of a schema property type. It should have a parse method to get the metadata and a type-only property to get its static type.
  - `$dataType`: T
