### sync

Sync the index
The sync strategy can be "full" meaning it will re sync the entire index, "reset" meaning it
will reset the index data and start from scratch, or if not specified, it will continue the
sync from the last sync point.

<a id="sync-parameters" />

#### Parameters

**sync**

- `strategy`: `object` (optional) — The sync strategy
  - `strategy`: `"full"` | `"reset"` (optional)

<a id="sync-returns" />

#### Returns

**sync**

- `Promise`: Promise\<void> — Sync the index The sync strategy can be "full" meaning it will re sync the entire index, "reset" meaning it will reset the index data and start from scratch, or if not specified, it will continue the sync from the last sync point.
