---
title: CreateShippingOptionsWorkflowInput
---

The data to create a flat rate or calculated shipping option.

- `CreateShippingOptionsWorkflowInput`: [CreateFlatRateShippingOptionInput](/resources/references/types/types/typesCreateFlatRateShippingOptionInput) | [CreateCalculatedShippingOptionInput](/resources/references/types/types/typesCreateCalculatedShippingOptionInput) — The data to create a flat rate or calculated shipping option.
  - `name`: `string` — The name of the shipping option.
  - `service_zone_id`: `string` — The ID of the service zone the shipping option belongs to.
  - `shipping_profile_id`: `string` — The ID of the shipping profile the shipping option belongs to.
  - `data`: `Record<string, unknown>` (optional) — Custom data that's necessary for the shipping option's fulfillment provider. Learn more about this property in [this documentation](/resources/commerce-modules/fulfillment/shipping-option#data-property).
  - `provider_id`: `string` — The ID of the shipping option's fulfillment provider.
  - `type`: `object` (optional) — The type of the shipping option.
    - `label`: `string` — The label of the shipping option type.
    - `description`: `string` (optional) — The description of the shipping option type.
    - `code`: `string` — The code of the shipping option type.
  - `type_id`: `string` (optional) — The ID of the type of shipping option.
  - `rules`: `object`\[] (optional) — The rules that determine when the shipping option is available.
    - `attribute`: `string` — The attribute to match against.

      Example:

      ```
      customer_group
      ```
    - `operator`: [RuleOperatorType](/resources/references/types/CommonTypes/types/typesCommonTypesRuleOperatorType) — The operator to use when matching the attribute.

      Example:

      ```
      in
      ```
    - `value`: `string` | `string`\[] — The value to match against.

      Example:

      ```
      cusgrp_123
      ```
  - `price_type`: `"flat"` — The type of the shipping option's price.
  - `prices`: [CreateFlatRateShippingOptionPriceRecord](/resources/references/types/types/typesCreateFlatRateShippingOptionPriceRecord)\[] — The prices for the shipping option. Only required if the price type is `flat`.
    - `currency_code`: `string`
    - `amount`: `number`
    - `rules`: [PriceRule](/resources/references/pricing/models/PriceRule)\[] (optional)
    - `region_id`: `string`
