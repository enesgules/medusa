The data to calculate shipping option prices.

- `CalculateShippingOptionsPricesWorkflowInput`: `object` — The data to calculate shipping option prices.
  - `cart_id`: `string` — The ID of the cart to calculate the shipping options for.
  - `shipping_options`: `object`\[] — The shipping options to calculate the prices for.
    - `id`: `string` — The ID of the shipping option.
    - `data`: `Record<string, unknown>` (optional) — Custom data that's necessary for the shipping option's fulfillment provider to calculate the price. Learn more about this property in [this documentation](/resources/commerce-modules/fulfillment/shipping-option#data-property).
