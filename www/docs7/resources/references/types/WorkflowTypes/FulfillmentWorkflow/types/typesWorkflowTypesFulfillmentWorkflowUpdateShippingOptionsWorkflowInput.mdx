---
title: UpdateShippingOptionsWorkflowInput
---

The data to update shipping options.

- `UpdateShippingOptionsWorkflowInput`: [UpdateFlatRateShippingOptionInput](/resources/references/types/WorkflowTypes/FulfillmentWorkflow/types/typesWorkflowTypesFulfillmentWorkflowUpdateFlatRateShippingOptionInput) | [UpdateCalculatedShippingOptionInput](/resources/references/types/WorkflowTypes/FulfillmentWorkflow/types/typesWorkflowTypesFulfillmentWorkflowUpdateCalculatedShippingOptionInput) — The data to update shipping options.
  - `id`: `string` — The ID of the shipping option.
  - `name`: `string` (optional) — The name of the shipping option.
  - `service_zone_id`: `string` (optional) — The ID of the service zone the shipping option belongs to.
  - `shipping_profile_id`: `string` (optional) — The ID of the shipping profile the shipping option belongs to.
  - `data`: `Record<string, unknown>` (optional) — Custom data that's necessary for the shipping option's fulfillment provider. Learn more about this property in [this documentation](/resources/commerce-modules/fulfillment/shipping-option#data-property).
  - `provider_id`: `string` (optional) — The ID of the shipping option's fulfillment provider.
  - `type`: `object` (optional) — The type of the shipping option.
    - `label`: `string` — The label of the shipping option type.
    - `description`: `string` (optional) — The description of the shipping option type.
    - `code`: `string` — The code of the shipping option type.
  - `type_id`: `string` (optional) — The ID of the type of shipping option.
  - `rules`: `object`\[] (optional) — The rules that determine when the shipping option is available.
    - `attribute`: `string` — The attribute to compare.

      Example:

      ```
      customer_group
      ```
    - `operator`: [RuleOperatorType](/resources/references/types/CommonTypes/types/typesCommonTypesRuleOperatorType) — The operator to compare with.

      Example:

      ```
      in
      ```
    - `value`: `string` | `string`\[] — The value to compare with.

      Example:

      ```
      cusgrp_123
      ```
  - `price_type`: `"flat"` (optional) — The price type of the shipping option.
  - `prices`: [UpdateShippingOptionPriceRecord](/resources/references/types/WorkflowTypes/FulfillmentWorkflow/types/typesWorkflowTypesFulfillmentWorkflowUpdateShippingOptionPriceRecord)\[] (optional) — The prices of the shipping option.
    - `id`: `string` (optional) — The ID of the price record.
    - `currency_code`: `string` (optional) — The currency code of the price.

      Example:

      ```
      usd
      ```
    - `amount`: `number` (optional) — The amount of the price.
    - `rules`: [PriceRule](/resources/references/pricing/models/PriceRule)\[] (optional) — The rules of the price.
    - `region_id`: `string` (optional) — The ID of the region that this price applies in.
