- `location_id`: `string` (optional) — The associated location's ID.
- `packed_at`: `null` | `Date` (optional) — The date the fulfillment was packed.
- `shipped_at`: `null` | `Date` (optional) — The date the fulfillment was shipped.
- `marked_shipped_by`: `null` | `string` (optional) — The id of the user that marked fulfillment as shipped
- `created_by`: `null` | `string` (optional) — The id of the user that created the fulfillment
- `delivered_at`: `null` | `Date` (optional) — The date the fulfillment was delivered.
- `data`: `null` | `Record<string, unknown>` (optional) — The data necessary for the associated fulfillment provider to process the fulfillment.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
