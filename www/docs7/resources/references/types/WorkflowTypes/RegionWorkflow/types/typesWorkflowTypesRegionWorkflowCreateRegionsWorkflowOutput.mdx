---
title: CreateRegionsWorkflowOutput
---

The created regions.

- `CreateRegionsWorkflowOutput`: [RegionDTO](/resources/references/region/interfaces/regionRegionDTO)\[] — The created regions.
  - `id`: `string` — The ID of the region.
  - `name`: `string` — The name of the region.
  - `currency_code`: `string` — The currency code of the region.
  - `automatic_taxes`: `boolean` — Setting to indicate whether taxes need to be applied automatically
  - `countries`: [RegionCountryDTO](/resources/references/region/interfaces/regionRegionCountryDTO)\[] — The countries of the region.
    - `id`: `string` — The ID of the country.
    - `iso_2`: `string` — The ISO 2 code of the country.
    - `iso_3`: `string` — The ISO 3 code of the country.
    - `num_code`: `string` — The country's code number.
    - `name`: `string` — The name of the country.
    - `display_name`: `string` — The display name of the country.
  - `payment_providers`: [PaymentProviderDTO](/resources/references/region/interfaces/regionPaymentProviderDTO)\[] — Payment providers available in the region
    - `id`: `string` — The ID of the payment provider.
    - `is_enabled`: `boolean` — Whether the payment provider is enabled.
  - `metadata`: `Record<string, any>` (optional) — Holds custom data in key-value pairs.
  - `created_at`: `string` — The date the region was created.
  - `updated_at`: `string` — The date the region was updated.
