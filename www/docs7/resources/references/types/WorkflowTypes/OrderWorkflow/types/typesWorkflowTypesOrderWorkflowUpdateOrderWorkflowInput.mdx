---
title: UpdateOrderWorkflowInput
---

The data to update an order's details.

- `UpdateOrderWorkflowInput`: `object` — The data to update an order's details.
  - `id`: `string` — The ID of the order to update.
  - `user_id`: `string` — The ID of the user updating the order.
  - `shipping_address`: [UpsertOrderAddressDTO](/resources/references/order/interfaces/orderUpsertOrderAddressDTO) (optional) — Create or update the shipping address of the order. Changing the country code will throw an error.
    - `customer_id`: `string` (optional) — The associated customer's ID.
    - `company`: `null` | `string` (optional) — The company name.
    - `first_name`: `null` | `string` (optional) — The first name of the customer.
    - `last_name`: `null` | `string` (optional) — The last name of the customer.
    - `address_1`: `null` | `string` (optional) — The address 1 of the address.
    - `address_2`: `null` | `string` (optional) — The address 2 of the address.
    - `city`: `null` | `string` (optional) — The city of the address.
    - `country_code`: `null` | `string` (optional) — The country code of the address.
    - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province of the address.
    - `postal_code`: `null` | `string` (optional) — The postal code of the address.
    - `phone`: `null` | `string` (optional) — The phone of the address.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `billing_address`: [UpsertOrderAddressDTO](/resources/references/order/interfaces/orderUpsertOrderAddressDTO) (optional) — Create or update the billing address of the order. Changing the country code will throw an error.
    - `customer_id`: `string` (optional) — The associated customer's ID.
    - `company`: `null` | `string` (optional) — The company name.
    - `first_name`: `null` | `string` (optional) — The first name of the customer.
    - `last_name`: `null` | `string` (optional) — The last name of the customer.
    - `address_1`: `null` | `string` (optional) — The address 1 of the address.
    - `address_2`: `null` | `string` (optional) — The address 2 of the address.
    - `city`: `null` | `string` (optional) — The city of the address.
    - `country_code`: `null` | `string` (optional) — The country code of the address.
    - `province`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province of the address.
    - `postal_code`: `null` | `string` (optional) — The postal code of the address.
    - `phone`: `null` | `string` (optional) — The phone of the address.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `email`: `string` (optional) — The new email of the order.
  - `locale`: `string` | `null` (optional) — The new locale of the order. When changed, all line items will be re-translated to the new locale.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — The new metadata of the order.
