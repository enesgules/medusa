title: BeginReceiveOrderReturnWorkflowInput

The details of a return requested to be received.

## Properties

**BeginReceiveOrderReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to receive.
- `created_by`: `string` (optional) — The ID of the user that's requesting the return receival.
- `description`: `string` (optional) — Description of the return receival.
- `internal_note`: `string` (optional) — A note viewed by admins only related to the return receival.
- `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs of data to store in the return receival.
