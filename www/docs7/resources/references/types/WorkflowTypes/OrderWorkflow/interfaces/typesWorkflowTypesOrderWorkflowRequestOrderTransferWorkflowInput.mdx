---
title: RequestOrderTransferWorkflowInput
---

The input to the request order transfer workflow.

## Properties

**RequestOrderTransferWorkflowInput**

- `order_id`: `string` — The ID of the order to transfer.
- `customer_id`: `string` — The ID of the customer to transfer the order to.
- `logged_in_user`: `string` — The ID of the logged in user requesting the transfer. Can be an admin user or a customer.
- `description`: `string` (optional) — Details of the transfer request.
- `internal_note`: `string` (optional) — A note viewed by admin users only.
- `update_order_email`: `boolean` (optional) — Whether to update the order.email to the transferred customer email.
