The details of the item to update in a claim.

## Properties

**UpdateClaimItemWorkflowInput**

- `claim_id`: `string` — The ID of the claim to update the item in.
- `action_id`: `string` — The ID of the action associated with the item to update. Every item has an `actions` property, whose value is an array of actions. You can find the action with the name `WRITE_OFF_ITEM` using its `action` property, and use the value of its `id` property.
- `data`: `object`
  - `quantity`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional)
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `reason_id`: `null` | `string` (optional)
  - `internal_note`: `null` | `string` (optional)
