title: BeginOrderClaimWorkflowInput

The details of the order claim to be requested.

## Properties

**BeginOrderClaimWorkflowInput**

- `type`: [OrderClaimType](/resources/references/fulfillment/types/fulfillmentOrderClaimType) — The type of the order claim.
- `order_id`: `string` — The ID of the order to create the claim for.
- `created_by`: `null` | `string` (optional) — The ID of the user creating the order claim.
- `internal_note`: `string` (optional) — An internal note viewed by admin users only.
- `description`: `string` (optional) — A description of the order claim.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs of data to store in the order claim.
