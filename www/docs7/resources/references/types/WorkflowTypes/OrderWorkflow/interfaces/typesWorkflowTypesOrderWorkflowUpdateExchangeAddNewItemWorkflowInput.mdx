The details of the outbound or new item to update in an order.

## Properties

**UpdateExchangeAddNewItemWorkflowInput**

- `exchange_id`: `string` — The ID of the exchange to update the item in.
- `action_id`: `string` — The ID of the action associated with the item to update. Every item has an `actions` property, whose value is an array of actions. You can find the action with the name `ITEM_ADD` using the item's `action` property, and use the value of the action's `id` property.
- `data`: `object` — The data to update in the item.
  - `quantity`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — The new quantity of the item.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `null` | `string` (optional) — A note viewed by admins only related to the item.
