The details of the item to be removed from the return.

## Properties

**DeleteRequestItemReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to remove the item from.
- `action_id`: `string` — The ID of the action associated with the item to remove. Every item has an `actions` property, whose value is an array of actions. You can find an action with the name `RETURN_ITEM` using its `action` property, and use the value of its `id` property.
