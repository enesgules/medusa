---
title: BeginOrderExchangeWorkflowInput
---

The details to request an order exchange.

## Properties

**BeginOrderExchangeWorkflowInput**

- `order_id`: `string` — The ID of the order to request an exchange for.
- `created_by`: `null` | `string` (optional) — The id of the user that creates the order exchange
- `internal_note`: `string` (optional) — An internal note viewed only by admin users.
- `description`: `string` (optional) — A description of the exchange.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs of data to store in the exchange.
