---
title: CancelOrderWorkflowInput
---

The details of the order cancelation.

## Properties

**CancelOrderWorkflowInput**

- `order_id`: `string` — The ID of the order to cancel.
- `no_notification`: `boolean` (optional) — Whether to notify the customer of the cancelation.
- `canceled_by`: `string` (optional) — The ID of the user that canceled the order.
