---
title: UpdateRequestItemReturnWorkflowInput
---

The details of updating a requested item in a return.

## Properties

**UpdateRequestItemReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to update the item in.
- `claim_id`: `string` (optional) — The ID of the claim associated with the return, if any.
- `exchange_id`: `string` (optional) — The ID of the exchange associated with the return, if any.
- `action_id`: `string` — The ID of the action associated with the item to update. Every item has an `actions` property, whose value is an array of actions. You can find an action with the name `RETURN_ITEM` using its `action` property, and use the value of its `id` property.
- `data`: `object` — The data to update in the item.
  - `quantity`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) (optional) — The new quantity of the item.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `null` | `string` (optional) — An internal note viewed only by admin users.
  - `reason_id`: `null` | `string` (optional) — The ID of the reason indicating why the item is being returned.
