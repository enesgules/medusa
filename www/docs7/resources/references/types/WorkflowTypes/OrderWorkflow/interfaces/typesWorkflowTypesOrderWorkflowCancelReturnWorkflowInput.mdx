title: CancelReturnWorkflowInput

The details to cancel a return.

## Properties

**CancelReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to cancel.
- `no_notification`: `boolean` (optional) — Whether to notify the customer of the return cancellation.
- `canceled_by`: `string` (optional) — The ID of the user that's canceling the return.
