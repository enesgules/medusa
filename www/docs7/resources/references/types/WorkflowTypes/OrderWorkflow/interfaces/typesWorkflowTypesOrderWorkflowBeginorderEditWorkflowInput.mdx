title: BeginorderEditWorkflowInput
---

The details of the order edit request.

## Properties

**BeginorderEditWorkflowInput**

- `order_id`: `string` — The ID of the order to request an edit for.
- `created_by`: `string` (optional) — The ID of the user requesting the order edit.

  Example:

  ```
  "user_123"
  ```
- `internal_note`: `string` (optional) — A note viewed by admins only related to the order edit.
- `description`: `string` (optional) — Describes the reason for the order edit.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs of data to store in the order edit.
