The data to mark items as received in a return.

## Properties

**ReceiveOrderReturnItemsWorkflowInput**

- `return_id`: `string` — The ID of the return to mark its items as received.
- `items`: [ReceiveReturnItem](/resources/references/types/interfaces/typesReceiveReturnItem)\[] — The items to mark as received.
  - `id`: `string` — The ID of the order item to receive.
  - `quantity`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) — The quantity of the item to receive.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `string` (optional) — An internal note viewed only by admin users.
  - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs of data to store in the return item.
