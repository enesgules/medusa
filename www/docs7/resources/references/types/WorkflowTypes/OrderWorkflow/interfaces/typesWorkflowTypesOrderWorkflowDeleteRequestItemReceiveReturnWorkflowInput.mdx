The details of the received item to be removed.

## Properties

**DeleteRequestItemReceiveReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to remove the item from.
- `action_id`: `string` — The ID of the action associated with the item to remove. Every item has an `actions` property, whose value is an array of actions. You can find an action with the name `RECEIVE_RETURN_ITEM` using its `action` property, and use the value of its `id` property.
