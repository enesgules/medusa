---
title: BeginOrderReturnWorkflowInput
---

The details of a return to create.

## Properties

**BeginOrderReturnWorkflowInput**

- `order_id`: `string` — The ID of the order to create the return for.
- `location_id`: `string` (optional) — The ID of the location to return the items to.
- `created_by`: `null` | `string` (optional) — The ID of the user creating the return.
- `internal_note`: `string` (optional) — A note viewed by admins only related to the return.
- `description`: `string` (optional) — Description of the return.
- `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs of data to store in the return.
