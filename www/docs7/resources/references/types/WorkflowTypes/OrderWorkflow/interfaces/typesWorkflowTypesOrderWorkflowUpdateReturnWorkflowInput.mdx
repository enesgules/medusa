title: UpdateReturnWorkflowInput
---

The data to update a return's details.

## Properties

**UpdateReturnWorkflowInput**

- `return_id`: `string` — The ID of the return to update.
- `location_id`: `null` | `string` (optional) — The ID of the stock location that items are returned to.
- `no_notification`: `boolean` (optional) — Whether to notify the customer about the return update.
- `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs of data to store in the return.
