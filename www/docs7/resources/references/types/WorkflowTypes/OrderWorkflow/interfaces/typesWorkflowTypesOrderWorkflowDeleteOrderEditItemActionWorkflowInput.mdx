The details to remove an item previously added to an order edit.

## Properties

**DeleteOrderEditItemActionWorkflowInput**

- `order_id`: `string` — The ID of the order to remove the item from its edit.
- `action_id`: `string` — The ID of the action associated with the item to remove. Every item has an `actions` property, whose value is an array of actions. You can find the action with the name `ITEM_ADD` using the item's `action` property, and use the value of the action's `id` property.
