---
title: TransferOrderToGuestWorkflowInput
---

The input to the transfer order to guest workflow.

## Properties

**TransferOrderToGuestWorkflowInput**

- `order_id`: `string` — The ID of the order to transfer.
- `email`: `string` — The email of the guest customer to transfer the order to. If no customer exists with this email, a guest customer is created.
- `logged_in_user`: `string` — The ID of the logged in user requesting the transfer.
- `description`: `string` (optional) — Details of the transfer.
- `internal_note`: `string` (optional) — A note viewed by admin users only.
