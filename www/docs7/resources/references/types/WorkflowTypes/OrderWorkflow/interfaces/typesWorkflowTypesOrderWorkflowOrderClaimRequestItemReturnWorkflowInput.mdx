The details of the items to be returned as part of the claim.

## Properties

**OrderClaimRequestItemReturnWorkflowInput**

- `return_id`: `string` — The ID of the return that's associated with the claim.
- `location_id`: `string` (optional) — The ID of the location to return the items to.
- `claim_id`: `string` — The ID of the claim to add the items to.
- `items`: [CreateReturnItem](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCreateReturnItem)\[] — The items to add to the claim as inbound items.
  - `id`: `string` — The ID of the order item to return.
  - `quantity`: [BigNumberInput](/resources/references/types/types/typesBigNumberInput) — The quantity of the item to return.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/types/types/typesBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `internal_note`: `null` | `string` (optional) — An internal note viewed only by admin users.
  - `reason_id`: `null` | `string` (optional) — The ID of the reason indicating why the item is being returned.
  - `note`: `null` | `string` (optional) — More details about the returned item.
  - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs of data to store in the return item.
