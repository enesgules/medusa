## Properties

**CancelOrderFulfillmentWorkflowInput**

- `order_id`: `string` — The ID of the order to cancel its fulfillment.
- `fulfillment_id`: `string` — The ID of the fulfillment to cancel.
- `no_notification`: `boolean` (optional) — Whether to notify the customer about the cancellation.
- `canceled_by`: `string` (optional) — The ID of the user that canceled the fulfillment.
