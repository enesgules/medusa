---
title: UpsertStockLocationAddressInput
---

The stock location address to create or update. If the `id` property isn't provided,
the stock location address is created. In that case, the `address_1` property is required.

- `UpsertStockLocationAddressInput`: [StockLocationAddressInput](/resources/references/types/StockLocationTypes/types/typesStockLocationTypesStockLocationAddressInput) & `object` — The stock location address to create or update. If the `id` property isn't provided, the stock location address is created. In that case, the `address_1` property is required.
  - `address_1`: `string` — The first line of the stock location address.
  - `address_2`: `string` | `null` (optional) — The second line of the stock location address.
  - `country_code`: `string` — The country code of the stock location address.
  - `city`: `string` | `null` (optional) — The city of the stock location address.
  - `phone`: `string` | `null` (optional) — The phone of the stock location address.
  - `province`: `string` | `null` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province of the stock location address.
  - `postal_code`: `string` | `null` (optional) — The postal code of the stock location address.
  - `metadata`: [MetadataType](/resources/references/types/CommonTypes/types/typesCommonTypesMetadataType) (optional) — Holds custom data in key-value pairs.
  - `id`: `string` (optional) — The ID of the stock location address, if updating.
