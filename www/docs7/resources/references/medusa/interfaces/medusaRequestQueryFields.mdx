---
title: RequestQueryFields
---

Fields that can be passed in the query parameters of a request.

## Properties

**RequestQueryFields**

- `fields`: `string` (optional) — Comma-separated fields that should be included in the returned data. if a field is prefixed with `+` it will be added to the default fields, using `-` will remove it from the default fields. without prefix it will replace the entire default fields.
- `offset`: `number` (optional) — The number of items to skip when retrieving a list.
- `limit`: `number` (optional) — Limit the number of items returned in the list.
- `order`: `string` (optional) — The field to sort the data by. By default, the sort order is ascending. To change the order to descending, prefix the field name with `-`.
- `with_deleted`: `boolean` (optional) — Whether to include deleted records in the result.
