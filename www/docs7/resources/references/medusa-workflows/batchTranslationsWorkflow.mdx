This documentation provides a reference to the `batchTranslationsWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow creates, updates, and deletes translations. It's used by the
[Manage Translations Admin API Route](/api/admin/translations/manage-translations).

You can use this workflow within your own customizations or custom workflows, allowing you
to create, update, and delete translations in your custom flows.

> **Note**
>
> This is available starting from [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3).

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/translation/workflows/batch-translations.ts#L73)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { batchTranslationsWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await batchTranslationsWorkflow(req.scope)
    .run({
      input: {
        create: [{
          reference_id: "prod_123",
          reference: "product",
          locale_code: "en-US",
          translations: {
            title: "Product Title",
            description: "Product Description",
          },
        }],
        update: [{
          id: "trans_123",
          translations: {
            title: "Product Title",
            description: "Product Description",
          },
        }],
        delete: ["trans_321"]
      }
    })

  res.send(result)
}
```

## Steps

- [createTranslationsWorkflow](/resources/references/medusa-workflows/createTranslationsWorkflow): Create one or more translations.
- [updateTranslationsWorkflow](/resources/references/medusa-workflows/updateTranslationsWorkflow): Update translations.
- [deleteTranslationsWorkflow](/resources/references/medusa-workflows/deleteTranslationsWorkflow): Delete one or more translations.

<a id="batchtranslationsworkflow-input" />

## Input

**batchTranslationsWorkflow**

- `BatchTranslationsWorkflowInput`: [BatchTranslationsWorkflowInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcBatchTranslationsWorkflowInput)
  - `create`: [CreateTranslationDTO](/resources/references/translation/interfaces/translationCreateTranslationDTO)\[] — The translations to create.
    - `reference_id`: `string` — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
  - `update`: [UpdateTranslationDTO](/resources/references/translation/interfaces/translationUpdateTranslationDTO)\[] — The translations to update.
    - `reference_id`: `string` (optional) — The ID of the data model being translated.

      Example:

      ```
      "prod_123"
      ```
    - `reference`: `string` (optional) — The name of the table that the translation belongs to.

      Example:

      ```
      "product"
      ```
    - `locale_code`: `string` (optional) — The BCP 47 language tag code for this translation.

      Example:

      ```
      "en-US"
      ```
    - `translations`: `Record<string, unknown>` (optional) — The translated fields as key-value pairs.

      Example:

      ```
      { * "title": "Product Title", * "description": "Product Description", * }
      ```
    - `id`: `string` — The ID of the translation to update.
  - `delete`: `string`\[] — The IDs of the translations to delete.

<a id="batchtranslationsworkflow-output" />

## Output

**batchTranslationsWorkflow**

- `created`: [TranslationDTO](/resources/references/translation/interfaces/translationTranslationDTO)\[]
  - `id`: `string` — The ID of the translation.
  - `reference_id`: `string` — The ID of the entity being translated.
  - `reference`: `string` — The type of entity being translated (e.g., "product", "product\_variant").
  - `locale_code`: `string` — The BCP 47 language tag code for this translation (e.g., "en-US", "fr-FR").
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.
  - `created_at`: `string` | `Date` — The date and time the translation was created.
  - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
- `updated`: [TranslationDTO](/resources/references/translation/interfaces/translationTranslationDTO)\[]
  - `id`: `string` — The ID of the translation.
  - `reference_id`: `string` — The ID of the entity being translated.
  - `reference`: `string` — The type of entity being translated (e.g., "product", "product\_variant").
  - `locale_code`: `string` — The BCP 47 language tag code for this translation (e.g., "en-US", "fr-FR").
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.
  - `created_at`: `string` | `Date` — The date and time the translation was created.
  - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
- `deleted`: `unknown`

## Emitted Events

- `translation.created` (since v2.12.3): Emitted when translations are created.

  ```ts
  {
    id, // The ID of the translation
  }
  ```
- `translation.updated` (since v2.12.3): Emitted when translations are updated.

  ```ts
  {
    id, // The ID of the translation
  }
  ```
- `translation.deleted` (since v2.12.3): Emitted when translations are deleted.

  ```ts
  {
    id, // The ID of the translation
  }
  ```
