This documentation provides a reference to the `deleteCartCreditLinesWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow deletes one or more credit lines from a cart.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/cart/workflows/delete-cart-credit-lines.ts#L13)

  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
