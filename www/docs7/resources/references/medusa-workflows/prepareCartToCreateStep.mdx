This documentation provides a reference to the `prepareCartToCreateStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step prepares the data used to create a cart, resolving the cart's
currency, region, customer, sales channel, and a default shipping address
when the region has a single country. It throws an error if no region is
provided.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { prepareCartToCreateStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = prepareCartToCreateStep({
      "input": {},
      "region": {},
      "customerData": {},
      "salesChannel": {}
    })
  }
)
```
