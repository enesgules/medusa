This documentation provides a reference to the `batchPropertyLabelsWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow creates, updates, or deletes property labels in batch.

> **Note**
>
> This is available starting from [Medusa v2.13.7](https://github.com/medusajs/medusa/releases/tag/v2.13.7).

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/settings/workflows/batch-property-labels.ts#L100)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { batchPropertyLabelsWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await batchPropertyLabelsWorkflow(req.scope)
    .run({
      input: {}
    })

  res.send(result)
}
```
