This documentation provides a reference to the `createCompleteReturnValidationStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that a return can be created and completed for an order.
If the order is canceled, the items do not exist in the order,
the return reasons are invalid, or the refund amount is greater than the order total,
the step will throw an error.

> **Note**
>
> You can retrieve an order details using [Query](/learn/fundamentals/module-links/query),
> or [useQueryGraphStep](/resources/references/medusa-workflows/steps/useQueryGraphStep).

## Example

```ts
const data = createCompleteReturnValidationStep({
  order: {
    id: "order_123",
    // other order details...
  },
  input: {
    order_id: "order_123",
    items: [
      {
        id: "orli_123",
        quantity: 1,
      }
    ]
  }
})
```

## Input

**createCompleteReturnValidationStep**

- `CreateCompleteReturnValidationStepInput`: [CreateCompleteReturnValidationStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcCreateCompleteReturnValidationStepInput)
  - `order`: `any` — The order's details.
  - `input`: [CreateOrderReturnWorkflowInput](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCreateOrderReturnWorkflowInput) — The data to create a return.
    - `order_id`: `string` — The ID of the order to return items from.
    - `created_by`: `null` | `string` (optional) — The ID of the customer that's creating the return
    - `items`: [CreateReturnItem](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCreateReturnItem)\[] — The items to return.
    - `return_shipping`: `object` (optional) — The shipping details of the returned items.
    - `note`: `null` | `string` (optional) — More details about the return.
    - `receive_now`: `boolean` (optional) — Whether to mark the return as received immediately.
    - `refund_amount`: `number` (optional) — The amount to refund the customer.
    - `location_id`: `null` | `string` (optional) — The ID of the location to return the items to. If not provided, the return shipping option's location is used.
