This documentation provides a reference to the `cancelOrderExchangeWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow cancels a confirmed exchange. It's used by the
[Cancel Exchange Admin API Route](/api/admin/exchanges/cancel-an-exchange).

You can use this workflow within your customizations or your own custom workflows, allowing you to cancel an exchange
for an order in your custom flow.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/order/workflows/exchange/cancel-exchange.ts#L114)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { cancelOrderExchangeWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await cancelOrderExchangeWorkflow(req.scope)
    .run({
      input: {
        exchange_id: "exchange_123",
      }
    })

  res.send(result)
}
```

## Input

**cancelOrderExchangeWorkflow**

- `CancelOrderExchangeWorkflowInput`: [CancelOrderExchangeWorkflowInput](/resources/references/types/WorkflowTypes/OrderWorkflow/interfaces/typesWorkflowTypesOrderWorkflowCancelOrderExchangeWorkflowInput)
  - `exchange_id`: `string` — The ID of the exchange to cancel.
  - `no_notification`: `boolean` (optional) — Whether to notify the customer of the cancellation.
  - `canceled_by`: `string` (optional) — The ID of the user that's canceling the exchange.
