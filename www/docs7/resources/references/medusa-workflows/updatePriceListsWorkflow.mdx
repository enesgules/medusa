This documentation provides a reference to the `updatePriceListsWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow updates one or more price lists. It's used by the
[Update Price List Admin API Route](/api/admin/price-lists/update-a-price-list).

You can use this workflow within your customizations or your own custom workflows, allowing you to
update price lists in your custom flows.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/price-list/workflows/update-price-lists.ts#L40)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { updatePriceListsWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await updatePriceListsWorkflow(req.scope)
    .run({
      input: {
        price_lists_data: [{
          id: "plist_123",
          title: "Test Price List",
        }]
      }
    })

  res.send(result)
}
```

## Steps

- [validatePriceListsStep](/resources/references/medusa-workflows/steps/validatePriceListsStep): This step validates that the specified price lists exist. If not valid, the step throws an error.
  - [updatePriceListsStep](/resources/references/medusa-workflows/steps/updatePriceListsStep): This step updates one or more price lists.

<a id="updatepricelistsworkflow-input" />

## Input

**updatePriceListsWorkflow**

- `price_lists_data`: [UpdatePriceListWorkflowInputDTO](/resources/references/types/interfaces/typesUpdatePriceListWorkflowInputDTO)\[]
  - `id`: `string` — The ID of the price list to update.
  - `title`: `string` (optional) — The title of the price list.
  - `description`: `null` | `string` (optional) — The description of the price list.
  - `starts_at`: `null` | `string` (optional) — The start date of the price list.
  - `ends_at`: `null` | `string` (optional) — The end date of the price list.
  - `status`: [PriceListStatus](/resources/references/pricing/types/pricingPriceListStatus) (optional) — The status of the price list.
  - `rules`: `Record<string, string[]>` (optional) — The rules associated with the price list.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
