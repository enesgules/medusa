This documentation provides a reference to the `batchTranslationSettingsWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow creates, updates, and deletes translation settings in batch.
It's used by the [List Translation Settings API route](/api/admin/translations/list-settings).

You can use this workflow within your own customizations or custom workflows, allowing you
to create, update, and delete translation settings in your custom flows.

> **Note**
>
> This is available starting from [Medusa v2.13.0](https://github.com/medusajs/medusa/releases/tag/v2.13.0).

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/translation/workflows/batch-translation-settings.ts#L65)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { batchTranslationSettingsWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await batchTranslationSettingsWorkflow(req.scope)
    .run({
      create: [{
        entity_type: "product",
        fields: ["title", "description"],
        is_active: true
      }],
      update: [{
        id: "ts_123",
        is_active: false
      }],
      delete: ["ts_456"]
    })

  res.send(result)
}
```

## Steps

- [createTranslationSettingsStep](/resources/references/medusa-workflows/steps/createTranslationSettingsStep): This step creates translation settings based on the provided input. It supports both single and multiple translation settings creation. In case of failure, it compensates by deleting the created translation settings.
- [updateTranslationSettingsStep](/resources/references/medusa-workflows/steps/updateTranslationSettingsStep): This step updates translation settings based on the provided input. It supports both single and multiple translation settings updates. In case of failure, it compensates by restoring the previous translation settings.
- [deleteTranslationSettingsStep](/resources/references/medusa-workflows/steps/deleteTranslationSettingsStep): This step deletes translation settings based on the provided IDs. It compensates by restoring the deleted translation settings in case of failure.

    - `id`: `string` — The ID of the translation settings to update.

      Example:

      ```
      "product"
      ```
    - `fields`: `string`\[] (optional) — The translatable fields.

      Example:

      ```
      ["title", "description", "material"]
      ```
    - `is_active`: `boolean` (optional) — Whether the entity translatable status is enabled.
  - `delete`: `string`\[] — Translation settings IDs to delete.
