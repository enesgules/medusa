This documentation provides a reference to the `createRegionsWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow creates one or more regions. It's used by the
[Create Region Admin API Route](/api/admin/regions/create-region).

You can use this workflow within your own customizations or custom workflows, allowing you
to create regions in your custom flows.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/region/workflows/create-regions.ts#L41)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { createRegionsWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await createRegionsWorkflow(req.scope)
    .run({
      input: {
        regions: [{
          currency_code: "usd",
          name: "United States",
          countries: ["us"],
        }]
      }
    })

  res.send(result)
}
```

## Steps

- [createRegionsStep](/resources/references/medusa-workflows/steps/createRegionsStep): This step creates one or more regions.
  - [setRegionsPaymentProvidersStep](/resources/references/medusa-workflows/steps/setRegionsPaymentProvidersStep): This step sets the payment providers available in regions.
  - [createPricePreferencesWorkflow](/resources/references/medusa-workflows/createPricePreferencesWorkflow): Create one or more price preferences.
  - [emitEventStep](/resources/references/medusa-workflows/steps/emitEventStep): This step emits an event, which you can listen to in a [subscriber](/learn/fundamentals/events-and-subscribers). You can pass data to the subscriber by including it in the `data` property. The event is only emitted after the workflow has finished successfully. So, even if it's executed in the middle of the workflow, it won't actually emit the event until the workflow has completed successfully. If the workflow fails, it won't emit the event at all.

## Input

**createRegionsWorkflow**

- `CreateRegionsWorkflowInput`: [CreateRegionsWorkflowInput](/resources/references/types/WorkflowTypes/RegionWorkflow/interfaces/typesWorkflowTypesRegionWorkflowCreateRegionsWorkflowInput)
  - `regions`: [CreateRegionDTO](/resources/references/region/interfaces/regionCreateRegionDTO) & `object`\[] — The regions to create.
    - `name`: `string` — The name of the region.
    - `currency_code`: `string` — The currency code of the region.
    - `automatic_taxes`: `boolean` (optional) — Setting to indicate whether taxes need to be applied automatically
    - `countries`: `string`\[] (optional) — The region's countries.
    - `payment_providers`: `string`\[] (optional) — The region's payment providers.
    - `metadata`: [MetadataType](/resources/references/region/types/regionMetadataType) (optional) — Holds custom data in key-value pairs.
    - `payment_providers`: `string`\[] (optional) — The IDs of payment providers that are available in the region.
    - `is_tax_inclusive`: `boolean` (optional) — Whether prices in the region are tax inclusive. Learn more in [this documentation](/resources/commerce-modules/pricing/tax-inclusive-pricing).

<a id="createregionsworkflow-output" />

## Output

**createRegionsWorkflow**

- `CreateRegionsWorkflowOutput`: [CreateRegionsWorkflowOutput](/resources/references/types/WorkflowTypes/RegionWorkflow/types/typesWorkflowTypesRegionWorkflowCreateRegionsWorkflowOutput)
  - `id`: `string` — The ID of the region.
  - `name`: `string` — The name of the region.
  - `currency_code`: `string` — The currency code of the region.
  - `automatic_taxes`: `boolean` — Setting to indicate whether taxes need to be applied automatically
  - `countries`: [RegionCountryDTO](/resources/references/region/interfaces/regionRegionCountryDTO)\[] — The countries of the region.
    - `id`: `string` — The ID of the country.
    - `iso_2`: `string` — The ISO 2 code of the country.
    - `iso_3`: `string` — The ISO 3 code of the country.
    - `num_code`: `string` — The country's code number.
    - `name`: `string` — The name of the country.
    - `display_name`: `string` — The display name of the country.
  - `payment_providers`: [PaymentProviderDTO](/resources/references/region/interfaces/regionPaymentProviderDTO)\[] — Payment providers available in the region
    - `id`: `string` — The ID of the payment provider.
    - `is_enabled`: `boolean` — Whether the payment provider is enabled.
  - `metadata`: `Record<string, any>` (optional) — Holds custom data in key-value pairs.
  - `created_at`: `string` — The date the region was created.
  - `updated_at`: `string` — The date the region was updated.
