This documentation provides a reference to the `validateStepShippingProfileDelete`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that the shipping profiles to delete are not linked to any products.
Otherwise, an error is thrown.

## Example

```ts
validateStepShippingProfileDelete({
  links: [
    {
      product_id: "product_123",
      shipping_profile_id: "sp_123"
    }
  ]
})
```

<a id="validatestepshippingprofiledelete-input" />

## Input

**validateStepShippingProfileDelete**

- `ValidateStepShippingProfileDeleteInput`: [ValidateStepShippingProfileDeleteInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcValidateStepShippingProfileDeleteInput)
  - `links`: `object`\[] — The links between products and shipping profiles.
    - `product_id`: `string` — The ID of the product linked to the shipping profile.
    - `shipping_profile_id`: `string` — The ID of the shipping profile to be deleted.
