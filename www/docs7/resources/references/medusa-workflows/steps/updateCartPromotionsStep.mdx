This documentation provides a reference to the `updateCartPromotionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates the promotions applied on a cart.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updateCartPromotionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updateCartPromotionsStep({
      "id": "id_TqwXtn95YS01JXM1bid"
    })
  }
)
```

## Input

**updateCartPromotionsStep**

- `UpdateCartPromotionStepInput`: [UpdateCartPromotionStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcUpdateCartPromotionStepInput)
  - `id`: `string` — The ID of the cart to update promotions for.
  - `promo_codes`: `string`\[] (optional) — The promotion codes to apply on the cart.
  - `action`: [ADD](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#add) | [REMOVE](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#remove) | [REPLACE](/resources/references/utils/PromotionUtils/enums/utilsPromotionUtilsPromotionActions#replace) (optional) — Whether to add, remove, or replace promotion codes.
