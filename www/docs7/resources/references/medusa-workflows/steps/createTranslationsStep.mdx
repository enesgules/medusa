This documentation provides a reference to the `createTranslationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more translations.

> **Note**
>
> This is available starting from [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3).

## Example

```ts
const data = createTranslationsStep([
  {
    reference_id: "prod_123",
    reference: "product",
    locale: "fr-FR",
    translations: { title: "Produit", description: "Description du produit" }
  }
])
```

<a id="createtranslationsstep-input" />

## Input

**createTranslationsStep**

- `CreateTranslationsStepInput`: [CreateTranslationsStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcCreateTranslationsStepInput)
  - `reference_id`: `string` — The ID of the data model being translated.

    Example:

    ```
    "prod_123"
    ```
  - `reference`: `string` — The name of the table that the translation belongs to.

    Example:

    ```
    "product"
    ```
  - `locale_code`: `string` — The BCP 47 language tag code for this translation.

    Example:

    ```
    "en-US"
    ```
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.

    Example:

    ```
    { * "title": "Product Title", * "description": "Product Description", * }
    ```

<a id="createtranslationsstep-output" />

## Output

**createTranslationsStep**

- `TranslationDTO[]`: [TranslationDTO](/resources/references/translation/interfaces/translationTranslationDTO)\[]
  - `id`: `string` — The ID of the translation.
  - `reference_id`: `string` — The ID of the entity being translated.
  - `reference`: `string` — The type of entity being translated (e.g., "product", "product\_variant").
  - `locale_code`: `string` — The BCP 47 language tag code for this translation (e.g., "en-US", "fr-FR").
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.
  - `created_at`: `string` | `Date` — The date and time the translation was created.
  - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
