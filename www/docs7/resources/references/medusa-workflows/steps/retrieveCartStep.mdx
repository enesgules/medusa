This documentation provides a reference to the `retrieveCartStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step retrieves a cart's details.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { retrieveCartStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = retrieveCartStep({
      "id": "id_lqgGPSBy6vANQLjZ2i"
    })
  }
)
```
