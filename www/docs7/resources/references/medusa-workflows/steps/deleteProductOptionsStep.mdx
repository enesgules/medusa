This documentation provides a reference to the `deleteProductOptionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more product options.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductOptionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductOptionsStep([
      "{value}"
    ])
  }
)
```
