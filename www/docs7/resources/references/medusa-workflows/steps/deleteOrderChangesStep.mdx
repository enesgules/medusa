This documentation provides a reference to the `deleteOrderChangesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes order changes.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteOrderChangesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteOrderChangesStep({
      "ids": [
        "id_kWogh8hA0EE"
      ]
    })
  }
)
```
