This documentation provides a reference to the `createCollectionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more collection.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { createCollectionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = createCollectionsStep([{
      "title": "patior"
    }])
  }
)
```

<a id="createcollectionsstep-input" />

## Input

**createCollectionsStep**

- `CreateProductCollectionDTO[]`: [CreateProductCollectionDTO](/resources/references/product/interfaces/productCreateProductCollectionDTO)\[]
  - `title`: `string` — The product collection's title.
  - `handle`: `string` (optional) — The product collection's handle. If not provided, the value of this attribute is set to the slug version of the title.
  - `product_ids`: `string`\[] (optional) — The products to associate with the collection.
  - `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — Holds custom data in key-value pairs.
