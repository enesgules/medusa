This documentation provides a reference to the `updateTaxRatesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates tax rates matching the specified filters.

## Example

```ts
const data = updateTaxRatesStep({
  selector: {
    id: "txr_123"
  },
  update: {
    name: "Default Tax Rate",
  }
})
```

  - `deleted_at`: `null` | `Date` — The deletion date of the tax rate.
