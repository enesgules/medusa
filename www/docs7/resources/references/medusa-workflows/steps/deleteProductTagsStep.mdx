This documentation provides a reference to the `deleteProductTagsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more product tags.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductTagsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductTagsStep([
      "{value}"
    ])
  }
)
```
