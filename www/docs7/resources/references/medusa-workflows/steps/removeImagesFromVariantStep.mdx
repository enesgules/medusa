This documentation provides a reference to the `removeImagesFromVariantStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step removes one or more images from a product variant.

> **Note**
>
> This is available starting from [Medusa v2.11.2](https://github.com/medusajs/medusa/releases/tag/v2.11.2).

## Example

```ts
const data = removeImagesFromVariantStep({
  variant_id: "variant_123",
  remove: ["img_123", "img_456"]
})
```
