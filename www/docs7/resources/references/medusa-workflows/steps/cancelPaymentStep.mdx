This documentation provides a reference to the `cancelPaymentStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step cancels one or more payments.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { cancelPaymentStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = cancelPaymentStep({
      "paymentIds": "{value}"
    })
  }
)
```

## Input

**cancelPaymentStep**

- `CancelPaymentStepInput`: [CancelPaymentStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcCancelPaymentStepInput)
  - `paymentIds`: `string` | `string`\[] — The ID(s) of the payment(s) to cancel.
