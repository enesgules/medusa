This documentation provides a reference to the `deleteProductVariantsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more product variants.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductVariantsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductVariantsStep([
      "{value}"
    ])
  }
)
```
