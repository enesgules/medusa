This documentation provides a reference to the `deleteProductTypesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more product types.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductTypesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductTypesStep([
      "{value}"
    ])
  }
)
```
