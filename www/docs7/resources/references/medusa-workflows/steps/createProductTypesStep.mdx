This documentation provides a reference to the `createProductTypesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more product types.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { createProductTypesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = createProductTypesStep([{
      "value": "{value}"
    }])
  }
)
```

<a id="createproducttypesstep-input" />

## Input

**createProductTypesStep**

- `CreateProductTypeDTO[]`: [CreateProductTypeDTO](/resources/references/product/interfaces/productCreateProductTypeDTO)\[]
  - `value`: `string` — The product type's value.
  - `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — Holds custom data in key-value pairs.

<a id="createproducttypesstep-output" />

## Output

**createProductTypesStep**

- `ProductTypeDTO[]`: [ProductTypeDTO](/resources/references/product/interfaces/productProductTypeDTO)\[]
  - `id`: `string` — The ID of the product type.
  - `value`: `string` — The value of the product type.
  - `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — Holds custom data in key-value pairs.
  - `created_at`: `string` | `Date` — When the product type was created.
  - `updated_at`: `string` | `Date` — When the product type was updated.
  - `deleted_at`: `string` | `Date` (optional) — When the product type was deleted.
