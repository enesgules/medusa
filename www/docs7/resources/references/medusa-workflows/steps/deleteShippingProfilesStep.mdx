This documentation provides a reference to the `deleteShippingProfilesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more shipping profiles.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteShippingProfilesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteShippingProfilesStep([
      "{value}"
    ])
  }
)
```
