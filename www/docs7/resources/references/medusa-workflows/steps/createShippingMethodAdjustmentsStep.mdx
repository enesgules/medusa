This documentation provides a reference to the `createShippingMethodAdjustmentsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates shipping method adjustments for a cart.

## Example

```ts
const data = createShippingMethodAdjustmentsStep({
  "shippingMethodAdjustmentsToCreate": [{
    "shipping_method_id": "sm_123",
    "code": "10OFF",
    "amount": 10
  }]
})
```

<a id="createshippingmethodadjustmentsstep-input" />

## Input

**createShippingMethodAdjustmentsStep**

- `CreateShippingMethodAdjustmentsStepInput`: [CreateShippingMethodAdjustmentsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcCreateShippingMethodAdjustmentsStepInput)
  - `shippingMethodAdjustmentsToCreate`: [CreateShippingMethodAdjustmentDTO](/resources/references/cart/interfaces/cartCreateShippingMethodAdjustmentDTO)\[] — The shipping method adjustments to create.
    - `shipping_method_id`: `string` — The associated shipping method's ID.
    - `code`: `string` — The code of the promotion that lead to this adjustment.
    - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount to adjust the original amount with.
      - `value`: `string` | `number`
      - `numeric`: `number`
      - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
      - `bigNumber`: `BigNumber` (optional)
    - `description`: `string` (optional) — The description of the shipping method adjustment.
    - `promotion_id`: `string` (optional) — The associated promotion's ID.
    - `provider_id`: `string` (optional) — The associated provider's ID.
