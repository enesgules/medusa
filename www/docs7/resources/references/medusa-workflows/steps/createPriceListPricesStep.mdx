This documentation provides a reference to the `createPriceListPricesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates prices for a price list.

## Example

```ts
const data = createPriceListPricesStep({
  data: [{
    id: "plist_123",
    prices: [
      {
        currency_code: "USD",
        amount: 1000,
        variant_id: "variant_123",
      }
    ]
  }],
  variant_price_map: {
    "variant_123": "pset_123"
  }
})
```

<a id="createpricelistpricesstep-input" />

## Input

**createPriceListPricesStep**

- `CreatePriceListPricesWorkflowStepDTO`: [CreatePriceListPricesWorkflowStepDTO](/resources/references/types/interfaces/typesCreatePriceListPricesWorkflowStepDTO) — The data to create prices for price lists.
  - `data`: Pick\<[CreatePriceListWorkflowInputDTO](/resources/references/types/interfaces/typesCreatePriceListWorkflowInputDTO), "prices"> & `object`\[] — The prices to create.
    - `id`: `string`
  - `variant_price_map`: `Record<string, string>` — An object whose keys are variant IDs and values are price set IDs.
