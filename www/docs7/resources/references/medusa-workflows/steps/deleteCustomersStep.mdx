This documentation provides a reference to the `deleteCustomersStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more customers.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteCustomersStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteCustomersStep([
      "{value}"
    ])
  }
)
```
