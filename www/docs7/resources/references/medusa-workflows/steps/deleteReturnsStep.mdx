This documentation provides a reference to the `deleteReturnsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more returns.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteReturnsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteReturnsStep({
      "ids": [
        "id_gXGwK9AWNPuU1XarAlgl"
      ]
    })
  }
)
```
