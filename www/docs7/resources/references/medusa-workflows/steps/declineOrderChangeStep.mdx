This documentation provides a reference to the `declineOrderChangeStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step declines an order change.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { declineOrderChangeStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = declineOrderChangeStep({
      "id": "id_91L5xNI8ztK"
    })
  }
)
```

<a id="declineorderchangestep-input" />

## Input

**declineOrderChangeStep**

- `DeclineOrderChangeDTO`: [DeclineOrderChangeDTO](/resources/references/order/interfaces/orderDeclineOrderChangeDTO) — The details of declining the order change.
  - `id`: `string` — The ID of the order change.
  - `declined_by`: `string` (optional) — The user or customer who declined the order change.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
