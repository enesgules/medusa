This documentation provides a reference to the `deleteOrderChangeActionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes order change actions.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteOrderChangeActionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteOrderChangeActionsStep({
      "ids": [
        "id_VJFU3KSRMmz2L7kaw"
      ]
    })
  }
)
```
