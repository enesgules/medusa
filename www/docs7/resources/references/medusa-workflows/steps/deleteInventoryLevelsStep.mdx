This documentation provides a reference to the `deleteInventoryLevelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more inventory levels.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteInventoryLevelsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteInventoryLevelsStep([
      "{value}"
    ])
  }
)
```
