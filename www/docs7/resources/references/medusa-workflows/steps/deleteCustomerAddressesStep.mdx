This documentation provides a reference to the `deleteCustomerAddressesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more customer addresses.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteCustomerAddressesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteCustomerAddressesStep([
      "{value}"
    ])
  }
)
```
