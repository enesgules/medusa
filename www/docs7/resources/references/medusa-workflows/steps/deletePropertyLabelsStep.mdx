This documentation provides a reference to the `deletePropertyLabelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

Workflow step to delete property labels.

> **Note**
>
> This is available starting from [Medusa v2.13.7](https://github.com/medusajs/medusa/releases/tag/v2.13.7).

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deletePropertyLabelsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deletePropertyLabelsStep({
      "ids": [
        "id_HIAVK1nXMQ"
      ]
    })
  }
)
```
