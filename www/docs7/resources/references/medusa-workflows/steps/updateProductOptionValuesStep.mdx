This documentation provides a reference to the `updateProductOptionValuesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates a product option value.

## Example

```ts
const data = updateProductOptionValuesStep({
  id: "optval_123",
  update: {
    metadata: { is_default: true }
  }
})
```

<a id="updateproductoptionvaluesstep-input" />

## Input

**updateProductOptionValuesStep**

- `UpdateProductOptionValuesStepInput`: [UpdateProductOptionValuesStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdateProductOptionValuesStepInput)
  - `id`: `string` — The ID of the product option value to update.
  - `update`: [UpdateProductOptionValueDTO](/resources/references/product/interfaces/productUpdateProductOptionValueDTO) — The data to update in the product option value.
    - `value`: `string` (optional) — The value of the product option value.
    - `metadata`: [MetadataType](/resources/references/product/types/productMetadataType) (optional) — The metadata of the product option value.
