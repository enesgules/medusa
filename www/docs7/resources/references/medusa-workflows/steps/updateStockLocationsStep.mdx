This documentation provides a reference to the `updateStockLocationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates stock locations matching the specified filters.

## Example

```ts
const data = updateStockLocationsStep({
  selector: {
    id: "sloc_123"
  },
  update: {
    name: "European Warehouse"
  }
})
```
