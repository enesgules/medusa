This documentation provides a reference to the `createSalesChannelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more sales channels.

## Example

```ts
const data = createSalesChannelsStep({
  data: [{
    name: "Webshop",
  }]
})
```

<a id="createsaleschannelsstep-input" />

## Input

**createSalesChannelsStep**

- `CreateSalesChannelsStepInput`: [CreateSalesChannelsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcCreateSalesChannelsStepInput)
  - `data`: [CreateSalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelCreateSalesChannelDTO)\[] — The sales channels to create.
    - `name`: `string` — The name of the sales channel.
    - `description`: `null` | `string` (optional) — The description of the sales channel.
    - `is_disabled`: `boolean` (optional) — Whether the sales channel is disabled.

<a id="createsaleschannelsstep-output" />

## Output

**createSalesChannelsStep**

- `SalesChannelDTO[]`: [SalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelSalesChannelDTO)\[]
  - `id`: `string` — The ID of the sales channel.
  - `name`: `string` — The name of the sales channel.
  - `description`: `null` | `string` — The description of the sales channel.
  - `is_disabled`: `boolean` — Whether the sales channel is disabled.
  - `metadata`: `null` | `Record<string, unknown>` — Holds custom data in key-value pairs.
  - `locations`: [SalesChannelLocationDTO](/resources/references/sales_channel/interfaces/sales_channelSalesChannelLocationDTO)\[] (optional) — The locations of the sales channel.
    - `sales_channel_id`: `string` — The associated sales channel's ID.
    - `location_id`: `string` — The associated location's ID.
    - `sales_channel`: [SalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelSalesChannelDTO) — The associated sales channel.
      - `id`: `string` — The ID of the sales channel.
      - `name`: `string` — The name of the sales channel.
      - `description`: `null` | `string` — The description of the sales channel.
      - `is_disabled`: `boolean` — Whether the sales channel is disabled.
      - `metadata`: `null` | `Record<string, unknown>` — Holds custom data in key-value pairs.
      - `locations`: [SalesChannelLocationDTO](/resources/references/sales_channel/interfaces/sales_channelSalesChannelLocationDTO)\[] (optional) — The locations of the sales channel.
