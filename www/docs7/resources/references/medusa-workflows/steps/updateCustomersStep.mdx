This documentation provides a reference to the `updateCustomersStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates one or more customers.

## Example

```ts
const data = updateCustomersStep({
  selector: {
    id: "cus_123"
  },
  update: {
    last_name: "Doe"
  }
})
```
