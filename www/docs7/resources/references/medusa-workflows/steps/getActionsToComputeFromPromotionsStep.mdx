This documentation provides a reference to the `getActionsToComputeFromPromotionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step retrieves the actions to compute based on the promotions
applied on items and shipping methods.

> **Tip**
>
> You can use the [retrieveCartStep](/resources/references/medusa-workflows/steps/retrieveCartStep) to retrieve items and shipping methods' details.

## Example

```ts
const data = getActionsToComputeFromPromotionsStep({
  // retrieve the details of the items and shipping methods from another workflow
  // or in another step using the Cart Module's service
  computeActionContext,
  promotionCodesToApply: ["10OFF"]
})
```

## Input

**getActionsToComputeFromPromotionsStep**

- `GetActionsToComputeFromPromotionsStepInput`: [GetActionsToComputeFromPromotionsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcGetActionsToComputeFromPromotionsStepInput)
  - `computeActionContext`: [ComputeActionContext](/resources/references/promotion/interfaces/promotionComputeActionContext) — The items and shipping methods to compute the actions for.
    - `currency_code`: `string` — The cart's currency
    - `customer`: `object` (optional) — The customer associated with the cart.
      - `id`: `string`
      - `groups`: `object`\[] (optional) — The customer groups the customer belongs to.
    - `region`: `object` (optional) — The region associated with the cart.
      - `id`: `string`
    - `shipping_address`: `object` (optional) — The shipping address associated with the cart.
      - `country_code`: `string`
    - `sales_channel_id`: `string` (optional)
    - `email`: `string` (optional) — The cart's email
    - `items`: [ComputeActionItemLine](/resources/references/promotion/interfaces/promotionComputeActionItemLine)\[] (optional) — The cart's line items.
      - `id`: `string` — The ID of the item line.
      - `quantity`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The quantity of the line item.
      - `subtotal`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The subtotal of the line item.
      - `original_total`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The total of the line item.
      - `is_discountable`: `boolean` — Whether the line item is discountable.
      - `adjustments`: [ComputeActionAdjustmentLine](/resources/references/promotion/interfaces/promotionComputeActionAdjustmentLine)\[] (optional) — The adjustments applied before on the line item.
      - `product`: `object` (optional) — The product ID of the line item. Our default promotion rules rely on the product ID to apply the promotion.
    - `shipping_methods`: [ComputeActionShippingLine](/resources/references/promotion/interfaces/promotionComputeActionShippingLine)\[] (optional) — The cart's shipping methods.
      - `id`: `string` — The ID of the shipping method.
      - `subtotal`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The subtotal of the shipping method.
      - `original_total`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The total of the shipping method.
      - `adjustments`: [ComputeActionAdjustmentLine](/resources/references/promotion/interfaces/promotionComputeActionAdjustmentLine)\[] (optional) — The adjustments applied before on the shipping method.
      - `shipping_option`: `object` (optional) — The shipping option type associated with the shipping method.
  - `promotionCodesToApply`: `string`\[] — The promotion codes applied on the items and shipping methods.
  - `options`: `ComputeActionOptions` (optional) — The options to configure how the actions are computed.
  - `additional_promotion_context`: `Record<string, unknown>` (optional) — The result of the `additional_promotion_context` hook, forwarded by the calling workflow. Its keys are merged on top of `computeActionContext` before promotion rules are evaluated, so consumers can extend the rule evaluation context with arbitrary attributes (e.g. `company.id`, "custom\_tier"). Values from `additional_promotion_context` take precedence over values on `computeActionContext` when keys conflict.

## Output

**getActionsToComputeFromPromotionsStep**

- `ComputeActions[]`: [ComputeActions](/resources/references/promotion/types/promotionComputeActions)\[]
  - `action`: `"addItemAdjustment"` — The type of action.
  - `item_id`: `string` — The associated item's ID.
  - `amount`: [BigNumberInput](/resources/references/promotion/types/promotionBigNumberInput) — The amount to remove off the item's total.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/promotion/types/promotionBigNumberRawValue) (optional)
      - `value`: `string` | `number`
    - `bigNumber`: `BigNumber` (optional)
  - `is_tax_inclusive`: `boolean` (optional) — Whether the promotion amount includes tax.
  - `code`: `string` — The promotion's code.
  - `description`: `string` (optional) — The promotion's description.
  - `adjustment_id`: `string` — The associated adjustment's ID.
  - `shipping_method_id`: `string` — The associated shipping method's ID.
