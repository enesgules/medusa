This documentation provides a reference to the `updatePropertyLabelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

Workflow step to update property labels.

> **Note**
>
> This is available starting from [Medusa v2.13.7](https://github.com/medusajs/medusa/releases/tag/v2.13.7).

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updatePropertyLabelsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updatePropertyLabelsStep({
      "property_labels": [{
        "id": "id_ysliTPNXRbVXNT"
      }]
    })
  }
)
```

<a id="updatepropertylabelsstep-input" />

## Input

**updatePropertyLabelsStep**

- `UpdatePropertyLabelsStepInput`: [UpdatePropertyLabelsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcUpdatePropertyLabelsStepInput)
  - `property_labels`: `object`\[]
    - `id`: `string`
    - `label`: `string` (optional)
    - `description`: `string` (optional)

<a id="updatepropertylabelsstep-output" />

## Output

**updatePropertyLabelsStep**

- `PropertyLabelDTO[]`: [PropertyLabelDTO](/resources/references/settings/interfaces/settingsPropertyLabelDTO)\[]
  - `id`: `string` — The ID of the property label.
  - `entity`: `string` — The entity this label applies to (e.g., "Order", "Product").
  - `property`: `string` — The property path (e.g., "display\_id", "customer.email").
  - `label`: `string` — Custom display name for the property.
  - `description`: `null` | `string` — Optional description providing context about the property.
  - `created_at`: `Date` — The date the label was created.
  - `updated_at`: `Date` — The date the label was last updated.
