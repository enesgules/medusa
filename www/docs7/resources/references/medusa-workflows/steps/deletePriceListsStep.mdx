This documentation provides a reference to the `deletePriceListsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more price lists.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deletePriceListsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deletePriceListsStep([
      "{value}"
    ])
  }
)
```
