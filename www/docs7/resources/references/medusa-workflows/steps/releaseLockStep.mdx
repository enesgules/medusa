This documentation provides a reference to the `releaseLockStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step releases a lock for a given key. Learn more about locks in the [Locking Module](/resources/infrastructure-modules/locking)
guide.

## Example

```ts
const data = releaseLockStep({
  key: "my-lock-key"
})
```

<a id="releaselockstep-input" />

## Input

**releaseLockStep**

- `ReleaseLockStepInput`: [ReleaseLockStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcReleaseLockStepInput)
  - `key`: `string` | `string`\[] — The keys to be released
  - `ownerId`: `string` (optional) — The ID of the lock's owner. The lock can be released either if it doesn't have an owner, or if its owner ID matches the one passed in this property.
  - `provider`: `string` (optional) — The provider name to use for locking. If no provider is passed, the default provider (in-memory or the provider configured in medusa-config.ts) will be used.
  - `executeOnSubWorkflow`: `boolean` (optional)
