This documentation provides a reference to the `removeProductOptionsFromProductStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step removes product options from products.

## Example

```ts
const data = removeProductOptionsFromProductStep([
  {
    product_id: "prod_123",
    product_option_id: "opt_123",
  },
])
```

<a id="removeproductoptionsfromproductstep-input" />

## Input

**removeProductOptionsFromProductStep**

- `RemoveProductOptionsFromProductStepInput`: [RemoveProductOptionsFromProductStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcRemoveProductOptionsFromProductStepInput)
  - `product_option_id`: `string` — The product option's ID.
  - `product_id`: `string` — The product's ID.
  - `product_option_value_ids`: `string`\[] (optional) — The IDs of specific option values to link. If not provided, all values will be linked.
