This documentation provides a reference to the `createShippingProfilesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more shipping profiles.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { createShippingProfilesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = createShippingProfilesStep({
      "name": "Brycen",
      "type": "{value}"
    })
  }
)
```

## Input

**createShippingProfilesStep**

- `CreateShippingProfilesStepInput`: [CreateShippingProfilesStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcCreateShippingProfilesStepInput)

  - `type`: `string` — The type of the shipping profile.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
