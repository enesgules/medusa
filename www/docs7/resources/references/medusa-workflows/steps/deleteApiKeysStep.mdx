This documentation provides a reference to the `deleteApiKeysStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more API keys.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteApiKeysStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteApiKeysStep([
      "{value}"
    ])
  }
)
```
