This documentation provides a reference to the `validateAndReturnShippingMethodsDataStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates shipping options to ensure they can be applied on a cart.
The step either returns the validated data or void.

## Example

```ts
const data = validateAndReturnShippingMethodsDataStep({
  id: "sm_123",
  provider_id: "my_provider",
  option_data: {},
  method_data: {},
  context: {
    id: "cart_123",
    shipping_address: {
      id: "saddr_123",
      first_name: "Jane",
      last_name: "Smith",
      address_1: "456 Elm St",
      city: "Shelbyville",
      country_code: "us",
      postal_code: "67890",
    },
    items: [
      {
        variant: {
          id: "variant_123",
          weight: 1,
          length: 1,
          height: 1,
          width: 1,
          material: "wood",
          product: {
            id: "prod_123"
          }
        }
      }
    ],
    product: {
      id: "prod_123",
      collection_id: "pcol_123",
      categories: [],
      tags: []
    },
    from_location: {
      id: "sloc_123",
      first_name: "John",
      last_name: "Doe",
      address_1: "123 Main St",
      city: "Springfield",
      country_code: "us",
      postal_code: "12345",
    },
  }
})
```
