This documentation provides a reference to the `deleteTaxRegionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more tax regions.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteTaxRegionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteTaxRegionsStep([
      "{value}"
    ])
  }
)
```
