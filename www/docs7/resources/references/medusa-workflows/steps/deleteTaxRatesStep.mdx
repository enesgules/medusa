This documentation provides a reference to the `deleteTaxRatesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more tax rates.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteTaxRatesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteTaxRatesStep([
      "{value}"
    ])
  }
)
```
