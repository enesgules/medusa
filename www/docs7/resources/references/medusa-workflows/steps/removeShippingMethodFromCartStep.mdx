This documentation provides a reference to the `removeShippingMethodFromCartStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step removes shipping methods from a cart.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { removeShippingMethodFromCartStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = removeShippingMethodFromCartStep({
      "shipping_method_ids": [
        "{value}"
      ]
    })
  }
)
```
