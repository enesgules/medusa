This documentation provides a reference to the `deleteRefundReasonsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more refund reasons.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteRefundReasonsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteRefundReasonsStep([
      "{value}"
    ])
  }
)
```
