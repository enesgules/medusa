This documentation provides a reference to the `updateRemoteLinksStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates links between two records of linked data models. This is useful to update
links with additional data such as metadata.

Learn more in the [Link documentation.](/learn/fundamentals/module-links/link#update-links).

## Example

```ts
const data = updateRemoteLinksStep([
  {
    [Modules.PRODUCT]: {
      product_id: "prod_321",
    },
    blog: {
      post_id: "post_321",
    },
    data: {
      metadata: {
        test: false
      }
    }
  }
])
```
