This documentation provides a reference to the `createDefaultSalesChannelStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates a default sales channel if none exist in the application.
This is useful when creating seed scripts.

## Example

```ts
const data = createDefaultSalesChannelStep({
  data: {
    name: "Webshop",
  }
})
```

<a id="createdefaultsaleschannelstep-input" />

## Input

**createDefaultSalesChannelStep**

- `CreateDefaultSalesChannelStepInput`: [CreateDefaultSalesChannelStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcCreateDefaultSalesChannelStepInput)
  - `data`: [CreateSalesChannelDTO](/resources/references/sales_channel/interfaces/sales_channelCreateSalesChannelDTO) — The default sales channel data.
    - `name`: `string` — The name of the sales channel.
    - `description`: `null` | `string` (optional) — The description of the sales channel.
    - `is_disabled`: `boolean` (optional) — Whether the sales channel is disabled.
