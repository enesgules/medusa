This documentation provides a reference to the `updateProductsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates one or more products.

## Example

To update products by their ID:

```ts
const data = updateProductsStep({
  products: [
    {
      id: "prod_123",
      title: "Shirt"
    }
  ]
})
```

To update products matching a filter:

```ts
const data = updateProductsStep({
  selector: {
    collection_id: "collection_123",
  },
  update: {
    material: "cotton",
  }
})
```
