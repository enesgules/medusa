This documentation provides a reference to the `deleteTaxRateRulesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more tax rate rules.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteTaxRateRulesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteTaxRateRulesStep([
      "{value}"
    ])
  }
)
```
