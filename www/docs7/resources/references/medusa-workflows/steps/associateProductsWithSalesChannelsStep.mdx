This documentation provides a reference to the `associateProductsWithSalesChannelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates links between products and sales channel records.

## Example

```ts
const data = associateProductsWithSalesChannelsStep({
  links: [
    {
      sales_channel_id: "sc_123",
      product_id: "prod_123"
    }
  ]
})
```

## Input

**associateProductsWithSalesChannelsStep**

  - `links`: `object`\[] — The links to create between products and sales channels.
    - `sales_channel_id`: `string` — The ID of the sales channel.
    - `product_id`: `string` — The ID of the product.
