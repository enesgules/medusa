This documentation provides a reference to the `deleteProductsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more products.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductsStep([
      "{value}"
    ])
  }
)
```
