This documentation provides a reference to the `deletePromotionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more promotions.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deletePromotionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deletePromotionsStep([
      "{value}"
    ])
  }
)
```
