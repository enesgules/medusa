This documentation provides a reference to the `deleteLineItemsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes line items.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteLineItemsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteLineItemsStep([
      "{value}"
    ])
  }
)
```
