This documentation provides a reference to the `updateCustomerAddressesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates one or more customer addresses.

## Example

```ts
const data = updateCustomerAddressesStep({
  selector: {
    customer_id: "cus_123"
  },
  update: {
    country_code: "us"
  }
})
```
