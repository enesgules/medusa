This documentation provides a reference to the `updatePriceSetsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates price sets.

## Example

```ts
const data = updatePriceSetsStep({
  selector: {
    id: ["pset_123"]
  },
  update: {
    prices: [
      {
        amount: 10,
        currency_code: "usd",
      }
    ]
  }
})
```
