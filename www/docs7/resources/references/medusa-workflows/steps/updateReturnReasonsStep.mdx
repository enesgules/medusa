This documentation provides a reference to the `updateReturnReasonsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates return reasons matching the specified filters.

## Example

```ts
const data = updateReturnReasonsStep({
  selector: {
    id: "rr_123",
  },
  update: {
    value: "damaged",
  }
})
```
