This documentation provides a reference to the `deleteCollectionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more collections.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteCollectionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteCollectionsStep([
      "{value}"
    ])
  }
)
```
