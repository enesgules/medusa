This documentation provides a reference to the `deleteSalesChannelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more sales channels.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteSalesChannelsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteSalesChannelsStep([
      "{value}"
    ])
  }
)
```
