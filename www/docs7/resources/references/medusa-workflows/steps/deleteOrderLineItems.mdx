This documentation provides a reference to the `deleteOrderLineItems`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes order line items.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteOrderLineItems } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteOrderLineItems({
      "ids": [
        "id_YEPt7WNl359YbidX"
      ]
    })
  }
)
```
