This documentation provides a reference to the `setRegionsPaymentProvidersStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step sets the payment providers available in regions.

## Example

```ts
const data = setRegionsPaymentProvidersStep({
  input: [
    {
      id: "reg_123",
      payment_providers: ["pp_system", "pp_stripe_stripe"]
    }
  ]
})
```

<a id="setregionspaymentprovidersstep-input" />

## Input

**setRegionsPaymentProvidersStep**

- `SetRegionsPaymentProvidersStepInput`: [SetRegionsPaymentProvidersStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcSetRegionsPaymentProvidersStepInput)
  - `input`: `object`\[] — The regions to set the payment providers for.
    - `id`: `string` — The ID of the region.
    - `payment_providers`: `string`\[] (optional) — The IDs of the payment providers that are available in the region.
