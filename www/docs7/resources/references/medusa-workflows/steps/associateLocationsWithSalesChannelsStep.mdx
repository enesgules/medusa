This documentation provides a reference to the `associateLocationsWithSalesChannelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates links between stock locations and sales channel records.

## Example

```ts
const data = associateLocationsWithSalesChannelsStep({
  links: [
    {
      sales_channel_id: "sc_123",
      location_id: "sloc_123"
    }
  ]
})
```

<a id="associatelocationswithsaleschannelsstep-input" />

## Input

**associateLocationsWithSalesChannelsStep**

- `AssociateLocationsWithSalesChannelsStepInput`: [AssociateLocationsWithSalesChannelsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcAssociateLocationsWithSalesChannelsStepInput)
  - `links`: `object`\[] — The links to create between locations and sales channels.
    - `sales_channel_id`: `string` — The ID of the sales channel.
    - `location_id`: `string` — The ID of the location.
