This documentation provides a reference to the `deleteAuthIdentityStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more auth identities.

> **Note**
>
> This is available starting from [Medusa v2.19.0](https://github.com/medusajs/medusa/releases/tag/v2.19.0).

## Example

To delete a single auth identity:

```ts
deleteAuthIdentityStep({
  id: "authid_1234",
})
```

To delete multiple auth identities:

```ts
deleteAuthIdentityStep({
  id: ["authid_1234", "authid_1235"],
})
```
