This documentation provides a reference to the `deleteStoresStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more stores.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteStoresStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteStoresStep([
      "{value}"
    ])
  }
)
```
