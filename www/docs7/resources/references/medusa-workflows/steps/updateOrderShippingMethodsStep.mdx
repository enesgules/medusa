This documentation provides a reference to the `updateOrderShippingMethodsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates order shipping methods.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updateOrderShippingMethodsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updateOrderShippingMethodsStep({
      "id": "id_M2ocwbyoaubnEQH3bn6P"
    })
  }
)
```
