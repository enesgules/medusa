This documentation provides a reference to the `updateOrderItemsTranslationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step re-translates all order line items when the order's locale changes.
It fetches items and their variants in batches to handle large orders gracefully.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updateOrderItemsTranslationsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updateOrderItemsTranslationsStep({
      "order_id": "order_123",
      "locale": "{value}"
    })
  }
)
```
