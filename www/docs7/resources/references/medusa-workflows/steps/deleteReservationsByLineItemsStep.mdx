This documentation provides a reference to the `deleteReservationsByLineItemsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes reservations by their associated line items.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteReservationsByLineItemsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteReservationsByLineItemsStep([
      "{value}"
    ])
  }
)
```
