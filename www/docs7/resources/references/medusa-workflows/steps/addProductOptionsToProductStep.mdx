This documentation provides a reference to the `addProductOptionsToProductStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step adds product options to products.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { addProductOptionsToProductStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = addProductOptionsToProductStep({
      "product_option_id": "{value}",
      "product_id": "prod_123"
    })
  }
)
```

<a id="addproductoptionstoproductstep-input" />

## Input

**addProductOptionsToProductStep**

- `AddProductOptionsToProductStepInput`: [AddProductOptionsToProductStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcAddProductOptionsToProductStepInput)
  - `product_option_id`: `string` — The product option's ID.
  - `product_id`: `string` — The product's ID.
  - `product_option_value_ids`: `string`\[] (optional) — The IDs of specific option values to link. If not provided, all values will be linked.
