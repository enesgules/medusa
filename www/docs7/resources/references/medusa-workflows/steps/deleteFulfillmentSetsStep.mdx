This documentation provides a reference to the `deleteFulfillmentSetsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more fulfillment sets.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteFulfillmentSetsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteFulfillmentSetsStep([
      "{value}"
    ])
  }
)
```
