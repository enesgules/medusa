This documentation provides a reference to the `deleteReservationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more reservations.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteReservationsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteReservationsStep([
      "{value}"
    ])
  }
)
```
