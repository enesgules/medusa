This documentation provides a reference to the `validateSearchIndexesExistStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that each requested search index is registered. If an
index is missing, the step throws an error.

## Example

```ts
validateSearchIndexesExistStep({
  index: "product",
})
```

<a id="validatesearchindexesexiststep-input" />

## Input

**validateSearchIndexesExistStep**

- `ValidateSearchIndexesExistStepInput`: [ValidateSearchIndexesExistStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcValidateSearchIndexesExistStepInput)
  - `index`: `string` | `string`\[] (optional) — The name of the index to validate. Defaults to every registered index, in which case there is nothing to check.
