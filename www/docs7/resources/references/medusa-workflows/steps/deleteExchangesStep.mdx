This documentation provides a reference to the `deleteExchangesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more exchanges.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteExchangesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteExchangesStep({
      "ids": [
        "id_WAwxlspzm0eaLcb6"
      ]
    })
  }
)
```

**deleteExchangesStep**

- `DeleteOrderExchangesInput`: [DeleteOrderExchangesInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcDeleteOrderExchangesInput)
