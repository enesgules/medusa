This documentation provides a reference to the `buildPriceSet`. It belongs to the `@medusajs/medusa/core-flows` package.

<a id="buildpriceset-parameters" />

## Parameters

**buildPriceSet**

- `prices`: ([ShippingOptionsPriceCurrencyCode](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcShippingOptionsPriceCurrencyCode) | `ShippingOptionsPriceRegionId`)\[]
  - `currency_code`: `string` — The currency code of the price.

    Example:

    ```
    usd
    ```
  - `amount`: `number` — The amount of the price.
  - `rules`: [PriceRule](/resources/references/pricing/models/PriceRule)\[] (optional) — The rules of the price.
    - `[IsDmlEntity]`: `boolean` (default: true)
    - `name`: [InferDmlEntityNameFromConfig](/resources/references/types/DmlTypes/types/typesDmlTypesInferDmlEntityNameFromConfig)\<TConfig>
    - `schema`: Schema
- `regionToCurrencyMap`: Map\<string, string>

<a id="buildpriceset-returns" />

## Returns

**buildPriceSet**

- `prices`: [CreatePricesDTO](/resources/references/pricing/interfaces/pricingCreatePricesDTO)\[] (optional) — The prices to create and add to this price set.
  - `id`: `string` (optional) — The ID of the money amount.
  - `currency_code`: `string` — The currency code of this money amount.
  - `amount`: [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) — The amount of this money amount.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `min_quantity`: `null` | [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) (optional) — The minimum quantity required to be purchased for this money amount to be applied.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `max_quantity`: `null` | [BigNumberInput](/resources/references/pricing/types/pricingBigNumberInput) (optional) — The maximum quantity required to be purchased for this money amount to be applied.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/pricing/types/pricingBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `rules`: [CreatePriceSetPriceRules](/resources/references/pricing/interfaces/pricingCreatePriceSetPriceRules) (optional) — The rules to add to the price. The object's keys are the attribute, and values are the value of that rule associated with this price.
