This documentation provides a reference to the `setActiveViewConfigurationStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step sets a view configuration as the active view for a user and entity.
It compensates by restoring the user's previously active view, or clearing it
if there wasn't one.

> **Note**
>
> This is available starting from [Medusa v2.10.3](https://github.com/medusajs/medusa/releases/tag/v2.10.3).

## Example

```ts
setActiveViewConfigurationStep({
  id: "viewconfig_123",
  entity: "orders",
  user_id: "user_123",
})
```

<a id="setactiveviewconfigurationstep-input" />

## Input

**setActiveViewConfigurationStep**

- `SetActiveViewConfigurationStepInput`: [SetActiveViewConfigurationStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcSetActiveViewConfigurationStepInput)
  - `id`: `string` — The ID of the view configuration to set as active.
  - `entity`: `string` — The entity the view configuration is for.
  - `user_id`: `string` — The ID of the user to set the active view configuration for.

## Output

**setActiveViewConfigurationStep**
