This documentation provides a reference to the `updateTranslationSettingsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates translation settings based on the provided input.
It supports both single and multiple translation settings updates.
In case of failure, it compensates by restoring the previous translation settings.

> **Note**
>
> This is available starting from [Medusa v2.13.0](https://github.com/medusajs/medusa/releases/tag/v2.13.0).

## Example

```ts
const result = updateTranslationSettingsStep({
  id: "ts_123",
  fields: ["title", "description", "material"],
  is_active: false
})
```

<a id="updatetranslationsettingsstep-input" />

## Input

**updateTranslationSettingsStep**

- `UpdateTranslationSettingsStepInput`: [UpdateTranslationSettingsStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdateTranslationSettingsStepInput)
  - `id`: `string` — The ID of the translation settings to update.
  - `entity_type`: `string` (optional) — The entity type.

    Example:

    ```
    "product"
    ```
  - `fields`: `string`\[] (optional) — The translatable fields.

    Example:

    ```
    ["title", "description", "material"]
    ```
  - `is_active`: `boolean` (optional) — Whether the entity translatable status is enabled.

<a id="updatetranslationsettingsstep-output" />

## Output

**updateTranslationSettingsStep**

- `TranslationSettingsDTO[]`: [TranslationSettingsDTO](/resources/references/translation/interfaces/translationTranslationSettingsDTO)\[]
  - `id`: `string` — The ID of the settings record.
  - `entity_type`: `string` — The entity type these settings apply to (e.g., "product", "product\_variant").
  - `fields`: `string`\[] — The translatable fields for this entity type.
  - `is_active`: `boolean` — Whether the entity translatable status is enabled.
  - `created_at`: `string` | `Date` — The date and time the settings were created.
  - `updated_at`: `string` | `Date` — The date and time the settings were last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the settings were deleted.
