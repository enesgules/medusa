This documentation provides a reference to the `deleteInventoryItemStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more inventory items.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteInventoryItemStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteInventoryItemStep([
      "{value}"
    ])
  }
)
```
