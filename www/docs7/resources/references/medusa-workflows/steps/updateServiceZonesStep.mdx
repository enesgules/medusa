This documentation provides a reference to the `updateServiceZonesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates service zones matching the specified filters.

## Example

```ts
const data = updateServiceZonesStep({
  selector: {
    id: "serzo_123"
  },
  update: {
    name: "US",
  }
})
```
