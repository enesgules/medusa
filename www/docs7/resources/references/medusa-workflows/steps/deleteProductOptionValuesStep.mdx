This documentation provides a reference to the `deleteProductOptionValuesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more product option values.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteProductOptionValuesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteProductOptionValuesStep([
      "{value}"
    ])
  }
)
```
