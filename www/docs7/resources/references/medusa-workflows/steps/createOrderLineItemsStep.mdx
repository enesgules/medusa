This documentation provides a reference to the `createOrderLineItemsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates order line items.

## Example

```ts
const data = createOrderLineItemsStep({
  items: [
    {
      variant_id: "variant_123",
      quantity: 1,
      unit_price: 10,
      title: "Shirt",
      order_id: "order_123"
    }
  ]
})
```
