This documentation provides a reference to the `deleteShippingOptionRulesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more shipping option rules.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteShippingOptionRulesStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteShippingOptionRulesStep({
      "ids": [
        "id_hF6cIUGi9F2J3klE4DFs"
      ]
    })
  }
)
```
