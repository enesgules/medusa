This documentation provides a reference to the `detachProductsFromSalesChannelsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step dismisses links between product and sales channel records.

## Example

```ts
const data = detachProductsFromSalesChannelsStep({
  links: [
    {
      sales_channel_id: "sc_123",
      product_id: "prod_123"
    }
  ]
})
```

<a id="detachproductsfromsaleschannelsstep-input" />

## Input

**detachProductsFromSalesChannelsStep**

- `DetachProductsFromSalesChannelsStepInput`: [DetachProductsFromSalesChannelsStepInput](/resources/references/core_flows/core_core_flows_src/interfaces/core_flowscore_core_flows_srcDetachProductsFromSalesChannelsStepInput)
  - `links`: `object`\[] — The links to dismiss between products and sales channels.
    - `sales_channel_id`: `string` — The ID of the sales channel.
    - `product_id`: `string` — The ID of the product.
