This documentation provides a reference to the `deleteCustomerGroupStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more customer groups.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteCustomerGroupStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteCustomerGroupStep([
      "{value}"
    ])
  }
)
```
