This documentation provides a reference to the `updateShippingMethodsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates a cart's shipping methods.

## Example

```ts
const data = updateOrderShippingMethodsStep([
  {
    id: "sm_123",
    amount: 10
  }
])
```

<a id="updateshippingmethodsstep-input" />

## Input

**updateShippingMethodsStep**

- `UpdateShippingMethodsStepInput`: [UpdateShippingMethodsStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdateShippingMethodsStepInput)
  - `id`: `string` — The ID of the shipping method.
  - `name`: `string` (optional) — The name of the shipping method.
  - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) (optional) — The amount of the shipping method.
    - `value`: `string` | `number`
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
      - `value`: `string` | `number`
    - `bigNumber`: `BigNumber` (optional)
  - `is_tax_inclusive`: `boolean` (optional) — The tax inclusivity setting of the shipping method.
  - `data`: `Record<string, unknown>` (optional) — The data of the shipping method.
  - `tax_lines`: [CreateTaxLineDTO](/resources/references/cart/interfaces/cartCreateTaxLineDTO)\[] | [UpdateTaxLineDTO](/resources/references/cart/interfaces/cartUpdateTaxLineDTO)\[] (optional) — The tax lines of the shipping method.
    - `description`: `string` (optional) — The description of the tax line.
    - `tax_rate_id`: `string` (optional) — The associated tax rate's ID.
    - `code`: `string` — The code of the tax line.
    - `rate`: `number` — The rate of the tax line.
    - `provider_id`: `string` (optional) — The associated provider's ID.
    - `item_id`: `string` (optional) — The associated item's ID.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
    - `data`: `null` | `Record<string, unknown>` (optional) — Holds data returned by the tax provider in key-value pairs.
    - `id`: `string` — The ID of the tax line.
  - `adjustments`: [CreateAdjustmentDTO](/resources/references/cart/interfaces/cartCreateAdjustmentDTO)\[] | [UpdateAdjustmentDTO](/resources/references/cart/interfaces/cartUpdateAdjustmentDTO)\[] (optional) — The adjustments of the shipping method.
    - `code`: `string` — The code of the promotion that lead to this adjustment.
    - `amount`: [BigNumberInput](/resources/references/cart/types/cartBigNumberInput) — The amount to adjust the original amount with.
      - `value`: `string` | `number`
      - `numeric`: `number`
      - `raw`: [BigNumberRawValue](/resources/references/cart/types/cartBigNumberRawValue) (optional)
      - `bigNumber`: `BigNumber` (optional)
    - `is_tax_inclusive`: `boolean` (optional) — Whether the adjustment amount includes tax.
    - `description`: `string` (optional) — The description of the adjustment.
    - `promotion_id`: `string` (optional) — The associated promotion's ID.
    - `provider_id`: `string` (optional) — The associated provider's ID.
    - `id`: `string` — The ID of the adjustment.
