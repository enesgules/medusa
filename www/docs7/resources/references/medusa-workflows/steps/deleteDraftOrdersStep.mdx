This documentation provides a reference to the `deleteDraftOrdersStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more draft orders.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteDraftOrdersStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteDraftOrdersStep({
      "orderIds": [
        "{value}"
      ]
    })
  }
)
```
