This documentation provides a reference to the `parseProductCsvStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step parses a CSV file holding products to import, returning the products as
objects that can be imported.

## Example

```ts
const data = parseProductCsvStep("products.csv")
```

<a id="parseproductcsvstep-input" />

## Input

**parseProductCsvStep**

- `string`: `string`
  - `string`: `string`

<a id="parseproductcsvstep-output" />

## Output

**parseProductCsvStep**

- `AdminCreateProduct[]`: [AdminCreateProduct](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProduct)\[]
  - `title`: `string` — The product's title.
  - `subtitle`: `null` | `string` (optional) — The product's subtitle.
  - `description`: `null` | `string` (optional) — The product's description.
  - `is_giftcard`: `boolean` (optional) — Whether the product is a gift card.
  - `discountable`: `boolean` (optional) — Whether discounts can be applied on the product.
  - `images`: `object`\[] (optional) — The product's images.
    - `url`: `string` — The image's URL.
  - `thumbnail`: `null` | `string` (optional) — The product's thumbnail URL.
  - `handle`: `null` | `string` (optional) — The product's handle.
  - `status`: [ProductStatus](/resources/references/types/types/typesProductStatus) (optional) — The product's status.
  - `type_id`: `null` | `string` (optional) — The ID of the product's type.
  - `external_id`: `null` | `string` (optional) — The ID of the product in an external or third-party system.
  - `collection_id`: `null` | `string` (optional) — The ID of the product's collection.
  - `shipping_profile_id`: `string` (optional) — The ID of the product's shipping profile.
  - `categories`: `object`\[] (optional) — The product's categories.
    - `id`: `string` — The ID of a product category that the product belongs to.
  - `tags`: `object`\[] (optional) — The product's tags.
    - `id`: `string` — The ID of the associated product tag.
  - `options`: ([AdminCreateProductOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductOption) | [AdminProductCreateLinkProductOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductCreateLinkProductOption))\[] (optional) — The product's options.
    - `title`: `string` — The option's title.
    - `values`: `string`\[] — The option's values.
    - `ranks`: `Record<string, number>` (optional) — The rank for each option value. The keys are the option values, and the values are their respective ranks.

      Example:

      ```
      { * "Small": 1, * "Medium": 2, * "Large": 3 * }
      ```
    - `is_exclusive`: `boolean` (optional) — Whether the option is exclusive to a specific product, or can be shared across multiple products.
    - `id`: `string` — The ID of the product option to link.
    - `value_ids`: `string`\[] (optional) — The IDs of specific option values to link. If undefined, every value will be linked by default.
  - `variants`: [AdminCreateProductVariant](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductVariant)\[] (optional) — The product's variants.
    - `title`: `string` — The variant's title.
    - `sku`: `null` | `string` (optional) — The variant's SKU.
    - `ean`: `null` | `string` (optional) — The variant's EAN.
    - `upc`: `null` | `string` (optional) — The variant's UPC.
    - `barcode`: `null` | `string` (optional) — The variant's barcode.
    - `hs_code`: `null` | `string` (optional) — The variant's HS code.
    - `mid_code`: `null` | `string` (optional) — The variant's MID code.
    - `allow_backorder`: `boolean` (optional) — Whether the variant can be ordered even if it's out of stock.
    - `manage_inventory`: `boolean` (optional) — Whether Medusa manages the variant's inventory. If disabled, the variant is always considered in stock.
    - `variant_rank`: `number` (optional) — The variant's ranking among its sibling variants.
    - `weight`: `null` | `number` (optional) — The variant's weight.
    - `length`: `null` | `number` (optional) — The variant's length.
    - `height`: `null` | `number` (optional) — The variant's height.
    - `width`: `null` | `number` (optional) — The variant's width.
    - `origin_country`: `null` | `string` (optional) — The variant's origin country.
    - `material`: `null` | `string` (optional) — The variant's material.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
    - `prices`: [AdminCreateProductVariantPrice](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductVariantPrice)\[] — The variant's prices.
      - `currency_code`: `string` — The price's currency code.

        Example:

        ```
        usd
        ```
      - `amount`: `number` — The price's amount.
      - `min_quantity`: `null` | `number` (optional) — The minimum quantity required in the cart for the price to apply.
      - `max_quantity`: `null` | `number` (optional) — The maximum quantity required in the cart for the price to apply.
      - `rules`: `Record<string, string>` (optional) — The price's rules. Currently, only supports a `region_id` key to specify the region that the price applies to.

        Example:

        ```
        { * "region_id": "region_123" * }
        ```
    - `inventory_items`: [AdminCreateProductVariantInventoryKit](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductVariantInventoryKit)\[] (optional) — The variant's inventory items. It's only available if `manage_inventory` is enabled.
      - `inventory_item_id`: `string`
      - `required_quantity`: `number`
    - `options`: `Record<string, string>` (optional) — The variant's values for the associated product's options.
  - `sales_channels`: `object`\[] (optional) — The sales channels that the product is available in.
    - `id`: `string` — The ID of a sales channel that the product is available in.
  - `weight`: `null` | `number` (optional) — The product's weight.
  - `length`: `null` | `number` (optional) — The product's length.
  - `height`: `null` | `number` (optional) — The product's height.
  - `width`: `null` | `number` (optional) — The product's width.
  - `hs_code`: `null` | `string` (optional) — The product's HS code.
  - `mid_code`: `null` | `string` (optional) — The product's MID code.
  - `origin_country`: `null` | `string` (optional) — The product's origin country.
  - `material`: `null` | `string` (optional) — The product's material.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
