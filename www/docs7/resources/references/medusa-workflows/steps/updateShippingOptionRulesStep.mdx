This documentation provides a reference to the `updateShippingOptionRulesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates one or more shipping option rules.

## Example

```ts
const data = updateShippingOptionRulesStep({
  data: [
    {
      id: "sor_123",
      operator: "in"
    }
  ]
})
```

<a id="updateshippingoptionrulesstep-input" />

## Input

**updateShippingOptionRulesStep**

- `UpdateFulfillmentShippingOptionRulesWorkflowDTO`: [UpdateFulfillmentShippingOptionRulesWorkflowDTO](/resources/references/types/types/typesUpdateFulfillmentShippingOptionRulesWorkflowDTO) — The data to update shipping option rules.
  - `data`: [UpdateShippingOptionRuleDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateShippingOptionRuleDTO)\[] — The shipping option rules to update.
    - `attribute`: `string` (optional) — The attribute of the shipping option rule.
    - `operator`: [RuleOperatorType](/resources/references/fulfillment/types/fulfillmentRuleOperatorType) (optional) — The operator of the shipping option rule.
    - `value`: `string` | `string`\[] (optional) — The value(s) of the shipping option rule.
    - `shipping_option_id`: `string` (optional) — The associated shipping option's ID.
    - `id`: `string` — The ID of the shipping option rule.
