This documentation provides a reference to the `updateReturnItemsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates return items.

## Example

```ts
const data = updateReturnItemsStep([
  {
    id: "orli_123",
    quantity: 2
  }
])
```

<a id="updatereturnitemsstep-input" />

## Input

**updateReturnItemsStep**

- `UpdateReturnItemBySelector`: [UpdateReturnItemBySelector](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdateReturnItemBySelector)
  - `id`: `string` — The ID of the return item to update.
