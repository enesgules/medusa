This documentation provides a reference to the `updatePricePreferencesAsArrayStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates or updates price preferences.

## Example

```ts
const data = updatePricePreferencesAsArrayStep([
  {
    attribute: "region_id",
    value: "reg_123",
    is_tax_inclusive: true
  }
])
```

<a id="updatepricepreferencesasarraystep-input" />

## Input

**updatePricePreferencesAsArrayStep**

- `UpdatePricePreferencesAsArrayStepInput`: [UpdatePricePreferencesAsArrayStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcUpdatePricePreferencesAsArrayStepInput)
  - `UpdatePricePreferencesAsArrayStepInput`: [UpdatePricePreferencesWorkflowInput](/resources/references/types/WorkflowTypes/PricingWorkflow/interfaces/typesWorkflowTypesPricingWorkflowUpdatePricePreferencesWorkflowInput)\[`"update"`]\[] — The price preferences to update.

<a id="updatepricepreferencesasarraystep-output" />

## Output

**updatePricePreferencesAsArrayStep**

- `PricePreferenceDTO[]`: [PricePreferenceDTO](/resources/references/pricing/interfaces/pricingPricePreferenceDTO)\[]
  - `id`: `string` — The ID of a price preference.
  - `attribute`: `null` | `string` — The rule attribute for the preference
  - `value`: `null` | `string` — The rule value for the preference
  - `is_tax_inclusive`: `boolean` — Flag specifying whether prices for the specified rule are tax inclusive.
  - `created_at`: `Date` — When the price preference was created.
  - `updated_at`: `Date` — When the price preference was updated.
  - `deleted_at`: `null` | `Date` — When the price preference was deleted.
