This documentation provides a reference to the `cancelFulfillmentStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step cancels a fulfillment.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { cancelFulfillmentStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = cancelFulfillmentStep("{value}")
  }
)
```
