This documentation provides a reference to the `deleteUsersStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more users.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteUsersStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteUsersStep([
      "{value}"
    ])
  }
)
```
