This documentation provides a reference to the `createInviteStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates one or more invites.

## Example

```ts
const data = createInviteStep([
  {
    email: "example@gmail.com"
  }
])
```

<a id="createinvitestep-input" />

## Input

**createInviteStep**

- `CreateInviteDTO[]`: [CreateInviteDTO](/resources/references/user/interfaces/userCreateInviteDTO)\[]
  - `email`: `string` — The email of the invite.
  - `accepted`: `boolean` (optional) — Whether the invite is accepted.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
  - `roles`: `null` | `string`\[] (optional) — The RBAC roles to assign to the user when the invite is accepted.

<a id="createinvitestep-output" />

## Output

**createInviteStep**

- `InviteDTO[]`: [InviteDTO](/resources/references/user/interfaces/userInviteDTO)\[]
  - `id`: `string` — The ID of the invite.
  - `email`: `string` — The email of the invite.
  - `accepted`: `boolean` — Whether the invite is accepted.
  - `token`: `string` — The token of the invite.
  - `expires_at`: `Date` — The invite's expiry date.
  - `metadata`: `null` | `Record<string, unknown>` — Holds custom data in key-value pairs.
  - `roles`: `null` | `string`\[] (optional) — The RBAC roles to assign to the user when the invite is accepted.
  - `created_at`: `Date` — The invite's creation date.
  - `updated_at`: `Date` — The invite's update date.
  - `deleted_at`: `null` | `Date` — The invite's deletion date.
