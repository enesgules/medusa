This documentation provides a reference to the `deleteClaimsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more order claims.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteClaimsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteClaimsStep({
      "ids": [
        "id_Vnm3Iz9qgElFGQ"
      ]
    })
  }
)
```

## Input

**deleteClaimsStep**

- `DeleteOrderClaimsInput`: [DeleteOrderClaimsInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcDeleteOrderClaimsInput)
  - `ids`: `string`\[] — The IDs of the claims to delete.
