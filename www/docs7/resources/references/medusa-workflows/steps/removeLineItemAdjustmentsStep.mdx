This documentation provides a reference to the `removeLineItemAdjustmentsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step removes line item adjustments from a cart.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { removeLineItemAdjustmentsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = removeLineItemAdjustmentsStep({
      "lineItemAdjustmentIdsToRemove": [
        "{value}"
      ]
    })
  }
)
```
