This documentation provides a reference to the `deleteCampaignsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more campaigns.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteCampaignsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteCampaignsStep([
      "{value}"
    ])
  }
)
```
