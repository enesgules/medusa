This documentation provides a reference to the `generateProductCsvStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step generates a CSV file that exports products. The CSV
file is created and stored using the registered [File Module Provider](/resources/infrastructure-modules/file).

## Example

```ts
const { data: products } = useQueryGraphStep({
  entity: "product",
  fields: ["*", "variants.*", "collection.*", "categories.*"]
})

// @ts-ignore
const data = generateProductCsvStep(products)
```
