This documentation provides a reference to the `updateReturnsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step updates one or more returns.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { updateReturnsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = updateReturnsStep({
      "id": "id_O4v4fbxgv8"
    })
  }
)
```
