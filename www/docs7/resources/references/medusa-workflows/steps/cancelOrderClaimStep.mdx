This documentation provides a reference to the `cancelOrderClaimStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step cancels a claim.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { cancelOrderClaimStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = cancelOrderClaimStep({
      "order_id": "order_123",
      "claim_id": "{value}"
    })
  }
)
```
