This documentation provides a reference to the `deleteFilesStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more files using the installed
[File Module Provider](/resources/infrastructure-modules/file). The files
will be removed from the database and the storage.

## Example

```ts
const data = deleteFilesStep([
  "id_123"
])
```

## Input

**deleteFilesStep**

- `DeleteFilesStepInput`: [DeleteFilesStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcDeleteFilesStepInput)
  - `DeleteFilesStepInput`: `string`\[] — The IDs of the files to delete.
