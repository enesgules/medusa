This documentation provides a reference to the `deleteRegionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more regions.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteRegionsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteRegionsStep([
      "{value}"
    ])
  }
)
```
