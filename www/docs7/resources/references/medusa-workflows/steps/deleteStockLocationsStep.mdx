This documentation provides a reference to the `deleteStockLocationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step deletes one or more stock locations.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { deleteStockLocationsStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = deleteStockLocationsStep([
      "{value}"
    ])
  }
)
```
