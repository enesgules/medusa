This documentation provides a reference to the `clearLayoutConfigurationStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step clears a user's personal layout configuration for a zone,
reverting them to the system default.

> **Note**
>
> This is available starting from [Medusa v2.17.2](https://github.com/medusajs/medusa/releases/tag/v2.17.2).

## Example

```ts
const data = clearLayoutConfigurationStep({
  zone: "products",
  user_id: "user_123",
})
```

## Input

**clearLayoutConfigurationStep**

- `ClearLayoutConfigurationStepInput`: [ClearLayoutConfigurationStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcClearLayoutConfigurationStepInput)
  - `zone`: `string` — The zone that the layout configuration applies to.
  - `user_id`: `string` — The ID of the user whose layout configuration is cleared.
