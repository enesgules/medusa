This documentation provides a reference to the `validateTranslationsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that the translations are supported by the store.

> **Note**
>
> This is available starting from [Medusa v2.12.3](https://github.com/medusajs/medusa/releases/tag/v2.12.3).

## Example

```ts
const data = validateTranslationsStep([
  {
    reference_id: "prod_123",
    reference: "product",
    locale: "fr-FR",
    translations: { title: "Produit", description: "Description du produit" }
  }
])
```

## Input

**validateTranslationsStep**

- `ValidateTranslationsStepInput`: [ValidateTranslationsStepInput](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcValidateTranslationsStepInput)
  - `reference_id`: `string` — The ID of the data model being translated.

    Example:

    ```
    "prod_123"
    ```
  - `reference`: `string` — The name of the table that the translation belongs to.

    Example:

    ```
    "product"
    ```
  - `locale_code`: `string` — The BCP 47 language tag code for this translation.

    Example:

    ```
    "en-US"
    ```
  - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.

    Example:

    ```
    { * "title": "Product Title", * "description": "Product Description", * }
    ```
  - `id`: `string` — The ID of the translation to update.
