This documentation provides a reference to the `createOrderClaimItemsFromActionsStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step creates claim items from a change action.

> **Note**
>
> You can retrieve an order change action details using [Query](/learn/fundamentals/module-links/query),
> or [useQueryGraphStep](/resources/references/medusa-workflows/steps/useQueryGraphStep).

## Example

```ts
const data = createOrderClaimItemsFromActionsStep({
  claimId: "claim_123",
  changes: [
    {
      id: "orchact_123",
      // other order change action details...
    }
  ]
})
```
