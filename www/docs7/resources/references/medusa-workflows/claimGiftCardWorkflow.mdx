This documentation provides a reference to the `claimGiftCardWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow claims a gift card for a customer. It validates the gift card
and customer, then transfers the gift card's store credit account balance to
the customer's store credit account. The customer must have a registered account
to claim a gift card.

You can use this workflow within your own customizations or custom workflows,
allowing you to wrap custom logic around gift card claiming.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/plugins/loyalty/src/workflows/gift-cards/workflows/claim-gift-card.ts#L100)

## Examples

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { claimGiftCardWorkflow } from "@medusajs/loyalty-plugin/workflows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  await claimGiftCardWorkflow(req.scope)
    .run({
      input: {
        code: "GC-XXXX-XXXX",
        customer_id: "cust_123",
      },
    })

  res.send(result)
}
```

## Steps

- [validateClaimGiftCardInputStep](/resources/references/medusa-workflows/validateClaimGiftCardInputStep): This step validates that a gift card can be claimed. It throws an error if the gift card does not have a store credit account, the gift card's store credit account has no code, or the customer does not have a registered account.
  - [claimStoreCreditAccountWorkflow](/resources/references/medusa-workflows/claimStoreCreditAccountWorkflow): Claim an anonymous store credit account for a customer.

<a id="claimgiftcardworkflow-input" />

## Input

**claimGiftCardWorkflow**

- `ClaimGiftCardWorkflowInput`: [ClaimGiftCardWorkflowInput](/resources/references/core_flows/plugins_loyalty_src_workflows/types/core_flowsplugins_loyalty_src_workflowsClaimGiftCardWorkflowInput)
  - `code`: `string` — The code of the gift card to claim.
  - `customer_id`: `string` — The ID of the customer claiming the gift card.
