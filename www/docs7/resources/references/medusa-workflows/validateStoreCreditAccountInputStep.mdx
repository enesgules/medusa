This documentation provides a reference to the `validateStoreCreditAccountInputStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates the input for creating store credit accounts. It throws an
error if no input is provided or if any entry is missing a currency code.

## Example

```ts
const data = validateStoreCreditAccountInputStep([
  { customer_id: "cust_123", currency_code: "usd" },
])
```

<a id="validatestorecreditaccountinputstep-input" />

## Input

**validateStoreCreditAccountInputStep**

- `ModuleCreateStoreCreditAccount[]`: [ModuleCreateStoreCreditAccount](/resources/references/store_credit/types/store_creditModuleCreateStoreCreditAccount)\[]
  - `code`: `string` (optional) — The unique code for the account. If not provided, one is auto-generated.
  - `customer_id`: `string` (optional) — The ID of the customer to associate with the account.
  - `currency_code`: `string` — The three-letter ISO currency code for the account.

    Example:

    ```
    usd
    ```
  - `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs to attach to the account.
