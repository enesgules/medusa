This documentation provides a reference to the `validatePaymentsRefundStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that the refund is valid for the payment.
If the payment's refundable amount is less than the amount to be refunded,
the step throws an error.

> **Note**
>
> You can retrieve a payment's details using [Query](/learn/fundamentals/module-links/query),
> or [useQueryGraphStep](/resources/references/medusa-workflows/steps/useQueryGraphStep).

## Example

```ts
const data = validatePaymentsRefundStep({
  payment: [{
    id: "payment_123",
    // other payment details...
  }],
  input: [
    {
      payment_id: "payment_123",
      amount: 10,
    }
  ]
})
```
