This documentation provides a reference to the `exportOrdersWorkflow`. It belongs to the `@medusajs/medusa/core-flows` package.

This workflow exports orders matching the specified filters. It's used to
export orders to a CSV file.

> **Note**
>
> This workflow doesn't return the exported orders. Instead, it sends a notification to the admin
> users that they can download the exported orders.

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/core/core-flows/src/order/workflows/export-orders.ts#L89)

## Examples

To export all orders:

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { exportOrdersWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await exportOrdersWorkflow(req.scope)
    .run({
      input: {
        select: ["*"],
      }
    })

  res.send(result)
}
```

To export orders matching a criteria:

**API Route**

```ts title="src/api/workflow/route.ts"
import type {
  MedusaRequest,
  MedusaResponse,
} from "@medusajs/framework/http"
import { exportOrdersWorkflow } from "@medusajs/medusa/core-flows"

export async function POST(
  req: MedusaRequest,
  res: MedusaResponse
) {
  const { result } = await exportOrdersWorkflow(req.scope)
    .run({
      input: {
        select: ["*"],
        filter: {
          created_at: {
            $gte: "2024-01-01",
            $lte: "2024-12-31"
          }
        }
      }
    })

  res.send(result)
}
```

## Input

**exportOrdersWorkflow**

- `ExportOrdersDTO`: [ExportOrdersDTO](/resources/references/core_flows/core_core_flows_src/types/core_flowscore_core_flows_srcExportOrdersDTO)
  - `select`: `string`\[] — The fields to select. These fields will be passed to [Query](/learn/fundamentals/module-links/query), so you can pass order properties or any relation names, including custom links.
  - `filter`: [FilterableOrderProps](/resources/references/order/interfaces/orderFilterableOrderProps) (optional) — The filters to select which orders to export.
    - `$and`: ([FilterableOrderProps](/resources/references/order/interfaces/orderFilterableOrderProps) | [BaseFilterable](/resources/references/order/interfaces/orderBaseFilterable)\<[FilterableOrderProps](/resources/references/order/interfaces/orderFilterableOrderProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "and" condition.
    - `$or`: ([FilterableOrderProps](/resources/references/order/interfaces/orderFilterableOrderProps) | [BaseFilterable](/resources/references/order/interfaces/orderBaseFilterable)\<[FilterableOrderProps](/resources/references/order/interfaces/orderFilterableOrderProps)>)\[] (optional) — An array of filters to apply on the entity, where each item in the array is joined with an "or" condition.
    - `id`: `string` | `string`\[] (optional) — The IDs to filter the orders by.
    - `sales_channel_id`: `string` | `string`\[] | [OperatorMap](/resources/references/order/types/orderOperatorMap)\<string> (optional) — Filter orders by their associated sales channel's ID.
    - `customer_id`: `string` | `string`\[] | [OperatorMap](/resources/references/order/types/orderOperatorMap)\<string> (optional) — Filter orders by their associated customer's ID.
    - `region_id`: `string` | `string`\[] | [OperatorMap](/resources/references/order/types/orderOperatorMap)\<string> (optional) — Filter orders by their associated region's ID.
    - `created_at`: [OperatorMap](/resources/references/order/types/orderOperatorMap)\<string> (optional) — Filter the orders by their creation date.
    - `updated_at`: [OperatorMap](/resources/references/order/types/orderOperatorMap)\<string> (optional) — Filter orders by their update date.
