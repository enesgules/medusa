This documentation provides a reference to the `cancelReturnValidateOrder`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that a return can be canceled.
If the return is canceled, its fulfillment aren't canceled,
or it has received items, the step will throw an error.

> **Note**
>
> You can retrieve a return details using [Query](/learn/fundamentals/module-links/query),
> or [useQueryGraphStep](/resources/references/medusa-workflows/steps/useQueryGraphStep).

## Example

```ts
const data = cancelReturnValidateOrder({
  orderReturn: {
    id: "return_123",
    // other order return details...
  },
  input: {
    return_id: "return_123"
  }
})
```
