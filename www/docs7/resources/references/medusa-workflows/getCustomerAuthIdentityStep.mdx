This documentation provides a reference to the `getCustomerAuthIdentityStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step returns the customer's auth identity from a queried list. It throws
an error if no auth identity is found.

```ts title="src/workflows/my-workflow.ts"
import { createWorkflow } from "@medusajs/framework/workflows-sdk"
import { getCustomerAuthIdentityStep } from "@medusajs/medusa/core-flows"

const myWorkflow = createWorkflow(
  "my-workflow",
  () => {
    const data = getCustomerAuthIdentityStep("{value}")
  }
)
```
