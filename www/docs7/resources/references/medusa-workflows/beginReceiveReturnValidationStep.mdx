This documentation provides a reference to the `beginReceiveReturnValidationStep`. It belongs to the `@medusajs/medusa/core-flows` package.

This step validates that a return can be received.
If the order or return is canceled, the step will throw an error.

> **Note**
>
> You can retrieve an order and return details using [Query](/learn/fundamentals/module-links/query),
> or [useQueryGraphStep](/resources/references/medusa-workflows/steps/useQueryGraphStep).

## Example

```ts
const data = beginReceiveReturnValidationStep({
  orderReturn: {
    id: "return_123",
    // other order return details...
  },
  order: {
    id: "order_123",
    // other order details...
  }
})
```
