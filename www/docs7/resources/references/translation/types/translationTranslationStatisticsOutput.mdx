title: TranslationStatisticsOutput
---

Output of getStatistics method.
Maps entity types to their translation statistics.

- `TranslationStatisticsOutput`: `Record<string, [EntityTypeStatistics](/references/translation/interfaces/translation.EntityTypeStatistics)>` — Output of getStatistics method. Maps entity types to their translation statistics.
  - `expected`: `number` — Expected total number of translated fields.
  - `translated`: `number` — Actual number of translated fields. This doesn't count translations that are null or empty.
  - `missing`: `number` — Number of missing translations for expected translatable fields.
  - `by_locale`: `Record<string, [LocaleStatistics](/references/translation/interfaces/translation.LocaleStatistics)>` — Breakdown of statistics by locale.
    - `expected`: `number` — Expected total number of translated fields.
    - `translated`: `number` — Actual number of translated fields. This doesn't count translations that are null or empty.
    - `missing`: `number` — Number of missing translations for expected translatable fields.
