This reference shows all the events emitted by the Medusa application related to the Translation Module. If you use the module outside the Medusa application, these events aren't emitted.

### Summary

| Event                                                                                | Description                            |
| ------------------------------------------------------------------------------------ | -------------------------------------- |
| [`translation.created`](/resources/references/translation/events#translationcreated) | Emitted when translations are created. |
| [`translation.updated`](/resources/references/translation/events#translationupdated) | Emitted when translations are updated. |
| [`translation.deleted`](/resources/references/translation/events#translationdeleted) | Emitted when translations are deleted. |

### translation.created

Emitted when translations are created.

#### Payload

```ts
{
  id, // The ID of the translation
}
```

#### Workflows Emitting this Event

- [createTranslationsWorkflow](/resources/references/medusa-workflows/createTranslationsWorkflow)
- [batchTranslationsWorkflow](/resources/references/medusa-workflows/batchTranslationsWorkflow)

### translation.updated

Emitted when translations are updated.

#### Payload

```ts
{
  id, // The ID of the translation
}
```

#### Workflows Emitting this Event

- [updateTranslationsWorkflow](/resources/references/medusa-workflows/updateTranslationsWorkflow)
- [batchTranslationsWorkflow](/resources/references/medusa-workflows/batchTranslationsWorkflow)

### translation.deleted

Emitted when translations are deleted.

#### Payload

```ts
{
  id, // The ID of the translation
}
```

#### Workflows Emitting this Event

- [deleteTranslationsWorkflow](/resources/references/medusa-workflows/deleteTranslationsWorkflow)
