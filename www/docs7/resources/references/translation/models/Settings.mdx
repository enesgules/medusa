This documentation provides a reference to the Settings data model. It belongs to the Translation Module.

> **Note**
>
> This is available starting from [Medusa v2.12.4](https://github.com/medusajs/medusa/releases/tag/v2.12.4).

[View source code](https://github.com/medusajs/medusa/blob/0ed927bdb7a396a8fd5f6447ed69b7b354b150d3/packages/modules/translation/src/models/settings.ts#L6)

**Settings**

- `id`: PrimaryKeyModifier\<IdProperty>
- `entity_type`: [TextProperty](/resources/references/utils/classes/utilsTextProperty) — The entity type that these settings apply to (e.g., "product", "product\_variant").
  - `$dataType`: `string` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)
  - `#filterable`: `boolean` (optional)
  - `#sortable`: `boolean` (optional)
  - `#facetable`: `boolean` | `object` (optional)
    - `types`: [SearchFacetKind](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFacetKind)\[] (optional)
  - `#array`: `boolean` (optional)
  - `#searchable`: `boolean` | `object` (optional)
    - `weight`: `number` (optional)
  - `dataType`: `object` — The runtime dataType for the schema. It is not the same as the "\$dataType".
    - `name`: `"text"`
    - `options`: `Record<string, any>` (optional)
- `fields`: JSONProperty\<NoInfer\<Record\<string, unknown>>> — The translatable fields for this entity type. Array of field names that can be translated.

  Example:

  ```
  ["title", "description", "material"]
  ```
- `is_active`: [BooleanProperty](/resources/references/utils/classes/utilsBooleanProperty) — Wether the entity translatable status is enabled.
  - `$dataType`: `boolean` — A type-only property to infer the JavaScript data-type of the schema property
  - `#retrievable`: `boolean` (optional)
  - `#providerOptions`: `Record<string, Record<string, unknown>>` (optional)
  - `#filterable`: `boolean` (optional)
  - `#sortable`: `boolean` (optional)
  - `#facetable`: `boolean` | `object` (optional)
    - `types`: [SearchFacetKind](/resources/references/types/SearchTypes/types/typesSearchTypesSearchFacetKind)\[] (optional)
  - `#array`: `boolean` (optional)
  - `dataType`: `object` — The runtime dataType for the schema. It is not the same as the "\$dataType".
    - `name`: `"boolean"`
    - `options`: `Record<string, any>` (optional)
