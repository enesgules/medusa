- `translations`: JSONProperty\<NoInfer\<Record\<string, unknown>>> — The translations of the entity. The object's keys are the field names of the entity, and its value is the translated value.The key-value pairs of the translated fields. The key is a property in the referenced resource, and the value is the translated value for that property.

  Example:

  ```
  { * "title": "Product Title", * "description": "Product Description", * }
  ```
