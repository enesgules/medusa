This documentation provides a reference to the `listTranslations` method. This belongs to the Translation Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves a paginated list of translations based on optional filters and configuration.

## Example

To retrieve a list of translations using their IDs:

```ts
const translations = await translationModuleService.listTranslations({
  id: ["tra_123", "tra_321"],
})
```

To specify relations that should be retrieved within the translations:

> **Note**
>
> You can only retrieve data models defined in the same module. To retrieve linked data models
> from other modules, use [Query](/learn/fundamentals/module-links/query) instead.

```ts
const translations = await translationModuleService.listTranslations(
  {
    id: ["tra_123", "tra_321"],
  },
  {
    relations: ["locale"],
  }
)
```

By default, only the first `15` records are retrieved. You can control pagination by specifying the `skip` and `take` properties of the `config` parameter:

```ts
const translations = await translationModuleService.listTranslations(
  {
    id: ["tra_123", "tra_321"],
  },
  {
    relations: ["locale"],
    take: 20,
    skip: 2,
  }
)
```

## Returns

**listTranslations**

- `Promise`: Promise\<[TranslationDTO](/resources/references/translation/interfaces/translationTranslationDTO)\[]> — The list of translations.
  - `TranslationDTO[]`: [TranslationDTO](/resources/references/translation/interfaces/translationTranslationDTO)\[]
    - `id`: `string` — The ID of the translation.
    - `reference_id`: `string` — The ID of the entity being translated.
    - `reference`: `string` — The type of entity being translated (e.g., "product", "product\_variant").
    - `locale_code`: `string` — The BCP 47 language tag code for this translation (e.g., "en-US", "fr-FR").
    - `translations`: `Record<string, unknown>` — The translated fields as key-value pairs.
    - `created_at`: `string` | `Date` — The date and time the translation was created.
    - `updated_at`: `string` | `Date` — The date and time the translation was last updated.
    - `deleted_at`: `null` | `string` | `Date` — The date and time the translation was deleted.
