---
title: TranslationStatisticsInput
---

Input for getStatistics method.

**TranslationStatisticsInput**

- `locales`: `string`\[] — Locales to check translations for.

  Example:

  ```
  ["en-US", "fr-FR"]
  ```
- `entities`: `Record<string, object>` — Key-value pairs of entity types and their configurations.
  - `count`: `number` — Total number of records for the entity type. For example, total number of products. This is necessary to compute expected translation counts.
