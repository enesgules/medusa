---
title: UpdateLocaleDTO
---

The attributes to update in the locale.

**UpdateLocaleDTO**

- `code`: `string` (optional) — The BCP 47 language tag code of the locale.

  Example:

  ```
  "en-US"
  ```
- `name`: `string` (optional) — The human-readable name of the locale.

  Example:

  ```
  "English (United States)"
  ```
- `id`: `string` — The ID of the locale to update.
