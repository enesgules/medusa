title: CreateLocaleDTO
---

The locale to be created.

**CreateLocaleDTO**

- `id`: `string` (optional) — The ID of the locale to create.
- `code`: `string` — The BCP 47 language tag code of the locale.

  Example:

  ```
  "en-US"
  ```
- `name`: `string` — The human-readable name of the locale.

  Example:

  ```
  "English (United States)"
  ```
