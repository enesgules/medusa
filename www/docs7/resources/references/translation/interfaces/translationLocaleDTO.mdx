The locale details.

**LocaleDTO**

- `id`: `string` — The ID of the locale.
- `code`: `string` — The BCP 47 language tag code of the locale (e.g., "en-US", "fr-FR").
- `name`: `string` — The human-readable name of the locale (e.g., "English (United States)").
- `created_at`: `string` | `Date` — The date and time the locale was created.
- `updated_at`: `string` | `Date` — The date and time the locale was last updated.
- `deleted_at`: `null` | `string` | `Date` — The date and time the locale was deleted.
