This documentation provides a reference to the `retrieveTranslationSettings` method. This belongs to the Translation Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves a translation setting by its ID.

## Example

```ts
const translationSetting = await translationModuleService.retrieveTranslationSettings("ts_123")
// Returns: {
//   id: "ts_123",
//   entity_type: "product",
//   fields: ["title", "description"],
//   is_active: true,
// }
```

<a id="retrievetranslationsettings-returns" />

## Returns

**retrieveTranslationSettings**

- `Promise`: Promise\<[TranslationSettingsDTO](/resources/references/translation/interfaces/translationTranslationSettingsDTO)> — The retrieved translation setting.
  - `id`: `string` — The ID of the settings record.
  - `entity_type`: `string` — The entity type these settings apply to (e.g., "product", "product\_variant").
  - `fields`: `string`\[] — The translatable fields for this entity type.
  - `is_active`: `boolean` — Whether the entity translatable status is enabled.
  - `created_at`: `string` | `Date` — The date and time the settings were created.
  - `updated_at`: `string` | `Date` — The date and time the settings were last updated.
  - `deleted_at`: `null` | `string` | `Date` — The date and time the settings were deleted.
