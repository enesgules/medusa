This documentation provides a reference to the `startAuthMfa` method. This belongs to the Auth Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method starts multi-factor authentication (MFA) setup for an auth identity using the requested provider.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

## Example

```ts
const mfaSetup = await authModuleService.startAuthMfa({
  auth_identity_id: "authusr_123",
  provider: "totp",
  label: "My App",
  issuer: "MyCompany"
})
```

## Parameters

**startAuthMfa**

- `data`: [AuthMfaStartDTO](/resources/references/auth/types/authAuthMfaStartDTO) — The data required to start multi-factor authentication (MFA) setup.
  - `auth_identity_id`: `string` — The ID of the authentication identity to set up multi-factor authentication (MFA) for.
  - `provider`: [AuthMfaProviderMethod](/resources/references/auth/types/authAuthMfaProviderMethod) — The multi-factor authentication (MFA) provider to use.
  - `label`: `string` | `null` (optional) — Optional label for the multi-factor authentication (MFA) configuration.
  - `issuer`: `string` (optional) — The issuer name for time-based one-time password (TOTP) apps.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the multi-factor authentication (MFA) setup.
- `sharedContext`: [Context](/resources/references/auth/interfaces/authContext) (optional) — A context used to share resources, such as transaction manager, between the application and the module.
  - `transactionManager`: TManager (optional) — An instance of a transaction manager of type `TManager`, which is a typed parameter passed to the context to specify the type of the `transactionManager`.
  - `manager`: TManager (optional) — An instance of a manager, typically an entity manager, of type `TManager`, which is a typed parameter passed to the context to specify the type of the `manager`.
  - `isolationLevel`: `string` (optional) — A string indicating the isolation level of the context. Possible values are `READ UNCOMMITTED`, `READ COMMITTED`, `REPEATABLE READ`, or `SERIALIZABLE`.
  - `enableNestedTransactions`: `boolean` (optional) — A boolean value indicating whether nested transactions are enabled.
  - `eventGroupId`: `string` (optional) — A string indicating the ID of the group to aggregate the events to be emitted at a later point.
  - `transactionId`: `string` (optional) — A string indicating the ID of the current transaction.
  - `runId`: `string` (optional) — A string indicating the ID of the current run.
  - `messageAggregator`: [IMessageAggregator](/resources/references/auth/interfaces/authIMessageAggregator) (optional) — An instance of a message aggregator, which is used to aggregate messages to be emitted at a later point.
  - `requestId`: `string` (optional) — A string indicating the ID of the current request.
  - `idempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the current workflow execution.
  - `parentStepIdempotencyKey`: `string` (optional) — A string indicating the idempotencyKey of the parent workflow execution.
  - `preventReleaseEvents`: `boolean` (optional) — preventReleaseEvents
  - `isCancelling`: `boolean` (optional) — A boolean value indicating whether the current workflow execution is being cancelled.
  - `cancelingFromParentStep`: `boolean` (optional) — Weither or not a sub workflow cancellation is being triggered from a parent step. If true, the parent step will not be triggered by the sub workflow.

## Returns

**startAuthMfa**

- `Promise`: Promise\<[AuthMfaStartResponse](/resources/references/auth/types/authAuthMfaStartResponse)> — The multi-factor authentication (MFA) setup response containing the configuration and setup details.
  - `mfa`: [AuthMfaDTO](/resources/references/auth/types/authAuthMfaDTO) — The created multi-factor authentication (MFA) configuration.
    - `id`: `string` — The multi-factor authentication (MFA) configuration's ID.
    - `auth_identity_id`: `string` (optional) — The ID of the authentication identity this multi-factor authentication (MFA) belongs to.
    - `auth_identity`: [AuthIdentityDTO](/resources/references/auth/interfaces/authAuthIdentityDTO) (optional) — The authentication identity this multi-factor authentication (MFA) belongs to.
    - `provider`: [AuthMfaProviderMethod](/resources/references/auth/types/authAuthMfaProviderMethod) — The multi-factor authentication (MFA) provider used.
    - `status`: [AuthMfaStatus](/resources/references/auth/types/authAuthMfaStatus) — The status of this multi-factor authentication (MFA) configuration.
    - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the multi-factor authentication (MFA) configuration.
  - `secret`: `string` (optional) — The secret key for manual time-based one-time password (TOTP) app setup.
  - `otpauth_url`: `string` (optional) — The QR code URL for easy time-based one-time password (TOTP) app setup.
