This documentation provides a reference to the `createAuthMfaChallenge` method. This belongs to the Auth Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method creates a multi-factor authentication (MFA) challenge for an auth identity with enabled multi-factor authentication (MFA) methods.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

## Example

```ts
const challenge = await authModuleService.createAuthMfaChallenge({
  auth_identity_id: "authusr_123",
})
```

## Returns

**createAuthMfaChallenge**

- `Promise`: Promise\<[AuthMfaChallengeDTO](/resources/references/auth/types/authAuthMfaChallengeDTO)> — The created multi-factor authentication (MFA) challenge.
  - `id`: `string` — The multi-factor authentication (MFA) challenge's ID.
  - `auth_identity_id`: `string` (optional) — The ID of the authentication identity being challenged.
  - `auth_identity`: [AuthIdentityDTO](/resources/references/auth/interfaces/authAuthIdentityDTO) (optional) — The authentication identity being challenged.
    - `id`: `string` — The ID of the auth identity.
    - `provider_identities`: [ProviderIdentityDTO](/resources/references/auth/interfaces/authProviderIdentityDTO)\[] (optional) — The list of provider identities linked to the auth identity.
    - `app_metadata`: `Record<string, unknown>` (optional) — Holds information related to the actor IDs tied to the auth identity.
  - `auth_provider`: `string` | `null` (optional) — The authentication provider handling the challenge.
  - `methods`: [AuthMfaChallengeMethod](/resources/references/auth/types/authAuthMfaChallengeMethod)\[] — Available methods for completing this challenge.
  - `expires_at`: `Date` — When the challenge expires.
  - `attempts`: `number` — Number of verification attempts made.
  - `max_attempts`: `number` — Maximum verification attempts allowed.
  - `completed_at`: `Date` | `null` (optional) — When the challenge was completed.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the challenge.
