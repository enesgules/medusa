This documentation provides a reference to the `requestAuthVerification` method. This belongs to the Auth Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method requests a verification code for a certain entity type - email, phone number, etc.
