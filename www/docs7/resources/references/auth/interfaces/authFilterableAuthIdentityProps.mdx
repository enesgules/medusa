The filters to apply on the retrieved auth identity.

**FilterableAuthIdentityProps**

- `id`: `string`\[] (optional) — The IDs to filter the auth identity by.
- `provider_identities`: `object` (optional) — The provider identities to filter the auth identity by.
  - `entity_id`: `string` (optional) — Filter the provider identities by the ID of the provider identity ID they are linked to.
  - `provider`: `string` (optional) — Filter the provider identities by the provider handle.
