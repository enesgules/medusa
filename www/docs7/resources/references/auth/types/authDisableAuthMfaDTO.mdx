---
title: DisableAuthMfaDTO
---

Data required to disable a multi-factor authentication (MFA) configuration.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `DisableAuthMfaDTO`: `object` — Data required to disable a multi-factor authentication (MFA) configuration.
  - `id`: `string` — The ID of the multi-factor authentication (MFA) configuration to disable.
  - `method`: [AuthMfaChallengeMethod](/resources/references/auth/types/authAuthMfaChallengeMethod) (optional) — Optional method for additional verification.
  - `code`: `string` (optional) — Optional verification code for the method.
