---
title: CreatePasswordResetTokenDTO
---

The data required to create a single-use password reset token.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `CreatePasswordResetTokenDTO`: `object` — The data required to create a single-use password reset token.
  - `provider`: `string` — The ID of the authentication provider, e.g. `emailpass`.
  - `entity_id`: `string` — The identifier of the entity requesting the reset, typically the email.
  - `ttl_seconds`: `number` (optional) — Optional token lifetime in seconds. Defaults to the module's password reset TTL when omitted.
