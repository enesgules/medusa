---
title: GenerateAuthMfaRecoveryCodesResponse
---

Response containing generated multi-factor authentication (MFA) recovery codes.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `GenerateAuthMfaRecoveryCodesResponse`: `object` — Response containing generated multi-factor authentication (MFA) recovery codes.
  - `codes`: `string`\[] — The generated recovery codes for emergency access.
