title: AuthMfaSelector
---

Filter for selecting multi-factor authentication (MFA) configurations.

- `AuthMfaSelector`: `object` — Filter for selecting multi-factor authentication (MFA) configurations.
  - `id`: `string` — The ID of the multi-factor authentication (MFA) configuration.
  - `auth_identity_id`: `string` (optional) — The ID of the authentication identity this multi-factor authentication (MFA) belongs to.
