---
title: CreateAuthMfaChallengeDTO
---

Data required to create a new multi-factor authentication (MFA) challenge.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `CreateAuthMfaChallengeDTO`: `object` — Data required to create a new multi-factor authentication (MFA) challenge.
  - `auth_identity_id`: `string` — The ID of the authentication identity to challenge.
  - `auth_provider`: `string` | `null` (optional) — The authentication provider handling the challenge.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the challenge.
