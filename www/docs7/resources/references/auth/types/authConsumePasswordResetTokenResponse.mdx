---
title: ConsumePasswordResetTokenResponse
---

The data returned when a password reset token is successfully consumed.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `ConsumePasswordResetTokenResponse`: `object` — The data returned when a password reset token is successfully consumed.
  - `auth_identity_id`: `string` — The ID of the auth identity associated with the consumed token.
  - `provider_identity_id`: `string` — The ID of the provider identity associated with the consumed token.
  - `entity_id`: `string` — The entity identifier associated with the consumed token.
