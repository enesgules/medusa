---
title: UseAuthMfaRecoveryCodeDTO
---

Data required to use a multi-factor authentication (MFA) recovery code.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `UseAuthMfaRecoveryCodeDTO`: `object` — Data required to use a multi-factor authentication (MFA) recovery code.
  - `auth_identity_id`: `string` — The ID of the authentication identity using the recovery code.
  - `code`: `string` — The recovery code to consume.
