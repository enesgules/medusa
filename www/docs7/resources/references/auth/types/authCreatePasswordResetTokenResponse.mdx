---
title: CreatePasswordResetTokenResponse
---

The data returned when issuing a password reset token.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `CreatePasswordResetTokenResponse`: `object` — The data returned when issuing a password reset token.
  - `jti`: `string` — The opaque token identifier. The caller is responsible for embedding it as the `jti` claim of the reset JWT.
  - `expires_at`: `Date` — The absolute expiration time of the stored token row.
