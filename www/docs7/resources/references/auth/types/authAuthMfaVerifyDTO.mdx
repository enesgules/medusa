---
title: AuthMfaVerifyDTO
---

Data required to verify and enable a multi-factor authentication (MFA) configuration.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `AuthMfaVerifyDTO`: `object` — Data required to verify and enable a multi-factor authentication (MFA) configuration.
  - `id`: `string` — The ID of the multi-factor authentication (MFA) configuration to verify.
  - `auth_identity_id`: `string` (optional) — The ID of the authentication identity this multi-factor authentication (MFA) belongs to.
  - `code`: `string` — The verification code from the multi-factor authentication (MFA) provider.
