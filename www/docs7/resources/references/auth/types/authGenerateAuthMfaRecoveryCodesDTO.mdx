---
title: GenerateAuthMfaRecoveryCodesDTO
---

Data required to generate multi-factor authentication (MFA) recovery codes.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `GenerateAuthMfaRecoveryCodesDTO`: `object` — Data required to generate multi-factor authentication (MFA) recovery codes.
  - `auth_identity_id`: `string` — The ID of the authentication identity to generate codes for.
  - `count`: `number` (optional) — Number of recovery codes to generate. Defaults to implementation-specific value.
