---
title: ConsumePasswordResetTokenDTO
---

The data required to consume a previously-issued password reset token.

> **Note**
>
> This is available starting from [Medusa v2.16.0](https://github.com/medusajs/medusa/releases/tag/v2.16.0).

- `ConsumePasswordResetTokenDTO`: `object` — The data required to consume a previously-issued password reset token.
  - `jti`: `string` — The token identifier extracted from the reset JWT's `jti` claim.
  - `provider`: `string` — The ID of the authentication provider the token was issued for.
  - `entity_id`: `string` — The identifier of the entity the token was issued for.
