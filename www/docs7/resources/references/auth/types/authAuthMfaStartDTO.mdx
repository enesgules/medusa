---
title: AuthMfaStartDTO
---

Data required to start multi-factor authentication (MFA) setup for an authentication identity.

> **Note**
>
> This is available starting from [Medusa v2.15.3](https://github.com/medusajs/medusa/releases/tag/v2.15.3).

- `AuthMfaStartDTO`: `object` — Data required to start multi-factor authentication (MFA) setup for an authentication identity.
  - `auth_identity_id`: `string` — The ID of the authentication identity to set up multi-factor authentication (MFA) for.
  - `provider`: [AuthMfaProviderMethod](/resources/references/auth/types/authAuthMfaProviderMethod) — The multi-factor authentication (MFA) provider to use.
  - `label`: `string` | `null` (optional) — Optional label for the multi-factor authentication (MFA) configuration.
  - `issuer`: `string` (optional) — The issuer name for time-based one-time password (TOTP) apps.
  - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the multi-factor authentication (MFA) setup.
