## updateShippingOptions(id, data, sharedContext?): Promise\<[ShippingOptionDTO](/resources/references/fulfillment/interfaces/fulfillmentShippingOptionDTO)>

This method updates an existing shipping option.

### Example

```ts
const shippingOption =
  await fulfillmentModuleService.updateShippingOptions(
    "so_123",
    {
      name: "Express shipping",
    }
  )
```
