---
title: UpdateGeoZoneDTO
---

The attributes to update in the geo zone. The value of the `type` attributes allows for passing more attributes.

- `UpdateGeoZoneDTO`: [UpdateCountryGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateCountryGeoZoneDTO) | [UpdateProvinceGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateProvinceGeoZoneDTO) | [UpdateCityGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateCityGeoZoneDTO) | [UpdateZipGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateZipGeoZoneDTO) — The attributes to update in the geo zone. The value of the `type` attributes allows for passing more attributes.
  - `service_zone_id`: `string` (optional) — The associated service zone's ID.
  - `country_code`: `string` (optional) — The ISO 2 character country code of the geo zone.
  - `metadata`: `null` | `Record<string, any>` (optional) — Holds custom data in key-value pairs.
  - `id`: `string` — The ID of the geo zone.
  - `type`: `"country"` (default: `"country"`) — The type of the geo zone.
  - `province_code`: `string` — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code of the geo zone.
  - `city`: `string` (optional) — The city of the geo zone.
  - `postal_expression`: `Record<string, any>` (optional) — The postal expression of the geo zone.
