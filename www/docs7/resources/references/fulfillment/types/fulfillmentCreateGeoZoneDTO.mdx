---
title: CreateGeoZoneDTO
---

The geo zone to be created. The value of the `type` attributes allows for passing more attributes.

- `CreateGeoZoneDTO`: [CreateCountryGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCountryGeoZoneDTO) | [CreateProvinceGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateProvinceGeoZoneDTO) | [CreateCityGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCityGeoZoneDTO) | [CreateZipGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateZipGeoZoneDTO) — The geo zone to be created. The value of the `type` attributes allows for passing more attributes.
  - `service_zone_id`: `string` — The associated service zone's ID.
  - `country_code`: `string` — The ISO 2 character country code of the geo zone.
  - `metadata`: `null` | `Record<string, any>` (optional) — Holds custom data in key-value pairs.
  - `type`: `"country"` (default: `"country"`) — The type of the geo zone.
  - `province_code`: `string` — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code of the geo zone.
  - `city`: `string` — The city of the geo zone.
  - `postal_expression`: `Record<string, any>` — The postal expression of the geo zone.
