This documentation provides a reference to the `updateShippingOptionRules` method. This belongs to the Fulfillment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

<a id="updateshippingoptionrules-data-sharedcontext-promiseshippingoptionruledto" />

## updateShippingOptionRules(data, sharedContext?): Promise\<[ShippingOptionRuleDTO](/resources/references/fulfillment/interfaces/fulfillmentShippingOptionRuleDTO)\[]>

This method updates existing shipping option rules.

### Example

```ts
const shippingOptionRules =
  await fulfillmentModuleService.updateShippingOptionRules([
    {
      id: "sorul_123",
      operator: "in",
    },
    {
      id: "sorul_321",
      attribute: "customer_group",
      value: "cp_vipgroup",
    },
  ])
```
