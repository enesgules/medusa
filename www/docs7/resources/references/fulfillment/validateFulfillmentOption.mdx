This documentation provides a reference to the `validateFulfillmentOption` method. This belongs to the Fulfillment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method validates a fulfillment option with the provider it belongs to.

## Example

```ts
const isValid =
  await fulfillmentModuleService.validateFulfillmentOption(
    "webshipper",
    {
      code: "express",
    }
  )
```

<a id="validatefulfillmentoption-parameters" />

## Parameters

**validateFulfillmentOption**

- `providerId`: `string` — The fulfillment provider's ID.
- `data`: `Record<string, unknown>` — The fulfillment option to validate.

<a id="validatefulfillmentoption-returns" />

## Returns

**validateFulfillmentOption**

- `Promise`: Promise\<boolean> — Whether the fulfillment option is valid with the specified provider.
  - `boolean`: `boolean`
