This documentation provides a reference to the `retrieveFulfillmentOptions` method. This belongs to the Fulfillment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves the fulfillment options of a fulfillment provider.

## Example

```ts
const fulfillment =
  await fulfillmentModuleService.retrieveFulfillmentOptions(
    "ful_123"
  )
```

<a id="retrievefulfillmentoptions-parameters" />

## Parameters

**retrieveFulfillmentOptions**

- `providerId`: `string` — The fulfillment provider's ID.

<a id="retrievefulfillmentoptions-returns" />

## Returns

**retrieveFulfillmentOptions**

- `Promise`: Promise\<Record\<string, unknown>\[]> — The fulfillment provider's options.
  - `Record<string, unknown>[]`: `Record<string, unknown>`\[]
    - `string`: `string`
    - `unknown`: `unknown`
