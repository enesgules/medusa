This documentation provides a reference to the `validateShippingOption` method. This belongs to the Fulfillment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method checks whether a shipping option can be used for a specified context.

## Example

```ts
const isValid =
  await fulfillmentModuleService.validateShippingOption(
    "so_123",
    {
      customer_group: "cg_vipgroup",
    }
  )
```

<a id="validateshippingoption-parameters" />

## Parameters

**validateShippingOption**

- `shippingOptionId`: `string` — The shipping option's ID.
- `context`: `Record<string, unknown>` — The context to check.

<a id="validateshippingoption-returns" />

## Returns

**validateShippingOption**

- `Promise`: Promise\<boolean> — Whether the shipping option is valid for the specified context.
  - `boolean`: `boolean`
