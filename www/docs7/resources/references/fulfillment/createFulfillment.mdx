This documentation provides a reference to the `createFulfillment` method. This belongs to the Fulfillment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method creates a fulfillment and call the provider to create a fulfillment.

## Example

```ts
const fulfillment =
  await fulfillmentModuleService.createFulfillment({
    location_id: "loc_123",
    provider_id: "webshipper",
    delivery_address: {
      address_1: "4120 Auto Park Cir",
      country_code: "us",
    },
    items: [
      {
        title: "Shirt",
        sku: "SHIRT",
        quantity: 1,
        barcode: "ABCED",
      },
    ],
    labels: [
      {
        tracking_number: "1234567",
        tracking_url: "https://example.com/tracking",
        label_url: "https://example.com/label",
      },
    ],
    order: {},
  })
```
