## updateServiceZones(id, data, sharedContext?): Promise\<[ServiceZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentServiceZoneDTO)>

This method updates an existing service zone.

### Example

```ts
const serviceZone =
  await fulfillmentModuleService.updateServiceZones(
    "serzo_123",
    {
      name: "US",
    }
  )
```
