## updateShippingProfiles(selector, data, sharedContext?): Promise\<[ShippingProfileDTO](/resources/references/fulfillment/interfaces/fulfillmentShippingProfileDTO)\[]>

This method updates existing shipping profiles.

### Example

```ts
const shippingProfiles =
  await fulfillmentModuleService.updateShippingProfiles([
    {
      id: "sp_123",
      name: "Default",
    },
    {
      id: "sp_321",
      name: "Digital",
    },
  ])
```
