A service zone to be created or updated.

**UpsertServiceZoneDTO**

- `id`: `string` (optional) — The ID of the service zone.
- `name`: `null` | `string` (optional) — The name of the service zone.
- `geo_zones`: ([UpdateCountryGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateCountryGeoZoneDTO) | [UpdateProvinceGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateProvinceGeoZoneDTO) | [UpdateCityGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateCityGeoZoneDTO) | [UpdateZipGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentUpdateZipGeoZoneDTO) | Omit\<[CreateCountryGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCountryGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateProvinceGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateProvinceGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateCityGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateCityGeoZoneDTO), "service\_zone\_id"> | Omit\<[CreateZipGeoZoneDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateZipGeoZoneDTO), "service\_zone\_id"> | `object`)\[] (optional) — The geo zones associated with the service zone.
  - `service_zone_id`: `string` (optional) — The associated service zone's ID.
  - `country_code`: `string` (optional) — The ISO 2 character country code of the geo zone.
  - `metadata`: `null` | `Record<string, any>` (optional) — Holds custom data in key-value pairs.
  - `id`: `string` — The ID of the geo zone.
  - `type`: `"country"` (default: `"country"`) — The type of the geo zone.
  - `province_code`: `string` — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code of the geo zone.
  - `city`: `string` (optional) — The city of the geo zone.
  - `postal_expression`: `Record<string, any>` (optional) — The postal expression of the geo zone.
