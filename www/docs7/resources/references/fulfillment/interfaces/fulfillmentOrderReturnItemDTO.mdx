The order return item details.

**OrderReturnItemDTO**

- `id`: `string` — The ID of the order return item.
- `return_id`: `string` — The associated return's ID.
- `order_id`: `string` — The associated order's ID.
- `item_id`: `string` — The associated line item's ID.
- `reason_id`: `null` | `string` (optional) — The associated reason's ID.
- `quantity`: `number` — The quantity of the item to return.
- `raw_quantity`: [BigNumberRawValue](/resources/references/fulfillment/types/fulfillmentBigNumberRawValue) — The raw quantity of the item to return.
  - `value`: `string` | `number`
- `received_quantity`: `number` (optional) — The received quantity of the return item.
- `raw_received_quantity`: [BigNumberRawValue](/resources/references/fulfillment/types/fulfillmentBigNumberRawValue) (optional) — The raw received quantity of the return item.
  - `value`: `string` | `number`
- `damaged_quantity`: `number` (optional) — The damaged quantity of the return item.
- `raw_damaged_quantity`: [BigNumberRawValue](/resources/references/fulfillment/types/fulfillmentBigNumberRawValue) (optional) — The raw damaged quantity of the return item.
  - `value`: `string` | `number`
- `metadata`: `null` | `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
- `created_at`: `string` | `Date` (optional) — The creation date of the return item.
- `updated_at`: `string` | `Date` (optional) — The update date of the return item.
