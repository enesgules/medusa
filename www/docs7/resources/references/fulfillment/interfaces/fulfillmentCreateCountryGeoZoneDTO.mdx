title: CreateCountryGeoZoneDTO
---

The geo zone to be created of type `country`.

**CreateCountryGeoZoneDTO**

- `service_zone_id`: `string` — The associated service zone's ID.
- `country_code`: `string` — The ISO 2 character country code of the geo zone.
- `metadata`: `null` | `Record<string, any>` (optional) — Holds custom data in key-value pairs.
- `type`: `"country"` (default: `"country"`) — The type of the geo zone.
