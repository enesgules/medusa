---
title: CreateProvinceGeoZoneDTO
---

The geo zone to be created of type `province`.

**CreateProvinceGeoZoneDTO**

- `service_zone_id`: `string` — The associated service zone's ID.
- `country_code`: `string` — The ISO 2 character country code of the geo zone.
- `metadata`: `null` | `Record<string, any>` (optional) — Holds custom data in key-value pairs.
- `type`: `"province"` (default: `"province"`) — The type of the geo zone.
- `province_code`: `string` — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code of the geo zone.
