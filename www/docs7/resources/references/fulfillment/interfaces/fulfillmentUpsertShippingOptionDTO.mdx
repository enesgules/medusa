A shipping option to be created or updated.

**UpsertShippingOptionDTO**

- `id`: `string` (optional) — The ID of the shipping option.
- `name`: `string` (optional) — The name of the shipping option.
- `price_type`: [ShippingOptionPriceType](/resources/references/fulfillment/types/fulfillmentShippingOptionPriceType) (optional) — The type of the shipping option's price.
- `service_zone_id`: `string` (optional) — The associated service zone's ID.
- `shipping_profile_id`: `string` (optional) — The associated shipping profile's ID.
- `provider_id`: `string` (optional) — The associated provider's ID.
- `shipping_option_type_id`: `string` (optional) — The ID of the shipping option type.
- `type_id`: `string` (optional) — The ID of the type of shipping option. Column doesn't exist on the entity -> normalized to `shipping_option_type_id`
- `type`: `string` | [CreateShippingOptionTypeDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateShippingOptionTypeDTO) | `object` (optional) — The shipping option type associated with the shipping option.
  - `label`: `string` — The label of the shipping option type.
  - `description`: `string` (optional) — The description of the shipping option type.
  - `code`: `string` — The code of the shipping option type.
  - `id`: `string` — The ID of the shipping option type.
- `data`: `null` | `Record<string, unknown>` (optional) — The data necessary for the associated fulfillment provider to process the shipping option and its associated fulfillments.
- `rules`: (Omit\<[CreateShippingOptionRuleDTO](/resources/references/fulfillment/interfaces/fulfillmentCreateShippingOptionRuleDTO), "shipping\_option\_id"> | `object`)\[] (optional) — The shipping option rules associated with the shipping option.
  - `id`: `string` — The ID of the shipping option rule.
