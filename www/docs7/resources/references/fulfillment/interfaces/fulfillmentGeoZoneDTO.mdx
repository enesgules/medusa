The geo zone details.

**GeoZoneDTO**

- `id`: `string` — The ID of the geo zone.
- `type`: [GeoZoneType](/resources/references/fulfillment/types/fulfillmentGeoZoneType) — The type of the geo zone.
- `country_code`: `string` — The country code of the geo zone.
- `province_code`: `null` | `string` — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province code of the geo zone.
- `city`: `null` | `string` — The city of the geo zone.
- `postal_expression`: `null` | `Record<string, unknown>` — The postal expression of the geo zone.
- `metadata`: `null` | `Record<string, unknown>` — Holds custom data in key-value pairs.
- `created_at`: `Date` — The creation date of the geo zone.
- `updated_at`: `Date` — The update date of the geo zone.
- `deleted_at`: `null` | `Date` — The deletion date of the geo zone.
