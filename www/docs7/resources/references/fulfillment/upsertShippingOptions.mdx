## upsertShippingOptions(data, sharedContext?): Promise\<[ShippingOptionDTO](/resources/references/fulfillment/interfaces/fulfillmentShippingOptionDTO)>

This method updates or creates a shipping option if it doesn't exist.

### Example

```ts
const shippingOptions =
  await fulfillmentModuleService.upsertShippingOptions({
    id: "so_123",
    name: "Express Shipping",
  })
```
