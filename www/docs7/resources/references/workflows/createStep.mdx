This documentation provides a reference to the `createStep` . It belongs to the Workflows SDK.

This function creates a [StepFunction](/resources/references/workflows/types/workflowsStepFunction) that can be used as a step in a workflow constructed by the [createWorkflow](/resources/references/workflows/createWorkflow) function.

## Example

```ts
import {
  createStep,
  StepResponse
} from "@medusajs/framework/workflows-sdk"

interface CreateProductInput {
  title: string
}

export const createProductStep = createStep(
  "createProductStep",
  async function (
    input: CreateProductInput,
    { container }
  ) {
    const productModuleService = container.resolve(
      "product"
    )
    const product = await productModuleService.createProducts(input)
    return new StepResponse({
      product
    }, {
      product_id: product.id
    })
  },
  async function (
    input,
    { container }
  ) {
    if (!input) {
      return
    }
    const productModuleService = container.resolve(
      "product"
    )
    await productModuleService.deleteProducts([input.product_id])
  }
)
```

## Type Parameters

**createStep**

- `TInvokeInput`: `object` (optional) — The type of the expected input parameter to the invocation function.
- `TInvokeResultOutput`: `object` (optional) — The type of the expected output parameter of the invocation function.
- `TInvokeResultCompensateInput`: `object` (optional) — The type of the expected input parameter to the compensation function.

<a id="createstep-parameters" />

## Parameters

**createStep**

- `nameOrConfig`: `string` | `object` & Omit\<[TransactionStepsDefinition](/resources/references/workflows/types/workflowsTransactionStepsDefinition), "next" | "uuid" | "action"> — The name of the step or its configuration.
  - `name`: `string`
- `invokeFn`: [InvokeFn](/resources/references/workflows/types/workflowsInvokeFn)\<TInvokeInput, TInvokeResultOutput, TInvokeResultCompensateInput> — An invocation function that will be executed when the workflow is executed. The function must return an instance of [StepResponse](/resources/references/workflows/classes/workflowsStepResponse). The constructor of [StepResponse](/resources/references/workflows/classes/workflowsStepResponse) accepts the output of the step as a first argument, and optionally as a second argument the data to be passed to the compensation function as a parameter.
- `compensateFn`: [CompensateFn](/resources/references/workflows/types/workflowsCompensateFn)\<TInvokeResultCompensateInput> (optional) — A compensation function that's executed if an error occurs in the workflow. It's used to roll-back actions when errors occur. It accepts as a parameter the second argument passed to the constructor of the [StepResponse](/resources/references/workflows/classes/workflowsStepResponse) instance returned by the invocation function. If the invocation function doesn't pass the second argument to `StepResponse` constructor, the compensation function receives the first argument passed to the `StepResponse` constructor instead.

<a id="createstep-returns" />

## Returns

**createStep**

- `StepFunction`: [StepFunction](/resources/references/workflows/types/workflowsStepFunction)\<TInvokeInput, TInvokeResultOutput> — A step function to be used in a workflow.
