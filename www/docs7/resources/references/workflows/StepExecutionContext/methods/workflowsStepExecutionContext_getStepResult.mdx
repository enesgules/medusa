---
title: getStepResult
---

Get access to the result returned by a named step. Returns undefined
when step is not found or when nothing was returned.

Adding a space hides the method from the autocomplete

<a id="getstepresult-parameters" />

## Parameters

\*\* getStepResult\*\*

- `stepId`: `string`
- `action`: `"invoke"` | `"compensate"` (optional)

<a id="getstepresult-returns" />

## Returns

\*\* getStepResult\*\*

- `any`: `any` — Get access to the result returned by a named step. Returns undefined when step is not found or when nothing was returned. Adding a space hides the method from the autocomplete
