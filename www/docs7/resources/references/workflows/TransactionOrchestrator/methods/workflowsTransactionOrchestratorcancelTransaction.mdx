---
title: cancelTransaction
---

Cancel and revert a transaction compensating all its executed steps. It can be an ongoing transaction or a completed one

<a id="canceltransaction-parameters" />

## Parameters

**cancelTransaction**

- `transaction`: [DistributedTransaction](/resources/references/workflows/classes/workflowsDistributedTransaction) — The transaction to be reverted
  - `#private`: `any`
  - `flow`: `any`
  - `handler`: [TransactionStepHandler](/resources/references/workflows/types/workflowsTransactionStepHandler)
  - `payload`: `any` (optional)
  - `modelId`: `string`
  - `transactionId`: `string`
  - `runId`: `string`
  - `errors`: `any`
  - `context`: `any`
  - `keyValueStore`: `any`
  - `keyPrefix`: `string`
- `options`: `object` (optional)
  - `preventExecuteNext`: `boolean` (optional)

<a id="canceltransaction-returns" />

## Returns

**cancelTransaction**

- `Promise`: Promise\<void> — Cancel and revert a transaction compensating all its executed steps. It can be an ongoing transaction or a completed one
