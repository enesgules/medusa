---
title: ModuleJoinerRelationship
---

- `ModuleJoinerRelationship`: [JoinerRelationship](/resources/references/workflows/types/workflowsJoinerRelationship) & `object`
  - `alias`: `string` — The alias used to reference the related service in queries.
  - `foreignKey`: `string` — The foreign key field on the related service used to join the relationship.
  - `primaryKey`: `string` — The primary key field on the current service used to join the relationship.
  - `serviceName`: `string` — The name of the related service.
  - `entity`: `string` (optional) — The entity name within the related service.
  - `inverse`: `boolean` (optional) — In an inverted relationship the foreign key is on the other service and the primary key is on the current service
  - `isList`: `boolean` (optional) — Force the relationship to return a list
  - `args`: `Record<string, any>` (optional) — Extra arguments to pass to the remoteFetchData callback
  - `deleteCascade`: `boolean` (optional) — If true, the link joiner will cascade deleting the relationship
  - `filterable`: `string`\[] (optional) — The fields to be filterable by the Index module using query.index
  - `hasMany`: `boolean` (optional) — Allow multiple relationships to exist for this entity
