---
title: SchedulerOptions
---

- `SchedulerOptions`: `object` & `object` | `object`
  - `concurrency`: `"allow"` | `"forbid"` (optional) — Setting whether to allow concurrent executions (eg. if the previous execution is still running, should the new one be allowed to run or not) By default concurrent executions are not allowed.
  - `numberOfExecutions`: `number` (optional) — Optionally limit the number of executions for the scheduled workflow. If not set, the workflow will run indefinitely.
  - `cron`: `string` — The cron expression to schedule the workflow execution.
  - `interval`: `number` — The interval (in ms) to schedule the workflow execution.
