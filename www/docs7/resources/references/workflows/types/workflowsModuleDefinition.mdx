---
title: ModuleDefinition
---

- `ModuleDefinition`: `object`
  - `key`: `string`
  - `defaultPackage`: `string` | `false`
  - `label`: `string`
  - `resolvePath`: `string` (optional)
  - `isRequired`: `boolean` (optional)
  - `isQueryable`: `boolean` (optional)
  - `dependencies`: `string`\[] (optional)
  - `__passSharedContainer`: `boolean` (optional) — only used in exceptional cases - relying on the shared contrainer breaks encapsulation
  - `defaultModuleDeclaration`: [InternalModuleDeclaration](/resources/references/workflows/types/workflowsInternalModuleDeclaration) | [ExternalModuleDeclaration](/resources/references/workflows/types/workflowsExternalModuleDeclaration)
    - `scope`: `"internal"`
    - `dependencies`: `string`\[] (optional)
    - `definition`: [CustomModuleDefinition](/resources/references/workflows/types/workflowsCustomModuleDefinition) (optional)
    - `resolve`: `string` | [ModuleExports](/resources/references/workflows/types/workflowsModuleExports) (optional)
    - `options`: `Record<string, unknown>` (optional)
    - `alias`: `string` (optional) — If multiple modules are registered with the same key, the alias can be used to differentiate them
    - `main`: `boolean` (optional) — If the module is the main module for the key when multiple ones are registered
    - `worker_mode`: `"shared"` | `"worker"` | `"server"` (optional)
    - `server`: `object` (optional)
