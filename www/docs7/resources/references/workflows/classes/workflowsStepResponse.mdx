title: StepResponse
---

This class is used to create the response returned by a step. A step return its data by returning an instance of `StepResponse`.

## Type parameters

**StepResponse**

- `TOutput`: `object` (optional) — The type of the output of the step.
- `TCompensateInput`: `object` (optional) — The type of the compensation input. If the step doesn't specify any compensation input, then the type of `TCompensateInput` is the same as that of `TOutput`.
