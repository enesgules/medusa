This reference shows all the events emitted by the Medusa application related to the Payment Module. If you use the module outside the Medusa application, these events aren't emitted.

### Summary

| Event                                                                      | Description                         |
| -------------------------------------------------------------------------- | ----------------------------------- |
| [`payment.captured`](/resources/references/payment/events#paymentcaptured) | Emitted when a payment is captured. |
| [`payment.refunded`](/resources/references/payment/events#paymentrefunded) | Emitted when a payment is refunded. |

### payment.captured

Emitted when a payment is captured.

#### Payload

```ts
{
  id, // the ID of the payment
}
```

#### Workflows Emitting this Event

- [capturePaymentWorkflow](/resources/references/medusa-workflows/capturePaymentWorkflow)
- [processPaymentWorkflow](/resources/references/medusa-workflows/processPaymentWorkflow)
- [markPaymentCollectionAsPaid](/resources/references/medusa-workflows/markPaymentCollectionAsPaid)

### payment.refunded

Emitted when a payment is refunded.

#### Payload

```ts
{
  id, // the ID of the payment
}
```

#### Workflows Emitting this Event

- [refundPaymentWorkflow](/resources/references/medusa-workflows/refundPaymentWorkflow)
