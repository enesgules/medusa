This documentation provides a reference to the `deleteCaptures` method. This belongs to the Payment Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method deletes a capture by its ID.

## Example

```ts
await paymentModuleService.deleteCaptures([
  "capt_123",
  "capt_321",
])
```
