title: CreatePaymentCollectionDTO
---

The payment collection to be created.

**CreatePaymentCollectionDTO**

- `currency_code`: `string` — The ISO 3 character currency code of the payment collection.
- `amount`: [BigNumberInput](/resources/references/payment/types/paymentBigNumberInput) — The amount of the payment collection.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/payment/types/paymentBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `metadata`: `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
