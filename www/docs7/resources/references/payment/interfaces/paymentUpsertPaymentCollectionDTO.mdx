---
title: UpsertPaymentCollectionDTO
---

The attributes in the payment collection to be created or updated.

**UpsertPaymentCollectionDTO**

- `id`: `string` (optional) — The ID of the payment collection.
- `currency_code`: `string` (optional) — The ISO 3 character currency code of the payment collection.
- `amount`: [BigNumberInput](/resources/references/payment/types/paymentBigNumberInput) (optional) — The amount of the payment collection.
  - `value`: `string` | `number`
  - `numeric`: `number`
  - `raw`: [BigNumberRawValue](/resources/references/payment/types/paymentBigNumberRawValue) (optional)
    - `value`: `string` | `number`
  - `bigNumber`: `BigNumber` (optional)
- `metadata`: `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
