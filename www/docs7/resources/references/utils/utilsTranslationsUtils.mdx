### applyTranslationsToTaxLines

<a id="applytranslationstotaxlines-parameters" />

#### Parameters

**applyTranslationsToTaxLines**

- `taxLines`: [ItemTaxLineDTO](/resources/references/tax/interfaces/taxItemTaxLineDTO)\[] | [ShippingTaxLineDTO](/resources/references/tax/interfaces/taxShippingTaxLineDTO)\[] — The tax lines to apply translations to.
  - `rate_id`: `string` (optional) — The associated rate's ID. When integrating with a third-party, you don't need to provide it. This is mainly used for the built-in rates.
  - `rate`: `number` — The rate of the tax line.
  - `code`: `null` | `string` — The code of the tax line.
  - `name`: `string` — The name of the tax line.
  - `provider_id`: `string` — The ID of the tax provider used to calculate and retrieve the tax line.
  - `data`: `null` | `Record<string, unknown>` (optional) — Additional data returned by the tax provider. Use this to store jurisdiction-level breakdown data (e.g. state, county, city rates) that is not captured in the aggregated rate.
  - `line_item_id`: `string` — The associated line item's ID.
  - `shipping_line_id`: `string` — The associated shipping line's ID.
- `locale`: `undefined` | `string` — The locale to apply translations to.
- `container`: [MedusaContainer](/resources/references/medusa/types/medusaMedusaContainer) — The container to use for the translations.

<a id="applytranslationstotaxlines-returns" />

#### Returns

**applyTranslationsToTaxLines**

- `Promise`: Promise\<[ItemTaxLineDTO](/resources/references/tax/interfaces/taxItemTaxLineDTO)\[] | [ShippingTaxLineDTO](/resources/references/tax/interfaces/taxShippingTaxLineDTO)\[]> — The tax lines with translations applied.
  - `ItemTaxLineDTO[] \| ShippingTaxLineDTO[]`: [ItemTaxLineDTO](/resources/references/tax/interfaces/taxItemTaxLineDTO)\[] | [ShippingTaxLineDTO](/resources/references/tax/interfaces/taxShippingTaxLineDTO)\[]
