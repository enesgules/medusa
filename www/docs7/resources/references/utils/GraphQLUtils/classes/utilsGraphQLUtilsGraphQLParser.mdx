## Methods

### parseQuery

<a id="parsequery-returns" />

#### Returns

**parseQuery**

- `service`: `string` (optional) — The name of the service to query.
- `alias`: `string` (optional) — The alias of the service entry point to query.
- `expands`: `object`\[] (optional) — Nested relationships to expand in the query result.
  - `property`: `string` — The property path to the relationship to expand.
  - `fields`: `string`\[] — The fields to retrieve for the expanded relationship.
  - `args`: [JoinerArgument](/resources/references/types/interfaces/typesJoinerArgument)\[] (optional) — Arguments to pass to the expanded relationship query.
    - `name`: `string` — The name of the argument.
    - `value`: `any` (optional) — The value of the argument.
  - `directives`: `object` (optional) — Directives to apply to fields in the expanded relationship.
- `fields`: `string`\[] — The fields to retrieve from the queried service.
- `args`: [JoinerArgument](/resources/references/types/interfaces/typesJoinerArgument)\[] (optional) — Arguments to pass to the service query.
  - `name`: `string` — The name of the argument.
  - `value`: `any` (optional) — The value of the argument.
- `directives`: `object` (optional) — Directives to apply to fields in the query.
