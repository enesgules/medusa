title: OrderEditWorkflowEvents
---

- `OrderEditWorkflowEvents`: `object`
  - `REQUESTED`: `"order-edit.requested"` (default: "order-edit.requested") — Emitted when an order edit is requested.
  - `CONFIRMED`: `"order-edit.confirmed"` (default: "order-edit.confirmed") — Emitted when an order edit request is confirmed.
  - `CANCELED`: `"order-edit.canceled"` (default: "order-edit.canceled") — Emitted when an order edit request is canceled.
