---
title: OrderWorkflowEvents
---

- `OrderWorkflowEvents`: `object`
  - `UPDATED`: `"order.updated"` (default: "order.updated") — Emitted when the details of an order or draft order is updated. This doesn't include updates made by an edit.
  - `PLACED`: `"order.placed"` (default: "order.placed") — Emitted when an order is placed, or when a draft order is converted to an order.
  - `CANCELED`: `"order.canceled"` (default: "order.canceled") — Emitted when an order is canceld.
  - `COMPLETED`: `"order.completed"` (default: "order.completed") — Emitted when orders are completed.
  - `ARCHIVED`: `"order.archived"` (default: "order.archived") — Emitted when an order is archived.
  - `FULFILLMENT_CREATED`: `"order.fulfillment_created"` (default: "order.fulfillment\_created") — Emitted when a fulfillment is created for an order.
  - `FULFILLMENT_CANCELED`: `"order.fulfillment_canceled"` (default: "order.fulfillment\_canceled") — Emitted when an order's fulfillment is canceled.
  - `RETURN_REQUESTED`: `"order.return_requested"` (default: "order.return\_requested") — Emitted when a return request is confirmed.
  - `RETURN_RECEIVED`: `"order.return_received"` (default: "order.return\_received") — Emitted when a return is marked as received.
  - `CLAIM_CREATED`: `"order.claim_created"` (default: "order.claim\_created") — Emitted when a claim is created for an order.
  - `EXCHANGE_CREATED`: `"order.exchange_created"` (default: "order.exchange\_created") — Emitted when an exchange is created for an order.
  - `TRANSFER_REQUESTED`: `"order.transfer_requested"` (default: "order.transfer\_requested") — Emitted when an order is requested to be transferred to another customer.
