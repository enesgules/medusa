title: IFulfillmentModuleService Reference

This section of the documentation provides a reference to the `IFulfillmentModuleService` interface’s methods. This is the interface developers use to use the functionalities provided by the Fulfillment Module.

> **Note**
>
> You should only use the methods in this reference when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).
