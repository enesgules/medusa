---
title: AuthVerificationRequestResponse
---

Response returned after requesting a verification token.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

- `AuthVerificationRequestResponse`: `object` — Response returned after requesting a verification token.
  - `verification`: [AuthVerificationDTO](/resources/references/auth/types/authAuthVerificationDTO) — The verification state.
    - `id`: `string` (optional)
    - `entity_id`: `string`
    - `auth_identity_id`: `string`
    - `entity_type`: `string`
    - `code_provider`: `string`
    - `provider_metadata`: `Record<string, unknown>` | `null` (optional)
    - `metadata`: `Record<string, unknown>` | `null` (optional)
    - `verified_at`: `Date` | `null` (optional)
    - `requested_at`: `Date`
