Payload used to verify an MFA challenge.

- `AuthMfaVerifyChallengePayload`: `object` — Payload used to verify an MFA challenge.
  - `method`: [AuthMfaChallengeMethod](/resources/references/auth/types/authAuthMfaChallengeMethod) — The MFA challenge method used for verification.
  - `code`: `string` — The verification code for the selected challenge method.
