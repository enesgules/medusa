---
title: AuthVerificationRequiredResponse
---

Response returned when authentication succeeds but must be completed with
verification before issuing a token.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

- `AuthVerificationRequiredResponse`: `object` — Response returned when authentication succeeds but must be completed with verification before issuing a token.
  - `token`: `string` — A token without an actor type (permissions) attached to it. Used to request and confirm verifications.
  - `verification_required`: `true` — Indicates that the client must complete verification.
  - `verification`: [AuthVerificationDTO](/resources/references/auth/types/authAuthVerificationDTO) (optional) — The verification state to show to the caller.
    - `id`: `string` (optional)
    - `entity_id`: `string`
    - `auth_identity_id`: `string`
    - `entity_type`: `string`
    - `code_provider`: `string`
    - `provider_metadata`: `Record<string, unknown>` | `null` (optional)
    - `metadata`: `Record<string, unknown>` | `null` (optional)
    - `verified_at`: `Date` | `null` (optional)
    - `requested_at`: `Date`
