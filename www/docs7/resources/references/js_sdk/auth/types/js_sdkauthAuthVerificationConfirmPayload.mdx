---
title: AuthVerificationConfirmPayload
---

Payload used to confirm a verification code.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

- `AuthVerificationConfirmPayload`: `object` — Payload used to confirm a verification code.
  - `code`: `string` — The verification code delivered to the user, such as an OTP or pseudorandom token.
  - `code_provider`: `string` (optional) — The verification provider to use. Defaults to `token`.
