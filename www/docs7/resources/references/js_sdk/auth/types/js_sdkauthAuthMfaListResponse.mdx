title: AuthMfaListResponse

Response containing the authenticated identity's MFA factors.

- `AuthMfaListResponse`: `object` — Response containing the authenticated identity's MFA factors.
  - `mfa_factors`: [AuthMfaDTO](/resources/references/auth/types/authAuthMfaDTO)\[] — The MFA factors configured for the authenticated identity.
    - `id`: `string` — The multi-factor authentication (MFA) configuration's ID.
    - `auth_identity_id`: `string` (optional) — The ID of the authentication identity this multi-factor authentication (MFA) belongs to.
    - `auth_identity`: [AuthIdentityDTO](/resources/references/auth/interfaces/authAuthIdentityDTO) (optional) — The authentication identity this multi-factor authentication (MFA) belongs to.
    - `provider`: [AuthMfaProviderMethod](/resources/references/auth/types/authAuthMfaProviderMethod) — The multi-factor authentication (MFA) provider used.
    - `status`: [AuthMfaStatus](/resources/references/auth/types/authAuthMfaStatus) — The status of this multi-factor authentication (MFA) configuration.
    - `metadata`: `Record<string, unknown>` | `null` (optional) — Additional metadata for the multi-factor authentication (MFA) configuration.
