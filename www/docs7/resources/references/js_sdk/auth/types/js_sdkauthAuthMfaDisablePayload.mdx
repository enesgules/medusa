---
title: AuthMfaDisablePayload
---

Payload used to disable an MFA factor.

- `AuthMfaDisablePayload`: `object` — Payload used to disable an MFA factor.
  - `method`: [AuthMfaChallengeMethod](/resources/references/auth/types/authAuthMfaChallengeMethod) (optional) — Optional challenge method used to authorize disabling MFA when configured.
  - `code`: `string` (optional) — Optional verification code for the selected challenge method.
