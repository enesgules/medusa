---
title: AuthVerificationRequestPayload
---

Payload used to request a verification token.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

- `AuthVerificationRequestPayload`: `object` — Payload used to request a verification token.
  - `entity_id`: `string` — The provider identity to verify.
  - `entity_type`: `string` — The kind of entity being verified, such as `email` or `phone_number`.
  - `code_provider`: `string` (optional) — The verification provider to use. Defaults to `token`.
  - `metadata`: `Record<string, unknown>` (optional) — Optional metadata to include in the verification request event.
