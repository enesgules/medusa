---
title: delete
---

This method deletes a price list. It sends a request to the
[Delete Price List](/api/admin/price-lists/delete-a-price-list)
API route.

## Example

```ts
sdk.admin.priceList.delete("plist_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The price list's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminPriceListDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPriceListDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"price_list"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
