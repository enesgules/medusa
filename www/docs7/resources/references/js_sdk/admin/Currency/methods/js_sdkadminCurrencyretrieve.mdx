title: retrieve
---

This method retrieves a currency by its code. It sends a request to the
[Get Currency](/api/admin/currencies/get-a-currency) API route.

## Example

To retrieve a currency by its code:

```ts
sdk.admin.currency.retrieve("usd")
.then(({ currency }) => {
  console.log(currency)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.currency.retrieve("usd", {
  fields: "code,symbol"
})
.then(({ currency }) => {
  console.log(currency)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `code`: `string` — The currency's code.
- `query`: [AdminCurrencyParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCurrencyParams) (optional) — Configure the fields to retrieve in the currency.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminCurrencyResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCurrencyResponse)> — The currency's details.
  - `currency`: [AdminCurrency](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCurrency) — The currency's details.
    - `code`: `string` — The currency's code.

      Example:

      ```
      usd
      ```
    - `symbol`: `string` — The currency's symbol.

      Example:

      ```
      $
      ```
    - `symbol_native`: `string` — The currency's symbol in its native language or country.

      Example:

      ```
      $
      ```
    - `name`: `string` — The currency's name.
    - `decimal_digits`: `number` — The number of digits after the decimal for prices in this currency.
    - `rounding`: `number` — The rounding percision applied on prices in this currency.
    - `created_at`: `string` — The date the currency was created.
    - `updated_at`: `string` — The date the currency was updated.
    - `deleted_at`: `null` | `string` — The date the currency was deleted.
