---
title: delete
---

This method deletes a promotion. It sends a request to the
[Delete Promotion](/api/admin/promotions/delete-a-promotion)
API route.

## Example

```ts
sdk.admin.promotion.delete("promo_123")
.then(({ promotion }) => {
  console.log(promotion)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The promotion's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[DeleteResponse](/resources/references/types/HttpTypes/types/typesHttpTypesDeleteResponse)\<"promotion">> — The deleted promotion's details.
  - `"promotion"`: `"promotion"`
