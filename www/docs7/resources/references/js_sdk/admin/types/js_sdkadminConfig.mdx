---
title: Config
---

Configuration options for the Medusa client.

- `Config`: `object` — Configuration options for the Medusa client.
  - `baseUrl`: `string` — The base URL of the Medusa server.
  - `globalHeaders`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Default headers to include with every request.
    - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
  - `publishableKey`: `string` (optional) — The publishable API key for storefront authentication.
  - `apiKey`: `string` (optional) — The secret API key for admin authentication.
  - `auth`: `object` (optional) — Authentication configuration.
    - `type`: `"jwt"` | `"session"` (optional) — The authentication type: "jwt" or "session".
    - `jwtTokenStorageKey`: `string` (optional) — The storage key for JWT tokens.
    - `jwtTokenStorageMethod`: `"local"` | `"session"` | `"memory"` | `"custom"` | `"nostore"` (optional) — The storage method for JWT tokens.
    - `fetchCredentials`: `"include"` | `"omit"` | `"same-origin"` (optional) — The credentials mode for fetch requests.
    - `storage`: [CustomStorage](/resources/references/js_sdk/admin/interfaces/js_sdkadminCustomStorage) (optional) — Custom storage implementation for JWT tokens.
  - `logger`: [Logger](/resources/references/js_sdk/admin/types/js_sdkadminLogger) (optional) — Custom logger instance.
    - `error`: (...`messages`: `string`\[]) => `void` — Log error messages.
    - `warn`: (...`messages`: `string`\[]) => `void` — Log warning messages.
    - `info`: (...`messages`: `string`\[]) => `void` — Log info messages.
    - `debug`: (...`messages`: `string`\[]) => `void` — Log debug messages.
  - `debug`: `boolean` (optional) — Whether to enable debug logging.
