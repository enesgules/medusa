---
title: delete
---

This method deletes a campaign by its ID. It sends a request to the
[Delete Campaign](/api/admin/campaigns/delete-a-campaign) API route.

## Example

```ts
sdk.admin.campaign.delete("procamp_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The campaign's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[DeleteResponse](/resources/references/types/HttpTypes/types/typesHttpTypesDeleteResponse)\<"campaign">> — The deletion's details.
  - `"campaign"`: `"campaign"`
