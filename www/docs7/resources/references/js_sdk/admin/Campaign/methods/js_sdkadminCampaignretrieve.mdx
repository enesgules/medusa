---
title: retrieve
---

This method retrieves a campaign by its ID. It sends a request to the
[Get Campaign](/api/admin/campaigns/get-a-campaign) API route.

## Example

To retrieve a campaign by its ID:

```ts
sdk.admin.campaign.retrieve("procamp_123")
.then(({ campaign }) => {
  console.log(campaign)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.campaign.retrieve("procamp_123", {
  fields: "id,*budget"
})
.then(({ campaign }) => {
  console.log(campaign)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `id`: `string` — The campaign's ID.
- `query`: [AdminGetCampaignParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminGetCampaignParams) (optional) — Configure the fields to retrieve in the campaign.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminCampaignResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCampaignResponse)> — The campaign's details.
  - `campaign`: [AdminCampaign](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCampaign) — The campaign's details.
    - `id`: `string` — The campaign's ID.
    - `name`: `string` — The campaign's name.
    - `description`: `string` — The campaign's description.
    - `currency`: `string` — The campaign's currency code.

      Example:

      ```
      usd
      ```
    - `campaign_identifier`: `string` — The campaign's identifier.
    - `starts_at`: `string` — The date the campaign and its promotions start at.
    - `ends_at`: `string` — The date the campaign and its promotions end at.
    - `budget`: `object` — The campaign's budget.
    - `created_at`: `string`
    - `updated_at`: `string`
    - `deleted_at`: `null` | `string`
