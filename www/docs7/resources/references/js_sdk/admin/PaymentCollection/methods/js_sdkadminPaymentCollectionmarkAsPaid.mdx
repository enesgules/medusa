---
title: markAsPaid
---

This method marks a payment collection as paid. It sends a request to the
[Mark as Paid](/api/admin/payment-collections/mark-as-paid)
API route.

The API route creates and authorizes a payment session, then capture its payment.
It uses the manual payment provider by default, or the provider passed in
`provider_id` to record the captured payment under a specific provider.

## Example

```ts
sdk.admin.paymentCollection.markAsPaid("paycol_123", {
  order_id: "order_123",
  // optional: record the payment under a specific provider
  provider_id: "pp_system_default"
})
.then(({ payment_collection }) => {
  console.log(payment_collection)
})
```

<a id="markaspaid-parameters" />

## Parameters

**markAsPaid**

- `id`: `string` — The payment collection to mark as paid.
- `body`: [AdminMarkPaymentCollectionAsPaid](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminMarkPaymentCollectionAsPaid) — The details to mark the payment collection as paid.
  - `order_id`: `string` — The ID of the order this payment collection belongs to.
  - `provider_id`: `string` (optional) — The ID of the payment provider to record the captured payment under. Defaults to the system (manual) payment provider when omitted.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the payment collection.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="markaspaid-returns" />

## Returns

**markAsPaid**

- `Promise`: Promise\<[AdminPaymentCollectionResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPaymentCollectionResponse)> — The payment collection's details.
  - `payment_collection`: [AdminPaymentCollection](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPaymentCollection) — The payment collection's details.
    - `payments`: [AdminPayment](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPayment)\[] (optional) — The associated payments.
    - `payment_sessions`: [AdminPaymentSession](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPaymentSession)\[] (optional) — The associated payment sessions.
    - `payment_providers`: [AdminPaymentProvider](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPaymentProvider)\[] — The associated payment providers.
    - `id`: `string` — The ID of the payment collection.
    - `currency_code`: `string` — The ISO 3 character currency code of the payment sessions and payments associated with payment collection.
    - `amount`: `number` — The total amount to be authorized and captured.
    - `authorized_amount`: `number` (optional) — The amount authorized within the associated payment sessions.
    - `captured_amount`: `number` (optional) — The amount captured within the associated payment sessions.
    - `refunded_amount`: `number` (optional) — The amount refunded within the associated payments.
    - `completed_at`: `string` | `Date` (optional) — When the payment collection was completed.
    - `created_at`: `string` | `Date` (optional) — When the payment collection was created.
    - `updated_at`: `string` | `Date` (optional) — When the payment collection was updated.
    - `metadata`: `Record<string, unknown>` (optional) — Holds custom data in key-value pairs.
    - `status`: [BasePaymentCollectionStatus](/resources/references/types/types/typesBasePaymentCollectionStatus) — The status of the payment collection.
