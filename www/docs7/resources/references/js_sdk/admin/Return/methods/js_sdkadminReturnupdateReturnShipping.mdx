---
title: updateReturnShipping
---

This method updates a shipping method in a return request by the ID of the shipping method's `SHIPPING_ADD` action.

Every shipping method has an `actions` property, whose value is an array of actions. You can check the action's name
using its `action` property, and use the value of the `id` property.

For example, `shipping_method.actions.find((action) => action.action === "SHIPPING_ADD")?.id` is
the ID of a shipping method's `SHIPPING_ADD` action.

This method sends a request to the
[Update Shipping Method in Return](/api/admin/returns/update-shipping-method)
API route.

## Example

```ts
sdk.admin.return.updateReturnShipping("return_123", "orchach_123", {
  custom_amount: 100,
})
.then(({ return }) => {
  console.log(return)
})
```

## Parameters

**updateReturnShipping**

- `id`: `string` — The ID of the return to update the shipping method in.
- `actionId`: `string` — The ID of the shipping method's `SHIPPING_ADD` action.
- `body`: [AdminUpdateReturnShipping](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateReturnShipping) — The details of the shipping method to update.
  - `custom_amount`: `number` (optional) — A custom amount to set for the shipping method. If not provided, the shipping option's fixed or calculated amount will be used.
  - `internal_note`: `string` (optional) — A note that is viewed by admins only to describe the shipping method.
  - `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the shipping method.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the return.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
