---
title: confirmRequest
---

This method confirms a return request. The return's changes are applied on the inventory quantity of the return
items and the order only after the return has been confirmed as received using the
[Confirm Return Receival](/api/admin/returns/confirm-return-receival)
API route.

This method sends a request to the
[Confirm Return Request](/api/admin/returns/confirm-return-request)
API route.

## Example

```ts
sdk.admin.return.confirmRequest("return_123", {
  no_notification: true,
})
.then(({ return }) => {
  console.log(return)
})
```

<a id="confirmrequest-parameters" />

## Parameters

**confirmRequest**

- `id`: `string` — The ID of the return to confirm.
- `body`: [AdminConfirmReturnRequest](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminConfirmReturnRequest) — The details of the return to confirm.
  - `no_notification`: `boolean` (optional) — Whether to send a notification to the customer for return updates.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the return.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="confirmrequest-returns" />

## Returns

**confirmRequest**

- `Promise`: Promise\<[AdminReturnResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnResponse)> — The return's details.
  - `return`: [AdminReturn](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturn) — The return's details.
    - `items`: [AdminReturnItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnItem)\[] — The return's items.
    - `id`: `string` — The return's ID.
    - `order_id`: `string` — The ID of the order that the return belongs to.
    - `status`: [ReturnStatus](/resources/references/order/types/orderReturnStatus) (optional) — The return's status.
    - `exchange_id`: `string` (optional) — The ID of the exchange that the return belongs to, if available.
    - `location_id`: `string` (optional) — The ID of the stock location that the items are returned to.
    - `claim_id`: `string` (optional) — The ID of the claim that the return belongs to, if available.
    - `order_version`: `number` — The order's version once the return is applied.
    - `display_id`: `number` — The display ID of the return.
    - `no_notification`: `boolean` (optional) — Whether to send the customers notifications about return updates.
    - `refund_amount`: `number` (optional) — The amount that is to be refunded to the customer.
    - `received_at`: `string` — The date when the return was received.
    - `created_at`: `string` — The date when the return was created.
    - `created_by`: `string` — The ID of the user that created the return.
    - `canceled_at`: `string` — The date when the return was canceled.
    - `requested_at`: `string`
