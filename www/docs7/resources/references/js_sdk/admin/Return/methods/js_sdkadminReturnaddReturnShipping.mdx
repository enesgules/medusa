---
title: addReturnShipping
---

This method adds a shipping method to a return request. It sends a request to the
[Add Shipping Method to Return](/api/admin/returns/add-shipping-method)
API route.

## Example

```ts
sdk.admin.return.addReturnShipping("return_123", {
  shipping_option_id: "so_123",
})
.then(({ return }) => {
  console.log(return)
})
```

<a id="addreturnshipping-parameters" />

## Parameters

**addReturnShipping**

- `id`: `string` — The ID of the return to add the shipping method to.
- `body`: [AdminAddReturnShipping](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminAddReturnShipping) — The details of the shipping method to add to the return.
  - `shipping_option_id`: `string` — The ID of the shipping option that the shipping method is created from.
  - `custom_amount`: `number` (optional) — A custom amount to set for the shipping method. If not provided, the shipping option's fixed or calculated amount will be used.
  - `description`: `string` (optional) — A note to describe the shipping method.
  - `internal_note`: `string` (optional) — A note that is viewed by admins only to describe the shipping method.
  - `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the shipping method.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the return.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

    - `order_id`: `string` — The ID of the order that the return belongs to.

    - `exchange_id`: `string` (optional) — The ID of the exchange that the return belongs to, if available.

    - `no_notification`: `boolean` (optional) — Whether to send the customers notifications about return updates.

    - `canceled_at`: `string` — The date when the return was canceled.
    - `requested_at`: `string`
