---
title: updateReceiveItem
---

This method updates a received item in the return by the ID of the item's `RECEIVE_RETURN_ITEM` action.

Every item has an `actions` property, whose value is an array of actions. You can check the action's name
using its `action` property, and use the value of the `id` property.

For example, `received_item.actions.find((action) => action.action === "RECEIVE_RETURN_ITEM")?.id` is
the ID of a received item's `RECEIVE_RETURN_ITEM` action.

This method sends a request to the
[Update Received Item](/api/admin/returns/update-received-item)
API route.

## Example

```ts
sdk.admin.return.updateReceiveItem("return_123", "orchach_123", {
  quantity: 2,
})
.then(({ return }) => {
  console.log(return)
})
```

## Parameters

**updateReceiveItem**

- `id`: `string` — The ID of the return to update the received item in.
- `actionId`: `string` — The ID of the received item's `RECEIVE_RETURN_ITEM` action.
- `body`: [AdminUpdateReceiveItems](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateReceiveItems) — The details of the received item to update.
  - `quantity`: `number` (optional) — The received quantity of the item.
  - `internal_note`: `string` (optional) — A note that is viewed by admins only to describe the received item.
  - `reason_id`: `string` (optional) — The ID of the return reason to associate with the item.
  - `metadata`: `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the received item.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the return.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
