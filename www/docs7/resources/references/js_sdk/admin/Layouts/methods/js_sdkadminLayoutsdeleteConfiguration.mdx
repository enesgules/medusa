---
title: deleteConfiguration
---

Remove the current user's personal layout configuration for a zone,
falling back to the zone's system default.

<a id="deleteconfiguration-parameters" />

## Parameters

**deleteConfiguration**

- `zone`: `string`
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional)
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="deleteconfiguration-returns" />

## Returns

**deleteConfiguration**

- `Promise`: Promise\<object> — Remove the current user's personal layout configuration for a zone, falling back to the zone's system default.
  - `success`: `boolean`
