---
title: removeRole
---

This method removes a role from a user. It sends a request to the
Remove User Role API route.

## Example

```ts
sdk.admin.user.removeRole("user_123", "role_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="removerole-parameters" />

## Parameters

**removeRole**

- `id`: `string` — The user's ID.
- `roleId`: `string` — The role's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="removerole-returns" />

## Returns

**removeRole**

- `Promise`: Promise\<[AdminUserRoleDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUserRoleDeleteResponse)> — The removal's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"user_role"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
