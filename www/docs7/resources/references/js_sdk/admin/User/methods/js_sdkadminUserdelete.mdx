---
title: delete
---

This method deletes a user. It sends a request to the
[Delete User](/api/admin/users/delete-a-user)
API route.

## Example

```ts
sdk.admin.user.delete("user_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the user to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminUserDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUserDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"user"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
