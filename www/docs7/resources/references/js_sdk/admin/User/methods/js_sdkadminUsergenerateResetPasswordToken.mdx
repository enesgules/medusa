---
title: generateResetPasswordToken
---

This method generates a reset password token for a user. It sends a request to the
Generate Reset Password Token for a User API route.

Useful for constructing the reset password link without sending an email.

The token is short-lived, can only be used once, and generating it invalidates
any reset password token previously issued for the user.

> **Note**
>
> This is available starting from [Medusa v2.20.0](https://github.com/medusajs/medusa/releases/tag/v2.20.0).

## Example

```ts
sdk.admin.user.generateResetPasswordToken("user_123")
.then(({ token }) => {
  console.log(token)
})
```

<a id="generateresetpasswordtoken-parameters" />

## Parameters

**generateResetPasswordToken**

- `id`: `string` — The ID of the user to generate the token for.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="generateresetpasswordtoken-returns" />

## Returns

**generateResetPasswordToken**

- `Promise`: Promise\<[AdminUserResetPasswordTokenResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUserResetPasswordTokenResponse)> — The generated reset password token.
  - `token`: `string` — The generated reset password token. Append it to the admin's `/reset-password` page as a `token` query parameter to build a link the user can open to set a new password. The token is short-lived, can only be used once, and generating it invalidates any reset password token previously issued for the user.
