---
title: listAuthProviders
---

This method retrieves the auth providers a user can authenticate with. It sends a
request to the List User Auth Providers API route.

> **Note**
>
> This is available starting from [Medusa v2.20.0](https://github.com/medusajs/medusa/releases/tag/v2.20.0).

## Example

```ts
sdk.admin.user.listAuthProviders("user_123")
.then(({ providers }) => {
  console.log(providers)
})
```

<a id="listauthproviders-parameters" />

## Parameters

**listAuthProviders**

- `id`: `string` — The user's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="listauthproviders-returns" />

## Returns

**listAuthProviders**

- `Promise`: Promise\<[AdminUserAuthProvidersResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUserAuthProvidersResponse)> — The IDs of the user's auth providers.
  - `providers`: `string`\[] — The IDs of the auth providers the user can authenticate with, such as `emailpass`.
