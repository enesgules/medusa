## Returns

**listRoles**

- `Promise`: Promise\<[AdminRbacPolicyRolesListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicyRolesListResponse)> — Lists the roles that include the given policy.
  - `limit`: `number` — The maximum number of items retrieved.
  - `offset`: `number` — The number of items to skip before retrieving the returned items.
  - `count`: `number` — The total number of items.
  - `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
  - `roles`: [AdminRbacRole](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacRole)\[] — The roles that include this policy.

    - `name`: `string` — The role's name.
    - `description`: `null` | `string` — The role's description.
    - `parent_id`: `null` | `string` — The ID of the parent role, if any.
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the role.
    - `policies`: [AdminRbacPolicy](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicy)\[] (optional) — The policies associated with the role.
    - `created_at`: `string` — The date the role was created.
    - `updated_at`: `string` — The date the role was updated.
    - `deleted_at`: `null` | `string` — The date the role was deleted.
