---
title: delete
---

This method deletes an RBAC policy by its ID. It sends a request to the
Delete RBAC Policy API route.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

## Example

```ts
sdk.admin.rbacPolicy.delete("policy_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The policy's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminRbacPolicyDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicyDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"rbac_policy"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
