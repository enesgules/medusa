title: list

This method retrieves a paginated list of locales. It sends a request to the
[List Locales](/api/admin/locales/list-locales)
API route.

## Example

To retrieve the list of locales:

```ts
sdk.admin.locale.list()
.then(({ locales, count, limit, offset }) => {
  console.log(locales)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.locale.list({
  limit: 10,
  offset: 10
})
.then(({ locales, count, limit, offset }) => {
  console.log(locales)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each locale:

```ts
sdk.admin.locale.list({
  fields: "code,name"
})
.then(({ locales, count, limit, offset }) => {
  console.log(locales)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

      Example:


      Example:

      ```
      English (United States)
      ```
    - `created_at`: `string` — The date the locale was created.
    - `updated_at`: `string` — The date the locale was updated.
    - `deleted_at`: `null` | `string` — The date the locale was deleted.
