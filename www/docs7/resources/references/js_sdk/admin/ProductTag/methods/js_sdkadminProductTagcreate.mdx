---
title: create
---

This method creates a product tag. It sends a request to the
[Create Product Tag](/api/admin/product-tags/create-product-tag)
API route.

## Example

```ts
sdk.admin.productTag.create({
  value: "shirt"
})
.then(({ product_tag }) => {
  console.log(product_tag)
})
```

<a id="create-parameters" />

## Parameters

**create**

- `body`: [AdminCreateProductTag](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateProductTag) — The details of the product tag.
  - `value`: `string` — The tag's value.
  - `external_id`: `null` | `string` (optional) — An external ID for the tag.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [AdminProductTagParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTagParams) (optional) — Configure the fields to retrieve in the product tag.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="create-returns" />

## Returns

**create**

- `Promise`: Promise\<[AdminProductTagResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTagResponse)> — The product tag's details.
  - `product_tag`: [AdminProductTag](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTag) — The tag's details.
    - `translations`: `null` | [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[] (optional) — The tag's translations.
    - `id`: `string` — The tag's ID.
    - `value`: `string` — The tag's value.
    - `created_at`: `string` — The date the tag was created.
    - `updated_at`: `string` — The date the tag was updated.
    - `deleted_at`: `null` | `string` (optional) — The date the tag was deleted.
    - `external_id`: `null` | `string` (optional) — An external ID for the tag.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
