---
title: delete
---

This method deletes a shipping profile. It sends a request to the
[Delete Shipping Profile](/api/admin/shipping-profiles/delete-a-shipping-profile)
API route.

## Example

```ts
sdk.admin.shippingProfile.delete("sp_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the shipping profile to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminShippingProfileDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingProfileDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"shipping_profile"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
