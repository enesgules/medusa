---
title: update
---

This method updates a shipping profile. It sends a request to the
[Update Shipping Profile](/api/admin/shipping-profiles/update-a-shipping-profile)
API route.

## Example

```ts
sdk.admin.shippingProfile.update("sp_123", {
  name: "Updated Shipping Profile",
})
.then(({ shipping_profile }) => {
  console.log(shipping_profile)
})
```

<a id="update-parameters" />

## Parameters

**update**

- `id`: `string` — The ID of the shipping profile to update.
- `body`: [AdminUpdateShippingProfile](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateShippingProfile) — The details of the shipping profile to update.
  - `name`: `string` (optional) — The name of the shipping profile.
  - `type`: `string` (optional) — The type of the shipping profile.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the shipping profile.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the shipping profile.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="update-returns" />

## Returns

**update**

- `Promise`: Promise\<[AdminShippingProfileResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingProfileResponse)> — The shipping profile's details.
  - `shipping_profile`: [AdminShippingProfile](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingProfile) — The shipping profile's details.
    - `id`: `string` — The ID of the shipping profile.
    - `name`: `string` — The name of the shipping profile.
    - `type`: `string` — The type of the shipping profile.
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the shipping profile.
    - `created_at`: `string` — The date when the shipping profile was created.
    - `updated_at`: `string` — The date when the shipping profile was updated.
    - `deleted_at`: `null` | `string` — The date when the shipping profile was deleted.
