---
title: entities
---

This method retrieves a paginated list of entities for a given entity type with only their
translatable fields.
It sends a request to the
[Get Translation Entities](/api/admin/translations/list-translatable-entities) API route.

> **Note**
>
> This is available starting from [Medusa v2.12.4](https://github.com/medusajs/medusa/releases/tag/v2.12.4).

## Example

To retrieve the entities for a given entity type:

```ts
sdk.admin.translation.entities({
  type: "product"
})
.then(({ data, count, offset, limit }) => {
  console.log(data)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.translation.entities({
  type: "product",
  limit: 10,
  offset: 10
})
.then(({ data, count, offset, limit }) => {
  console.log(data)
})
```

## Parameters

**entities**

- `query`: [AdminTranslationEntitiesParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslationEntitiesParams) — The query parameters including the entity type and pagination configurations.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
  - `limit`: `number` (optional) — The maximum number of items to retrieve.
  - `offset`: `number` (optional) — The number of items to skip before retrieving the returned items.
  - `order`: `string` (optional) — The field to sort by and in which order.

    Example:

    ```
    -created_at
    ```
  - `with_deleted`: `boolean` (optional) — Whether to include soft-deleted items in the results.
  - `type`: `string` — The entity type to retrieve (e.g., "product", "product\_variant"). This determines which table to query and which translatable fields to return.

    Example:

    ```
    "product"
    ```
  - `id`: `string` | `string`\[] (optional) — Filter by entity ID(s). Can be a single ID or an array of IDs.

    Example:

    ```
    "prod_123"
    ```
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="entities-returns" />

## Returns

**entities**

- `Promise`: Promise\<[AdminTranslationEntitiesResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslationEntitiesResponse)> — The paginated list of entities with their translatable fields.
  - `data`: `Record<string, unknown>` & `object`\[] — The list of entities with their translatable fields. Each entity contains only the fields configured as translatable for that entity type in the translation settings, plus all translations for all locales.
    - `id`: `string`
    - `translations`: [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[]
  - `count`: `number` — The total count of entities.
  - `offset`: `number` — The offset of the current page.
  - `limit`: `number` — The limit of items per page.
