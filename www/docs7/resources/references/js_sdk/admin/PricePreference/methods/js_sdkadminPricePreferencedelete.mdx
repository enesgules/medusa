---
title: delete
---

This method deletes a price preference. It sends a request to the
[Delete Price Preference](/api/admin/price-preferences/delete-a-price-preference)
API route.

## Example

```ts
sdk.admin.pricePreference.delete("prpref_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The price preference's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminPricePreferenceDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPricePreferenceDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"price_preference"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
