---
title: delete
---

This method deletes a stock location. It sends a request to the
[Delete Stock Location](/api/admin/stock-locations/delete-a-stock-location)
API route.

## Example

```ts
sdk.admin.stockLocation.delete("sloc_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the stock location to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminStockLocationDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminStockLocationDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"stock_location"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
