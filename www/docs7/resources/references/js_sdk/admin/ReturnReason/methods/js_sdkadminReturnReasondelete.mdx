---
title: delete
---

This method deletes a return reason. It sends a request to the
[Delete Return Reason](/api/admin/return-reasons/delete-a-return-reason)
API route.

## Example

```ts
sdk.admin.returnReason.delete("ret_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The return reason's ID.
- `query`: [AdminReturnReasonParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReasonParams) (optional) — Query parameters to pass to the request.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminReturnReasonDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReasonDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"return_reason"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
