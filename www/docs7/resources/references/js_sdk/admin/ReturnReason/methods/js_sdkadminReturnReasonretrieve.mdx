---
title: retrieve
---

This method retrieves a return reason by ID. It sends a request to the
[Get Return Reason](/api/admin/return-reasons/get-a-return-reason)
API route.

## Example

To retrieve a return reason by its ID:

```ts
sdk.admin.returnReason.retrieve("ret_123")
.then(({ return_reason }) => {
  console.log(return_reason)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.returnReason.retrieve("ret_123", {
  fields: "id,value"
})
.then(({ return_reason }) => {
  console.log(return_reason)
})
```

Learn more about the `fields` property in the [API reference](/api/admin/select-fields-and-relations).

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `id`: `string` — The return reason's ID.
- `query`: [AdminReturnReasonParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReasonParams) (optional) — Configure the fields and relations to retrieve in the return reason.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminReturnReasonResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReasonResponse)> — The return reason's details.
  - `return_reason`: [AdminReturnReason](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminReturnReason) — The return reason's details.
    - `id`: `string` — The return reason's ID.
    - `value`: `string` — The return reason's value.

      Example:

      ```
      "refund"
      ```
    - `label`: `string` — The return reason's label.

      Example:

      ```
      "Refund"
      ```
    - `description`: `null` | `string` (optional) — The return reason's description.
    - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs that can be added to the return reason.
    - `created_at`: `string` — The date that the return reason was created.
    - `updated_at`: `string` — The date that the return reason was updated.
