---
title: delete
---

This method deletes a file by its ID from the configured File Module Provider. It sends a request to the
[Delete File](/api/admin/uploads/delete-a-file)
API route.

## Example

```ts
sdk.admin.upload.delete("test.txt")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the file to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminFileDeleteResponse](/resources/references/types/HttpTypes/types/typesHttpTypesAdminFileDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: TObject — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
