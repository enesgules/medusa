---
title: delete
---

This method deletes a product type. It sends a request to the
[Delete Product Type](/api/admin/product-types/delete-a-product-type)
API route.

## Example

```ts
sdk.admin.productType.delete("ptyp_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The product type's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminProductTypeDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTypeDeleteResponse)> — The product type's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"product_type"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
