---
title: retrieve
---

This method retrieves a product type by its ID. It sends a request to the
[Get Product Type](/api/admin/product-types/get-a-product-type)
API route.

## Example

To retrieve a product type by its ID:

```ts
sdk.admin.productType.retrieve("ptyp_123")
.then(({ product_type }) => {
  console.log(product_type)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.productType.retrieve("ptyp_123", {
  fields: "id,*products"
})
.then(({ product_type }) => {
  console.log(product_type)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `id`: `string` — The product type's ID.
- `query`: [AdminProductTypeParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTypeParams) (optional) — Configure the fields to retrieve in the product type.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminProductTypeResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductTypeResponse)> — The product type's details.
  - `product_type`: [AdminProductType](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductType) — The product type's details.
    - `translations`: `null` | [AdminTranslation](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTranslation)\[] (optional) — The product type's translations.
    - `id`: `string` — The product type's ID.
    - `value`: `string` — The product type's value.
    - `created_at`: `string` — The date the product type was created.
    - `updated_at`: `string` — The date the product type was updated.
    - `deleted_at`: `null` | `string` (optional) — The date the product type was deleted.
    - `external_id`: `null` | `string` (optional) — An external ID for the product type.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
