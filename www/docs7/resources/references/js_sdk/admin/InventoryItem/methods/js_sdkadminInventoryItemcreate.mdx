title: create
---

This method creates an inventory item. It sends a request to the
[Create Inventory Item](/api/admin/inventory-items/create-inventory-item)
API route.

## Example

```ts
sdk.admin.inventoryItem.create({
  sku: "SHIRT"
})
.then(({ inventory_item }) => {
  console.log(inventory_item)
})
```
