---
title: update
---

This method updates a customer group's details. It sends a request to the
[Update Customer](/api/admin/customer-groups/update-a-customer-group)
API route.

## Example

```ts
sdk.admin.customerGroup.update("cusgroup_123", {
  name: "VIP"
})
.then(({ customer_group }) => {
  console.log(customer_group)
})
```

<a id="update-parameters" />

## Parameters

**update**

- `id`: `string` — The customer group's ID.
- `body`: [AdminUpdateCustomerGroup](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateCustomerGroup) — The details to update in the group.
  - `name`: `string` (optional) — The customer group's name.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [AdminGetCustomerGroupParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminGetCustomerGroupParams) (optional) — Configure the fields to retrieve in the customer group.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="update-returns" />

## Returns

**update**

- `Promise`: Promise\<[AdminCustomerGroupResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCustomerGroupResponse)> — The customer group's details.
  - `customer_group`: [AdminCustomerGroup](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCustomerGroup) — The customer group's details.
    - `customers`: [AdminCustomer](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCustomer)\[] — The customers in the group.
    - `id`: `string` — The customer group's ID.
    - `name`: `null` | `string` — The customer group's name.
    - `metadata`: `null` | `Record<string, unknown>` — Key-value pairs of custom data.
    - `created_at`: `string` — The date the customer group was created.
    - `updated_at`: `string` — The date the customer group was updated.
