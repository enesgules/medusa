---
title: create
---

This method creates an API key. It sends a request to the [Create API Key](/api/admin/api-keys/create-api-key)
API route.

## Example

```ts
sdk.admin.apiKey.create({
  title: "Development",
  type: "publishable"
})
.then(({ api_key }) => {
  console.log(api_key)
})
```

## Returns

- `Promise`: Promise\<[AdminApiKeyResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminApiKeyResponse)> — The created API key

    - `title`: `string` — The API key's title.
    - `type`: [ApiKeyType](/resources/references/api_key/types/api_keyApiKeyType) — The API key's type.

    - `updated_at`: `Date` — The date the API key was updated.
    - `revoked_by`: `null` | `string` — The ID of the user that revoked the API key.

    - `deleted_at`: `null` | `Date` — The date the API key was deleted.
