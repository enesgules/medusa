title: delete
---

This method deletes a shipping option type. It sends a request to the
[Delete Shipping Option Type](/api/admin/shipping-option-types/delete-shipping-option-type)
API route.

## Example

```ts
sdk.admin.shippingOptionType.delete("sotype_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The shipping option type's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminShippingOptionTypeDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminShippingOptionTypeDeleteResponse)> — The shipping option type's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"shipping_option_type"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
