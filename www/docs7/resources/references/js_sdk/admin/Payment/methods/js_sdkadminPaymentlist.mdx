This method retrieves a paginated list of payments. It sends a request to the
[List Payments](/api/admin/payments/list-payments) API route.

## Example

To retrieve the list of payments:

```ts
sdk.admin.payment.list()
.then(({ payments, count, limit, offset }) => {
  console.log(payments)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.payment.list({
  limit: 10,
  offset: 10
})
.then(({ payments, count, limit, offset }) => {
  console.log(payments)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each payment:

```ts
sdk.admin.payment.list({
  fields: "id,*payment_collection"
})
.then(({ payments, count, limit, offset }) => {
  console.log(payments)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
