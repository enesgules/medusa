This method creates a product. It sends a request to the
[Create Product](/api/admin/products/create-product)
API route.

## Example

```ts
sdk.admin.product.create({
  title: "Shirt",
  options: [{
    title: "Default",
    values: ["Default Option"]
  }],
  variants: [
    {
      title: "Default",
      options: {
        Default: "Default Option"
      },
      prices: []
    }
  ],
  shipping_profile_id: "sp_123"
})
.then(({ product }) => {
  console.log(product)
})
```
