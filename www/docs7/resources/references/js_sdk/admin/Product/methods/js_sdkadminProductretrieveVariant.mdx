title: retrieveVariant
---

This method retrieves a product's variant. It sends a request to the
[Retrieve Variant](/api/admin/products/get-variant)
API route.

## Example

To retrieve a product variant by its ID:

```ts
sdk.admin.product.retrieveVariant(
  "prod_123",
  "variant_123"
)
.then(({ variant }) => {
  console.log(variant)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.product.retrieveVariant(
  "prod_123",
  "variant_123",
  {
    fields: "id, *product"
  }
)
.then(({ variant }) => {
  console.log(variant)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).

<a id="retrievevariant-parameters" />

## Parameters

**retrieveVariant**

- `productId`: `string` — The product's ID.
- `id`: `string` — The variant's ID.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the product variant.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
