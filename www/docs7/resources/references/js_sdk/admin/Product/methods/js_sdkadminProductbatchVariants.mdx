---
title: batchVariants
---

This method manages the variants of a product. It sends a request to the
[Manage Variants](/api/admin/products/manage-variants-in-a-product)
API route.

## Example

```ts
sdk.admin.product.batchVariants("prod_123", {
  create: [
    {
      title: "Blue Shirt",
      options: {
        Color: "Blue"
      },
      prices: []
    }
  ],
  update: [
    {
      id: "variant_123",
      title: "Pants"
    }
  ],
  delete: ["variant_123"]
})
.then(({ created, updated, deleted }) => {
  console.log(created, updated, deleted)
})
```
