---
title: updateVariant
---

This method updates a variant of a product. It sends a request to the
[Update Variant](/api/admin/products/update-variant)
API route.

## Example

```ts
sdk.admin.product.updateVariant(
  "prod_123",
  "variant_123",
    {
    title: "Blue Shirt",
  }
)
.then(({ product }) => {
  console.log(product)
})
```

<a id="updatevariant-parameters" />

## Parameters

**updateVariant**

- `productId`: `string` — The product's ID.
- `id`: `string` — The variant's ID.
- `body`: [AdminUpdateProductVariant](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateProductVariant) — The data to update in the variant.
  - `id`: `string` (optional) — The variant's ID.
  - `title`: `string` (optional) — The variant's title.
  - `sku`: `null` | `string` (optional) — The variant's SKU.
  - `ean`: `null` | `string` (optional) — The variant's EAN.
  - `upc`: `null` | `string` (optional) — The variant's UPC.
  - `barcode`: `null` | `string` (optional) — The variant's barcode.

  - `mid_code`: `null` | `string` (optional) — The variant's MID code.

  - `allow_backorder`: `boolean` (optional) — Whether the variant can be ordered even if it's out of stock.
  - `manage_inventory`: `boolean` (optional) — Whether Medusa should manage the variant's inventory. If disabled, the variant is always considered in stock.
  - `variant_rank`: `number` (optional) — The variant's ranking among its sibling variants.
  - `weight`: `null` | `number` (optional) — The variant's weight.
  - `length`: `null` | `number` (optional) — The variant's length.
  - `height`: `null` | `number` (optional) — The variant's height.
  - `width`: `null` | `number` (optional) — The variant's width.
  - `origin_country`: `null` | `string` (optional) — The variant's origin country.
  - `material`: `null` | `string` (optional) — The variant's material.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
  - `prices`: [AdminUpdateProductVariantPrice](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateProductVariantPrice)\[] (optional) — The variant's prices.
    - `id`: `string` (optional) — The price's ID.


    - `min_quantity`: `null` | `number` (optional) — The minimum quantity required in the cart for the price to apply.
    - `max_quantity`: `null` | `number` (optional) — The maximum quantity required in the cart for the price to apply.
    - `rules`: `Record<string, string>` (optional) — The price's rules.
  - `options`: `Record<string, string>` (optional) — The variant's values for the associated product's options.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the product.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
