---
title: createImport
---

This method creates a product import. The products are only imported after
the import is confirmed using the [confirmImport](/resources/references/js_sdk/admin/Product/methods/js_sdkadminProductconfirmImport) method.

This method sends a request to the
[Create Product Import](/api/admin/products/create-product-import-2)
API route.

> **Note**
>
> This is available starting from [Medusa v2.8.5](https://github.com/medusajs/medusa/releases/tag/v2.8.5).

## Example

```ts
sdk.admin.product.createImport({
  file // uploaded File instance
})
.then(({ transaction_id }) => {
  console.log(transaction_id)
})
```

<a id="createimport-parameters" />

## Parameters

**createImport**

- `body`: [AdminImportProductRequest](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminImportProductRequest) — The import's details.
  - `file`: [File](/resources/references/core_flows/core_flowsFile) — The CSV file to import the products from. It's an uploaded file of type [File](https://developer.mozilla.org/en-US/docs/Web/API/File).
- `query`: `object` (optional) — Query parameters to pass to the request.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="createimport-returns" />

## Returns

**createImport**

- `Promise`: Promise\<[AdminImportProductsResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminImportProductsResponse)> — The import's details.
  - `transaction_id`: `string` — The ID of the import product workflow execution's transaction. This is useful to confirm the import using the `/admin/products/:transaction-id/import` API route.
  - `summary`: `object` — Details of the products to create or update when the import is confirmed.
    - `toCreate`: `number` — The number of products that will be created by the import.
    - `toUpdate`: `number` — The number of products that will be updated by the import.
