title: update
---

This method updates an order. It sends a request to the
[Update Order Email](/api/admin/orders/update-order)
API route.

## Example

```ts
sdk.admin.order.update(
  "order_123",
  {
    email: "new_email@example.com",
    shipping_address: {
      first_name: "John",
      last_name: "Doe",
      address_1: "123 Main St",
    }
  }
)
.then(({ order }) => {
  console.log(order)
})
```
