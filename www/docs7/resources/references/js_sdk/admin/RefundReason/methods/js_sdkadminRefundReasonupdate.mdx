---
title: update
---

This method updates a refund reason. It sends a request to the
[Update Refund Reason](/api/admin/refund-reasons/update-a-refund-reason)
API route.

> **Note**
>
> This is available starting from [Medusa v2.11.0](https://github.com/medusajs/medusa/releases/tag/v2.11.0).

## Example

```ts
sdk.admin.refundReason.update("ret_123", {
  code: "refund",
  label: "Refund",
})
.then(({ refund_reason }) => {
  console.log(refund_reason)
})
```

<a id="update-parameters" />

## Parameters

**update**

- `id`: `string` — The refund reason's ID.
- `body`: [AdminUpdateRefundReason](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateRefundReason) — The details of the refund reason to update.
  - `label`: `string` (optional) — The refund reason's label.

    Example:

    ```
    "Refund"
    ```
  - `code`: `string` (optional) — The refund reason's code.

    Example:

    ```
    "refund"
    ```
  - `description`: `null` | `string` (optional) — The refund reason's description.
- `query`: [AdminRefundReasonParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReasonParams) (optional) — Configure the fields and relations to retrieve in the refund reason.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="update-returns" />

## Returns

**update**

- `Promise`: Promise\<[AdminRefundReasonResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReasonResponse)> — The refund reason's details.
  - `refund_reason`: [AdminRefundReason](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReason) — The refund reason's details.
    - `id`: `string` — The refund reason's ID.
    - `label`: `string` — The refund reason's label.

      Example:

      ```
      "Refund"
      ```
    - `code`: `string` — The refund reason's code.

      Example:

      ```
      "refund"
      ```
    - `description`: `null` | `string` (optional) — The refund reason's description.
    - `metadata`: `null` | `Record<string, any>` (optional) — Custom key-value pairs that can be added to the refund reason.
    - `created_at`: `string` — The date that the refund reason was created.
    - `updated_at`: `string` — The date that the refund reason was updated.
