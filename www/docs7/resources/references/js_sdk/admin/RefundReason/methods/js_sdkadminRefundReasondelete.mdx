title: delete

This method deletes a refund reason. It sends a request to the
[Delete Refund Reason](/api/admin/refund-reasons/delete-a-refund-reason)
API route.

> **Note**
>
> This is available starting from [Medusa v2.11.0](https://github.com/medusajs/medusa/releases/tag/v2.11.0).

## Example

```ts
sdk.admin.refundReason.delete("ret_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The refund reason's ID.
- `query`: [AdminRefundReasonParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReasonParams) (optional) — Query parameters to pass to the request.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminRefundReasonDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRefundReasonDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"refund_reason"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
