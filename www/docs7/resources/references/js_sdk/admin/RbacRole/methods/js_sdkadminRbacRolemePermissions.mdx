---
title: mePermissions
---

Retrieves the authenticated actor's resolved permission set: a flat list
of `resource:operation` strings with wildcards already expanded.

## Example

```ts
sdk.admin.rbacRole.mePermissions().then(({ permissions }) => {
  console.log(permissions) // ["product:read", "customer:read", ...]
})
```

<a id="mepermissions-parameters" />

## Parameters

**mePermissions**

- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="mepermissions-returns" />

## Returns

**mePermissions**

- `Promise`: Promise\<[AdminRbacMePermissionsResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacMePermissionsResponse)> — The flat permission list.
  - `permissions`: `string`\[] — The actor's effective `resource:operation` permissions, with wildcards already expanded.
