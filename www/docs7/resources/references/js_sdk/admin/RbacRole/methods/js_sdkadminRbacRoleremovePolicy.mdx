---
title: removePolicy
---

This method removes a policy from an RBAC role. It sends a request to the
Remove Role Policy API route.

## Example

```ts
sdk.admin.rbacRole.removePolicy("role_123", "policy_456")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="removepolicy-parameters" />

## Parameters

**removePolicy**

- `roleId`: `string` — The role's ID.
- `policyId`: `string` — The policy's ID to remove.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="removepolicy-returns" />

## Returns

**removePolicy**

- `Promise`: Promise\<[AdminRbacPolicyDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicyDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"rbac_policy"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
