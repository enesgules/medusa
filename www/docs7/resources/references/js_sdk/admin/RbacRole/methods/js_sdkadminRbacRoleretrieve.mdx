---
title: retrieve
---

This method retrieves an RBAC role's details. It sends a request to the
Get RBAC Role API route.

> **Note**
>
> This is available starting from [Medusa v2.15.5](https://github.com/medusajs/medusa/releases/tag/v2.15.5).

## Example

```ts
sdk.admin.rbacRole.retrieve("role_123")
.then(({ role }) => {
  console.log(role)
})
```

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `id`: `string` — The role's ID.
- `query`: [AdminRbacRoleParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacRoleParams) (optional) — Configure the fields to retrieve in the role.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
  - `policies`: `string` | `string`\[] (optional) — Comma-separated relations to include in the response. Can include `policies`.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminRbacRoleResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacRoleResponse)> — The role's details.
  - `role`: [AdminRbacRole](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacRole) — The role's details.
    - `id`: `string` — The role's ID.
    - `name`: `string` — The role's name.
    - `description`: `null` | `string` — The role's description.
    - `parent_id`: `null` | `string` — The ID of the parent role, if any.
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the role.
    - `policies`: [AdminRbacPolicy](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicy)\[] (optional) — The policies associated with the role.
    - `created_at`: `string` — The date the role was created.
    - `updated_at`: `string` — The date the role was updated.
    - `deleted_at`: `null` | `string` — The date the role was deleted.
