---
title: listPolicies
---

This method retrieves a paginated list of policies associated with an RBAC role.
It sends a request to the List Role Policies API route.

## Example

```ts
sdk.admin.rbacRole.listPolicies("role_123")
.then(({ policies, count, limit, offset }) => {
  console.log(policies)
})
```

## Returns

**listPolicies**

- `Promise`: Promise\<[AdminRbacPolicyListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicyListResponse)> — The paginated list of policies.
  - `limit`: `number` — The maximum number of items retrieved.
  - `offset`: `number` — The number of items to skip before retrieving the returned items.
  - `count`: `number` — The total number of items.
  - `estimate_count`: `number` (optional) — The estimated count retrieved from the PostgreSQL query planner, which may be inaccurate.
  - `policies`: [AdminRbacPolicy](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminRbacPolicy)\[] — The list of policies.
    - `id`: `string` — The policy's ID.
    - `key`: `string` — The policy's unique key.
    - `resource`: `string` — The resource the policy applies to.
    - `operation`: `string` — The operation the policy allows.
    - `name`: `null` | `string` — The policy's name.
    - `description`: `null` | `string` — The policy's description.
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the policy.
    - `inherited_from_role_id`: `null` | `string` (optional) — The role ID the policy is inherited from, if any.
    - `created_at`: `string` — The date the policy was created.
    - `updated_at`: `string` — The date the policy was updated.
    - `deleted_at`: `null` | `string` — The date the policy was deleted.
