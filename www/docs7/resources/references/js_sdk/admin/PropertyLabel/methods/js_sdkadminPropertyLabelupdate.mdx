Update a property label

<a id="update-parameters" />

## Parameters

**update**

- `id`: `string`
- `body`: Omit\<[AdminUpdatePropertyLabel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdatePropertyLabel), "id">
  - `label`: `string` (optional)
  - `description`: `null` | `string` (optional)
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional)
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="update-returns" />

## Returns

**update**

- `Promise`: Promise\<[AdminPropertyLabelResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPropertyLabelResponse)> — Update a property label
  - `property_label`: [AdminPropertyLabel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminPropertyLabel) — The property label.
    - `id`: `string` — The ID of the property label.
    - `entity`: `string` — The entity this label applies to (e.g., "Order", "Product").
    - `property`: `string` — The property path (e.g., "display\_id", "customer.email").
    - `label`: `string` — Custom display name for the property.
    - `description`: `string` (optional) — Optional description providing context about the property.
    - `created_at`: `Date` — The date the label was created.
    - `updated_at`: `Date` — The date the label was last updated.
