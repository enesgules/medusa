---
title: listEntities
---

This method retrieves the list of entities that support view configurations.

> **Note**
>
> This is available starting from [Medusa v2.18.0](https://github.com/medusajs/medusa/releases/tag/v2.18.0).

## Example

```ts
sdk.admin.views.listEntities()
.then(({ entities }) => {
  console.log(entities)
})
```

<a id="listentities-parameters" />

## Parameters

**listEntities**

- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="listentities-returns" />

## Returns

**listEntities**

- `Promise`: Promise\<[AdminEntityListResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminEntityListResponse)> — The list of supported entities.
  - `entities`: [AdminEntityInfo](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminEntityInfo)\[] — List of available entities.
    - `name`: `string` — Entity name in PascalCase.
    - `pluralName`: `string` — Plural/route key.
    - `module`: `string` — Module this entity belongs to.
    - `propertyCount`: `number` — Number of properties on this entity.
    - `hasOverrides`: `boolean` — Whether this entity has custom overrides.
