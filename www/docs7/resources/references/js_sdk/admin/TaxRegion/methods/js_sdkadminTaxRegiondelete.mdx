---
title: delete
---

This method deletes a tax region. It sends a request to the
[Delete Tax Region](/api/admin/tax-regions/delete-a-tax-region)
API route.

## Example

```ts
sdk.admin.taxRegion.delete("txreg_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the tax region to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminTaxRegionDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRegionDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"tax_region"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
