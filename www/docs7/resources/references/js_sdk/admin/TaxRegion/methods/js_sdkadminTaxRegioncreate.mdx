---
title: create
---

This method creates a tax region. It sends a request to the
[Create Tax Region](/api/admin/tax-regions/create-tax-region)
API route.

## Example

```ts
sdk.admin.taxRegion.create({
  country_code: "us",
  province_code: "ca",
  default_tax_rate: {
    code: "VAT",
    name: "VAT",
    rate: 20, // 20%
    is_combinable: true,
  },
})
.then(({ tax_region }) => {
  console.log(tax_region)
})
```

<a id="create-parameters" />

## Parameters

**create**

- `body`: [AdminCreateTaxRegion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateTaxRegion) — The details of the tax region to create.
  - `country_code`: `string` — The country code of the tax region.
  - `provider_id`: `null` | `string` (optional) — The ID of the tax provider.
  - `province_code`: `null` | `string` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province or state code of the tax region.
  - `parent_id`: `null` | `string` (optional) — The ID of the parent tax region.
  - `default_tax_rate`: `object` (optional) — The default tax rate of the tax region.
    - `rate`: `number` (optional) — The percentage rate of the default tax rate.
    - `code`: `string` — The code of the default tax rate.
    - `name`: `string` — The name of the default tax rate.
    - `is_combinable`: `boolean` (optional) — Whether the default tax rate is combinable with other tax rates.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the default tax rate.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Custom key-value pairs that can be added to the tax region.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the tax region.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="create-returns" />

## Returns

**create**

- `Promise`: Promise\<[AdminTaxRegionResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRegionResponse)> — The tax region's details.
  - `tax_region`: [AdminTaxRegion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRegion) — The tax region's details.
    - `id`: `string` — The tax region's ID.
    - `country_code`: `null` | `string` — The tax region's country code.

      Example:

      ```
      "us"
      ```
    - `province_code`: `null` | `string` — The tax region's lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province or state code.

      Example:

      ```
      "us-ca"
      ```
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the tax region.
    - `parent_id`: `null` | `string` — The ID of the parent tax region.
    - `provider_id`: `null` | `string` — The ID of the tax provider for the region.
    - `created_at`: `string` — The date the tax region was created.
    - `updated_at`: `string` — The date the tax region was updated.
    - `deleted_at`: `null` | `string` — The date the tax region was deleted.
    - `created_by`: `null` | `string` — The ID of the user who created the tax region.
    - `tax_rates`: [AdminTaxRate](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRate)\[] — The tax rates associated with the tax region.
    - `parent`: `null` | [AdminTaxRegion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRegion) — The parent tax region.
    - `children`: [AdminTaxRegion](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRegion)\[] — The child tax regions.
