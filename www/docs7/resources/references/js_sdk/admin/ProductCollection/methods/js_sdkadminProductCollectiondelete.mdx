---
title: delete
---

This method deletes a product collection. It sends a request to the
[Delete Collection](/api/admin/collections/delete-a-collection)
API route.

## Example

```ts
sdk.admin.productCollection.delete("pcol_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The collection's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminCollectionDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCollectionDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"collection"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
