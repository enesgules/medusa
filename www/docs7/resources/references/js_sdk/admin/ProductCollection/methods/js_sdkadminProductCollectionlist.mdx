title: list

This method retrieves a paginated list of collections. It sends a request to the
[List Collections](/api/admin/collections/list-collections) API route.

## Example

To retrieve the list of collections:

```ts
sdk.admin.productCollection.list()
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.productCollection.list({
  limit: 10,
  offset: 10
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each collection:

```ts
sdk.admin.productCollection.list({
  fields: "id,*products"
})
.then(({ collections, count, limit, offset }) => {
  console.log(collections)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
