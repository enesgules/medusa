---
title: cancelRequest
---

This method cancels an exchange request. It sends a request to the
[Cancel Exchange Request](/api/admin/exchanges/cancel-exchange-request)
API route.

## Example

```ts
sdk.admin.exchange.cancel("exchange_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="cancelrequest-parameters" />

## Parameters

**cancelRequest**

- `id`: `string` — The exchange's ID.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the exchange.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="cancelrequest-returns" />

## Returns

**cancelRequest**

- `Promise`: Promise\<[AdminExchangeDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminExchangeDeleteResponse)> — The cancelation's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"exchange"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
