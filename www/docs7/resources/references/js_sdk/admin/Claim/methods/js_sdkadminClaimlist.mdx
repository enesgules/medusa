title: list
---

This method retrieves a paginated list of claims. It sends a request to the
[List Claims](/api/admin/claims/list-claims) API route.

## Example

To retrieve the list of claims:

```ts
sdk.admin.claim.list()
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

To configure the pagination, pass the `limit` and `offset` query parameters.

For example, to retrieve only 10 items and skip 10 items:

```ts
sdk.admin.claim.list({
  limit: 10,
  offset: 10
})
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

Using the `fields` query parameter, you can specify the fields and relations to retrieve
in each claim:

```ts
sdk.admin.claim.list({
  fields: "id,*additional_items"
})
.then(({ claims, count, limit, offset }) => {
  console.log(claims)
})
```

Learn more about the `fields` property in the [API reference](/api/store/select-fields-and-relations).
