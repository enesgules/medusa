---
title: create
---

This method creates a claim. It sends a request to the
[Create Claim](/api/admin/claims/create-a-claim) API route.

## Example

```ts
sdk.admin.claim.create({
  type: "refund",
  order_id: "order_123",
})
.then(({ claim }) => {
  console.log(claim)
})
```

<a id="create-parameters" />

## Parameters

**create**

- `body`: [AdminCreateClaim](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminCreateClaim) — The claim's details.
  - `type`: `"refund"` | `"replace"` — The claim's type. If `refund`, it means the claim's items are returned and the customer is refunded. If `replace`, it means the merchant will send new items in place of the returned items.
  - `order_id`: `string` — The ID of the order this claim is created for.
  - `description`: `string` (optional) — The claim's description.
  - `internal_note`: `string` (optional) — An internal note viewed by admin users only.
  - `reason_id`: `null` | `string` (optional) — The ID of the associated reason.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the claim.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
