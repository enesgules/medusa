---
title: updateItem
---

This method updates a claim item by the ID of the item's `WRITE_OFF_ITEM` action. It
sends a request to the [Update Claim Item](/api/admin/claims/update-a-claim-item) API route.

Every item has an `actions` property, whose value is an array of actions.
You can check the action's name using its `action` property, and use the value of the `id` property.

## Example

```ts
sdk.admin.claim.updateItem(
  "claim_123", 
  "ordchact_123",
  {
    quantity: 1
  }
  )
.then(({ claim }) => {
  console.log(claim)
})
```

<a id="updateitem-parameters" />

## Parameters

**updateItem**

- `id`: `string` — The claim's ID.
- `actionId`: `string` — The id of the order item's `WRITE_OFF_ITEM` action.
- `body`: [AdminUpdateClaimItem](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateClaimItem) — The details to update.
  - `quantity`: `number` (optional) — The item's claimed quantity.
  - `reason_id`: `null` | `string` (optional) — The ID of the associated claim reason.
  - `internal_note`: `null` | `string` (optional) — An internal note viewed by admin users only.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the claim.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).
