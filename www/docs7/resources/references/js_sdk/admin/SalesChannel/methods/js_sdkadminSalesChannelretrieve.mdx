---
title: retrieve
---

This method retrieves a sales channel. It sends a request to the
[Retrieve Sales Channel](/api/admin/sales-channels/get-a-sales-channel)
API route.

## Example

To retrieve a sales channel by its ID:

```ts
sdk.admin.salesChannel.retrieve("sc_123")
.then(({ sales_channel }) => {
  console.log(sales_channel)
})
```

To specify the fields and relations to retrieve:

```ts
sdk.admin.salesChannel.retrieve("sc_123", {
  fields: "id,*products"
})
.then(({ sales_channel }) => {
  console.log(sales_channel)
})
```

Learn more about the `fields` property in the [API reference](/api/admin/select-fields-and-relations).

<a id="retrieve-parameters" />

## Parameters

**retrieve**

- `id`: `string` — The ID of the sales channel to retrieve.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields and relations to retrieve in the sales channel.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="retrieve-returns" />

## Returns

**retrieve**

- `Promise`: Promise\<[AdminSalesChannelResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminSalesChannelResponse)> — The sales channel's details.
  - `sales_channel`: [AdminSalesChannel](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminSalesChannel) — The sales channel's details.
    - `id`: `string` — The sales channel's ID.
    - `name`: `string` — The sales channel's name.
    - `description`: `null` | `string` — The sales channel's description.
    - `is_disabled`: `boolean` — Whether the sales channel is disabled.
    - `metadata`: `null` | `Record<string, unknown>` — Custom key-value pairs that can be added to the sales channel.
    - `created_at`: `string` — The sales channel's creation date.
    - `updated_at`: `string` — The sales channel's last updated date.
    - `deleted_at`: `null` | `string` — The sales channel's deletion date.
