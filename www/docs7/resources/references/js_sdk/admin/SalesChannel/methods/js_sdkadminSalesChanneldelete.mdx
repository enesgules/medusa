---
title: delete
---

This method deletes a sales channel. It sends a request to the
[Delete Sales Channel](/api/admin/sales-channels/delete-a-sales-channel)
API route.

## Example

```ts
sdk.admin.salesChannel.delete("sc_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the sales channel to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminSalesChannelDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminSalesChannelDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"sales-channel"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
