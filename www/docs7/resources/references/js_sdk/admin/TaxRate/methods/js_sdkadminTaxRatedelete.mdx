---
title: delete
---

This method deletes a tax rate. It sends a request to the
[Delete Tax Rate](/api/admin/tax-rates/delete-a-tax-rate)
API route.

## Example

```ts
sdk.admin.taxRate.delete("txrat_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="delete-parameters" />

## Parameters

**delete**

- `id`: `string` — The ID of the tax rate to delete.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request.
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="delete-returns" />

## Returns

**delete**

- `Promise`: Promise\<[AdminTaxRateDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminTaxRateDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"tax_rate"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
