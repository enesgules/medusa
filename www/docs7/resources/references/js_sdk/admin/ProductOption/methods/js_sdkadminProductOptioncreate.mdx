title: create
---

This method creates a product option. It sends a request to the
[Create Option](/api/admin/product-options/create-product-option)
API route.

## Example

```ts
sdk.admin.productOption.create({
  title: "Size",
  values: ["S", "M"]
})
.then(({ product_option }) => {
  console.log(product_option)
})
```
