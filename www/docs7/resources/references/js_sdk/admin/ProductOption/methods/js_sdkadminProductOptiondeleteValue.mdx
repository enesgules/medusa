---
title: deleteValue
---

This method deletes a product option value. It sends a request to the
Delete Product Option Value Admin API route.

## Example

```ts
sdk.admin.productOption.deleteValue("opt_123", "optval_123")
.then(({ deleted }) => {
  console.log(deleted)
})
```

<a id="deletevalue-parameters" />

## Parameters

**deleteValue**

- `optionId`: `string` — The product option's ID.
- `valueId`: `string` — The product option value's ID.
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="deletevalue-returns" />

## Returns

**deleteValue**

- `Promise`: Promise\<[AdminProductOptionValueDeleteResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOptionValueDeleteResponse)> — The deletion's details.
  - `id`: `string` — The ID of the item that was deleted.
  - `object`: `"product_option_value"` — The type of the item that was deleted.
  - `deleted`: `boolean` — Whether the item was deleted successfully.
  - `parent`: [AdminProductOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOption) (optional) — The parent resource of the item that was deleted, if applicable.
    - `products`: `null` | [AdminProduct](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProduct)\[] (optional) — The associated products' details.
    - `values`: [AdminProductOptionValue](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOptionValue)\[] (optional) — The option's values.
    - `id`: `string` — The option's ID.
    - `title`: `string` — The option's title.
    - `is_exclusive`: `boolean` — Whether the option is exclusive or global.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
    - `created_at`: `string` (optional) — The date the option was created.
    - `updated_at`: `string` (optional) — The date the option was updated.
    - `deleted_at`: `null` | `string` (optional) — The date the option was deleted.
