---
title: updateValue
---

This method updates a product option value. It sends a request to the
Update Product Option Value Admin API route.

## Example

```ts
sdk.admin.productOption.updateValue("opt_123", "optval_123", {
  metadata: { is_default: true }
})
.then(({ product_option_value }) => {
  console.log(product_option_value)
})
```

<a id="updatevalue-parameters" />

## Parameters

**updateValue**

- `optionId`: `string` — The product option's ID.
- `valueId`: `string` — The product option value's ID.
- `body`: [AdminUpdateProductOptionValue](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminUpdateProductOptionValue) — The data to update in the option value.
  - `value`: `string` (optional) — The option value's value.
  - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
- `query`: [SelectParams](/resources/references/types/HttpTypes/interfaces/typesHttpTypesSelectParams) (optional) — Configure the fields to retrieve in the option value.
  - `fields`: `string` (optional) — The fields and relations to retrieve separated by commas. Learn more in the [API reference](/api/store/select-fields-and-relations).
- `headers`: [ClientHeaders](/resources/references/js_sdk/admin/types/js_sdkadminClientHeaders) (optional) — Headers to pass in the request
  - `tags`: `string`\[] — Tags to cache data under for Next.js applications. Learn more in [Next.js's documentation](https://nextjs.org/docs/app/building-your-application/caching#fetch-optionsnexttags-and-revalidatetag).

<a id="updatevalue-returns" />

## Returns

**updateValue**

- `Promise`: Promise\<[AdminProductOptionValueResponse](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOptionValueResponse)> — The product option value's details.
  - `product_option_value`: [AdminProductOptionValue](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOptionValue) — The product option value's details.
    - `option`: `null` | [AdminProductOption](/resources/references/types/HttpTypes/interfaces/typesHttpTypesAdminProductOption) (optional) — The option's details.
    - `id`: `string` — The option value's ID.
    - `value`: `string` — The option's value.
    - `rank`: `number` (optional) — The value's rank among other option values.
    - `option_id`: `null` | `string` (optional) — The ID of the option that the value belongs to.
    - `metadata`: `null` | `Record<string, unknown>` (optional) — Key-value pairs of custom data.
    - `created_at`: `string` (optional) — The date the option value was created.
    - `updated_at`: `string` (optional) — The date the option value was updated.
    - `deleted_at`: `null` | `string` (optional) — The date the option value was deleted.
