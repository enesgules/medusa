This method indicates that a property's value must be unique in the database.
A unique index is created on the property.

## Example

```ts
import { model } from "@medusajs/framework/utils"

const User = model.define("user", {
  email: model.text().unique(),
  // ...
})

export default User
```

<a id="unique-parameters" />

## Parameters

**unique**

- `name`: `string` (optional) — The unique index's name. If not provided, Medusa generates the name.
