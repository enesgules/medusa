This method defines a property whose value can only be one of the specified values.

## Example

```ts
import { model } from "@medusajs/framework/utils"

const MyCustom = model.define("my_custom", {
  color: model.enum(["black", "white"]),
  // ...
})

export default MyCustom
```

<a id="enum-type-parameters" />

## Type Parameters

**enum**

- `Values`: `unknown`\[] | `EnumLike` (optional) — The type of possible values. By default, it's `string`.

<a id="enum-parameters" />

## Parameters

**enum**

- `values`: Values — An array of possible values.
