title: define Method - DML Reference

This method defines a data model.

## Example

```ts
import { model } from "@medusajs/framework/utils"

const MyCustom = model.define("my_custom", {
  id: model.id(),
  name: model.text(),
})

export default MyCustom
```

<a id="define-type-parameters" />

## Type Parameters

**define**

- `Schema`: [DMLSchema](/resources/references/types/DmlTypes/types/typesDmlTypesDMLSchema) (optional) — The type of the accepted schema in the second parameter of the method.
  - `$dataType`: T
  - `type`: [RelationshipTypes](/resources/references/types/DmlTypes/types/typesDmlTypesRelationshipTypes)
- `TConfig`: [IDmlEntityConfig](/resources/references/types/DmlTypes/types/typesDmlTypesIDmlEntityConfig) (optional)
  - `name`: `string` (optional)
  - `tableName`: `string`

<a id="define-parameters" />

## Parameters

**define**

- `nameOrConfig`: TConfig — Either the data model's name, or configurations to name the data model. The data model's name must be unique.
- `schema`: Schema — The schema of the data model's properties.
