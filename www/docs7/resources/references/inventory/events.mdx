This reference shows all the events emitted by the Medusa application related to the Inventory Module. If you use the module outside the Medusa application, these events aren't emitted.

## Inventory Item Events

### Summary

| Event                                                                                    | Description                               |
| ---------------------------------------------------------------------------------------- | ----------------------------------------- |
| [`inventory-item.created`](/resources/references/inventory/events#inventory-itemcreated) | Emitted when inventory items are created. |
| [`inventory-item.updated`](/resources/references/inventory/events#inventory-itemupdated) | Emitted when inventory items are updated. |
| [`inventory-item.deleted`](/resources/references/inventory/events#inventory-itemdeleted) | Emitted when inventory items are deleted. |

### inventory-item.created

Emitted when inventory items are created.

#### Payload

```ts
{
  id, // The ID of the inventory item
}
```

#### Workflows Emitting this Event

- [createInventoryItemsWorkflow](/resources/references/medusa-workflows/createInventoryItemsWorkflow)
- [createProductVariantsWorkflow](/resources/references/medusa-workflows/createProductVariantsWorkflow)
- [createProductsWorkflow](/resources/references/medusa-workflows/createProductsWorkflow)
- [batchProductVariantsWorkflow](/resources/references/medusa-workflows/batchProductVariantsWorkflow)
- [batchProductsWorkflow](/resources/references/medusa-workflows/batchProductsWorkflow)
- [importProductsWorkflow](/resources/references/medusa-workflows/importProductsWorkflow)

### inventory-item.updated

Emitted when inventory items are updated.

#### Payload

```ts
{
  id, // The ID of the inventory item
}
```

#### Workflows Emitting this Event

- [updateInventoryItemsWorkflow](/resources/references/medusa-workflows/updateInventoryItemsWorkflow)

### inventory-item.deleted

Emitted when inventory items are deleted.

#### Payload

```ts
{
  id, // The ID of the inventory item
}
```

#### Workflows Emitting this Event

- [deleteInventoryItemWorkflow](/resources/references/medusa-workflows/deleteInventoryItemWorkflow)

## Inventory Level Events

### inventory-level.updated

Emitted when inventory levels are updated. This includes adjustments to
the stocked or reserved quantity, such as during order fulfillment.

#### Payload

```ts
{
  id, // The ID of the inventory level
  order_id, // (optional) The ID of the order, if the update was triggered by an order flow
}
```

#### Workflows Emitting this Event

- [createOrderFulfillmentWorkflow](/resources/references/medusa-workflows/createOrderFulfillmentWorkflow)
- [cancelOrderFulfillmentWorkflow](/resources/references/medusa-workflows/cancelOrderFulfillmentWorkflow)
