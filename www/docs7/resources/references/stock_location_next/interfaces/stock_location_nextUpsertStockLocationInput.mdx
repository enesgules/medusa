---
title: UpsertStockLocationInput
---

A stock location to create or update. If the `id` property isn't provided,
the stock location is created. In that case, the `name` property is required.

**UpsertStockLocationInput**

- `name`: `string` (optional) — The name of the stock location.
- `address_id`: `null` | `string` (optional) — The associated address's ID.
- `address`: [StockLocationAddressInput](/resources/references/stock_location_next/types/stock_location_nextStockLocationAddressInput) (optional) — The associated address's details.
  - `address_1`: `string` — The first line of the stock location address.
  - `address_2`: `string` | `null` (optional) — The second line of the stock location address.
  - `country_code`: `string` — The country code of the stock location address.
  - `city`: `string` | `null` (optional) — The city of the stock location address.
  - `phone`: `string` | `null` (optional) — The phone of the stock location address.
  - `province`: `string` | `null` (optional) — The lower-case [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) province of the stock location address.
  - `postal_code`: `string` | `null` (optional) — The postal code of the stock location address.
  - `metadata`: [MetadataType](/resources/references/stock_location_next/types/stock_location_nextMetadataType) (optional) — Holds custom data in key-value pairs.
- `metadata`: [MetadataType](/resources/references/stock_location_next/types/stock_location_nextMetadataType) (optional) — Holds custom data in key-value pairs.
- `id`: `string` (optional) — The ID of the stock location, if updating.
