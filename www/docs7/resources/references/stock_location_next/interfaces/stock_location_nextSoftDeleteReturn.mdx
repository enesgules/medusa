---
title: SoftDeleteReturn
---

An object that is used to specify an entity's related entities that should be soft-deleted when the main entity is soft-deleted.

## Type parameters

**SoftDeleteReturn**

- `TReturnableLinkableKeys`: `object` (optional)

**SoftDeleteReturn**

- `returnLinkableKeys`: TReturnableLinkableKeys\[] (optional) — An array of strings, each being the ID attribute names of the entity's relations.
