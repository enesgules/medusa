---
title: CrossModuleJoinTarget
---

Describes an external table that can be filtered or sorted against.

- `CrossModuleJoinTarget`: `object` — Describes an external table that can be filtered or sorted against.
  - `schema`: `string` (optional) — PostgreSQL schema for the target table. Defaults to `public`.
  - `table`: `string` — Target table name.
  - `primaryKey`: `string` (optional) — Primary key column on the target table. Defaults to `id`.
  - `filters`: [FilterQuery](/resources/references/stock_location_next/types/stock_location_nextFilterQuery)\<any> (optional) — Filters applied to the target table.
