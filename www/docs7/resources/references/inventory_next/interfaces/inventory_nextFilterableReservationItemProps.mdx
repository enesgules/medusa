title: FilterableReservationItemProps
---

The filters to apply on retrieved reservation items.

**FilterableReservationItemProps**

- `id`: `string` | `string`\[] (optional) — The IDs to filter reservation items by.
- `type`: `string` | `string`\[] (optional)
- `line_item_id`: `string` | `string`\[] (optional) — Filter reservation items by the ID of their associated line item.
- `inventory_item_id`: `string` | `string`\[] (optional) — Filter reservation items by the ID of their associated inventory item.
- `location_id`: `string` | `string`\[] (optional) — Filter reservation items by the ID of their associated location.
- `description`: `string` | [StringComparisonOperator](/resources/references/inventory_next/interfaces/inventory_nextStringComparisonOperator) (optional) — Description filters to apply on the reservation items' `description` attribute.
  - `lt`: `string` (optional) — The filtered string must be less than this value.
  - `gt`: `string` (optional) — The filtered string must be greater than this value.
  - `gte`: `string` (optional) — The filtered string must be greater than or equal to this value.
  - `lte`: `string` (optional) — The filtered string must be less than or equal to this value.
  - `contains`: `string` (optional) — The filtered string must contain this value.
  - `starts_with`: `string` (optional) — The filtered string must start with this value.
  - `ends_with`: `string` (optional) — The filtered string must end with this value.
- `created_by`: `string` | `string`\[] (optional) — The "created by" values to filter reservation items by.
- `quantity`: `number` | [NumericalComparisonOperator](/resources/references/inventory_next/interfaces/inventory_nextNumericalComparisonOperator) (optional) — Filters to apply on the reservation items' `quantity` attribute.
  - `lt`: `number` (optional) — The filtered number must be less than this value.
  - `gt`: `number` (optional) — The filtered number must be greater than this value.
  - `gte`: `number` (optional) — The filtered number must be greater than or equal to this value.
  - `lte`: `number` (optional) — The filtered number must be less than or equal to this value.
