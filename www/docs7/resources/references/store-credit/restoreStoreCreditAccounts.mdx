This documentation provides a reference to the `restoreStoreCreditAccounts` method. This belongs to the Store Credit Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method restores soft-deleted store credit accounts by their IDs.

## Example

```ts
await storeCreditModuleService.restoreStoreCreditAccounts(["sca_123"])
```
