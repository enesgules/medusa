This documentation provides a reference to the `retrieveAccountStats` method. This belongs to the Store Credit Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves the balance statistics for a store credit account.

## Example

```ts
const stats = await storeCreditModuleService.retrieveAccountStats({
  account_id: "sca_123",
})
```

## Returns

**retrieveAccountStats**

- `Promise`: Promise\<[ModuleAccountStats](/resources/references/store_credit/types/store_creditModuleAccountStats)> — The account statistics including balance, credits, and debits.
  - `id`: `string` — The store credit account's ID.
  - `balance`: [BigNumberValue](/resources/references/store_credit/types/store_creditBigNumberValue) — The current balance of the account (credits minus debits).
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/store_credit/types/store_creditBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `credits`: [BigNumberValue](/resources/references/store_credit/types/store_creditBigNumberValue) — The total amount credited to the account.
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/store_credit/types/store_creditBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
  - `debits`: [BigNumberValue](/resources/references/store_credit/types/store_creditBigNumberValue) — The total amount debited from the account.
    - `numeric`: `number`
    - `raw`: [BigNumberRawValue](/resources/references/store_credit/types/store_creditBigNumberRawValue) (optional)
    - `bigNumber`: `BigNumber` (optional)
