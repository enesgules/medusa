This reference shows all the events emitted by the Medusa application related to the Customer Module. If you use the module outside the Medusa application, these events aren't emitted.

### Summary

| Event                                                                       | Description                         |
| --------------------------------------------------------------------------- | ----------------------------------- |
| [`customer.created`](/resources/references/customer/events#customercreated) | Emitted when a customer is created. |
| [`customer.updated`](/resources/references/customer/events#customerupdated) | Emitted when a customer is updated. |
| [`customer.deleted`](/resources/references/customer/events#customerdeleted) | Emitted when a customer is deleted. |

### customer.created

Emitted when a customer is created.

#### Payload

```ts
{
  id, // The ID of the customer
}
```

#### Workflows Emitting this Event

- [createCustomersWorkflow](/resources/references/medusa-workflows/createCustomersWorkflow)
- [createCustomerAccountWorkflow](/resources/references/medusa-workflows/createCustomerAccountWorkflow)

### customer.updated

Emitted when a customer is updated.

#### Payload

```ts
{
  id, // The ID of the customer
}
```

#### Workflows Emitting this Event

- [updateCustomersWorkflow](/resources/references/medusa-workflows/updateCustomersWorkflow)

### customer.deleted

Emitted when a customer is deleted.

#### Payload

```ts
{
  id, // The ID of the customer
}
```

#### Workflows Emitting this Event

- [deleteCustomersWorkflow](/resources/references/medusa-workflows/deleteCustomersWorkflow)
- [removeCustomerAccountWorkflow](/resources/references/medusa-workflows/removeCustomerAccountWorkflow)
