This documentation provides a reference to the `retrieveCustomerGroup` method. This belongs to the Customer Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method retrieves a customer group by its ID.

## Example

```ts
const customerGroup =
  await customerModuleService.retrieveCustomerGroup("cusgroup_123")
```
