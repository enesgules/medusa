This documentation provides a reference to the `createCustomerAddresses` method. This belongs to the Customer Module.

> **Note**
>

## createCustomerAddresses(addresses, sharedContext?): Promise\<[CustomerAddressDTO](/resources/references/customer/interfaces/customerCustomerAddressDTO)\[]>

This method adds addresses to customers.

### Example

```ts
const addresses = await customerModuleService.createCustomerAddresses([
  {
    customer_id: "cus_123",
    address_name: "Home",
    address_1: "432 Stierlin Rd",
    city: "Mountain View",
    country_code: "us",
  },
])
```

  - `postal_code`: `null` | `string` (optional) — The postal code.
  - `phone`: `null` | `string` (optional) — The phone.
  - `metadata`: [MetadataType](/resources/references/customer/types/customerMetadataType) (optional) — Holds custom data in key-value pairs.
