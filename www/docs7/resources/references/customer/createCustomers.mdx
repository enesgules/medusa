## createCustomers(data, sharedContext?): Promise\<[CustomerDTO](/resources/references/customer/interfaces/customerCustomerDTO)\[]>

This method creates customers.

### Example

```ts
const customers = await customerModuleService.createCustomers([Customers
  {
    email: "john@smith.com",
    first_name: "John",
    last_name: "Smith",
  },
])
```
