This documentation provides a reference to the `deleteReservationItems` method. This belongs to the Inventory Next Module.

> **Note**
>
> You should only use this methods when implementing complex customizations. For common cases, check out [available workflows instead](/resources/medusa-workflows-reference).

This method deletes reservation items by their IDs.

## Example

```ts
await inventoryModuleService.deleteReservationItems(
  "resitem_123"
)
```
