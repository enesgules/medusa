title: Tools

In this section of the documentation, you'll find tools that are useful for your development as you build a commerce application with Medusa. You'll find CLI tools, SDKs, storefront starters, and more.

For each of these tools, you'll learn how to set them up and use them in your project.

## CLI Tools

CLI tools help you setup Medusa, manage the database, and more.

- [create-medusa-app](/resources/create-medusa-app)
- [Medusa CLI](/resources/medusa-cli/commands/new)

***

## Developer Tools

Developer tools facilitate the development of your Medusa application by providing utilities for linting and other uses.

- [ESLint Plugin](/resources/lint/rules)

***

## SDKs

SDKs help you build client applications, such as storefronts or admin dashboards, with Medusa. They're also useful when extending the Medusa Admin with widgets and UI routes.

- [JS SDK](/resources/js-sdk/auth/overview)

***

## Storefront Starters

A storefront starter is a storefront with the basic commerce features that you can use with your Medusa application. You can use it as-is or build on top of it. Learn more about building a storefront in the [Storefront Development](/resources/storefront-development) documentation.

- [Next.js Starter Storefront](/resources/nextjs-starter/guides/revalidate-cache)
