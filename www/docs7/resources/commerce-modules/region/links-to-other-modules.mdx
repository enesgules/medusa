## Cart Module

Medusa defines a read-only link between the [Cart Module](/resources/commerce-modules/cart)'s `Cart` data model and the `Region` data model. Because the link is read-only from the `Cart`'s side, you can only retrieve the region of a cart, and not the other way around.

### Retrieve with Query

To retrieve the region of a cart with [Query](/learn/fundamentals/module-links/query), pass `region.*` in `fields`:

<Tabs>
  <Tab title="query.graph">
    ```ts
    const { data: carts } = await query.graph({
      entity: "cart",
      fields: [
        "region.*",
      ],
    })

    // carts[0].region
    ```
  </Tab>

  <Tab title="useQueryGraphStep">
    ```ts
    import { useQueryGraphStep } from "@medusajs/medusa/core-flows"

    // ...

    const { data: carts } = useQueryGraphStep({
      entity: "cart",
      fields: [
        "region.*",
      ],
    })

    // carts[0].region
    ```
  </Tab>
</Tabs>

## Payment Module

You can specify for each region which payment providers are available for use.

Medusa defines a module link between the `PaymentProvider` and the `Region` data models.

![A diagram showcasing an example of how resources from the Payment and Region modules are linked](https://res.cloudinary.com/dza7lstvk/image/upload/v1711569520/Medusa%20Resources/payment-region_jyo2dz.jpg)

### Retrieve with Query

To retrieve the payment providers of a region with [Query](/learn/fundamentals/module-links/query), pass `payment_providers.*` in `fields`:

<Tabs>
  <Tab title="query.graph">
    ```ts
    const { data: regions } = await query.graph({
      entity: "region",
      fields: [
        "payment_providers.*",
      ],
    })

    // regions[0].payment_providers
    ```
  </Tab>

  <Tab title="useQueryGraphStep">
    ```ts
    import { useQueryGraphStep } from "@medusajs/medusa/core-flows"

    // ...

    const { data: regions } = useQueryGraphStep({
      entity: "region",
      fields: [
        "payment_providers.*",
      ],
    })

    // regions[0].payment_providers
    ```
  </Tab>
</Tabs>

### Manage with Link

To manage the payment providers in a region, use [Link](/learn/fundamentals/module-links/link):

<Tabs>
  <Tab title="link.create">
    ```ts
    import { Modules } from "@medusajs/framework/utils"

    // ...

    await link.create({
      [Modules.REGION]: {
        region_id: "reg_123",
      },
      [Modules.PAYMENT]: {
        payment_provider_id: "pp_stripe_stripe",
      },
    })
    ```
  </Tab>

  <Tab title="createRemoteLinkStep">
    ```ts
    import { Modules } from "@medusajs/framework/utils"
    import { createRemoteLinkStep } from "@medusajs/medusa/core-flows"

    // ...

    createRemoteLinkStep({
      [Modules.REGION]: {
        region_id: "reg_123",
      },
      [Modules.PAYMENT]: {
        payment_provider_id: "pp_stripe_stripe",
      },
    })
    ```
  </Tab>
</Tabs>
