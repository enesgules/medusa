---
title: Auth JS SDK Methods
---

The [JS SDK](/resources/js-sdk) allows you to send requests to the Medusa server application from your client applications, such as a storefront or the Medusa Admin dashboard.

Use the following methods or properties to send requests to authentication related API routes in your Medusa application. They are provided by the `@medusajs/js-sdk` package.

The following links will take you to the reference documentation for the [JS SDK](/resources/js-sdk).

- [callback](/resources/references/js-sdk/auth/callback)
- [createUser](/resources/references/js-sdk/auth/createUser)
- [listProviders](/resources/references/js-sdk/auth/listProviders)
- [login](/resources/references/js-sdk/auth/login)
- [logout](/resources/references/js-sdk/auth/logout)
- [refresh](/resources/references/js-sdk/auth/refresh)
- [register](/resources/references/js-sdk/auth/register)
- [resetPassword](/resources/references/js-sdk/auth/resetPassword)
- [updateProvider](/resources/references/js-sdk/auth/updateProvider)
