In this guide, you'll learn about the options you can pass to the Loyalty Plugin.

## Options Example

```js title="medusa-config.js"
module.exports = defineConfig({
  // ...
  plugins: [
    {
      resolve: "@medusajs/loyalty-plugin",
      options: {
        prefix: "GC",
        sections: 3,
      },
    },
  ],
})
```
