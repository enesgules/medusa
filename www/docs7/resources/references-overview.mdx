title: References
---

This section of the documentation holds references related to the Medusa server and admin. These references are useful for your development and customizations. You can find lists of emitted events, Medusa Admin widget injection zones, built-in workflows to use in your customizations, and more.

- [Admin Widget Injection Zones](/resources/admin-widget-injection-zones): List of injection zones you can add widgets in.
- [Container Resources](/resources/medusa-container-resources): Resources you can access through the Medusa and Module containers.
- [Core Workflows](/resources/references/medusa-workflows/createApiKeysWorkflow): Built-in workflows and steps you can use in your customizations.
- [Data Model Language](/resources/references/data-model/define): API reference of the Data Model Langauge (DML).
- [Data Model Repository](/resources/data-model-repository-reference/methods/create): List of methods in your service extending the data model repository.
- [Events](/resources/references/events): List of events emitted by Medusa's Commerce Modules.
- [Helper Steps](/resources/references/helper-steps/createEntitiesStep): Steps to query data, emit events, create links, and more.
- [Service Factory](/resources/service-factory-reference/methods/create): List of methods in your service extending the service factory.
- [Testing Framework](/resources/test-tools-reference/medusaIntegrationTestRunner): API reference of functions you can use to write tests.
- [Workflows SDK](/resources/references/workflows/applyStep): API reference of the Workflow SDK functions and helpers.
