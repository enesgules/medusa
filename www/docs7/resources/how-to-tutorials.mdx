title: How-to & Tutorials
---

In this section of the documentation, you'll find how-to guides and tutorials that will help you customize the Medusa server and admin. These guides are useful after you've learned Medusa's main concepts in the [Get Started](/learn) section of the documentation.

You can follow these guides to learn how to customize the Medusa server and admin to fit your business requirements. This section of the documentation also includes deployment guides to help you deploy your Medusa server and admin to different platforms.

## Example Snippets

For a quick access to code snippets of the different concepts you learned about, such as API routes and workflows, refer to the [Examples Snippets](/resources/examples) documentation.

## Tutorials

Tutorials are step-by-step guides that take you through implementing a specific use case in Medusa. You can follow these guides whether you're a beginner or an experienced Medusa developer.

While tutorials show you a specific use case, they also help you understand how to implement similar use cases in your own projects. Also, you can implement the use case in a tutorial differently to fit your business requirements.

- [Abandoned Cart](/resources/how-to-tutorials/tutorials/abandoned-cart): Learn how to send abandoned cart notifications to customers.
- [Add Gift Message](/resources/how-to-tutorials/tutorials/gift-message): Learn how to add a gift option and message to items in the cart.
- [Add Product Category Images](/resources/how-to-tutorials/tutorials/category-images): Learn how to add images to product categories in Medusa.
- [Agentic Commerce](/resources/how-to-tutorials/tutorials/agentic-commerce): Learn how to build Agentic Commerce with Medusa to support purchase with AI agents like ChatGPT.
- [Analytics with Segment](/resources/integrations/guides/segment): Learn how to integrate Segment with Medusa to track user interactions and events.
- [Bundled Products](/resources/recipes/bundled-products/examples/standard): Learn how to implement bundled products in your Medusa store.
- [Custom Item Pricing](/resources/examples/guides/custom-item-price): Learn how to use prices from external systems for products.
- [Customer Tiers](/resources/how-to-tutorials/tutorials/customer-tiers): Learn how to implement customer tiers in your Medusa store.
- [First-Purchase Discounts](/resources/how-to-tutorials/tutorials/first-purchase-discounts): Learn how to implement first-purchase discounts in your Medusa store.
- [Generate Invoices](/resources/how-to-tutorials/tutorials/invoice-generator): Learn how to generate invoices for orders in your Medusa store.
- [Integrate Payload CMS](/resources/integrations/guides/payload): Learn how to integrate Payload CMS with Medusa to manage your product content.
- [Localization with Contentful](/resources/integrations/guides/contentful): Learn how to implement localization in Medusa by integrating Contentful.
- [Loyalty Points System](/resources/how-to-tutorials/tutorials/loyalty-points): Learn how to implement a loyalty points system in your Medusa store.
- [Magento Migration](/resources/integrations/guides/magento): Learn how to migrate data from Magento to Medusa.
- [Meta Product Feed](/resources/how-to-tutorials/tutorials/product-feed): Learn how to implement a product feed for Meta (Facebook and Instagram) and Google using Medusa.
- [Newsletter with Mailchimp](/resources/integrations/guides/mailchimp): Learn how to integrate Mailchimp with Medusa to manage and automate newsletters.
- [Personalized Products](/resources/recipes/personalized-products/example): Learn how to implement personalized products in your Medusa store.
- [Phone Authentication](/resources/how-to-tutorials/tutorials/phone-auth): Learn how to allow users to authenticate using their phone numbers.
- [Pre-Order Products](/resources/how-to-tutorials/tutorials/preorder): Learn how to implement pre-order functionality for products in your Medusa store.
- [Product Builder](/resources/how-to-tutorials/tutorials/product-builder): Learn how to implement a product builder that allows customers to customize products before adding them to the cart.
- [Product Rentals](/resources/how-to-tutorials/tutorials/product-rentals): Learn how to implement product rentals in your Medusa store.
- [Product Reviews](/resources/how-to-tutorials/tutorials/product-reviews): Learn how to implement product reviews in your Medusa store.
- [Quote Management](/resources/examples/guides/quote-management): Learn how to implement quote management, useful for B2B use cases.
- [Re-Order](/resources/how-to-tutorials/tutorials/re-order): Learn how to allow customers to re-order previous orders.
- [Saved Payment Methods](/resources/how-to-tutorials/tutorials/saved-payment-methods): Learn how to implement saved payment methods in your Medusa store.
- [Wishlist Plugin](/resources/plugins/guides/wishlist): Learn how to build a plugin for wishlist functionalities.
