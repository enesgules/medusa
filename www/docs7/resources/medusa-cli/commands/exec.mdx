Run a custom CLI script using Medusa's CLI tool. Learn more about it in [Custom CLI Scripts guide](/learn/fundamentals/custom-cli-scripts).

```bash
npx medusa exec [file] [args...]
```

## Arguments

<table>
  <thead>
    <tr>
      <th>
        Argument
      </th>

      <th>
        Description
      </th>

      <th>
        Required
      </th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>
        `file`
      </td>

      <td>
        The path to the TypeScript or JavaScript file containing the function to execute.
      </td>

      <td>
        Yes
      </td>
    </tr>

    <tr>
      <td>
        `args`
      </td>

      <td>
        A list of arguments to pass to the function. These arguments are passed in the `args` property of the function's object parameter.
      </td>

      <td>
        No
      </td>
    </tr>
  </tbody>
</table>
